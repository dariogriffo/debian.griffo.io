What is delta?

delta is a syntax-highlighting pager for git, diff, grep and blame output. Set it as git's pager once and every git diff, git show, git log -p, git blame and git add -p comes out with the code highlighted the way your editor shows it, the changed words marked inside each changed line, optional side-by-side columns and line numbers, and file headers you can jump between with n and N. It also reads any unified diff, compares two files directly and highlights ripgrep's JSON output. It is written in Rust by Dan Davison, uses the same syntax definitions and colour themes as bat, is configured from your ~/.gitconfig, and is MIT licensed. The package is called git-delta; the command it installs is delta.

🚀 Why Latest Versions Matter: delta ships a few releases a year, with new options, better side-by-side wrapping and fixes for the many ways git, terminals and pagers interact. Debian trixie is frozen at 0.18.2 and Bookworm has no git-delta at all, so options from the current manual may simply not exist in your copy. This repository uses the same package name, git-delta, so apt install git-delta and apt upgrade give you the current release instead of the archive's.

⚡ Key Features of delta

🎨 Syntax Highlighting

Code inside a diff is highlighted the way your editor shows it, with the syntax definitions and colour themes bat uses. Pick one with syntax-theme, or let delta follow the terminal's light or dark background.

🔍 Word-Level Changes

Inside each changed line delta marks the exact words that differ, so a renamed variable or a flipped condition stands out instead of hiding in two nearly identical red and green lines.

↔️ Side-by-Side View

side-by-side = true puts the old and new versions in two columns with line numbers, wrapping long lines instead of cutting them off. Try it for one command with git -c delta.side-by-side=true diff.

🧭 Navigation and Links

With navigate = true, n and N jump from file to file through a long git log -p. With hyperlinks = true, file paths and commit hashes become clickable in terminals that support it.

🧩 Blame, Grep and Conflicts

git blame gets highlighted code with the commit details grouped, git grep and rg --json results are highlighted and grouped by file, and conflicted files during a merge are shown as readable diffs.

⚙️ Lives in ~/.gitconfig

Every option sits in a [delta] section of your git config, and named feature sets switch a whole look at once. The package ships upstream's themes.gitconfig, a collection of ready-made themes.

🚀 Always ahead of the official archives: Debian and Ubuntu freeze package versions when a release ships. This repository publishes new upstream releases typically within hours. A simple apt upgrade keeps you on the latest version.

# Make delta git's pager: diff, show, log -p, blame and grep go through it
git config --global core.pager delta

# git add -p with the same highlighting
git config --global interactive.diffFilter 'delta --color-only'

# n and N jump between files
git config --global delta.navigate true

# Conflicts show the common ancestor too
git config --global merge.conflictStyle zdiff3

# Try it
git diff

🎯 Basic Usage Examples

Reading diffs:

# Side by side, for one command
git -c delta.side-by-side=true diff

# Or always, with line numbers
git config --global delta.side-by-side true
git config --global delta.line-numbers true

# Walk through history; n and N jump between files
git log -p

# Stage hunks with highlighting
git add -p

Beyond git diff:

# Compare two files directly
delta old.conf new.conf

# Any unified diff
diff -u a.txt b.txt | delta

# ripgrep matches, highlighted and grouped by file
rg --json -C 2 'TODO' | delta

# git blame and git grep go through delta too
git blame src/main.rs
git grep -n 'TODO'

Themes and configuration:

# Preview every syntax theme on a real diff
git show | delta --show-syntax-themes

# Load the delta themes the package ships and preview them
git config --global --add include.path /etc/delta/themes.gitconfig
git show | delta --show-themes

# Use one of them
git config --global delta.features mellow-barbet

# The configuration delta actually ends up with
delta --show-config

🔧 Tool Integrations

delta is a filter between git and your pager, so most of the integration happens in your git config and your terminal:

  • git: core.pager delta covers diff, show, log -p, stash show -p, blame and grep; interactive.diffFilter needs --color-only, because git expects one line back for every line of the hunk
  • less: delta pages its output through less, which the package recommends; without it delta prints straight to the terminal. DELTA_PAGER or delta.pager picks another pager, and --paging=never turns paging off
  • lazygit: lazygit can render its diffs through delta; point its pager setting at delta --dark --paging=never
  • difftastic: the two complement each other: delta as git's pager for everyday diffs, difftastic through git difftool when you want a diff by syntax tree
  • ripgrep: rg --json piped into delta gives highlighted, file-grouped search results in the same theme as your diffs
  • Your terminal: delta works out whether the background is light or dark, and delta.dark or delta.light fixes a wrong guess; kitty and Ghostty open the links hyperlinks = true produces
  • Your shell: bash, zsh and fish completions for delta come with the package

❓ Frequently asked questions

Is delta in the official Debian repositories?

Yes, but the official Debian archive ships delta 0.18.2, while this repository serves delta 0.22.0, rebuilt within hours of each upstream release.

How do I install the latest delta on Debian?

Add the deb.griffo.io repository once using the instructions above, then run: sudo apt install git-delta. New releases arrive through the normal sudo apt upgrade.

Are the packages signed and how are they built?

Every package is signed with the repository's GPG key (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) and built from upstream releases in public GitHub packaging repositories that anyone can inspect.

Which Debian releases are supported?

Debian 12 Bookworm, Debian 13 Trixie, Forky and Sid.
