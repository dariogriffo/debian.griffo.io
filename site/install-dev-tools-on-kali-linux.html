Latest developer tools on Kali Linux

63 developer tools at their latest upstream versions, one apt command, GPG-signed

⚡ The short answer. Yes, deb.griffo.io works on Kali Linux. 63 developer tools install with plain apt on Kali Linux, with the same setup command as Debian and Ubuntu: it reads VERSION_CODENAME from /etc/os-release and asks for the matching suite, kali-rolling on Kali Linux.

Kali Linux is a rolling distribution built from Debian testing. Its own archive is focused on security tooling; general developer tools come from Debian at whatever version testing has. deb.griffo.io serves Kali its own kali-rolling suite, carrying the same packages as its Debian testing suite, so the tools below install with plain apt.

Kali sets VERSION_CODENAME=kali-rolling, and this repository has a kali-rolling suite, so the setup command works as it is. It is built from the Debian testing (forky) packages and published with them, so Kali never waits on a separate build.

Kali is served by the subscription repository only: the free mirror has no kali-rolling suite.

❓ Common questions

Why is there no free mirror for Kali?

The free mirror carries the Debian and Ubuntu release suites only. The kali-rolling suite is part of the subscription repository, which also includes the free trial.

Does adding it interfere with Kali's own tools?

No. The packages here are general developer tools under their own names, versioned with a ~griffo suffix so that an official package of the same version always wins, and Kali's security tooling comes from its own archive as before.

Is deb.griffo.io an official Kali Linux repository?

No. It is an unofficial repository maintained by Dario Griffo, not affiliated with Kali Linux. Every package is built automatically from the official upstream release, the packaging is open source on GitHub, and the archive is GPG-signed.

Does it cost anything?

The repository is a subscription (€15 a year or €150 once) with a free trial.

How do I remove the repository?

Delete /etc/apt/sources.list.d/deb.griffo.io.list and /etc/apt/keyrings/deb.griffo.io.gpg, then run sudo apt update. Tools you installed stay until you apt remove them.
