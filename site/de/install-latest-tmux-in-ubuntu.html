Was ist tmux?

tmux ist der Terminal-Multiplexer: Er führt viele Shells in einem einzigen Terminal aus, aufgeteilt in Fenster und Panes, und lässt sie weiterlaufen, wenn du die Verbindung trennst. Eine tmux-Sitzung lebt in einem Serverprozess, nicht in deinem Terminalfenster, du kannst dich also von ihr abkoppeln (detach), das Fenster schließen oder die ssh-Verbindung verlieren und dich später wieder anhängen, mit jedem Programm noch genau dort, wo du es verlassen hast. Innerhalb einer Sitzung öffnest du Fenster wie Tabs, teilst jedes in Panes nebeneinander oder übereinander, scrollst mit der Tastatur zurück und kopierst Text, und steuerst das alles aus einer Konfigurationsdatei oder aus Skripten. tmux ist in C geschrieben, wurde von Nicholas Marriott begonnen und steht unter der ISC-Lizenz.

🚀 Warum die neueste Version zählt: tmux erweitert laufend, was ein Terminal kann: tmux 3.8 brachte schwebende und modale Panes, und jedes Release bringt neue Optionen und korrigiert den Umgang mit dem Terminal. Ubuntu 26.04 liefert tmux 3.6a und Noble 3.4, jeweils für die Lebensdauer des Release eingefroren, ein frisches System verpasst also alles, was seitdem erschienen ist. Dieses Repository liefert tmux 3.8 unter demselben Paketnamen, es ersetzt das tmux der Distribution also beim nächsten apt upgrade an Ort und Stelle.

⚡ Hauptfunktionen von tmux

🔌 Abkoppeln und wieder anhängen

Starte einen langen Build oder einen Serverprozess in tmux, koppel dich ab, melde dich ab oder verliere das Netz, und häng dich von überall wieder an: Die Sitzung und alles darin lief weiter, während du weg warst.

🪟 Fenster und Panes

Jede Sitzung enthält Fenster wie Tabs, und jedes Fenster teilt sich in Panes, sodass sich ein Editor, eine Shell und ein mitlaufendes Log einen Bildschirm teilen. Panes lassen sich mit ein paar Tasten in der Größe ändern, auf volle Größe zoomen und neu anordnen.

🎈 Schwebende und modale Panes

tmux 3.8 bringt schwebende Panes, die über dem Layout liegen, und modale Panes, die das Fenster übernehmen, bis du sie schließt, für einen schnellen Befehl oder eine Auswahl, ohne deine Aufteilung zu stören.

📋 Kopiermodus und Zwischenablage

Scroll durch den Verlauf eines Panes zurück, durchsuche ihn und markiere Text mit vi- oder emacs-Tasten. Kopierter Text landet über OSC 52 in der Zwischenablage deines Desktops, selbst aus einem tmux auf einem entfernten Server.

🖼️ Bilder im Terminal

Dieser Build hat Sixel-Unterstützung aktiviert, Programme, die Sixel-Bilder zeichnen, zeigen sie also in einem tmux-Pane an, wenn dein Terminal Sixel ebenfalls unterstützt.

🧰 Skriptbar und konfigurierbar

Jede Aktion ist ein Befehl: Leg sie in ~/.tmux.conf auf eine Taste oder führe sie aus einem Shell-Skript aus, um ein ganzes Sitzungslayout in einem Rutsch aufzubauen. Plugin-Manager und Sitzungswerkzeuge bauen genau darauf auf.

🚀 Immer vor den offiziellen Archiven: Debian und Ubuntu frieren Paketversionen beim Release ein. Dieses Repository veröffentlicht neue Upstream-Releases in der Regel innerhalb von Stunden. Ein einfaches apt upgrade hält dich auf der neuesten Version.

🎯 Grundlegende Verwendungsbeispiele

Sitzungen, Fenster und Panes:

# Die laufenden Sitzungen auflisten
tmux ls

# In tmux ist das Präfix Ctrl-b, gefolgt von:
# c  neues Fenster          n / p   nächstes / vorheriges Fenster
# %  links/rechts teilen    "       oben/unten teilen
# Pfeiltasten  zwischen Panes wechseln   z  aktuelles Pane zoomen
# [  Kopiermodus, zum Zurückscrollen und Markieren von Text
# d  abkoppeln

Ein Layout per Skript:

# Eine abgekoppelte Sitzung mit einem Editor links und einer Shell rechts
tmux new-session -d -s dev -n code
tmux split-window -h -t dev:code
tmux send-keys -t dev:code.0 'nvim' Enter
tmux attach -t dev

# Die Konfiguration neu laden, ohne etwas neu zu starten
tmux source-file ~/.tmux.conf

🔧 Werkzeug-Integrationen

Weil das Paket tmux heißt, funktioniert nach dem Upgrade alles weiter, was auf tmux aufbaut:

  • ssh: lass tmux auf dem Server laufen, nicht auf deinem Laptop, dann koppelt dich eine abgebrochene Verbindung nur ab; ssh -t host tmux attach holt die Sitzung zurück
  • Plugins: tmux-plugin-manager (tpm) und die Plugins, die er installiert, laden genau wie vorher aus ~/.tmux.conf
  • Sitzungswerkzeuge: tmuxinator und byobu steuern den Befehl tmux, sie bekommen die neue Version also, ohne dass etwas neu konfiguriert werden muss
  • Zwischenablage: mit OSC 52 landet im Kopiermodus kopierter Text in der Zwischenablage des Terminals, vor dem du sitzt, auch über ssh
  • Terminal-Funktionen: ncurses 6.6 ist statisch gelinkt, Zwischenablage, Cursorfarbe und -form sowie gestylte Unterstreichungen verhalten sich also auf jeder unterstützten Version gleich
  • systemd: mit systemd-Unterstützung gebaut, wie das eigene Paket der Distribution, und seine Sockets in /tmp sind auf dieselbe Weise vor der Bereinigung durch systemd-tmpfiles geschützt
  • Dokumentation: das tmux-Wiki unter github.com/tmux/tmux/wiki deckt den Einstieg, die FAQ und jede Option ab

❓ Häufig gestellte Fragen

Ist tmux in den offiziellen Ubuntu-Paketquellen?

Ja, aber das offizielle Ubuntu-Archiv liefert tmux 3.6a, während dieses Repository tmux 3.8 bereitstellt, wenige Stunden nach jedem Upstream-Release neu gebaut.

Wie installiere ich das neueste tmux unter Ubuntu?

Fügen Sie das deb.griffo.io-Repository einmalig hinzu (Anleitung oben) und führen Sie dann aus: sudo apt install tmux. Neue Releases kommen über das normale sudo apt upgrade.

Sind die Pakete signiert und wie werden sie gebaut?

Jedes Paket ist mit dem GPG-Schlüssel des Repositories (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) signiert und wird aus Upstream-Releases in öffentlichen GitHub-Repositories gebaut, die jeder einsehen kann.

Welche Ubuntu-Versionen werden unterstützt?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing, 26.04 Resolute und 26.10 Stonking.
