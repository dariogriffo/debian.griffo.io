Was ist yt-dlp?

yt-dlp ist ein Kommandozeilen-Downloader für Audio und Video, der weit über tausend Seiten unterstützt. Es begann als Fork von youtube-dl (über das inzwischen inaktive youtube-dlc) und ist seitdem das aktiv gepflegte Projekt der beiden — mit einer weitaus mächtigeren Formatauswahl, SponsorBlock-Integration, nativer Unterstützung zum Einbetten von Untertiteln, Kapiteln und Metadaten sowie einem Plugin-System für eigene Extraktoren.

🚀 Warum neueste Versionen wichtig sind: mehr als bei jedem anderen Tool in diesem Repository. yt-dlp spricht mit Seiten, die ihre Player und APIs ohne Vorwarnung ändern, und die Korrektur kommt als neues yt-dlp-Release — oft innerhalb weniger Tage. Einer eingefrorenen Archivversion fehlen nicht nur Funktionen: Ihre Extraktoren hören auf zu funktionieren, und Downloads scheitern an Signatur- oder Formatfehlern, bis du aktualisierst. Die aktuelle Version zu fahren ist genau der Punkt.

⚡ Hauptfunktionen von yt-dlp

🌐 Tausende von Seiten

Über 1.700 Extraktoren für Videoplattformen, Sender, Podcast-Hoster und Nachrichtenseiten, dazu ein generischer Extraktor, der Medien auch auf Seiten findet, für die niemand einen Extraktor geschrieben hat.

🎚️ Präzise Formatauswahl

-f und -S bieten eine vollständige Ausdruckssprache über Auflösung, Codec, Bitrate und Container — du bekommst genau den Stream, den du willst, statt des Standards.

🎧 Audio extrahieren

-x --audio-format mp3 zieht die Tonspur heraus und kodiert sie neu; mit --embed-thumbnail und --embed-metadata entstehen getaggte Dateien, die jeder Musikplayer versteht.

💬 Untertitel & Kapitel

Untertitel in jeder verfügbaren Sprache herunterladen oder einbetten, automatische Untertitel behalten und Kapitelmarken direkt in die Ausgabedatei schreiben — oder daran aufteilen.

⏭️ SponsorBlock

Sponsorensegmente, Intros und Eigenwerbung schon beim Herunterladen markieren oder entfernen, dank der SponsorBlock-Datenbank — ganz ohne nachträglichen Schnitt.

🍪 Cookies & Sitzungen

--cookies-from-browser liest eine angemeldete Sitzung direkt aus Firefox oder Chromium, damit private, altersbeschränkte und mitgliederexklusive Inhalte funktionieren.

🚀 Immer den offiziellen Archiven voraus: Debian und Ubuntu frieren Paketversionen zum Release-Zeitpunkt ein — dieses Repository veröffentlicht neue Upstream-Releases in der Regel innerhalb weniger Stunden. Ein einfaches apt upgrade hält dich auf der neuesten Version.

🎯 Grundlegende Verwendungsbeispiele

Alltägliches Herunterladen:

# Ein Video in der besten verfügbaren Qualität herunterladen
yt-dlp 'https://example.com/watch?v=...'

# Bestes MP4 bis 1080p
yt-dlp -S 'res:1080,ext:mp4' 'URL'

# Nur Audio, als getaggtes MP3
yt-dlp -x --audio-format mp3 --embed-thumbnail --embed-metadata 'URL'

# Vor der Auswahl alle angebotenen Formate ansehen
yt-dlp -F 'URL'

Untertitel, Kapitel und Sponsoren:

# Englische Untertitel einbetten, inklusive automatischer Untertitel
yt-dlp --embed-subs --sub-langs en --write-auto-subs 'URL'

# Kapitelmarken in die Datei schreiben
yt-dlp --embed-chapters 'URL'

# Sponsorensegmente und Intros schon beim Herunterladen entfernen
yt-dlp --sponsorblock-remove sponsor,intro 'URL'

# Nur einen Abschnitt statt des ganzen Videos holen
yt-dlp --download-sections '*00:01:30-00:04:00' 'URL'

Playlists, Archive und Automatisierung:

# Eine ganze Playlist, in saubere Ordner pro Uploader
yt-dlp -o '%(uploader)s/%(title)s.%(ext)s' 'PLAYLIST_URL'

# Einen Kanal synchron halten, ohne Altes erneut zu laden
yt-dlp --download-archive seen.txt 'CHANNEL_URL'

# Private oder altersbeschränkte Inhalte über eine angemeldete Browser-Sitzung
yt-dlp --cookies-from-browser firefox 'URL'

# Schnellere Downloads über aria2c
yt-dlp --downloader aria2c --downloader-args aria2c:'-x 8 -s 8' 'URL'

🔧 Tool-Integrationen

yt-dlp ist das Download-Backend, das viele andere Programme erwarten:

  • ffmpeg: Zusammenführen, Remuxen, Audioextraktion und Einbetten rufen es auf
  • mpv: spielt eine URL direkt ab, indem es sie im Hintergrund an yt-dlp übergibt
  • aria2: optionaler externer Downloader für parallele, segmentierte Übertragungen
  • Medienserver: Bibliotheken von Jellyfin, Kodi und Navidrome werden häufig aus yt-dlp-Ausgabevorlagen befüllt
  • Konfigurationsdateien: lege deine üblichen Optionen in ~/.config/yt-dlp/config ab und tippe sie nie wieder

🚀 Warum deb.griffo.io?

📊 Repository-Vergleich:
  • Offizielles Ubuntu: verfügbar, aber eingefroren auf der Version, mit der das Release erschien — Monate an Extraktor-Korrekturen hinterher
  • pip / pipx: aktuell, aber außerhalb von apt, und PEP 668 macht ein systemweites pip install unter Ubuntu umständlich
  • deb.griffo.io: neueste Version mit automatischen Updates
  • ✅ Funktionierende Extraktoren: das neueste Release — genau das, woran Downloads gelingen oder scheitern
  • ✅ Keine manuelle Einrichtung: kein pip, kein virtualenv, kein Self-Update, das nach /usr/local/bin schreibt
  • ✅ Automatische Updates: Pakete werden innerhalb von Stunden nach Upstream-Releases aktualisiert
  • ✅ Vollständiges Paket: der offizielle Upstream-Build, die Handbuchseite yt-dlp.1 und Vervollständigungen für bash, zsh und fish
  • ✅ Jede Architektur: ausgeliefert als Architecture: all — amd64, arm64, armhf, riscv64 und der Rest installieren dasselbe Paket
  • ✅ Multi-Distribution: läuft auf Ubuntu 22.04, 24.04, 25.10 und 26.04
  • ✅ Einfache Wartung: Updates mit den üblichen apt-Befehlen

❓ Häufig gestellte Fragen

Ist yt-dlp in den offiziellen Ubuntu-Paketquellen?

Ja, aber das offizielle Ubuntu-Archiv liefert yt-dlp 2026.03.17, während dieses Repository yt-dlp 2026.08.19 bereitstellt, wenige Stunden nach jedem Upstream-Release neu gebaut.

Wie installiere ich das neueste yt-dlp unter Ubuntu?

Fügen Sie das deb.griffo.io-Repository einmalig hinzu (Anleitung oben) und führen Sie dann aus: sudo apt install yt-dlp. Neue Releases kommen über das normale sudo apt upgrade.

Sind die Pakete signiert und wie werden sie gebaut?

Jedes Paket ist mit dem GPG-Schlüssel des Repositories (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) signiert und wird aus Upstream-Releases in öffentlichen GitHub-Repositories gebaut, die jeder einsehen kann.
