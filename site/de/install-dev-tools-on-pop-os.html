Aktuelle Entwicklertools für Pop!_OS

61 Entwicklertools in der neuesten Upstream-Version, ein apt-Befehl, GPG-signiert

⚡ Die kurze Antwort. Ja, deb.griffo.io funktioniert unter Pop!_OS. 61 Entwicklertools lassen sich unter Pop!_OS 24.04 LTS und Pop!_OS 22.04 LTS mit ganz normalem apt installieren, mit demselben Einrichtungsbefehl wie unter Debian und Ubuntu: Er liest UBUNTU_CODENAME aus /etc/os-release und fragt nach der passenden Suite, unter Pop!_OS 24.04 LTS also nach noble.

Pop!_OS ist die auf Ubuntu LTS basierende Distribution von System76 und eine beliebte Wahl für Entwickler-Workstations. Ihr Archiv folgt dem darunterliegenden Ubuntu LTS, die mitgelieferten Entwicklertools stehen also auf dem Stand, den dieses Ubuntu-Release eingefroren hat. deb.griffo.io liefert von jedem Tool unten das aktuelle Upstream-Release, gebaut für dieselbe Ubuntu-Basis.

❓ Häufige Fragen

Kollidieren diese Pakete mit den COSMIC- oder System76-Repositories?

Nein. Es handelt sich um Entwicklertools, die weder System76 noch Ubuntu in aktuellen Versionen paketieren, und jedes Paket trägt das Versionssuffix ~griffo. Gibt es ein offizielles Paket in derselben Version, bevorzugt apt das offizielle.

Ist deb.griffo.io ein offizielles Repository von Pop!_OS?

Nein. Es ist ein inoffizielles Repository, das von Dario Griffo betreut wird und in keiner Verbindung zu Pop!_OS steht. Jedes Paket wird automatisch aus dem offiziellen Upstream-Release gebaut, die Paketierung ist Open Source auf GitHub, und das Archiv ist GPG-signiert.

Kostet das etwas?

Das Repository ist ein Abo (€15 pro Jahr oder einmalig €150) mit kostenloser Testphase. Ein kostenloser Mirror, deb-free.griffo.io, liefert eine kleinere Auswahl an Tools mit Verzögerung, mit derselben Einrichtung auf dieser Distribution.

Wie entferne ich das Repository wieder?

Löschen Sie /etc/apt/sources.list.d/deb.griffo.io.list und /etc/apt/keyrings/deb.griffo.io.gpg und führen Sie dann sudo apt update aus. Bereits installierte Tools bleiben, bis Sie sie mit apt remove entfernen.
