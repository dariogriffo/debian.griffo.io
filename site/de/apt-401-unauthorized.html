🔐 apt meldet 401 Unauthorized

Was es bedeutet, wenn die Meldung von deb.griffo.io kommt, und die drei Auswege

⚡ Die kurze Antwort. An Ihrem System ist nichts kaputt, und kein Paket wurde entfernt. Seit dem 1. Oktober 2026, 12:00 Uhr britischer Zeit, erfordert das Herunterladen von Paketen von deb.griffo.io ein Abonnement. apt update funktioniert weiterhin für alle; apt install und apt upgrade brauchen Zugangsdaten. Sie haben drei Auswege, alle unten beschrieben: Zugangsdaten hinterlegen, auf den immer kostenlosen Spiegel wechseln oder das .deb direkt von GitHub holen, was kostenlos ist und es immer bleiben wird.

Noch kein Abo, oder ist Ihre Testphase abgelaufen? In einer Minute haben Sie Zugang: Die 14-tägige kostenlose Testphase braucht nur eine E-Mail-Adresse, keine Karte. Danach kostet es €15 im Jahr oder einmalig €150 für immer. Ihre Zugangsdaten kommen per E-Mail; hinterlegen Sie sie wie in Schritt 1 gezeigt.

🔍 Der Fehler, den Sie sehen

E: Failed to fetch https://deb.griffo.io/apt/pool/main/g/ghostty/ghostty_1.3.1-5~trixie_amd64.deb  401  Unauthorized [IP: 2a01:… 443]
E: Unable to fetch some archives, maybe run apt-get update or try with --fix-missing?

apt-get update --fix-missing hilft hier nicht, denn es fehlt nichts: Der Server hat geantwortet, und die Antwort lautete „Sie sind nicht authentifiziert“. Manche apt-Versionen melden The repository … is not signed, aber nur, wenn der Schlüssel das Problem ist; ein bloßes 401 betrifft immer die Authentifizierung.

1. Sie haben ein Abonnement: Zugangsdaten hinterlegen

Zugangsdaten gehören nach /etc/apt/auth.conf.d/ und nie in die sources.list-Zeile, wo jeder Benutzer des Rechners sie lesen könnte und apt sie in Fehlermeldungen ausplaudern würde:

Befehle ausführen
sudo tee /etc/apt/auth.conf.d/deb.griffo.io.conf > /dev/null <<'EOF'
machine deb.griffo.io
login your-email@example.com
password your-subscription-password
EOF
sudo chmod 600 /etc/apt/auth.conf.d/deb.griffo.io.conf
sudo apt update
tee /etc/apt/auth.conf.d/deb.griffo.io.conf > /dev/null <<'EOF'
machine deb.griffo.io
login your-email@example.com
password your-subscription-password
EOF
chmod 600 /etc/apt/auth.conf.d/deb.griffo.io.conf
apt update

Danach funktioniert sudo apt install <package> genau wie zuvor. Kommt weiterhin 401, prüfen Sie der Reihe nach:

Noch kein Abo und Sie möchten wissen, worauf Sie sich einlassen? So funktioniert das Abonnement beschreibt den gesamten Ablauf: Zugangsdaten per E-Mail, unbegrenzt viele Rechner, Verlängerung, Kündigung und Erstattung.

  • Die machine-Zeile lautet deb.griffo.io: kein https://, kein Schrägstrich am Ende, kein /apt-Pfad.
  • Die Datei liegt in /etc/apt/auth.conf.d/ und ihr Name endet auf .conf. apt ignoriert jede andere Endung stillschweigend.
  • Die Datei gehört root und hat den Modus 600. apt verweigert Zugangsdaten, die andere Benutzer lesen können.
  • Keine überflüssigen Anführungszeichen um das Passwort und keine Leerzeichen am Ende.
  • Kommen Sie nicht weiter? Fragen Sie im Discord. Das ist der schnellste Weg zur Lösung.

2. Auf den immer kostenlosen Spiegel wechseln

deb-free.griffo.io braucht kein Konto und keine Zahlung, niemals. Er liefert die neueste Version, die mindestens zwei Monate alt ist, und veröffentlicht Sicherheits- und Patch-Korrekturen für diese Version sofort. Derzeit führt er cliamp, Ghostty, lazydocker, Oh My Posh, Uncloud und Zed; jedes andere Werkzeug kann auf Anfrage aufgenommen werden, also fragen Sie im Discord, wenn Sie eines brauchen.

Befehle ausführen
sudo rm -f /etc/apt/sources.list.d/deb.griffo.io.list
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb-free.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb-free.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb-free.griffo.io.gpg] https://deb-free.griffo.io/apt $(. /etc/os-release; echo ${DEBIAN_CODENAME:-${UBUNTU_CODENAME:-$VERSION_CODENAME}}) main" | sudo tee /etc/apt/sources.list.d/deb-free.griffo.io.list > /dev/null
sudo apt update
rm -f /etc/apt/sources.list.d/deb.griffo.io.list
install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb-free.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | gpg --dearmor --yes -o /etc/apt/keyrings/deb-free.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb-free.griffo.io.gpg] https://deb-free.griffo.io/apt $(. /etc/os-release; echo ${DEBIAN_CODENAME:-${UBUNTU_CODENAME:-$VERSION_CODENAME}}) main" | tee /etc/apt/sources.list.d/deb-free.griffo.io.list > /dev/null
apt update
sudo apt install extrepo
sudo extrepo enable griffo-free
sudo apt update

🧩 Zur extrepo-Option. extrepo ist Debians eigenes Werkzeug für externe Repositories: Es legt die Sources-Datei an und installiert den Signaturschlüssel für dich, nachdem es ihn gegen signierte Metadaten geprüft hat. Dieses Repository ist dort als griffo registriert, der für immer kostenlose Spiegel als griffo-free. Unter Debian (bookworm, trixie, forky und sid) sind die Befehle oben damit die gesamte Einrichtung.

Ubuntu wird nicht abgedeckt, denn extrepo veröffentlicht Metadaten nur für Debian-Suites: dort nimmst du die Befehle mit sudo oder als root.

Aktivieren Sie nicht beide Repositorys gleichzeitig. apt würde die jeweils höhere Version installieren (die aus dem Abo), und Sie stünden wieder vor einem 401. Alle Details zum kostenlosen Spiegel →

3. Das .deb von GitHub holen

Jedes Paket hier wird öffentlich gebaut, und die Build-Artefakte hängen an einem öffentlichen GitHub-Release. Diese Downloads sind kostenlos und ohne Authentifizierung, heute wie nach dem 1. Oktober:

wget https://github.com/dariogriffo/ghostty-debian/releases/latest/download/ghostty_1.3.1-5~trixie_amd64.deb
sudo apt install ./ghostty_1.3.1-5~trixie_amd64.deb
wget https://github.com/dariogriffo/ghostty-debian/releases/latest/download/ghostty_1.3.1-5~trixie_amd64.deb
apt install ./ghostty_1.3.1-5~trixie_amd64.deb

Sie verlieren die automatischen Upgrades (genau dafür bezahlt das Abonnement), aber nie den Zugang zur Software. Das Paketierungs-Repository jedes Werkzeugs ist unter So werden die Pakete gebaut aufgeführt.

❓ Warum das passiert ist

Mehr als 40 Werkzeuge für 8 Debian- und Ubuntu-Suites zu bauen, jeweils wenige Stunden nach jeder Upstream-Version, kostet jeden einzelnen Tag Geld und Zeit. Das Abonnement bezahlt dafür; den kostenlosen Spiegel gibt es, damit niemand von Software ausgesperrt wird, die er mit vollem Recht nutzen darf.
