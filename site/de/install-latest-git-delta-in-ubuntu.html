Was ist delta?

delta ist ein Pager mit Syntaxhervorhebung für die Ausgabe von git, diff, grep und blame. Einmal als Pager von git eingetragen, erscheinen git diff, git show, git log -p, git blame und git add -p mit Code, der so eingefärbt ist wie in deinem Editor, mit markierten geänderten Wörtern innerhalb jeder geänderten Zeile, wahlweise zweispaltig mit Zeilennummern, und mit Datei-Überschriften, zwischen denen du mit n und N springst. Es liest außerdem jedes Unified-Diff, vergleicht zwei Dateien direkt und hebt die JSON-Ausgabe von ripgrep hervor. Geschrieben in Rust von Dan Davison, mit denselben Syntaxdefinitionen und Farbthemen wie bat, konfiguriert über deine ~/.gitconfig, MIT-lizenziert. Das Paket heißt git-delta, der Befehl, den es installiert, delta.

🚀 Warum die neueste Version zählt: delta erscheint mehrmals im Jahr, mit neuen Optionen, besserem Zeilenumbruch in der Zweispaltenansicht und Korrekturen für die vielen Arten, wie git, Terminals und Pager zusammenspielen. Ubuntu 26.04 ist bei 0.18.2 eingefroren, 24.04 LTS bei 0.16.5, und 22.04 hat gar kein git-delta, Optionen aus dem aktuellen Handbuch gibt es in deiner Version also womöglich schlicht nicht. Dieses Repository verwendet denselben Paketnamen, git-delta, daher bekommst du mit apt install git-delta und apt upgrade das aktuelle Release statt dem aus dem Archiv.

⚡ Hauptfunktionen von delta

🎨 Syntaxhervorhebung

Code im Diff wird so eingefärbt wie in deinem Editor, mit den Syntaxdefinitionen und Farbthemen von bat. Wähle eines mit syntax-theme oder lass delta dem hellen oder dunklen Hintergrund des Terminals folgen.

🔍 Änderungen auf Wortebene

In jeder geänderten Zeile markiert delta genau die Wörter, die sich unterscheiden: eine umbenannte Variable oder eine umgedrehte Bedingung fällt sofort auf, statt sich in zwei fast gleichen roten und grünen Zeilen zu verstecken.

↔️ Zweispaltenansicht

side-by-side = true stellt alte und neue Fassung in zwei Spalten mit Zeilennummern nebeneinander und bricht lange Zeilen um, statt sie abzuschneiden. Für einen einzelnen Befehl: git -c delta.side-by-side=true diff.

🧭 Navigation und Links

Mit navigate = true springen n und N durch ein langes git log -p von Datei zu Datei. Mit hyperlinks = true werden Dateipfade und Commit-Hashes in Terminals, die das können, anklickbar.

🧩 Blame, Grep und Konflikte

git blame bekommt eingefärbten Code mit gruppierten Commit-Angaben, Treffer von git grep und rg --json werden hervorgehoben und nach Datei gruppiert, und Dateien mit Merge-Konflikten erscheinen als lesbare Diffs.

⚙️ Wohnt in ~/.gitconfig

Jede Option steht in einem [delta]-Abschnitt deiner git-Konfiguration, und benannte Feature-Sets wechseln einen ganzen Look auf einmal. Das Paket liefert upstreams themes.gitconfig mit, eine Sammlung fertiger Themen.

🚀 Immer vor den offiziellen Archiven: Debian und Ubuntu frieren Paketversionen beim Release ein. Dieses Repository veröffentlicht neue Upstream-Releases in der Regel innerhalb von Stunden. Ein einfaches apt upgrade hält dich auf der neuesten Version.

🎯 Grundlegende Verwendungsbeispiele

Diffs lesen:

# Zweispaltig, für einen Befehl
git -c delta.side-by-side=true diff

# Oder immer, mit Zeilennummern
git config --global delta.side-by-side true
git config --global delta.line-numbers true

# Durch die Historie gehen; n und N springen zwischen Dateien
git log -p

# Hunks mit Hervorhebung stagen
git add -p

Über git diff hinaus:

# Zwei Dateien direkt vergleichen
delta old.conf new.conf

# Jedes Unified-Diff
diff -u a.txt b.txt | delta

# ripgrep-Treffer, hervorgehoben und nach Datei gruppiert
rg --json -C 2 'TODO' | delta

# Auch git blame und git grep laufen durch delta
git blame src/main.rs
git grep -n 'TODO'

Themen und Konfiguration:

# Jedes Syntaxthema an einem echten Diff ansehen
git show | delta --show-syntax-themes

# Die mitgelieferten delta-Themen laden und ansehen
git config --global --add include.path /etc/delta/themes.gitconfig
git show | delta --show-themes

# Eines davon verwenden
git config --global delta.features mellow-barbet

# Die Konfiguration, mit der delta tatsächlich arbeitet
delta --show-config

🔧 Werkzeug-Integrationen

delta ist ein Filter zwischen git und deinem Pager, die Integration passiert also größtenteils in deiner git-Konfiguration und deinem Terminal:

  • git: core.pager delta deckt diff, show, log -p, stash show -p, blame und grep ab; interactive.diffFilter braucht --color-only, weil git für jede Zeile des Hunks genau eine Zeile zurück erwartet
  • less: delta blättert seine Ausgabe mit less, das das Paket empfiehlt; ohne less schreibt delta direkt ins Terminal. DELTA_PAGER oder delta.pager wählt einen anderen Pager, --paging=never schaltet das Blättern ab
  • lazygit: lazygit kann seine Diffs durch delta darstellen; trage in seiner Pager-Einstellung delta --dark --paging=never ein
  • difftastic: die beiden ergänzen sich: delta als Pager von git für die alltäglichen Diffs, difftastic über git difftool, wenn du ein Diff nach Syntaxbaum willst
  • ripgrep: rg --json an delta weitergereicht ergibt hervorgehobene, nach Datei gruppierte Suchergebnisse im selben Thema wie deine Diffs
  • Dein Terminal: delta erkennt selbst, ob der Hintergrund hell oder dunkel ist, und delta.dark oder delta.light korrigiert eine falsche Vermutung; kitty und Ghostty öffnen die Links, die hyperlinks = true erzeugt
  • Deine Shell: Vervollständigungen für delta in bash, zsh und fish kommen mit dem Paket

🚀 Warum deb.griffo.io?

📊 Repository-Vergleich:
  • Offizielles Ubuntu: liefert git-delta 0.18.2 in 26.04, 0.16.5 in 24.04 und keines in 22.04, jeweils eingefroren für die Lebensdauer des Release
  • cargo install git-delta: eine Rust-Toolchain und ein paar Minuten Kompilieren für eine Binärdatei in ~/.cargo/bin für einen Benutzer, ohne Vervollständigungen, bei jedem Release von Hand neu gebaut
  • Upstream-Downloads: ein .deb oder Tarball von der GitHub-Release-Seite, aktuell an dem Tag, an dem du es holst, und danach für jedes Release erneut von Hand zu holen
  • deb.griffo.io: neueste Version mit automatischen Updates
  • ✅ Derselbe Paketname wie in den Archiven: git-delta, genau wie Debian und Ubuntu es nennen, ein einfaches sudo apt install git-delta nimmt also diese neuere Version und apt upgrade ersetzt eine ältere Archivkopie an Ort und Stelle
  • ✅ Paket git-delta, Befehl delta: du installierst git-delta und startest delta. Zwei ähnliche Namen haben nichts damit zu tun: das Archivpaket delta ist ein Testfall-Reduzierer (multidelta, singledelta), und der Befehl git delta aus git-extras listet Dateien, die sich von einem anderen Branch unterscheiden
  • ✅ Der offizielle Build: upstreams Release-Binärdatei unter /usr/bin/delta, unverändert, mit Vervollständigungen für bash, zsh und fish und themes.gitconfig unter /etc/delta/themes.gitconfig, wo auch Debians eigenes Paket sie ablegt; upstream liefert keine Manpage, die Referenz ist delta --help
  • ✅ Schlanke Abhängigkeiten: empfiehlt git und less und braucht keines davon zum Laufen: ohne less gibt delta seine Ausgabe einfach ungeblättert aus
  • ✅ Automatische Updates: Pakete werden innerhalb von Stunden nach dem Upstream-Release aktualisiert
  • ✅ Drei Architekturen: amd64, arm64 und armhf auf Ubuntu 22.04, 24.04, 25.10, 26.04 und 26.10; einen Build für i386, ppc64el, s390x oder riscv64 gibt es nicht
  • ✅ Multi-Distribution: läuft auf Ubuntu 22.04, 24.04, 25.10, 26.04 und 26.10
  • ✅ Einfache Wartung: Updates mit den üblichen apt-Befehlen

❓ Häufig gestellte Fragen

Ist delta in den offiziellen Ubuntu-Paketquellen?

Ja, aber das offizielle Ubuntu-Archiv liefert delta 0.18.2, während dieses Repository delta 0.22.0 bereitstellt, wenige Stunden nach jedem Upstream-Release neu gebaut.

Wie installiere ich das neueste delta unter Ubuntu?

Fügen Sie das deb.griffo.io-Repository einmalig hinzu (Anleitung oben) und führen Sie dann aus: sudo apt install git-delta. Neue Releases kommen über das normale sudo apt upgrade.

Sind die Pakete signiert und wie werden sie gebaut?

Jedes Paket ist mit dem GPG-Schlüssel des Repositories (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) signiert und wird aus Upstream-Releases in öffentlichen GitHub-Repositories gebaut, die jeder einsehen kann.

Welche Ubuntu-Versionen werden unterstützt?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing, 26.04 Resolute und 26.10 Stonking.
