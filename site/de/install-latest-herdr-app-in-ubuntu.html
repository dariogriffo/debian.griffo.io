Was ist Herdr?

Herdr ist eine Desktop-App für Terminals und Coding-Agenten. Die Arbeit ist in Spaces organisiert, meist einer pro Repository, und jeder Space hat Tabs, die in Panes geteilt sind, sodass eine Shell, ein Editor und zwei Coding-Agenten nebeneinander in einem Fenster sitzen. Eine Agenten-Seitenleiste listet jeden Agenten aus allen Spaces mit seinem Status (Working, Blocked, wenn er auf dich wartet, Done oder Idle), und du siehst auf einen Blick, welcher eine Antwort braucht. Das Fenster zu schließen hält nichts an: die Terminals laufen in herdr-core (hc), einem kleinen Hintergrundprozess, und sind noch da, wenn du Herdr wieder öffnest. Es ist in Rust geschrieben, Apache-2.0-lizenziert und zu Hause auf herdr.dev.

🚀 Warum die neueste Version zählt: Herdr ist jung und entwickelt sich schnell: neue Layouts, Mod-APIs, Korrekturen für entfernte Rechner und ein besserer Agenten-Status kommen mit den meisten Releases. Ubuntu paketiert Herdr überhaupt nicht, und der eingebaute Selbst-Updater der App ist in diesem Build abgeschaltet, Updates kommen also auf demselben Weg wie der Rest des Systems. Ein normales apt upgrade hält jeden Rechner, an dem du arbeitest, aktuell.

⚡ Hauptfunktionen von Herdr

🗂️ Spaces, Tabs und Panes

Gib jedem Repository seinen eigenen Space, öffne darin Tabs und teile sie in Panes. Das Projekt wechseln heißt den Space wechseln, und jedes Terminal bleibt, wo du es gelassen hast.

🤖 Agenten-Seitenleiste

Jeder Coding-Agent in jedem Space erscheint in einer Liste mit seinem Status: Working, Blocked (wartet auf dich), Done oder Idle. Die blockierten sind die, die du dir zuerst ansiehst.

♾️ Terminals, die das Fenster überleben

Die Terminals laufen in herdr-core (hc), nicht im Fenster. Schließ Herdr, und deine Shells, Builds und Agenten laufen weiter; öffne es wieder, und alles ist zurück.

🌐 Entfernte Rechner über SSH

Füge einen Rechner hinzu, den du per SSH erreichst, und die Terminals eines Space laufen dort, sodass eine lange Agenten-Sitzung weiterläuft, wenn dein Laptop schläft oder das Netz wechselt.

🎨 Palette, Themes und Layouts

Strg+Umschalt+P öffnet eine Befehlspalette für alles; Themes und eingebaute Layouts (Herdr, Terminals und das Retro-Layout Herdr 98) ändern, wie das Fenster aussieht und was es zeigt.

🧩 JavaScript-Mods

In JavaScript geschriebene Mods zeichnen eigene Panels und Menüs, ein Arbeitsablauf, den die App noch nicht abdeckt, lässt sich also ergänzen, ohne auf ein Release zu warten.

🚀 Immer vor den offiziellen Archiven: Debian und Ubuntu frieren Paketversionen beim Release ein. Dieses Repository veröffentlicht neue Upstream-Releases in der Regel innerhalb von Stunden. Ein einfaches apt upgrade hält dich auf der neuesten Version.

🔧 Werkzeug-Integrationen

Herdr ist ein Zuhause für die Kommandozeilen-Werkzeuge, die du schon benutzt, worauf es ankommt, ist also vor allem der Rechner drumherum:

  • Desktop-Sitzung: Herdr ist eine grafische App und braucht eine X11- oder Wayland-Sitzung; auf einem Server ohne Bildschirm lässt du die Terminals stattdessen über einen entfernten Rechner dort laufen
  • Vulkan: das Fenster wird mit Vulkan gezeichnet, ein funktionierender Vulkan-Treiber ist also Pflicht. Das Paket empfiehlt mesa-vulkan-drivers, das Intel- und AMD-Grafik abdeckt; der proprietäre NVIDIA-Treiber bringt seinen eigenen mit
  • herdr-core: hc liegt in ~/.local/bin in deinem Home-Verzeichnis, beim ersten Start von der App installiert, nicht von apt; es ist der Prozess, der die Terminals am Leben hält, solange das Fenster zu ist
  • Entfernte Rechner: füge einen Rechner hinzu, den du per SSH erreichst, und die Terminals eines Space laufen dort, lange Agenten-Sitzungen überstehen es also, wenn dein Laptop schläft oder die Verbindung verliert
  • Coding-Agenten: starte deine Agenten-CLIs in Panes wie jeden anderen Befehl; die Agenten-Seitenleiste sammelt sie über alle Spaces und zeigt, welcher blockiert auf dich wartet
  • herdr im Terminal: das Paket herdr auf dieser Seite ist ein anderes Programm, ein Agenten-Multiplexer fürs Terminal; Herdr ist die Desktop-App, und beide lassen sich nebeneinander installieren
  • Deine Werkzeuge: Neovim oder Helix in einem Pane, lazygit in einem zweiten und ein Agent in einem dritten, alles im selben Space

🚀 Warum deb.griffo.io?

📊 Repository-Vergleich:
  • Offizielles Ubuntu: paketiert Herdr nicht, apt install herdr-app schlägt auf einem frischen System fehl
  • Upstream-Downloads: Release-Builds von releases.herdr.dev, die sich an apt vorbei selbst aktualisieren, auf jedem Rechner einzeln
  • Selbst aus dem Quelltext bauen: eine Rust-Toolchain, die Entwicklungspakete für Grafik und Fenstersystem und ein langer Build
  • deb.griffo.io: neueste Version mit automatischen Updates
  • ✅ Die einzige apt-Quelle: Herdr ist weder in den Debian- noch in den Ubuntu-Archiven; dieses Repository paketiert das offizielle Upstream-Release
  • ✅ Ein Name überall: das Paket heißt herdr-app und der Befehl auch: sudo apt install herdr-app, dann herdr-app oder der Eintrag im Starter
  • ✅ Updates über apt: der Selbst-Updater der App ist in diesem Build abgeschaltet, die Version auf der Platte ist also immer die, die apt installiert hat, und nichts überschreibt sie hinter dem Rücken des Paketmanagers
  • ✅ Vollständiges Paket: die Herdr-Desktop-App mit deklarierten Abhängigkeiten, damit sie sich auf jeder unterstützten Version installieren lässt, und dem Vulkan-Treiber als Empfehlung; herdr-core richtet die App beim ersten Start selbst ein
  • ✅ Automatische Updates: Pakete werden innerhalb von Stunden nach dem Upstream-Release aktualisiert
  • ✅ Zwei Architekturen: amd64 und arm64 gleichermaßen auf Ubuntu 22.04, 24.04, 25.10 und 26.04; einen Build für i386, armhf oder riscv64 gibt es nicht
  • ✅ Multi-Distribution: läuft auf Ubuntu 22.04, 24.04, 25.10 und 26.04
  • ✅ Einfache Wartung: Updates mit den üblichen apt-Befehlen

❓ Häufig gestellte Fragen

Ist Herdr Desktop in den offiziellen Ubuntu-Paketquellen?

Nein, Herdr Desktop ist nicht in den offiziellen Ubuntu-Archiven paketiert. Dieses Repository ist derzeit die einzige apt-Quelle und liefert Herdr Desktop 0.1.9.

Wie installiere ich das neueste Herdr Desktop unter Ubuntu?

Fügen Sie das deb.griffo.io-Repository einmalig hinzu (Anleitung oben) und führen Sie dann aus: sudo apt install herdr-app. Neue Releases kommen über das normale sudo apt upgrade.

Sind die Pakete signiert und wie werden sie gebaut?

Jedes Paket ist mit dem GPG-Schlüssel des Repositories (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) signiert und wird aus Upstream-Releases in öffentlichen GitHub-Repositories gebaut, die jeder einsehen kann.

Welche Ubuntu-Versionen werden unterstützt?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing und 26.04 Resolute.
