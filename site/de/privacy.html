Datenschutz und Cookies

Was deb.griffo.io und sein apt-Repository erheben, warum, und was Sie dagegen tun können

Zuletzt aktualisiert: 19. Oktober 2026

Kurz gesagt. Auf dieser Website wird kein Cookie gesetzt, solange Sie Google Analytics nicht zustimmen, und diese Entscheidung können Sie jederzeit ändern. Wenn Sie eine Testphase starten oder ein Abonnement abschließen, speichert das Repository, was es für Ihren apt-Zugang braucht: Ihre E-Mail-Adresse, den Status Ihres Abonnements und einen Hash Ihres Passworts. Kartendaten gehen an Stripe und erreichen diese Website nie.

1. Wer diese Website betreibt

deb.griffo.io, die Startseite von deb-free.griffo.io und die apt-Repositories dahinter werden von Dario Griffo („ich“) betrieben. Fragen und Anliegen zu Ihren Daten können Sie über GitHub oder die Discord-Community des Projekts vorbringen.

2. Statistik

Google Analytics, nur mit Ihrer Zustimmung. Bis Sie im Cookie-Hinweis auf Akzeptieren klicken, wird kein Google-Skript geladen, kein Google-Cookie gesetzt und nichts von Ihrem Browser an Google gesendet. Stimmen Sie zu, erfasst Google Analytics die Seiten, die Sie besuchen, und einige Aktionen darauf: das Öffnen des Formulars für die kostenlose Testphase, den Start einer Testphase und den Wechsel zur Bezahlseite. Dieselben Messungen zeigen auch, ob Werbung für diese Website wirkt; Ihre Zustimmung erlaubt Google daher außerdem, eine Testphase oder einen Kauf mit einer Anzeige zu verknüpfen, die Sie angeklickt haben. Personalisierte Werbung bleibt ausgeschaltet.

Abgeschlossene Käufe. Geht eine Zahlung ein, meldet der Server des Repositorys den Verkauf an Google Analytics: Tarif, Betrag, Währung und die Referenz von Stripe für den Bezahlvorgang. Die Meldung enthält weder Namen noch E-Mail-Adresse. Mit Ihrem Besuch verknüpft wird sie nur, wenn Sie den Statistik-Cookies zugestimmt hatten.

Ahrefs Web Analytics. Die Seiten von deb.griffo.io laden außerdem Ahrefs Web Analytics, das ohne Cookies arbeitet und Seitenstatistiken nur zusammengefasst ausweist.

3. Kostenlose Testphase

Für eine Testphase geben Sie eine E-Mail-Adresse ein. Das Formular ist durch Cloudflare Turnstile geschützt, das erst geladen wird, wenn Sie das Formular öffnen; der Server prüft dessen Ergebnis bei Cloudflare und übermittelt dabei Ihre IP-Adresse. Das Repository speichert Ihre E-Mail-Adresse und, nur wenn Sie den Statistik-Cookies zugestimmt haben, die Google-Analytics-Client-ID aus dem _ga-Cookie, damit ein späterer Kauf dem Besuch zugeordnet werden kann, mit dem die Testphase begann. An die E-Mail-Adresse gehen Ihre Zugangsdaten, eine Erinnerung vor dem Ende der Testphase und weitere Nachrichten zu Ihrem Zugang.

4. Zahlungen

Zahlungen wickelt Stripe ab. Kartendaten gehen an Stripe und erreichen weder diese Website noch ihre Server; für die Nutzung von Stripe gelten dessen eigene Bedingungen und Datenschutzhinweise. Das Repository speichert Ihre E-Mail-Adresse, die Referenzen von Stripe für Sie und Ihr Abonnement, den Tarif, seinen Status und seine Laufzeit. An diese Adresse gehen Ihre Zugangsdaten und Nachrichten zu Ihrem Abonnement, darunter einmalig, ein paar Tage nach dem Start, die Bitte um eine Bewertung.

5. Zugriff auf das Repository

apt meldet sich mit Ihrem Login (Ihrer E-Mail-Adresse) und einem für Sie erzeugten Passwort an, das nur als bcrypt-Hash gespeichert wird. Wie jeder Webserver protokollieren die Server des Repositorys Anfragen, darunter IP-Adresse, User-Agent und die angeforderte Datei, um den Dienst zu betreiben und Missbrauch zu verhindern.

7. Ihre Möglichkeiten

  • Ändern Sie Ihre Cookie-Entscheidung jederzeit über Cookie-Einstellungen unten auf jeder Seite. Eine Ablehnung löscht die Cookies von Google Analytics.
  • Fragen Sie, was über Sie gespeichert ist, oder lassen Sie es berichtigen oder löschen, über GitHub oder die Discord-Community. GitHub-Issues sind öffentlich, posten Sie dort also nicht Ihre E-Mail-Adresse; schreiben Sie nur, dass Sie ein Datenschutzanliegen haben, dann geht es privat weiter. Mit der Löschung Ihres Kontos endet Ihr Zugang zum Repository.

8. Änderungen

Ändert sich diese Seite, wird die neue Fassung hier mit aktualisiertem Datum veröffentlicht.
