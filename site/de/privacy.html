Datenschutz

Was deb.griffo.io und sein apt-Repository erheben, warum, und was Sie dagegen tun können

Zuletzt aktualisiert: 19. Oktober 2026

Kurz gesagt. Diese Website setzt keine Cookies, und ihre Statistik speichert nichts auf Ihrem Gerät; deshalb gibt es auch keinen Cookie-Hinweis zum Wegklicken. Besuche zählt ein kleiner eigener Dienst auf unserem eigenen Server, der Sie von einem Tag auf den nächsten nicht wiedererkennen kann. Wenn Sie eine Testphase starten oder ein Abonnement abschließen, speichert das Repository, was es für Ihren apt-Zugang braucht: Ihre E-Mail-Adresse, den Status Ihres Abonnements und einen Hash Ihres Passworts. Kartendaten gehen an Stripe und erreichen diese Website nie.

1. Wer diese Website betreibt

deb.griffo.io, deb-free.griffo.io und die apt-Repositories dahinter werden von Dario Griffo („ich“) betrieben. Fragen und Anliegen zu Ihren Daten können Sie über GitHub oder die Discord-Community des Projekts vorbringen.

2. Statistik

Seitenaufrufe zählt ttics, ein kleiner Statistikdienst, den ich selbst auf unserem eigenen Server betreibe. Kein Dritter erhält die Daten. Beim Laden einer Seite sendet Ihr Browser ihm die Adresse der Seite und einige Angaben zum Besuch. Daraus erfasst er:

  • die besuchte Seite (ihren Pfad, ohne Query-String);
  • den Host der Website, die Sie hierher verlinkt hat, nie die vollständige Adresse;
  • die utm_-Kampagnenparameter in der Adresse, sofern vorhanden (sie kennzeichnen einen Besuch, der über eine Anzeige oder einen Newsletter kam);
  • die Sprache der Seite;
  • eine Geräteklasse (Smartphone, Tablet oder Desktop), ermittelt aus der Breite des Fensters;
  • die Familie von Browser und Betriebssystem, etwa Firefox unter Linux, ohne Versionen;
  • einige Aktionen: das Öffnen des Formulars für die kostenlose Testphase, den Start einer Testphase und den Wechsel zur Bezahlseite;
  • einen täglichen Besucher-Hash, der unten erklärt wird.

Der Besucher-Hash ist ein SHA-256 aus einem Zufallswert, der sich jeden Tag ändert (dem Tages-Salt), Ihrer IP-Adresse, dem User-Agent Ihres Browsers und dem Hostnamen der Website. Damit kann der Dienst zählen, wie viele verschiedene Personen an einem bestimmten Tag die Website besucht haben. Jedes Salt wird nach zwei Tagen gelöscht; danach lässt sich der Hash aus keiner Adresse mehr neu berechnen, und der Hash eines neuen Tages stimmt nie mit einem alten überein, sodass Sie über Tage hinweg nicht wiedererkannt werden können. Ihre IP-Adresse und Ihr vollständiger User-Agent werden nie gespeichert; sie fließen nur in diesen Hash ein. Offensichtliche Bots und Crawler werden verworfen, bevor irgendetwas erfasst wird.

Mit diesen Zahlen sehe ich, welche Seiten Menschen helfen, das Gesuchte zu finden, und ob Werbung für die Website wirkt: Einem Besuch mit Kampagnenparametern werden die am selben Tag gestarteten Testphasen und Bezahlvorgänge zugerechnet.

Ahrefs Web Analytics. Die Seiten von deb.griffo.io laden außerdem Ahrefs Web Analytics, einen cookielosen Dienst von Ahrefs, der Seitenstatistiken nur zusammengefasst ausweist.

3. Kostenlose Testphase

Für eine Testphase geben Sie eine E-Mail-Adresse ein. Das Formular ist durch Cloudflare Turnstile geschützt, dessen Skript erst abgerufen wird, wenn Sie das Formular öffnen; ein Besuch, bei dem es nie geöffnet wird, lädt es also nie. Zur Prüfung der Antwort übermittelt der Server sie zusammen mit Ihrer IP-Adresse an Cloudflare. Das Repository speichert Ihre E-Mail-Adresse und schickt daran Ihre Zugangsdaten, eine Erinnerung vor dem Ende der Testphase und weitere Nachrichten zu Ihrem Zugang. Ihre IP-Adresse wird außerdem, ausschließlich im Arbeitsspeicher, genutzt, um pro Adresse und Tag nur eine Testanfrage zuzulassen.

4. Zahlungen

Zahlungen wickelt Stripe ab. Kartendaten gehen an Stripe und erreichen weder diese Website noch ihre Server; für die Nutzung von Stripe gelten dessen eigene Bedingungen und Datenschutzerklärung. Das Repository speichert Ihre E-Mail-Adresse, die Referenzen von Stripe für Sie und Ihr Abonnement, den Tarif, seinen Status und seine Daten. Über diese E-Mail-Adresse wird ein Kauf einer früheren Testphase zugeordnet, damit ich sehen kann, wie viele Testphasen zu Abonnements werden. An die Adresse gehen Ihre Zugangsdaten und Nachrichten zu Ihrem Abonnement, darunter einmalig, ein paar Tage nach dem Start, die Bitte um eine Bewertung.

5. Zugriff auf das Repository und Serverlogs

apt meldet sich mit Ihrem Login (Ihrer E-Mail-Adresse) und einem für Sie erzeugten Passwort an, das nur als bcrypt-Hash gespeichert wird. Wie jeder Webserver protokollieren die Server hinter der Website und dem Repository Anfragen, darunter IP-Adresse, User-Agent und die angeforderte Datei, um den Dienst zu betreiben und Missbrauch zu verhindern. Die Ausnahme ist der Statistikdienst: Sein Log enthält weder die Adresse noch den User-Agent noch den Referrer.

6. Cookies und Browserspeicher

Diese Website setzt keine Cookies, und die Statistik schreibt nichts in Ihren Browser. Das Einzige, was die Website selbst dort ablegen kann, ist eine Einstellung: Wenn Sie die Installationsbefehle zwischen sudo, root und extrepo umschalten, wird Ihre Wahl als deb-griffo-install-variant im Local Storage Ihres Browsers gespeichert, damit die nächste Seite dieselbe Variante zeigt. Sie verlässt Ihren Browser nie, und das Löschen Ihrer Websitedaten entfernt sie. Cloudflare Turnstile (nur wenn Sie das Formular für die Testphase öffnen) und Stripe (nur wenn Sie zur Bezahlseite wechseln) werden von diesen Unternehmen nach deren eigenen Richtlinien betrieben.

7. Ihre Rechte

  • Fragen Sie, was über Sie gespeichert ist, oder lassen Sie es berichtigen oder löschen, über GitHub oder die Discord-Community. GitHub-Issues sind öffentlich, posten Sie dort also nicht Ihre E-Mail-Adresse; schreiben Sie nur, dass Sie ein Datenschutzanliegen haben, dann geht es privat weiter. Mit der Löschung Ihres Kontos endet Ihr Zugang zum Repository.
  • Die Statistik lässt sich nicht auf Sie zurückführen. Sie enthält weder Namen noch E-Mail-Adresse, IP-Adresse oder Cookie, und der tägliche Hash lässt sich keiner Person mehr zuordnen, sobald sein Salt gelöscht ist; darin gibt es also nichts, was sich für einen einzelnen Besucher nachschlagen oder löschen ließe.
  • Sie können sich beschweren, und zwar bei Ihrer Datenschutzaufsichtsbehörde, wenn Sie meinen, dass mit Ihren Daten nicht ordnungsgemäß umgegangen wurde.
