Was ist bottom?

bottom — der Befehl heißt btm — ist ein grafischer Prozess- und Systemmonitor für das Terminal, in Rust geschrieben und von gtop, gotop und htop inspiriert. Standardmäßig verhält es sich wie ein Dashboard: CPU, Speicher, Netzwerk, Festplatten, Temperaturen und Prozesse teilen sich einen Bildschirm, und jedes Widget lässt sich sortieren, zoomen oder auf das ganze Terminal ausklappen.

🚀 Warum neueste Versionen wichtig sind: die offiziellen Archive hängen mehrere Minor-Releases zurück — und genau dort passierte das Interessante: getrennte Erfassung von Cache und Puffern, GPU-Auslastung im Speicher-Widget, eingebaute Farbthemen, das Ausblenden von Kernel-Threads und eine lange Liste von Korrekturen für neuere Kernel und Sensoren. Ein Monitor, der die Hardware falsch abliest, ist schlimmer als keiner — dieses Tool sollte aktuell bleiben.

⚡ Hauptfunktionen von bottom

📈 Live-Diagramme

CPU (pro Kern oder gemittelt), Speicher, Netzwerkdurchsatz, Festplatten-I/O und Temperaturen als laufende Diagramme, die du mit + und - zoomst.

🔍 Prozesssuche

/ filtert die Prozessliste — mit Regex, Ganzwort- und Groß-/Kleinschreibungs-Schaltern und je einem Tastendruck zum Sortieren nach CPU, Speicher, PID oder Name.

🌲 Baumansicht

t macht aus der Prozessliste einen Baum, sodass ein außer Kontrolle geratener Worker unter seinem Elternprozess auftaucht statt allein in der Liste.

🎛️ Eigene Layouts

Die Konfigurationsdatei beschreibt Zeilen, Spalten und Widget-Verhältnisse — so zeigt das Dashboard die vier Dinge, die du wirklich beobachtest, statt der neun Standard-Widgets.

🎨 Eingebaute Themes

--theme gruvbox, nord und deren helle Varianten stecken im Binary, und jede Farbe lässt sich in bottom.toml überschreiben.

🖥️ Basis-Modus

btm --basic lässt die Diagramme weg und liefert eine kompakte Zahlenübersicht, die auch über eine langsame SSH-Verbindung oder in einem kleinen tmux-Pane lesbar bleibt.

🚀 Immer den offiziellen Archiven voraus: Debian und Ubuntu frieren Paketversionen zum Release-Zeitpunkt ein — dieses Repository veröffentlicht neue Upstream-Releases in der Regel innerhalb weniger Stunden. Ein einfaches apt upgrade hält dich auf der neuesten Version.

🎯 Grundlegende Verwendungsbeispiele

Alltägliche Überwachung:

# Das komplette Dashboard
btm

# Zweimal pro Sekunde aktualisieren, zehn Minuten Verlauf behalten
btm --rate 500ms --retention 10m

# Direkt im Prozess-Widget starten, bereits ausgeklappt
btm --default_widget_type proc --expanded

# Prozessbaum, gruppiert, mit vollständigen Befehlszeilen
btm --tree --process_command

Innerhalb des Dashboards:

# Tasten, die die Arbeit machen
#   ?        Hilfe in der App mit allen Tastenkürzeln
#   e        ausgewähltes Widget auf das ganze Terminal ausklappen
#   f        Anzeige einfrieren, während du sie liest
#   +  -  =  Diagramm hinein-, herauszoomen oder zurücksetzen
#   /        Prozessliste durchsuchen
#   c m p n  nach CPU, Speicher, PID oder Name sortieren
#   dd       ausgewählten Prozess beenden
#   t        Prozessbaum umschalten

An die eigene Maschine anpassen:

# Fahrenheit, keine CPU-Durchschnittszeile, Punkt- statt Braille-Marker
btm --fahrenheit --hide_avg_cpu --dot_marker

# Cache und Puffer als eigene Speicherzeile zählen
btm --enable_cache_memory

# Akku-Widget auf einem Laptop
btm --battery

# Ein Farbthema, das zum restlichen Terminal passt
btm --theme gruvbox

🔧 Tool-Integrationen

bottom ist für ein Terminal-zentriertes Setup gebaut:

  • Konfigurationsdatei: ~/.config/bottom/bottom.toml hält Layout, Widget-Verhältnisse, Farben und deine üblichen Optionen an einer Stelle
  • Desktop-Eintrag: das Paket installiert bottom.desktop samt Icon, sodass bottom auch im Anwendungsmenü als Systemmonitor erscheint
  • tmux und Zellij: fühlt sich in einem schmalen Pane wohl; --basic hält es lesbar, wenn der Pane klein wird
  • GPUs: NVIDIA- und AMD-Auslastung erscheint im Speicher-Widget, sofern die Treiber vorhanden sind; --disable_gpu schaltet das Sammeln ab
  • Server: der amd64-Build ist statisch gelinkt — ein nackter Debian- oder Ubuntu-Server braucht nichts außer dem Paket

🚀 Warum deb.griffo.io?

📊 Repository-Vergleich:
  • Offizielles Ubuntu: liefert btm in universe, aber eingefroren auf dem Stand zum Release-Zeitpunkt, ohne späteres Upgrade
  • cargo install bottom: aktuell, kompiliert aber minutenlang, landet außerhalb von apt und bringt weder Handbuchseite noch Vervollständigungen oder Desktop-Eintrag
  • Upstream-Tarball: das offizielle Binary, das du für jedes Release von Hand neu herunterladen musst
  • deb.griffo.io: neueste Version mit automatischen Updates
  • ✅ Aktuelle Widgets: das neueste Release mit allen Widgets, Themes und Sensor-Korrekturen, die upstream nach dem Einfrieren des Archivs hinzukamen
  • ✅ Drop-in für bottom: das Paket heißt nach dem Befehl btm und deklariert Provides/Replaces für bottom, passt also genau dort hinein, wo das Archivpaket war
  • ✅ Automatische Updates: Pakete werden innerhalb von Stunden nach Upstream-Releases aktualisiert
  • ✅ Vollständiges Paket: das Upstream-Binary plus Handbuchseite btm.1, Vervollständigungen für bash, zsh und fish, Desktop-Eintrag und Icon
  • ✅ Fünf Architekturen: amd64, arm64, armhf, i386 und riscv64 — derselbe Monitor auf Laptop, Raspberry Pi und RISC-V-Board
  • ✅ Multi-Distribution: läuft auf Ubuntu 22.04, 24.04, 25.10 und 26.04
  • ✅ Einfache Wartung: Updates mit den üblichen apt-Befehlen

❓ Häufig gestellte Fragen

Ist bottom in den offiziellen Ubuntu-Paketquellen?

Ja, aber das offizielle Ubuntu-Archiv liefert bottom 0.12.3, während dieses Repository bottom 0.14.9 bereitstellt, wenige Stunden nach jedem Upstream-Release neu gebaut.

Wie installiere ich das neueste bottom unter Ubuntu?

Fügen Sie das deb.griffo.io-Repository einmalig hinzu (Anleitung oben) und führen Sie dann aus: sudo apt install btm. Neue Releases kommen über das normale sudo apt upgrade.

Sind die Pakete signiert und wie werden sie gebaut?

Jedes Paket ist mit dem GPG-Schlüssel des Repositories (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) signiert und wird aus Upstream-Releases in öffentlichen GitHub-Repositories gebaut, die jeder einsehen kann.

Welche Ubuntu-Versionen werden unterstützt?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing und 26.04 Resolute.
