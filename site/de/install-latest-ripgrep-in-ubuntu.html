Was ist ripgrep?

ripgrep (der Befehl rg) ist ein zeilenorientiertes Suchwerkzeug, geschrieben in Rust von Andrew Gallant. Es durchsucht das aktuelle Verzeichnis rekursiv nach einem Regex-Muster, respektiert dabei deine .gitignore-Regeln und überspringt versteckte, ignorierte und binäre Dateien automatisch. Es ist die Suchmaschine hinter Editoren wie VS Code und in der Regel schneller als GNU grep, The Silver Searcher und ack.

🚀 Warum neueste Versionen wichtig sind: ripgrep gewinnt zwischen Releases echte Funktionalität — Hyperlinks, um direkt in den Editor zu springen, --engine auto für transparenten PCRE2-Fallback, reichhaltigere --json-Ausgabe und stetige Durchsatzgewinne in der Regex-Engine. Die Archivversion ist älter als das meiste davon.

⚡ Hauptfunktionen von ripgrep

🚀 Extrem schnell

Eine Regex-Engine auf Basis endlicher Automaten, SIMD-Literalsuche, Memory Maps und paralleles Durchlaufen von Verzeichnissen machen es auf großen Bäumen schneller als grep.

🙈 Respektiert .gitignore

Überspringt standardmäßig ignorierte, versteckte und binäre Dateien, sodass die Treffer die sind, die dich interessieren. Mit -u, -uu oder -uuu übersteuerbar.

🌍 Volle Unicode-Unterstützung

Standardmäßig Unicode-fähig — Zeichenklassen, Groß-/Kleinschreibung, Wortgrenzen und Graphem-Behandlung funktionieren korrekt, ohne nennenswerten Geschwindigkeitsverlust.

🧩 PCRE2-Regex

-P aktiviert Look-around und Rückwärtsreferenzen. In diesem Build ist PCRE2 einkompiliert, es funktioniert also sofort und mit JIT.

📄 Filtern nach Dateityp

Beschränke die Suche mit -t rust auf eine Sprache, schließe mit -T html aus oder definiere eigene Typen. Über 800 Globs sind eingebaut.

🔁 Mehrzeilig & Ersetzen

Suche über Zeilengrenzen hinweg mit -U, sieh dir Ersetzungen mit -r an und gib strukturierte Ergebnisse mit --json aus.

🚀 Immer den offiziellen Archiven voraus: Debian und Ubuntu frieren Paketversionen beim Release ein — dieses Repository veröffentlicht neue Upstream-Releases typischerweise innerhalb von Stunden. Ein einfaches apt upgrade hält dich auf der neuesten Version.

🎯 Grundlegende Verwendungsbeispiele

Alltägliche Suche:

# Aktuellen Verzeichnisbaum durchsuchen
rg 'TODO'

# Groß-/Kleinschreibung ignorieren, ganzes Wort
rg -i -w 'timeout'

# 3 Zeilen Kontext um jeden Treffer anzeigen
rg -C 3 'panic!'

# Nur die Dateien mit Treffern auflisten
rg -l 'BurntSushi'

Eingrenzen, was durchsucht wird:

# Nur Rust-Dateien
rg -t rust 'unsafe'

# Alles außer HTML und CSS
rg -T html -T css 'font-size'

# Ignorierte und versteckte Dateien einbeziehen
rg -uu 'password'

# Mit einem Glob eingrenzen
rg -g '*.toml' 'version'

Mehr als nur grep:

# Look-around und Rückwärtsreferenzen via PCRE2
rg -P '(?<=fn )\w+' src/

# Über Zeilengrenzen hinweg suchen
rg -U 'struct \w+ \{\n[^}]*pub'

# Ersetzung ansehen (schreibt keine Dateien)
rg 'v(\d+)\.(\d+)' -r 'v$1.$2.0'

# Strukturierte Ausgabe für Skripte
rg --json 'error' | jq -r 'select(.type=="match") | .data.path.text'

🔧 Integrationen

ripgrep ist das Such-Backend, das viele andere Werkzeuge erwarten:

  • fzf: interaktives grep mit Live-Reload und rg als Quelle
  • Neovim / Telescope: live_grep nutzt ripgrep, wenn es im PATH liegt
  • Helix: die globale Suche basiert auf denselben Bibliotheken
  • bat: syntaxhervorgehobene Vorschauen der Treffer
  • Yazi: Dateimanager-Suche auf Basis von ripgrep

❓ Häufig gestellte Fragen

Ist ripgrep in den offiziellen Ubuntu-Paketquellen?

Ja, aber das offizielle Ubuntu-Archiv liefert ripgrep 15.1.0, während dieses Repository ripgrep 15.2.0 bereitstellt, wenige Stunden nach jedem Upstream-Release neu gebaut.

Wie installiere ich das neueste ripgrep unter Ubuntu?

Fügen Sie das deb.griffo.io-Repository einmalig hinzu (Anleitung oben) und führen Sie dann aus: sudo apt install ripgrep. Neue Releases kommen über das normale sudo apt upgrade.

Sind die Pakete signiert und wie werden sie gebaut?

Jedes Paket ist mit dem GPG-Schlüssel des Repositories (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) signiert und wird aus Upstream-Releases in öffentlichen GitHub-Repositories gebaut, die jeder einsehen kann.

Welche Ubuntu-Versionen werden unterstützt?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing und 26.04 Resolute.
