📊 Versiones de paquetes de Debian 13 y Ubuntu

Lo que distribuyen los archivos oficiales, junto a lo que sirve este repositorio — 2026-08-20

⚡ La respuesta corta. De las 48 herramientas de este repositorio, 33 no están ni en Debian 13 ni en Ubuntu 26.04, y el resto están congeladas en la versión que era la actual cuando se publicaron esas versiones estables. Debian y Ubuntu congelan las versiones de los paquetes al publicar una versión estable y después incorporan sobre todo correcciones de seguridad, un intercambio deliberado y a menudo acertado — pero significa que la versión que se obtiene con apt install en un sistema estándar es la que era la actual el día del lanzamiento. Esta tabla es el cuadro completo para un catálogo de herramientas de desarrollo, regenerada cada vez que se publica un paquete en lugar de escrita a mano.

📋 La tabla

Las versiones oficiales proceden de los propios archivos de Debian y Ubuntu (el servicio madison), comparadas con la versión estable actual de cada uno: Debian 13 «Trixie» y Ubuntu 26.04 «Resolute». Backports, testing y unstable quedan excluidos — la pregunta es qué ofrece un sistema estable sin modificar. La última columna es lo que sirve hoy este repositorio.

🔍 Cómo leerla

  • «no empaquetado» significa que el archivo no tiene ningún paquete con ese nombre, en la versión estable actual de esa distribución. En un sistema estándar, apt install falla con «Unable to locate package».
  • Las versiones se muestran tal como las reportan los archivos, sin epochs ni revisiones de Debian, de modo que 1:0.44.1-1ubuntu2 se lee como 0.44.1 — el número que reconocería el proyecto upstream.
  • Una herramienta puede estar en Ubuntu y no en Debian, o al revés: los dos archivos toman decisiones independientes y se congelan en fechas distintas.
  • Nada de esto es una crítica a Debian. Un archivo congelado es lo que hace que una versión estable sea estable, y para muchísimos paquetes es exactamente lo que se quiere. Encaja mal con las herramientas que publican cada pocas semanas, que es justamente la razón de ser de este repositorio.

✅ Compruebe cualquier fila por su cuenta

Todos los números de arriba son públicos. En una máquina Debian o Ubuntu:

apt-cache policy ripgrep        # qué instalaría su sistema, y desde dónde
apt-cache madison ripgrep       # todas las versiones que ofrecen sus fuentes configuradas
rmadison ripgrep                # qué distribuyen los archivos oficiales, sin instalar nada

rmadison viene del paquete devscripts y consulta el mismo servicio con el que se construye esta tabla. La columna de deb.griffo.io sigue la versión más reciente de cada proyecto y se reconstruye a las pocas horas; el repositorio de empaquetado de cada herramienta está listado en cómo se construyen los paquetes.

📦 Cómo obtener en su lugar la versión actual

Una sola línea de repositorio cubre todas las herramientas de la tabla, reconstruidas a las pocas horas de cada versión upstream:

Ejecutar los comandos
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | sudo tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
sudo apt update
