¿Qué es Atuin AI?

Atuin AI es el agente de shell de Atuin. Atuin lo incluía integrado hasta la 18.24 y lo quitó en la 18.25; ahora sigue vivo como binario independiente, atuin-ai. Pulsa ? en un prompt vacío y se abre un chat en tu propia terminal: describe lo que quieres hacer y te sugiere el comando, o hazle una pregunta y te la responde. Con tu permiso también puede buscar en tu historial de Atuin, leer y editar archivos y ejecutar comandos. Habla con un servidor Atuin AI que alojas tú mismo (upstream lo publica como imagen Docker), y ese servidor puede ponerse delante de cualquier endpoint compatible con OpenAI: Ollama, vLLM o una API alojada. El cliente está escrito en Rust por el equipo de Atuin y tiene licencia MIT.

🚀 Por qué importa la última versión: Atuin AI es joven y avanza rápido, y upstream no publica ninguna versión, solo commits en main. Este repositorio compila una instantánea cada viernes cuando main ha cambiado, con versión <versión del cliente>.<AAAAMMDD> (por ejemplo 0.1.0.20261127), así que apt upgrade te trae los cambios de la semana sin toolchain de Rust. Debian no empaqueta atuin-ai en absoluto.

⚡ Funciones clave de Atuin AI

❓ A una tecla

Pulsa ? en un prompt vacío para abrir el agente. En cualquier otro sitio ? escribe un signo de interrogación como siempre, así que nunca estorba al comando que estás escribiendo.

💡 Sugerencias de comandos

Describe la tarea con palabras normales ("busca archivos de más de 1 GB modificados esta semana") y recibe un comando que puedes leer, editar y ejecutar, en vez de rebuscar en las páginas man.

📜 Conoce tu historial

Con permiso, el agente busca en tu historial de Atuin, así que puede encontrar el comando que ejecutaste el mes pasado o partir de cómo sueles hacer las cosas en esta máquina.

🛠️ Archivos y comandos

Puede leer y editar archivos y ejecutar comandos por ti, y pregunta antes de hacerlo. Tú decides qué toca tu sistema.

🏠 Tu propio servidor

El cliente habla con un servidor Atuin AI que ejecutas tú, así que tus prompts y tu historial van a donde tú decidas. Upstream distribuye el servidor como ghcr.io/atuinsh/atuin-ai-server.

🔌 Cualquier modelo compatible con OpenAI

El servidor funciona con cualquier endpoint compatible con OpenAI: un modelo local con Ollama o vLLM, o una API alojada. Cambia de modelo en el servidor sin tocar el cliente.

🚀 Siempre por delante de los archivos oficiales: Debian y Ubuntu congelan las versiones de los paquetes cuando publican una release; este repositorio publica las nuevas versiones upstream normalmente en cuestión de horas. Un simple apt upgrade te mantiene en la última versión.

Cómo funciona el espejo gratuito →

🧩 Sobre la opción extrepo. extrepo es la herramienta propia de Debian para repositorios externos: escribe el archivo de sources e instala la clave de firma por ti, comprobándola antes contra metadatos firmados. Este repositorio está registrado en ella como griffo, y el espejo gratuito para siempre como griffo-free, así que en Debian (bookworm, trixie, forky y sid) los comandos de arriba son toda la configuración.

extrepo solo configura el archivo de sources y la clave: las credenciales de una suscripción siguen yendo en /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu no está cubierto, porque extrepo publica metadatos solo para las suites de Debian: allí usa los comandos con sudo o como root.

Paso 3: Primer arranque

# Indicar al cliente dónde está tu servidor Atuin AI
# (un ejemplo comentado: /usr/share/doc/atuin-ai/examples/ai.example.toml)
mkdir -p ~/.atuin
cat > ~/.atuin/ai.toml <<'EOF'
endpoint = "http://localhost:8080"
# api_token = "..."   # solo si el servidor define AUTH_TOKEN
EOF

# Asignar ? en tu shell, después de la línea init de Atuin
echo 'eval "$(atuin-ai init bash)"' >> ~/.bashrc

# Abrir una shell nueva y pulsar ? en un prompt vacío
exec bash

🎯 Ejemplos básicos de uso

Configurar la shell:

🔧 Integraciones

Atuin AI se sitúa entre tu shell, tu historial de Atuin y el modelo que elijas:

  • Atuin: una dependencia obligatoria, que se instala con él desde deb.griffo.io; el agente busca en la misma base de datos de historial que usa atuin search, y solo si lo permites
  • Atuin 18.25 y posteriores: la 18.25 quitó el agente integrado, así que este paquete es la forma de conservar el chat con ? en un Atuin actual
  • bash, zsh y fish: atuin-ai init bash, zsh o fish imprime el atajo de teclado; cárgalo después del init de Atuin para que ambos atajos convivan
  • Servidor Atuin AI: ghcr.io/atuinsh/atuin-ai-server, con Docker o Podman en la misma máquina o en cualquier sitio al que llegue el cliente; define AUTH_TOKEN allí y api_token en ~/.atuin/ai.toml para protegerlo
  • Ollama y vLLM: todos los prompts se quedan en tu propio hardware si apuntas el servidor a un endpoint local compatible con OpenAI
  • API alojadas: cualquier proveedor que hable la API de OpenAI funciona igual, configurado en el servidor, nunca en el cliente

🚀 ¿Por qué elegir deb.griffo.io?

📊 Comparativa de repositorios:
  • Debian oficial: no empaqueta Atuin AI, apt install atuin-ai falla en un sistema recién instalado
  • Descargas de upstream: no hay: upstream no publica versiones, tags ni binarios del cliente
  • cargo build desde el código: un clon, una toolchain de Rust y unos minutos de compilación, repetidos a mano cada vez que main cambia
  • deb.griffo.io: última versión con actualizaciones automáticas
  • ✅ Compilado desde main de upstream: a partir del código de upstream con su propio Cargo.lock; las notas de versión y /usr/share/doc/atuin-ai/changelog.Debian indican el commit exacto de upstream de cada instantánea
  • ✅ Trae Atuin consigo: depende de atuin, que deb.griffo.io también ofrece, así que un solo apt install atuin-ai te da los dos
  • ✅ Solo el cliente: el paquete instala /usr/bin/atuin-ai y un ai.toml de ejemplo; el servidor se queda en Docker, donde upstream lo distribuye
  • ✅ Actualizaciones automáticas: cada nueva instantánea llega con un simple apt upgrade
  • ✅ Dos arquitecturas: amd64 y arm64 en Bookworm, Trixie, Forky y Sid, las mismas dos que el paquete Atuin del que depende; no hay compilación para i386 ni armhf
  • ✅ Multidistribución: funciona en Bookworm, Trixie, Forky y Sid
  • ✅ Mantenimiento sencillo: actualizaciones con los comandos apt de siempre

❓ Preguntas frecuentes

¿Está Atuin AI en los repositorios oficiales de Debian?

No, Atuin AI no está empaquetado en los archivos oficiales de Debian. Este repositorio es actualmente la única fuente apt y ofrece Atuin AI 0.1.0.20261125.

¿Cómo instalo el último Atuin AI en Debian?

Añade el repositorio deb.griffo.io una sola vez con las instrucciones de arriba y ejecuta: sudo apt install atuin-ai. Las nuevas versiones llegan con el sudo apt upgrade habitual.

¿Los paquetes están firmados y cómo se compilan?

Cada paquete está firmado con la clave GPG del repositorio (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) y se compila a partir de versiones upstream en repositorios públicos de GitHub que cualquiera puede inspeccionar.

¿Qué versiones de Debian son compatibles?

Debian 12 Bookworm, Debian 13 Trixie, Forky y Sid.
