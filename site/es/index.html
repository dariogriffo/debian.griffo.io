deb.griffo.io

Repositorio no oficial para las últimas herramientas de desarrollo

🚀 Siempre actualizado: Este repositorio proporciona las versiones más actuales de herramientas de desarrollo populares como paquetes de Debian, actualizados regularmente para garantizar que tenga acceso a las últimas funciones y correcciones de seguridad.

⚡ Instalación rápida

Agregue este repositorio a su sistema Debian y comience a instalar las últimas versiones de sus herramientas de desarrollo favoritas:

Ejecutar los comandos

Paso 1: Agregar repositorio

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | sudo tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
sudo apt update

Buscar paquetes tras agregar el repositorio

Una vez agregado el repositorio, puede usar las herramientas estándar de apt para explorar los paquetes disponibles:

# Listar todos los paquetes de este repositorio
apt-cache search --names-only '' | grep -v '^lib'

# Mostrar detalles de un paquete específico
apt-cache show zig

# Verificar qué versión se instalará y desde qué fuente
apt-cache policy zig

🚀 ¿Por qué elegir deb.griffo.io?

Este repositorio no oficial se especializa en proporcionar las versiones más actualizadas de herramientas de desarrollo populares como paquetes de Debian correctamente empaquetados. Mientras que los repositorios oficiales de Debian a menudo se quedan atrás de los lanzamientos upstream, nos aseguramos de que obtenga:

  • ✅ Últimas versiones estables en horas después de la publicación original
  • ✅ Compilaciones nocturnas para características de vanguardia (Zig, ZLS)
  • ✅ Empaquetado Debian adecuado con dependencias correctas
  • ✅ Soporte para múltiples distribuciones (Bookworm, Trixie, Forky, Sid)
  • ✅ Actualizaciones automatizadas garantizando disponibilidad continua

⚠️ Información importante

Alcance: Este repositorio se enfoca exclusivamente en empaquetado no oficial de Debian. Para problemas con las herramientas en sí, por favor contacte a los respectivos proyectos originales.

Actualizaciones: Los paquetes se actualizan automáticamente cuando se publican nuevas versiones en los proyectos originales, asegurando que siempre tenga acceso a las últimas características y parches de seguridad.

Comunidad: Este es un proyecto impulsado por la comunidad destinado a cerrar la brecha entre las herramientas de desarrollo de rápida evolución y el ciclo de empaquetado estable de Debian.
