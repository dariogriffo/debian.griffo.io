Cómo funciona el espejo gratuito →

🧩 Sobre la opción extrepo. extrepo es la herramienta propia de Debian para repositorios externos: escribe el archivo de sources e instala la clave de firma por ti, comprobándola antes contra metadatos firmados. Este repositorio está registrado en ella como griffo, y el espejo gratuito para siempre como griffo-free, así que en Debian (bookworm, trixie, forky y sid) los comandos de arriba son toda la configuración.

extrepo solo configura el archivo de sources y la clave: las credenciales de una suscripción siguen yendo en /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu no está cubierto, porque extrepo publica metadatos solo para las suites de Debian: allí usa los comandos con sudo o como root.

📦 Paquetes fuente

Además de los paquetes binarios .deb, este repositorio también ofrece paquetes fuente de Debian para todas las herramientas soportadas. Los paquetes fuente permiten inspeccionar el empaquetado, reconstruir los binarios localmente o aplicar parches propios, todo con las herramientas estándar de Debian. Un paquete fuente consta de tres archivos:

  • .dsc — archivo de descripción con sumas de verificación y metadatos
  • .orig.tar.gz — tarball del código fuente upstream sin modificar
  • .debian.tar.xz — capa de empaquetado específica de Debian (directorio debian/)

Descargar y compilar

# Descargar el código fuente de un paquete (crea un directorio en la carpeta actual)
apt-get source zig

# O descargarlo sin desempaquetar — solo el .dsc y los tarballs
apt-get source --download-only zig

# Entrar en el directorio del código fuente desempaquetado (el número de versión variará)
cd zig-stable-0.14.0

# Compilar un .deb binario sin firmar (adecuado para uso local)
dpkg-buildpackage -b --no-sign

# El .deb resultante aparece un nivel más arriba
ls ../zig-stable_*.deb

# Instalar automáticamente todas las dependencias de compilación de un paquete

Por qué deb.griffo.ioHecho para quienes quieren lo último

Este repositorio no oficial se especializa en proporcionar las versiones más actualizadas de herramientas de desarrollo populares como paquetes de Debian correctamente empaquetados. Mientras que los repositorios oficiales suelen quedarse atrás de las versiones upstream, aquí obtiene:

  • Últimas versiones estables a las pocas horas de su publicación upstream
  • Compilaciones nocturnas para funcionalidades de vanguardia (Zig, ZLS)
  • Empaquetado Debian adecuado con dependencias correctas
  • Soporte para múltiples distribuciones — Debian (Bookworm, Trixie, Forky, Sid) y Ubuntu (Jammy, Noble, Questing, Resolute)
  • Paquetes fuente — descargue, inspeccione y reconstruya cualquier paquete localmente con apt-get source
  • Actualizaciones automatizadas que garantizan disponibilidad continua

PreciosPaga una vez al año, o nunca más

Debian y Ubuntu congelan las versiones de los paquetes durante años. Este mirror sigue cada herramienta que distribuye y publica cada nueva versión upstream en cuestión de horas — firmada con GPG, directamente en apt. Una suscripción mantiene esa automatización en marcha. ¿Prefieres actualizar a mano? Todos los .deb siguen siendo gratuitos en GitHub.

Por qué existe la suscripción

No es una licencia del software. Todas las herramientas son de código abierto y cada .deb se puede seguir descargando gratis. Lo que paga la suscripción es la maquinaria que hay alrededor, y lo mucho que ha crecido.

Información importanteLas preguntas que más nos hacen

No está pagando por el software. Todas las herramientas de aquí son de código abierto, y nada de este repositorio cambia su licencia ni lo que le costaría compilarlas usted mismo. La suscripción paga el empaquetado que las envuelve: producir paquetes Debian en condiciones para herramientas cuyos autores no publican ninguno, reconstruirlos automáticamente a las pocas horas de cada versión upstream y poner esas compilaciones a disposición de versiones antiguas de Debian y Ubuntu que, de otro modo, se quedarían años atrás. Eso es mantenimiento e infraestructura continuos, no una licencia de software. Y si prefiere no pagarlo, todos los .deb siguen siendo gratuitos en GitHub: simplemente tendrá que actualizarlos usted mismo.
En un par de minutos recibes un correo con un usuario — la dirección con la que pagaste — y una contraseña generada. Van en /etc/apt/auth.conf.d/deb.griffo.io.conf, y apt las envía por HTTPS en cada descarga: autenticación HTTP Basic, que apt soporta de forma nativa desde hace años. No hay panel en el que entrar, ni token que rotar, ni límite de máquinas que usen las mismas credenciales. La renovación es silenciosa y no cambia nada; si cancelas, conservas el acceso hasta el final del periodo que ya pagaste. Cómo funciona la suscripción, en detalle →
No hay nada roto en su sistema y nada de lo que ya tiene instalado se ve afectado: los paquetes instalados nunca caducan ni comprueban una licencia. A partir del 1 de octubre de 2026, descargar paquetes requiere una suscripción: apt update, apt policy y explorar el repositorio siguen siendo gratuitos para todo el mundo, mientras que apt install y apt upgrade necesitan credenciales guardadas en /etc/apt/auth.conf.d/. Hay tres caminos posibles, con los comandos exactos: agregar sus credenciales, cambiar al espejo gratis para siempre en deb-free.griffo.io, o descargar el .deb directamente de la publicación pública de GitHub, que es gratis y siempre lo será. Este repositorio se centra exclusivamente en el empaquetado no oficial de Debian. Para problemas con las herramientas en sí, contacte con los respectivos proyectos upstream. Aquí solo se atienden cuestiones relacionadas con el empaquetado.
Los paquetes se actualizan automáticamente cuando se publican nuevas versiones upstream, normalmente en cuestión de horas, para que siempre tenga acceso a las últimas funcionalidades y parches de seguridad.
Este repositorio funciona con reprepro, configurado para conservar solo la última versión de cada paquete, así que apt install zig=0.15.2 deja de funcionar en cuanto sale 0.16.0. Por eso los paquetes de Zig se nombran según su nivel de estabilidad: zig es un metapaquete que siempre instala zig-stable, zig-oldstable contiene la estable anterior y se puede instalar en paralelo, y zig-0 está obsoleto. Con ambos instalados, sudo update-alternatives --config zig decide a cuál apunta /usr/bin/zig.
