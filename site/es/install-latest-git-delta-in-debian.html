¿Qué es delta?

delta es un paginador con resaltado de sintaxis para la salida de git, diff, grep y blame. Configúralo una vez como paginador de git y cada git diff, git show, git log -p, git blame y git add -p sale con el código coloreado como en tu editor, las palabras cambiadas marcadas dentro de cada línea modificada, columnas lado a lado y números de línea opcionales, y cabeceras de archivo entre las que saltas con n y N. También lee cualquier diff unificado, compara dos archivos directamente y resalta la salida JSON de ripgrep. Está escrito en Rust por Dan Davison, usa las mismas definiciones de sintaxis y temas de color que bat, se configura desde tu ~/.gitconfig y tiene licencia MIT. El paquete se llama git-delta; el comando que instala es delta.

🚀 Por qué importa la última versión: delta publica varias versiones al año, con opciones nuevas, mejor ajuste de líneas en la vista lado a lado y correcciones para las muchas formas en que git, las terminales y los paginadores interactúan. Debian trixie está congelado en 0.18.2 y Bookworm no tiene git-delta, así que opciones del manual actual pueden no existir en tu copia. Este repositorio usa el mismo nombre de paquete, git-delta, así que apt install git-delta y apt upgrade te dan la versión actual en lugar de la del archivo.

⚡ Funciones clave de delta

🎨 Resaltado de sintaxis

El código dentro de un diff se colorea como en tu editor, con las definiciones de sintaxis y los temas de color de bat. Elige uno con syntax-theme o deja que delta siga el fondo claro u oscuro de la terminal.

🔍 Cambios a nivel de palabra

Dentro de cada línea modificada delta marca exactamente las palabras que difieren, así una variable renombrada o una condición invertida salta a la vista en vez de esconderse en dos líneas roja y verde casi idénticas.

↔️ Vista lado a lado

side-by-side = true pone la versión vieja y la nueva en dos columnas con números de línea, ajustando las líneas largas en vez de cortarlas. Pruébalo para un solo comando con git -c delta.side-by-side=true diff.

🧭 Navegación y enlaces

Con navigate = true, n y N saltan de archivo en archivo por un git log -p largo. Con hyperlinks = true, las rutas y los hashes de commit se vuelven clicables en las terminales que lo admiten.

🧩 Blame, grep y conflictos

git blame muestra el código coloreado con los datos del commit agrupados, los resultados de git grep y rg --json se resaltan y agrupan por archivo, y los archivos en conflicto durante un merge se ven como diffs legibles.

⚙️ Vive en ~/.gitconfig

Cada opción va en una sección [delta] de tu configuración de git, y los conjuntos de opciones con nombre cambian todo el aspecto de una vez. El paquete incluye el themes.gitconfig de upstream, una colección de temas listos.

🚀 Siempre por delante de los archivos oficiales: Debian y Ubuntu congelan las versiones de los paquetes cuando publican una release; este repositorio publica las nuevas versiones upstream normalmente en cuestión de horas. Un simple apt upgrade te mantiene en la última versión.

Cómo funciona el espejo gratuito →

🧩 Sobre la opción extrepo. extrepo es la herramienta propia de Debian para repositorios externos: escribe el archivo de sources e instala la clave de firma por ti, comprobándola antes contra metadatos firmados. Este repositorio está registrado en ella como griffo, y el espejo gratuito para siempre como griffo-free, así que en Debian (bookworm, trixie, forky y sid) los comandos de arriba son toda la configuración.

extrepo solo configura el archivo de sources y la clave: las credenciales de una suscripción siguen yendo en /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu no está cubierto, porque extrepo publica metadatos solo para las suites de Debian: allí usa los comandos con sudo o como root.

Paso 3: Primer arranque

# Hacer de delta el paginador de git: diff, show, log -p, blame y grep pasan por él
git config --global core.pager delta

# git add -p con el mismo resaltado
git config --global interactive.diffFilter 'delta --color-only'

# n y N saltan entre archivos
git config --global delta.navigate true

# Los conflictos muestran también el ancestro común
git config --global merge.conflictStyle zdiff3

# Pruébalo
git diff

🎯 Ejemplos básicos de uso

Leer diffs:

# Lado a lado, para un solo comando
git -c delta.side-by-side=true diff

# O siempre, con números de línea
git config --global delta.side-by-side true
git config --global delta.line-numbers true

# Recorrer el historial; n y N saltan entre archivos
git log -p

# Preparar hunks con resaltado
git add -p

Más allá de git diff:

# Comparar dos archivos directamente
delta old.conf new.conf

# Cualquier diff unificado
diff -u a.txt b.txt | delta

# Coincidencias de ripgrep, resaltadas y agrupadas por archivo
rg --json -C 2 'TODO' | delta

# git blame y git grep también pasan por delta
git blame src/main.rs
git grep -n 'TODO'

Temas y configuración:

# Ver cada tema de sintaxis sobre un diff real
git show | delta --show-syntax-themes

# Cargar los temas de delta que trae el paquete y verlos
git config --global --add include.path /etc/delta/themes.gitconfig
git show | delta --show-themes

# Usar uno de ellos
git config --global delta.features mellow-barbet

# La configuración con la que delta acaba trabajando
delta --show-config

🔧 Integraciones

delta es un filtro entre git y tu paginador, así que casi toda la integración ocurre en tu configuración de git y en tu terminal:

  • git: core.pager delta cubre diff, show, log -p, stash show -p, blame y grep; interactive.diffFilter necesita --color-only, porque git espera recibir una línea por cada línea del hunk
  • less: delta pagina su salida con less, que el paquete recomienda; sin él, delta imprime directamente en la terminal. DELTA_PAGER o delta.pager eligen otro paginador, y --paging=never desactiva la paginación
  • lazygit: lazygit puede mostrar sus diffs a través de delta; apunta su ajuste de paginador a delta --dark --paging=never
  • difftastic: se complementan: delta como paginador de git para el día a día, difftastic con git difftool cuando quieres un diff por árbol sintáctico
  • ripgrep: rg --json enviado a delta da resultados de búsqueda resaltados y agrupados por archivo, con el mismo tema que tus diffs
  • Tu terminal: delta averigua si el fondo es claro u oscuro, y delta.dark o delta.light corrigen una suposición equivocada; kitty y Ghostty abren los enlaces que produce hyperlinks = true
  • Tu shell: el paquete trae el autocompletado de delta para bash, zsh y fish

🚀 ¿Por qué elegir deb.griffo.io?

📊 Comparativa de repositorios:
  • Debian oficial: trae git-delta 0.18.2 en trixie y ninguno en Bookworm, congelado durante toda la vida de la versión
  • cargo install git-delta: una toolchain de Rust y unos minutos de compilación para un binario en ~/.cargo/bin de un solo usuario, sin autocompletado, recompilado a mano en cada versión
  • Descargas de upstream: un .deb o tarball de la página de versiones de GitHub, actual el día que lo bajas y a bajar de nuevo a mano en cada versión posterior
  • deb.griffo.io: última versión con actualizaciones automáticas
  • ✅ El mismo nombre de paquete que en los archivos: git-delta, igual que lo llaman Debian y Ubuntu, así que un simple sudo apt install git-delta elige esta versión más nueva y apt upgrade reemplaza en su sitio una copia más vieja del archivo
  • ✅ Paquete git-delta, comando delta: instalas git-delta y ejecutas delta. Dos nombres parecidos no tienen nada que ver: el paquete delta del archivo es un reductor de casos de prueba (multidelta, singledelta), y el comando git delta de git-extras lista los archivos que difieren de otra rama
  • ✅ La compilación oficial: el binario de la versión de upstream en /usr/bin/delta, sin cambios, con autocompletado para bash, zsh y fish y themes.gitconfig en /etc/delta/themes.gitconfig, donde lo pone el propio paquete de Debian; upstream no publica página de manual, la referencia es delta --help
  • ✅ Dependencias ligeras: recomienda git y less y no necesita ninguno para funcionar: sin less, delta simplemente imprime su salida sin paginar
  • ✅ Actualizaciones automáticas: los paquetes se actualizan pocas horas después de cada versión upstream
  • ✅ Cuatro arquitecturas: amd64, arm64 y armhf en Bookworm, Trixie, Forky y Sid; i386 solo en Trixie, Forky y Sid, porque la compilación i386 de upstream necesita glibc 2.39 y Bookworm tiene 2.36; no hay compilación para ppc64el, s390x ni riscv64
  • ✅ Multidistribución: funciona en Bookworm, Trixie, Forky y Sid
  • ✅ Mantenimiento sencillo: actualizaciones con los comandos apt de siempre

❓ Preguntas frecuentes

¿Está delta en los repositorios oficiales de Debian?

Sí, pero el archivo oficial de Debian trae delta 0.18.2, mientras que este repositorio ofrece delta 0.22.0, recompilado pocas horas después de cada versión upstream.

¿Cómo instalo el último delta en Debian?

Añade el repositorio deb.griffo.io una sola vez con las instrucciones de arriba y ejecuta: sudo apt install git-delta. Las nuevas versiones llegan con el sudo apt upgrade habitual.

¿Los paquetes están firmados y cómo se compilan?

Cada paquete está firmado con la clave GPG del repositorio (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) y se compila a partir de versiones upstream en repositorios públicos de GitHub que cualquiera puede inspeccionar.

¿Qué versiones de Debian son compatibles?

Debian 12 Bookworm, Debian 13 Trixie, Forky y Sid.
