¿Qué es ripgrep?

ripgrep (el comando rg) es una herramienta de búsqueda orientada a líneas escrita en Rust por Andrew Gallant. Busca recursivamente en el directorio actual un patrón de expresión regular respetando las reglas de tu .gitignore y omitiendo automáticamente archivos ocultos, ignorados y binarios. Es el motor de búsqueda que usan editores como VS Code y suele ser más rápido que GNU grep, The Silver Searcher y ack.

🚀 Por qué importan las últimas versiones: ripgrep gana capacidades reales entre versiones: hipervínculos para saltar directamente a tu editor, --engine auto para recurrir a PCRE2 de forma transparente, una salida --json más rica y mejoras constantes de rendimiento en su motor de expresiones regulares. La versión del archivo oficial es anterior a casi todo eso.

⚡ Características principales de ripgrep

🚀 Extremadamente rápido

Un motor de expresiones regulares basado en autómatas finitos, escaneo SIMD de literales, mapeo de memoria y recorrido de directorios en paralelo lo hacen más rápido que grep en árboles grandes.

🙈 Respeta .gitignore

Omite por defecto los archivos ignorados, ocultos y binarios, así que los resultados son los que realmente te interesan. Puedes anularlo con -u, -uu o -uuu.

🌍 Soporte Unicode completo

Compatible con Unicode por defecto: clases de caracteres, plegado de mayúsculas, límites de palabra y grafemas funcionan correctamente, sin coste real de velocidad.

🧩 Expresiones PCRE2

-P habilita look-around y retrorreferencias. Esta compilación incluye PCRE2, así que funciona de inmediato y con JIT.

📄 Filtrado por tipo de archivo

Limita la búsqueda a un lenguaje con -t rust, exclúyelo con -T html o define tus propios tipos. Incluye más de 800 patrones.

🔁 Multilínea y sustitución

Busca a través de saltos de línea con -U, previsualiza sustituciones con -r y genera resultados estructurados con --json.

🚀 Siempre por delante de los archivos oficiales: Debian y Ubuntu congelan las versiones de los paquetes cuando publican una release; este repositorio publica las nuevas versiones upstream normalmente en cuestión de horas. Un simple apt upgrade te mantiene en la última versión.

🎯 Ejemplos de uso básico

Búsquedas del día a día:

# Buscar en el árbol de directorios actual rg 'TODO' # Sin distinguir mayúsculas, palabra completa rg -i -w 'timeout' # Mostrar 3 líneas de contexto por coincidencia rg -C 3 'panic!' # Listar solo los archivos con coincidencias rg -l 'BurntSushi'

Filtrar qué se busca:

# Solo archivos Rust rg -t rust 'unsafe' # Todo excepto HTML y CSS rg -T html -T css 'font-size' # Incluir archivos ignorados y ocultos rg -uu 'password' # Restringir con un glob rg -g '*.toml' 'version'

Más allá de grep:

# Look-around y retrorreferencias con PCRE2 rg -P '(?<=fn )\w+' src/ # Buscar a través de saltos de línea rg -U 'struct \w+ \{\n[^}]*pub' # Previsualizar una sustitución (no escribe archivos) rg 'v(\d+)\.(\d+)' -r 'v$1.$2.0' # Salida estructurada para scripts rg --json 'error' | jq -r 'select(.type=="match") | .data.path.text'
