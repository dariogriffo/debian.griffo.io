¿Qué es Fastfetch?

Fastfetch es una herramienta estilo neofetch para obtener información del sistema y mostrarla de forma hermosa en tu terminal — SO, kernel, hardware, tiempo de actividad, paquetes, entorno de escritorio y mucho más, junto al logo de tu distro. Escrita principalmente en C con el rendimiento y la personalización en mente, se convirtió en la sucesora de facto cuando neofetch fue archivado, y se desarrolla activamente con lanzamientos frecuentes.

😤 El problema de la versión del archivo: Las versiones antiguas de Ubuntu no incluyen fastfetch en absoluto, y donde el archivo lo tiene, está congelado en el momento de la importación. Upstream avanza rápido: nuevos logos, nuevos módulos de detección y correcciones para hardware nuevo llegan constantemente, así que la versión del archivo se queda atrás en silencio. Este repositorio ofrece builds actualizados de upstream manteniendo exactamente la misma disposición de archivos que el paquete oficial del archivo, por lo que el cambio es transparente en ambas direcciones.
🚀 Siempre por delante de los archivos oficiales: Debian y Ubuntu congelan las versiones de los paquetes al publicar cada versión — este repositorio publica las nuevas versiones upstream normalmente en cuestión de horas. Un simple apt upgrade te mantiene siempre en la última versión.

⚡ Características principales de Fastfetch

🏎️ Rápido por diseño

Escrito en C con detección concurrente — muestra la información completa del sistema en milisegundos, una fracción del tiempo de arranque de neofetch.

🧩 Más de 50 módulos de información

SO, kernel, CPU, GPU, memoria, discos, batería, pantalla, DE/WM, terminal, paquetes, reproductor multimedia y muchos más — cada uno configurable individualmente.

🎨 Presets incluidos

Este paquete incluye todos los presets integrados en /usr/share/fastfetch/presets/ — incluido un preset neofetch fiel para una familiaridad instantánea.

📝 Configuración en JSONC

Un único archivo de configuración JSONC documentado controla módulos, formato y logos. Genera un punto de partida con fastfetch --gen-config.

🖼️ Logos flexibles

Cientos de logos de distros integrados, además de logos en imagen mediante los protocolos sixel/kitty/iTerm, arte ASCII personalizado, o ninguno en absoluto.

🐚 Completados de shell

Completados para bash, zsh y fish más una página de manual — instalados en las rutas estándar de Debian, igual que el paquete del archivo.

🏆 ¿Por qué este repositorio en lugar de la versión del archivo?

  • Versión actual: nuevas versiones upstream en cuestión de horas, sin quedar congeladas durante toda la vida de una release de Debian
  • Misma disposición: alineado archivo por archivo con el paquete oficial de Debian — presets, completados y página de manual en los lugares estándar
  • Cambio directo: instalar desde este repositorio simplemente actualiza el paquete del archivo; al quitar el repositorio se vuelve atrás limpiamente
  • Actualizaciones automáticas: las nuevas versiones llegan con tu apt upgrade habitual
  • Multi-arch: amd64, arm64, armhf, ppc64el, s390x y riscv64

❓ Preguntas frecuentes

¿Está Fastfetch en los repositorios oficiales de Ubuntu?

Sí, pero el archivo oficial de Ubuntu trae Fastfetch 2.57.1, mientras que este repositorio ofrece Fastfetch 2.66.0, recompilado pocas horas después de cada versión upstream.

¿Cómo instalo el último Fastfetch en Ubuntu?

Añade el repositorio deb.griffo.io una sola vez con las instrucciones de arriba y ejecuta: sudo apt install fastfetch. Las nuevas versiones llegan con el sudo apt upgrade habitual.

¿Los paquetes están firmados y cómo se compilan?

Cada paquete está firmado con la clave GPG del repositorio (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) y se compila a partir de versiones upstream en repositorios públicos de GitHub que cualquiera puede inspeccionar.

¿Qué versiones de Ubuntu son compatibles?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing y 26.04 Resolute.
