¿Qué es cliamp?

cliamp es Winamp 2.x rehecho para la terminal: un editor de listas, un ecualizador gráfico, un visualizador de espectro y un sistema de temas que hace las veces de skins, todo dibujado en texto. Reproduce archivos locales (MP3, FLAC, OGG, WAV), radio por internet y pódcast, y transmite desde Spotify, Qobuz, Navidrome, Jellyfin, Emby, Plex, SoundCloud, NetEase y YouTube Music en una sola interfaz. Con --daemon, el mismo binario se convierte en un reproductor sin interfaz gobernado por un socket IPC: tu barra de estado, tus atajos y tus scripts hablan con la música que ya está sonando.

🚀 Por qué importan las últimas versiones: Casi todo cliamp es pegamento hacia servicios que no paran de moverse: Spotify, Qobuz, SoundCloud, NetEase y YouTube Music cambian sus endpoints sin avisar, y un proveedor que se rompió este mes se arregla en la versión de este mes, no en una compilación del año pasado. Por eso cliamp publica varias versiones por semana. Ni Debian ni Ubuntu lo empaquetan, así que aquí una compilación actual no es un lujo: es la única forma de tenerlo por apt.

⚡ Características principales de cliamp

🎚️ Winamp, en texto

El editor de listas, el ecualizador gráfico y la disposición clásica con vúmetros, redibujados con caracteres de bloque. 20 temas incluidos, de dracula y nord a vantablack, cambian todo el aspecto como hacían las skins.

📡 Radio y streaming

Un catálogo de radio por internet con favoritos, más Spotify, Qobuz, Navidrome, Jellyfin, Emby, Plex, SoundCloud, NetEase y YouTube Music detrás de una sola opción --provider y del asistente interactivo cliamp setup.

📊 29 visualizadores

Barras de espectro, osciloscopio, campo estéreo, lluvia de Matrix, llamas, fuegos artificiales y más, todos alimentados por la misma FFT. cliamp vis los cambia en caliente; --low-power lo apaga todo cuando importa la batería.

🎛️ Controles de audio de verdad

Ecualizador paramétrico con presets, velocidad de reproducción de 0,25× a 2×, mezcla a mono, reproducción sin huecos, cambio de dispositivo de salida y control explícito de frecuencia de muestreo, profundidad de bits y búfer.

🖥️ Demonio sin interfaz e IPC

cliamp --daemon reproduce sin TUI y responde a cliamp status, next o volume por su socket, mientras cliamp visstream emite las bandas del visualizador como NDJSON para Waybar, quickshell y cualquier cosa que lea una tubería.

🧩 Plugins Lua en un sandbox

Una API de plugins con hooks para eventos de reproducción, atajos, notificaciones, HTTP y almacenamiento, todo dentro de un sandbox. Los ejemplos incluidos cubren el archivo de «sonando ahora», webhooks y ecualización automática por género.

🚀 Siempre por delante de los archivos oficiales: Debian y Ubuntu congelan las versiones de los paquetes cuando sale una release. Este repositorio publica las nuevas versiones upstream normalmente en pocas horas. Un simple apt upgrade te mantiene en la última versión.

Cómo funciona el espejo gratuito →

🧩 O deja que lo haga extrepo. En Debian —bookworm, trixie, forky y sid— este repositorio está registrado en extrepo, la herramienta propia de Debian, que escribe el archivo de sources e instala por ti la clave de firma verificada:

sudo apt install extrepo
sudo extrepo enable griffo
sudo apt update
apt install extrepo
extrepo enable griffo
apt update

Usa griffo-free en lugar de griffo para habilitar el espejo gratuito para siempre. extrepo solo configura el archivo de sources y la clave: las credenciales de una suscripción siguen yendo en /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu no está cubierto —extrepo publica metadatos solo para las suites de Debian—, así que allí usa los comandos de arriba.

🎯 Ejemplos de uso básico

Reproducir cosas:

# Un archivo, una carpeta o la URL de un flujo
cliamp ~/Música/albums/1997
cliamp https://stream.example.org/radio.mp3

# Empezar a sonar ya, en aleatorio
cliamp ~/Música --auto-play --shuffle

# Una lista guardada, por su nombre
cliamp --playlist roadtrip

# Una URL de YouTube Music (necesita yt-dlp)
cliamp "https://music.youtube.com/watch?v=..."

# ¿Qué he escuchado?
cliamp history

Aspecto y sonido:

# Listar y cambiar de tema
cliamp theme list
cliamp theme tokyo-night

# Listar y cambiar de visualizador
cliamp vis list
cliamp vis Stereo

# Presets del ecualizador y velocidad de reproducción
cliamp eq Rock
cliamp speed 1.25

# Elegir un dispositivo de salida
cliamp --audio-device list
cliamp device "USB Audio"

# Disposición de 80 columnas para una terminal pequeña
cliamp --compact

Sin interfaz y con scripts:

# Ejecutar sin TUI, sirviendo IPC
cliamp --daemon ~/Música

# Controlar el reproductor en marcha desde cualquier sitio
cliamp toggle
cliamp next
cliamp volume -3
cliamp seek 90
cliamp status

# Alimentar una barra de estado con las bandas del visualizador
cliamp visstream | jq -c .

# Gestionar los plugins Lua
cliamp plugins list

🔧 Integraciones

cliamp se apoya a propósito en lo que tu sistema ya tiene:

  • ALSA: el audio sale por libasound, de ahí la dependencia del paquete y que funcione en un servidor pelado, sin sesión de escritorio
  • ffmpeg: recomendado, y usado para los formatos y flujos que los decodificadores integrados no cubren
  • yt-dlp: sugerido, y necesario para reproducir YouTube y YouTube Music
  • MPRIS sobre D-Bus: las teclas multimedia de tu teclado y el widget de «sonando ahora» de tu escritorio controlan cliamp como a cualquier otro reproductor
  • Waybar, quickshell y tu shell: el socket IPC y cliamp visstream alimentan barras de estado y widgets, y este paquete incluye las completaciones de bash y zsh

🚀 ¿Por qué elegir deb.griffo.io?

📊 Comparación de repositorios:
  • Debian oficial: no empaqueta cliamp, apt install cliamp falla en un sistema estándar
  • go install: actual, pero es una compilación cgo en cada máquina, que antes exige las cabeceras de desarrollo de ALSA, FLAC, Ogg y Vorbis
  • El script de instalación upstream: cómodo, pero deja un binario en ~/.local/bin a espaldas del gestor de paquetes, y luego cliamp upgrade reemplaza ese binario a su propio ritmo
  • deb.griffo.io: última versión con actualizaciones automáticas
  • ✅ La única fuente apt: cliamp no está ni en los archivos de Debian ni en los de Ubuntu; este repositorio empaqueta la compilación oficial upstream
  • ✅ El streaming se rompe y se arregla upstream: los servicios de música con los que habla cliamp cambian constantemente, así que estar en la versión de este mes marca la diferencia entre que un proveedor funcione o no
  • ✅ Actualizaciones automáticas: paquetes actualizados pocas horas después de cada versión upstream
  • ✅ Paquete completo: /usr/bin/cliamp, una página de manual, un lanzador de escritorio con el icono de la aplicación y las completaciones de bash y zsh
  • ✅ Dependencias honestas: depende de ALSA, recomienda ffmpeg y sugiere yt-dlp, así que una instalación mínima sigue siendo mínima
  • ✅ Dos arquitecturas: amd64 y arm64, el mismo paquete cubre tu portátil y tu Raspberry Pi
  • ✅ Multidistribución: funciona en Bookworm, Trixie, Forky y Sid
  • ✅ Mantenimiento fácil: comandos apt estándar para actualizar

❓ Preguntas frecuentes

¿Está cliamp en los repositorios oficiales de Debian?

No, cliamp no está empaquetado en los archivos oficiales de Debian. Este repositorio es actualmente la única fuente apt y ofrece cliamp 1.63.2.

¿Cómo instalo el último cliamp en Debian?

Añade el repositorio deb.griffo.io una sola vez con las instrucciones de arriba y ejecuta: sudo apt install cliamp. Las nuevas versiones llegan con el sudo apt upgrade habitual.

¿Los paquetes están firmados y cómo se compilan?

Cada paquete está firmado con la clave GPG del repositorio (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) y se compila a partir de versiones upstream en repositorios públicos de GitHub que cualquiera puede inspeccionar.

¿Qué versiones de Debian son compatibles?

Debian 12 Bookworm, Debian 13 Trixie, Forky y Sid.
