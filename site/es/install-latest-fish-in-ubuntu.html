¿Qué es fish?

fish es un shell de línea de comandos inteligente y fácil de usar. Sugiere comandos mientras escribes a partir de tu historial y de las completaciones, resalta la sintaxis sobre la marcha, genera completaciones con Tab a partir de las páginas de manual instaladas y prescinde de las arcanas reglas de comillas que heredaron otros shells. Todo funciona de inmediato: no hay que configurar nada para que fish resulte cómodo.

🚀 Por qué importan las últimas versiones: fish 4 se reescribió en Rust y desde entonces avanza rápido: arranque más veloz, mejores completaciones y un flujo constante de mejoras interactivas. La versión congelada en el archivo oficial es anterior a buena parte de eso.

⚡ Características principales de fish

💡 Autosugerencias

Mientras escribes, fish sugiere el resto del comando a partir de tu historial y de las completaciones. Pulsa → para aceptarla.

🎨 Resaltado de sintaxis

Los comandos se colorean mientras los escribes, así una errata o una comilla sin cerrar se ve antes de pulsar Enter.

⌨️ Completaciones desde las páginas de manual

fish analiza tus páginas de manual instaladas para generar completaciones, de modo que hasta las herramientas más oscuras completan sus opciones.

🧠 Scripting sensato

Sin sorpresas por división de palabras, sin [[ ]] frente a [ ], y con listas de verdad. Los scripts se leen como se comportan.

🔍 Historial buscable

Escribe un prefijo y pulsa ↑ para recorrer solo los comandos que coinciden, con búsqueda por subcadena incluida.

🛠️ Configurable en el navegador

fish_config abre una interfaz para prompts, colores, funciones y atajos, sin arqueología de dotfiles.

🚀 Siempre por delante de los archivos oficiales: Debian y Ubuntu congelan las versiones de los paquetes cuando publican una release; este repositorio publica las nuevas versiones upstream normalmente en cuestión de horas. Un simple apt upgrade te mantiene en la última versión.

Scripting sin trampas:

# Las listas son listas de verdad, sin división de palabras
set files *.txt; echo (count $files) archivos

# La sustitución de comandos no necesita comillas invertidas
echo "hoy es "(date +%A)

# Los condicionales se leen con naturalidad
if test -f /etc/os-release; echo encontrado; end

# Recorrer una lista
for f in *.md; echo procesando $f; end

Personalizarlo:

# Definir una función y guardarla para la próxima vez

# Las abreviaturas se expanden al escribir, a diferencia de los alias

# Añadir al PATH de forma permanente, sin editar un dotfile

# Definir una variable universal, compartida por todas las sesiones
set -U EDITOR nvim

🔧 Combina bien con

fish es ciudadano de primera clase en el conjunto de herramientas moderno:

  • starship: prompt multi-shell con soporte nativo para fish
  • zoxide: zoxide init fish y salta a directorios por frecuencia
  • fzf: incluye atajos de fish para historial y búsqueda de archivos
  • atuin: sustituye el historial de fish por una base de datos buscable y sincronizada
  • Oh My Posh: otro motor de prompts con inicializador para fish

🚀 ¿Por qué elegir deb.griffo.io?

📊 Comparativa de repositorios:
  • Ubuntu oficial: disponible, pero congelado en la versión con la que se publicó la release
  • Instalación manual: requiere una cadena de herramientas de Rust y CMake, o gestionar el binario a mano
  • deb.griffo.io: última versión con actualizaciones automáticas
  • ✅ Últimas funciones: las mejoras interactivas y de rendimiento más recientes
  • ✅ Sin configuración manual: binarios precompilados, sin necesidad de compilar con cargo
  • ✅ Actualizaciones automáticas: paquetes actualizados pocas horas después de cada versión upstream
  • ✅ Paquete completo: fish, fish_indent, fish_key_reader y las páginas de manual
  • ✅ Sin dependencias: compilación musl estática; las funciones y completaciones van embebidas, así que no hay que instalar fish-common
  • ✅ Multidistribución: funciona en Ubuntu 22.04, 24.04, 25.10 y 26.04
  • ✅ Mantenimiento sencillo: comandos apt estándar para actualizar

❓ Preguntas frecuentes

¿Está fish en los repositorios oficiales de Ubuntu?

Sí, pero el archivo oficial de Ubuntu trae fish 4.2.1, mientras que este repositorio ofrece fish 4.8.1, recompilado pocas horas después de cada versión upstream.

¿Cómo instalo el último fish en Ubuntu?

Añade el repositorio deb.griffo.io una sola vez con las instrucciones de arriba y ejecuta: sudo apt install fish. Las nuevas versiones llegan con el sudo apt upgrade habitual.

¿Los paquetes están firmados y cómo se compilan?

Cada paquete está firmado con la clave GPG del repositorio (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) y se compila a partir de versiones upstream en repositorios públicos de GitHub que cualquiera puede inspeccionar.

¿Qué versiones de Ubuntu son compatibles?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing y 26.04 Resolute.
