¿Qué es yt-dlp?

yt-dlp es un descargador de audio y vídeo por línea de comandos que soporta bastante más de mil sitios. Nació como un fork de youtube-dl (pasando por el ya inactivo youtube-dlc) y hoy es el proyecto que se mantiene activamente de los dos, con un selector de formatos mucho más potente, integración con SponsorBlock, soporte nativo para incrustar subtítulos, capítulos y metadatos, y un sistema de plugins para extractores propios.

🚀 Por qué importa la última versión: más que en cualquier otra herramienta de este repositorio. yt-dlp habla con sitios que cambian sus reproductores y sus API sin avisar, y el arreglo llega como una nueva versión de yt-dlp, a menudo en cuestión de días. A una versión congelada del archivo no solo le faltan funciones: sus extractores dejan de funcionar y las descargas fallan con errores de firma o de formato hasta que actualizas. Ir a la última versión es justamente el objetivo.

⚡ Funciones clave de yt-dlp

🌐 Miles de sitios

Más de 1.700 extractores que cubren plataformas de vídeo, cadenas de televisión, servicios de podcasts y medios de noticias, además de un extractor genérico que encuentra medios en páginas para las que nadie escribió uno.

🎚️ Selección precisa de formato

-f y -S ofrecen todo un lenguaje de expresiones sobre resolución, códec, tasa de bits y contenedor, para pedir exactamente el flujo que quieres en lugar del que venga por defecto.

🎧 Extracción de audio

-x --audio-format mp3 extrae la pista de audio y la recodifica; con --embed-thumbnail y --embed-metadata obtienes archivos etiquetados que cualquier reproductor entiende.

💬 Subtítulos y capítulos

Descarga o incrusta subtítulos en cualquier idioma disponible, conserva los automáticos y escribe las marcas de capítulo en el archivo de salida, o divídelo por ellas.

⏭️ SponsorBlock

Marca o elimina segmentos patrocinados, intros y autopromoción durante la descarga usando la base de datos de SponsorBlock, sin tocar después un editor.

🍪 Cookies y sesiones

--cookies-from-browser lee una sesión iniciada directamente de Firefox o Chromium, para que funcione el contenido privado, con restricción de edad o solo para miembros.

🚀 Siempre por delante de los archivos oficiales: Debian y Ubuntu congelan las versiones de los paquetes cuando publican una release; este repositorio publica las nuevas versiones upstream normalmente en cuestión de horas. Un simple apt upgrade te mantiene en la última versión.

🎯 Ejemplos básicos de uso

Descargas del día a día:

# Descargar un vídeo con la mejor calidad disponible
yt-dlp 'https://example.com/watch?v=...'

# El mejor MP4 hasta 1080p
yt-dlp -S 'res:1080,ext:mp4' 'URL'

# Solo audio, como MP3 etiquetado
yt-dlp -x --audio-format mp3 --embed-thumbnail --embed-metadata 'URL'

# Ver todos los formatos disponibles antes de elegir
yt-dlp -F 'URL'

Subtítulos, capítulos y patrocinios:

# Incrustar subtítulos en inglés, incluidos los automáticos
yt-dlp --embed-subs --sub-langs en --write-auto-subs 'URL'

# Escribir las marcas de capítulo en el archivo
yt-dlp --embed-chapters 'URL'

# Quitar segmentos patrocinados e intros durante la descarga
yt-dlp --sponsorblock-remove sponsor,intro 'URL'

# Bajar solo un fragmento en lugar del vídeo entero
yt-dlp --download-sections '*00:01:30-00:04:00' 'URL'

Listas de reproducción, archivos y automatización:

# Una lista entera, en carpetas ordenadas por autor
yt-dlp -o '%(uploader)s/%(title)s.%(ext)s' 'PLAYLIST_URL'

# Mantener un canal sincronizado sin volver a descargar lo antiguo
yt-dlp --download-archive seen.txt 'CHANNEL_URL'

# Contenido privado o con restricción de edad, usando una sesión del navegador
yt-dlp --cookies-from-browser firefox 'URL'

# Descargas más rápidas mediante aria2c
yt-dlp --downloader aria2c --downloader-args aria2c:'-x 8 -s 8' 'URL'

🔧 Integraciones con otras herramientas

yt-dlp es el motor de descarga que espera mucho otro software:

  • ffmpeg: unir, remuxar, extraer audio e incrustar dependen de él
  • mpv: reproduce una URL directamente pasándosela a yt-dlp al vuelo
  • aria2: descargador externo opcional para transferencias paralelas y segmentadas
  • Servidores multimedia: las bibliotecas de Jellyfin, Kodi y Navidrome se llenan a menudo con plantillas de salida de yt-dlp
  • Archivos de configuración: pon tus opciones habituales en ~/.config/yt-dlp/config y deja de reescribirlas

🚀 ¿Por qué elegir deb.griffo.io?

📊 Comparativa de repositorios:
  • Debian oficial: disponible, pero congelado en la versión con la que se publicó la release, con meses de arreglos de extractores de retraso
  • pip / pipx: actualizado, pero fuera de apt, y PEP 668 hace incómodo un pip install a nivel de sistema en Debian
  • deb.griffo.io: última versión con actualizaciones automáticas
  • ✅ Extractores que funcionan: la versión más reciente, que es lo que hace que las descargas sigan funcionando
  • ✅ Sin configuración manual: sin pip, sin virtualenv, sin autoactualizaciones escribiendo en /usr/local/bin
  • ✅ Actualizaciones automáticas: paquetes actualizados pocas horas después de cada release upstream
  • ✅ Paquete completo: la compilación oficial upstream, la página de manual yt-dlp.1 y autocompletados para bash, zsh y fish
  • ✅ Todas las arquitecturas: se publica como Architecture: all, así que amd64, arm64, armhf, riscv64 y el resto instalan el mismo paquete
  • ✅ Multidistribución: funciona en Bookworm, Trixie, Forky y Sid
  • ✅ Mantenimiento sencillo: comandos apt de siempre para actualizar

❓ Preguntas frecuentes

¿Está yt-dlp en los repositorios oficiales de Debian?

Sí, pero el archivo oficial de Debian trae yt-dlp 2025.04.30, mientras que este repositorio ofrece yt-dlp 2026.08.19, recompilado pocas horas después de cada versión upstream.

¿Cómo instalo el último yt-dlp en Debian?

Añade el repositorio deb.griffo.io una sola vez con las instrucciones de arriba y ejecuta: sudo apt install yt-dlp. Las nuevas versiones llegan con el sudo apt upgrade habitual.

¿Los paquetes están firmados y cómo se compilan?

Cada paquete está firmado con la clave GPG del repositorio (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) y se compila a partir de versiones upstream en repositorios públicos de GitHub que cualquiera puede inspeccionar.

¿Qué versiones de Debian son compatibles?

Debian 12 Bookworm, Debian 13 Trixie, Forky y Sid.
