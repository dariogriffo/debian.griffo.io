¿Qué es Serie?

Serie es una interfaz de terminal para recorrer el historial de un repositorio Git. Muestra lo mismo que git log --graph --all, pero el grafo se dibuja con el protocolo de imágenes del emulador de terminal en lugar de aproximarse con arte ASCII, así que ramas y fusiones se leen de un vistazo. Junto al grafo hay una lista de commits que se recorre y se busca, con una vista de detalle. Es deliberadamente un visor, no un cliente Git: no hace commit, ni ramas, ni push.

🚀 Por qué importa la última versión: Serie es un proyecto joven, aún antes del 1.0, y las funciones llegan en versiones normales: comandos de usuario, atajos personalizables, opciones de estilo y orden del grafo y soporte para la variante con marcadores Unicode del protocolo gráfico de Kitty. El soporte de imágenes en los terminales también se mueve, así que la compilación que dibuja bien en tu terminal suele ser la actual.

⚡ Funciones clave de Serie

🖼️ Un grafo de commits de verdad

El grafo se renderiza como imágenes mediante el protocolo de Kitty o iTerm2, así que las líneas de rama siguen siendo legibles con decenas de ramas en paralelo.

🔍 Historial con búsqueda

Una lista de commits junto al grafo que se desplaza y se busca, en lugar de paginar la salida de git log.

📄 Vista de detalle

Selecciona un commit y verás su mensaje, sus refs y su diff sin salir del grafo.

🎛️ Opciones del grafo

Orden cronológico o topológico, celdas de ancho simple o doble, aristas redondeadas o angulares: se fija en la línea de comandos o en la configuración.

⌨️ Atajos personalizables

? muestra los atajos actuales, y todos se pueden redefinir en config.toml.

🧰 Comandos de usuario

Ejecuta tus propios comandos sobre el commit seleccionado: en una vista dedicada, en segundo plano, o suspendiendo Serie para algo interactivo.

🚀 Siempre por delante de los archivos oficiales: Debian y Ubuntu congelan las versiones de los paquetes cuando publican una release; este repositorio publica las nuevas versiones upstream normalmente en cuestión de horas. Un simple apt upgrade te mantiene en la última versión.

🎯 Ejemplos básicos de uso

Recorrer el historial:

# El historial completo del repositorio actual
serie

# Solo los commits más recientes, en repositorios muy grandes
serie -n 5000

# Orden topológico en vez de cronológico
serie -o topo

# Empezar con HEAD seleccionado en lugar del commit más nuevo
serie -i head

Ajustar el grafo a tu terminal:

# Forzar un protocolo de imagen si la detección se equivoca
serie -p kitty
serie -p iterm
serie -p kitty-unicode

# Celdas del grafo más estrechas para una ventana pequeña
serie -g single

# Aristas angulares en vez de redondeadas
serie -s angular

# O el aspecto amplio y redondeado en una terminal ancha
serie -g double -s rounded

Configuración y uso diario:

# El archivo de configuración, para atajos y valores por defecto
mkdir -p ~/.config/serie
$EDITOR ~/.config/serie/config.toml

# O apuntar Serie a una configuración en otro sitio
SERIE_CONFIG_FILE=~/dotfiles/serie.toml serie

# Serie solo lee el historial: git sigue siendo tu cliente
git -C ~/src/project log --oneline -5

# Así que hacer commit sigue siendo tarea de git
git commit -v

🔧 Integraciones con otras herramientas

Serie necesita dos cosas y colabora con una tercera:

  • git: un repositorio Git normal y el binario git, que el paquete instala como dependencia
  • Tu terminal: un emulador que hable el protocolo de imágenes de Kitty o iTerm2: Ghostty, Kitty, WezTerm e iTerm2 valen
  • Archivo de configuración: $XDG_CONFIG_HOME/serie/config.toml, o lo que apunte SERIE_CONFIG_FILE
  • Comandos de usuario: asigna git diff, un editor o tu propio script a una tecla y ejecútalo sobre el commit seleccionado
  • Tu cliente git: Serie no hace commit ni push a propósito, así que convive con lazygit, GitUI o git a secas en vez de sustituirlos

🚀 ¿Por qué elegir deb.griffo.io?

📊 Comparativa de repositorios:
  • Debian oficial: no empaqueta Serie: un sistema recién instalado no tiene nada que instalar
  • cargo install --locked serie: actualizado, pero exige toolchain de Rust y compilar en cada máquina, fuera de apt
  • Tarball upstream: el binario oficial, descargado a mano en cada versión
  • deb.griffo.io: última versión con actualizaciones automáticas
  • ✅ Joven y en movimiento: los comandos de usuario, los atajos personalizables y las opciones del grafo llegaron en versiones normales: la compilación actual es otra herramienta comparada con una de hace un año
  • ✅ La única fuente apt: Serie no está ni en los archivos de Debian ni en los de Ubuntu; este repositorio empaqueta la compilación oficial upstream
  • ✅ Actualizaciones automáticas: los paquetes se actualizan pocas horas después de cada versión upstream
  • ✅ Empaquetado honesto: el binario upstream en /usr/bin/serie, con git como dependencia; upstream no publica página de manual ni completaciones, así que el paquete no se las inventa
  • ✅ Dos arquitecturas: amd64 y arm64, ambas compilaciones estáticas con musl y sin dependencias
  • ✅ Multidistribución: funciona en Bookworm, Trixie, Forky y Sid
  • ✅ Mantenimiento sencillo: actualizaciones con los comandos apt de siempre

❓ Preguntas frecuentes

¿Está Serie en los repositorios oficiales de Debian?

No, Serie no está empaquetado en los archivos oficiales de Debian. Este repositorio es actualmente la única fuente apt y ofrece Serie 0.8.1.

¿Cómo instalo el último Serie en Debian?

Añade el repositorio deb.griffo.io una sola vez con las instrucciones de arriba y ejecuta: sudo apt install serie. Las nuevas versiones llegan con el sudo apt upgrade habitual.

¿Los paquetes están firmados y cómo se compilan?

Cada paquete está firmado con la clave GPG del repositorio (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) y se compila a partir de versiones upstream en repositorios públicos de GitHub que cualquiera puede inspeccionar.

¿Qué versiones de Debian son compatibles?

Debian 12 Bookworm, Debian 13 Trixie, Forky y Sid.
