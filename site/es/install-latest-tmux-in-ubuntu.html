¿Qué es tmux?

tmux es el multiplexor de terminal: ejecuta muchas shells dentro de una sola terminal, repartidas en ventanas y paneles, y las mantiene en marcha cuando te desconectas. Una sesión de tmux vive en un proceso servidor, no en la ventana de tu terminal, así que puedes desconectarte de ella (detach), cerrar la ventana o perder la conexión ssh, y volver a conectarte más tarde con cada programa todavía en marcha justo donde lo dejaste. Dentro de una sesión abres ventanas como si fueran pestañas, divides cada una en paneles uno al lado del otro o uno encima del otro, recorres el historial y copias texto con el teclado, y lo controlas todo desde un fichero de configuración o desde scripts. tmux está escrito en C, lo inició Nicholas Marriott y tiene licencia ISC.

🚀 Por qué importa la última versión: tmux no deja de ampliar lo que puede hacer una terminal: tmux 3.8 trajo los paneles flotantes y modales, y cada versión añade opciones y corrige el manejo de la terminal. Ubuntu 26.04 incluye tmux 3.6a y Noble 3.4, cada uno congelado durante toda la vida de su versión, así que un sistema recién instalado se pierde todo lo publicado desde entonces. Este repositorio publica tmux 3.8 con el mismo nombre de paquete, así que sustituye al tmux de la distribución en el siguiente apt upgrade.

⚡ Funciones clave de tmux

🔌 Desconectar y volver a conectar

Lanza una compilación larga o un proceso servidor dentro de tmux, desconéctate, cierra la sesión o pierde la red, y vuelve a conectarte desde cualquier sitio: la sesión y todo lo que contiene siguieron en marcha mientras no estabas.

🪟 Ventanas y paneles

Cada sesión contiene ventanas como si fueran pestañas, y cada ventana se divide en paneles, así que un editor, una shell y la cola de un log comparten una sola pantalla. Los paneles se redimensionan, se amplían a pantalla completa y se reorganizan con unas pocas teclas.

🎈 Paneles flotantes y modales

tmux 3.8 añade paneles flotantes que se sitúan por encima de la disposición y paneles modales que ocupan la ventana hasta que los cierras, para un comando rápido o un selector sin tocar tus divisiones.

📋 Modo copia y portapapeles

Recorre el historial de un panel, busca en él y selecciona texto con las teclas de vi o de emacs. El texto copiado llega al portapapeles de tu escritorio mediante OSC 52, incluso desde un tmux que se ejecuta en un servidor remoto.

🖼️ Imágenes en la terminal

Esta compilación tiene activado el soporte de sixel, así que los programas que dibujan imágenes sixel las muestran dentro de un panel de tmux cuando tu terminal también admite sixel.

🧰 Programable y configurable

Cada acción es un comando: asígnalo a una tecla en ~/.tmux.conf o ejecútalo desde un script de shell para montar de una vez la disposición completa de una sesión. Los gestores de plugins y las herramientas de sesiones se basan precisamente en eso.

🚀 Siempre por delante de los archivos oficiales: Debian y Ubuntu congelan las versiones de los paquetes cuando publican una release; este repositorio publica las nuevas versiones upstream normalmente en cuestión de horas. Un simple apt upgrade te mantiene en la última versión.

🎯 Ejemplos básicos de uso

Sesiones, ventanas y paneles:

# Listar las sesiones en marcha
tmux ls

# Dentro de tmux, el prefijo es Ctrl-b, seguido de:
# c  nueva ventana        n / p   ventana siguiente / anterior
# %  dividir izq./der.    "       dividir arriba/abajo
# flechas  moverse entre paneles  z  ampliar el panel actual
# [  modo copia, para recorrer el historial y seleccionar texto
# d  desconectarse

Montar una disposición con un script:

# Una sesión desconectada con un editor a la izquierda y una shell a la derecha
tmux new-session -d -s dev -n code
tmux split-window -h -t dev:code
tmux send-keys -t dev:code.0 'nvim' Enter
tmux attach -t dev

# Recargar la configuración sin reiniciar nada
tmux source-file ~/.tmux.conf

🔧 Integraciones

Como el paquete se llama tmux, todo lo que se apoya en tmux sigue funcionando después de la actualización:

  • ssh: ejecuta tmux en el servidor, no en tu portátil, y una conexión caída solo te desconecta de la sesión; ssh -t host tmux attach la recupera
  • Plugins: tmux-plugin-manager (tpm) y los plugins que instala se cargan desde ~/.tmux.conf exactamente igual que antes
  • Herramientas de sesiones: tmuxinator y byobu usan el comando tmux, así que obtienen la nueva versión sin nada que reconfigurar
  • Portapapeles: con OSC 52, el texto copiado en el modo copia llega al portapapeles de la terminal que tienes delante, incluso a través de ssh
  • Funciones de la terminal: ncurses 6.6 se enlaza estáticamente, así que el portapapeles, el color y la forma del cursor y los subrayados con estilo se comportan igual en todas las versiones soportadas
  • systemd: compilado con soporte de systemd, como el propio paquete de la distribución, y sus sockets en /tmp quedan protegidos de la limpieza de systemd-tmpfiles de la misma manera
  • Documentación: la wiki de tmux en github.com/tmux/tmux/wiki cubre los primeros pasos, las preguntas frecuentes y todas las opciones

🚀 ¿Por qué elegir deb.griffo.io?

📊 Comparativa de repositorios:
  • Ubuntu oficial: incluye tmux 3.6a en 26.04 y 3.4 en Noble, cada uno congelado durante toda la vida de su versión
  • Descargas de upstream: tmux solo publica el código fuente, así que no hay ningún binario listo para descargar para ninguna versión
  • Compilar desde el código fuente: una toolchain de C más los paquetes de desarrollo de libevent y ncurses, un configure y un make en cada versión, y nada que lo actualice por ti
  • deb.griffo.io: última versión con actualizaciones automáticas
  • ✅ El mismo nombre de paquete que Ubuntu: el paquete se llama tmux, exactamente como en el archivo de Ubuntu, así que este repositorio actualiza el tmux de serie en su sitio con apt upgrade
  • ✅ Compilado desde cada versión etiquetada: compilado desde el tarball de la versión con soporte de systemd, jemalloc e imágenes sixel activado, como la propia compilación de la distribución, y registrado en /etc/shells
  • ✅ Un solo tmux de Jammy a Resolute: la misma versión en todas las Ubuntu soportadas, así que un único ~/.tmux.conf se comporta igual en todas tus máquinas
  • ✅ Actualizaciones automáticas: los paquetes se actualizan pocas horas después de cada versión upstream
  • ✅ Dos arquitecturas: amd64 y arm64 en todas las versiones, así que el mismo tmux funciona en servidores, portátiles y placas ARM como la Raspberry Pi
  • ✅ Multidistribución: funciona en Ubuntu 22.04, 24.04, 25.10 y 26.04
  • ✅ Mantenimiento sencillo: actualizaciones con los comandos apt de siempre

❓ Preguntas frecuentes

¿Está tmux en los repositorios oficiales de Ubuntu?

Sí, pero el archivo oficial de Ubuntu trae tmux 3.6a, mientras que este repositorio ofrece tmux 3.8, recompilado pocas horas después de cada versión upstream.

¿Cómo instalo el último tmux en Ubuntu?

Añade el repositorio deb.griffo.io una sola vez con las instrucciones de arriba y ejecuta: sudo apt install tmux. Las nuevas versiones llegan con el sudo apt upgrade habitual.

¿Los paquetes están firmados y cómo se compilan?

Cada paquete está firmado con la clave GPG del repositorio (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) y se compila a partir de versiones upstream en repositorios públicos de GitHub que cualquiera puede inspeccionar.

¿Qué versiones de Ubuntu son compatibles?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing, 26.04 Resolute y 26.10 Stonking.
