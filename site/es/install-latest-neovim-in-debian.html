¿Qué es Neovim?

Neovim es un editor de texto hiperextensible basado en Vim que refactoriza el clásico código de Vim para el desarrollo moderno. Incluye un cliente integrado del Language Server Protocol, análisis de sintaxis y comprensión del código gracias a Treesitter, un motor de tareas asíncrono y scripting en Lua de primera clase — de modo que los plugins y la configuración son rápidos, programables y fáciles de mantener.

El Debian oficial trixie trae Neovim 0.10.4, y Bookworm se queda mucho más atrás. Este repositorio ofrece Neovim 0.12.4 por igual en Bookworm, Trixie, Forky y Sid.

⚡ Características principales de Neovim

🌙 Configuración en Lua

Configura y programa el editor en Lua con una API rica y estable. Un lenguaje de programación de verdad en lugar de Vimscript para configuraciones rápidas y fáciles de mantener.

🔌 LSP integrado

Un cliente nativo del Language Server Protocol aporta autocompletado, diagnósticos, ir a la definición y refactorización a cualquier lenguaje que tenga un servidor.

🌳 Treesitter

Análisis incremental para un resaltado de sintaxis preciso, indentación y selecciones estructurales — mucho más allá del resaltado basado en expresiones regulares.

🚀 Asincronía y plugins

Un bucle de eventos y tareas no bloqueante mantiene la interfaz fluida, impulsando un enorme ecosistema de plugins modernos en Lua e interfaces remotas.

🚀 Siempre por delante de los archivos oficiales: Debian y Ubuntu congelan las versiones de los paquetes al publicar cada versión — este repositorio publica las nuevas versiones upstream normalmente en cuestión de horas. Un simple apt upgrade te mantiene siempre en la última versión.

🚀 ¿Por qué elegir deb.griffo.io?

⚠️ Estado en el Debian oficial: Neovim sí está en los archivos oficiales de Debian, pero congelado — trixie trae 0.10.4 y las versiones más antiguas se quedan aún más atrás. deb.griffo.io sigue el upstream y ofrece 0.12.4 hoy mismo.
  • ✅ Acceso inmediato: Consigue Neovim 0.12.4 ahora mismo, sin esperar a la próxima versión de Debian
  • ✅ Últimas características: Las mejoras más recientes de LSP, Treesitter y la API de Lua en cuanto se publican
  • ✅ Actualizaciones automáticas: Paquetes recompilados pocas horas después de cada versión upstream
  • ✅ Binario oficial de upstream: Reempaquetado a partir de la versión precompilada oficial, no una recompilación aparte
  • ✅ Multidistribución: Funciona en Bookworm, Trixie, Forky y Sid
  • ✅ Sin compilación: Binario precompilado, sin necesidad de compilar desde el código fuente

❓ Preguntas frecuentes

¿Está Neovim en los repositorios oficiales de Debian?

Sí, pero el archivo oficial de Debian trae Neovim 0.10.4, mientras que este repositorio ofrece Neovim 0.12.4, recompilado pocas horas después de cada versión upstream.

¿Cómo instalo el último Neovim en Debian?

Añade el repositorio deb.griffo.io una sola vez con las instrucciones de arriba y ejecuta: sudo apt install neovim. Las nuevas versiones llegan con el sudo apt upgrade habitual.

¿Los paquetes están firmados y cómo se compilan?

Cada paquete está firmado con la clave GPG del repositorio (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) y se compila a partir de versiones upstream en repositorios públicos de GitHub que cualquiera puede inspeccionar.

¿Qué versiones de Debian son compatibles?

Debian 12 Bookworm, Debian 13 Trixie, Forky y Sid.
