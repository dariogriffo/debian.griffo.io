¿Qué es Rust?

Rust es un lenguaje de programación de sistemas centrado en la velocidad, la seguridad de memoria y la concurrencia fiable, y este paquete es la toolchain oficial estable de Rust: los binarios de static.rust-lang.org, exactamente lo que instala rustup, reempaquetados sin modificar. Cada compilación se verifica antes de empaquetarse: la firma GPG del manifiesto de la versión contra la clave de firma de versiones de Rust (huella 108F 6620 5EAE B0AA A8DD 5E1C 85AB 96E6 FA1B E5FE) y el SHA-256 de cada tarball contra ese manifiesto. Un solo paquete, rust-stable, te da rustc, cargo, rustdoc, rustfmt, clippy, rust-analyzer y la biblioteca estándar, y se actualiza con cada versión estable, cada seis semanas más las versiones de corrección. Debian y Ubuntu empaquetan el mismo compilador como rustc; el nombre distinto aquí es intencionado, como se explica más abajo.

🚀 Por qué importan las últimas versiones: Rust publica una versión estable nueva cada seis semanas y los crates avanzan con ella: las nuevas funciones del lenguaje y APIs de la biblioteca se usan en cuanto se estabilizan, y un crate que declara un rust-version más reciente no compila con un compilador más antiguo. Ubuntu empaqueta Rust como rustc y cargo, y 26.04 está congelado en rustc 1.93.1ubuntu1, así que un sistema recién instalado se queda más atrás con cada versión. Este repositorio ofrece Rust 1.100.0 como rust-stable, una toolchain completa que ocupa el lugar de rustc y cargo de la distribución y avanza con cada apt upgrade.

⚡ Funciones clave de Rust

🦀 La toolchain completa

rustc, cargo, rustdoc, rustfmt, clippy (cargo clippy), rust-analyzer, los envoltorios rust-gdb y rust-lldb y la biblioteca estándar para tu máquina, todo de la misma versión.

🔏 Binarios oficiales verificados

Exactamente los binarios que rustup descargaría de static.rust-lang.org, reempaquetados sin modificar. La compilación comprueba la firma GPG del manifiesto y el SHA-256 de cada tarball antes de empaquetar nada.

👥 Una instalación para todos los usuarios

Una única toolchain para todo el sistema, compartida por todos los usuarios de la máquina, en lugar de un ~/.rustup en cada directorio personal, y actualizada por apt junto con el resto del sistema.

🧩 Siempre juntos, nunca mezclados

rustc, cargo, la biblioteca estándar, clippy y rustfmt son una familia con versiones atadas. Sustituir solo rustc juntaría un compilador nuevo con una std antigua, por eso rust-stable mueve siempre la toolchain entera.

🎯 Targets extra como paquetes

Binarios estáticos para Linux con rust-stable-std-musl, que trae su propio musl, y WebAssembly con wasm32-unknown-unknown, wasm32-wasip1 y wasm32-wasip2, cada uno a un apt install de distancia.

📚 Código fuente y documentación offline

rust-stable-src añade el código fuente de la biblioteca estándar que lee rust-analyzer, y rust-stable-doc deja en disco The Book, la documentación de la API de std y el libro de Cargo para leerlos sin conexión.

🚀 Siempre por delante de los archivos oficiales: Debian y Ubuntu congelan las versiones de los paquetes cuando publican una release; este repositorio publica las nuevas versiones upstream normalmente en cuestión de horas. Un simple apt upgrade te mantiene en la última versión.

🔧 Integraciones

La toolchain se instala como cualquier otro paquete del sistema, así que el resto de tu entorno la encuentra sin configuración:

  • Estructura: todo vive en /usr/lib/rust-stable con su propio LLVM incluido, y los comandos se enlazan en /usr/bin, así que están en el PATH de todos los usuarios sin tocar el perfil de la shell
  • Enlazado: el paquete depende de un compilador de C (gcc o clang) y de libc6-dev, que rustc usa para enlazar, así que cargo build funciona nada más instalar
  • Editores: rust-analyzer forma parte del paquete, así que cualquier editor con cliente de language server puede usarlo; rust-stable-src le permite navegar dentro de la biblioteca estándar
  • Depuradores: rust-gdb y rust-lldb arrancan gdb o lldb con los pretty-printers de Rust cargados, para que los tipos de Rust se vean legibles
  • Shell: las páginas de manual de cargo y sus autocompletados para bash y zsh se instalan con el paquete
  • Targets cruzados: las bibliotecas estándar de musl y WebAssembly son paquetes aparte, que se añaden con apt install en lugar de rustup target add
  • Documentación: rust-stable-doc instala la documentación HTML en /usr/share/doc/rust-stable-doc/html, y todo está también en línea en doc.rust-lang.org

🚀 ¿Por qué elegir deb.griffo.io?

📊 Comparativa de repositorios:
  • Ubuntu oficial: empaqueta Rust como rustc y cargo, versión 1.93.1ubuntu1 en 26.04, congelada durante toda la vida de la versión
  • rustup: los mismos binarios oficiales, instalados por separado para cada usuario en ~/.rustup y actualizados con rustup update en vez de con apt
  • Compilar desde el código fuente: arrancar rustc con un compilador anterior y compilar su LLVM, una compilación larga y pesada
  • deb.griffo.io: última versión con actualizaciones automáticas
  • ✅ Una toolchain coherente: el paquete se llama rust-stable y no rustc porque el compilador, cargo, std, clippy y rustfmt tienen que venir de la misma versión, así que se publican y actualizan juntos
  • ✅ Los binarios oficiales: exactamente lo que rustup instala desde static.rust-lang.org, sin modificar, verificado al compilar contra la clave de firma de versiones de Rust y las sumas SHA-256 del manifiesto
  • ✅ Paquete completo: la toolchain en /usr/lib/rust-stable con su propio LLVM, comandos en /usr/bin, páginas de manual y autocompletado de cargo, con rust-stable-src recomendado y la documentación y los targets musl y WebAssembly como paquetes opcionales
  • ✅ Actualizaciones automáticas: los paquetes se actualizan pocas horas después de cada versión upstream
  • ✅ Dos arquitecturas: amd64 y arm64 en todas las versiones, incluida la Raspberry Pi 4 y 5 con un sistema de 64 bits
  • ✅ Multidistribución: funciona en Ubuntu 22.04, 24.04, 25.10 y 26.04
  • ✅ Mantenimiento sencillo: actualizaciones con los comandos apt de siempre

❓ Preguntas frecuentes

¿Está Rust en los repositorios oficiales de Ubuntu?

Sí, pero el archivo oficial de Ubuntu trae Rust 1.93.1ubuntu1, mientras que este repositorio ofrece Rust 1.100.0, recompilado pocas horas después de cada versión upstream.

¿Cómo instalo el último Rust en Ubuntu?

Añade el repositorio deb.griffo.io una sola vez con las instrucciones de arriba y ejecuta: sudo apt install rust-stable. Las nuevas versiones llegan con el sudo apt upgrade habitual.

¿Los paquetes están firmados y cómo se compilan?

Cada paquete está firmado con la clave GPG del repositorio (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) y se compila a partir de versiones upstream en repositorios públicos de GitHub que cualquiera puede inspeccionar.

¿Qué versiones de Ubuntu son compatibles?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing, 26.04 Resolute y 26.10 Stonking.
