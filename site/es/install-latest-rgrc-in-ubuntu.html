¿Qué es rgrc?

rgrc, el Rusty Generic Colouriser, es una reescritura rápida en Rust del clásico grc. Ponlo delante de un comando y colorea su salida: ping, df, ls, ps, docker, journalctl, kubectl, dig, mount, ip, netstat y unos 97 comandos en total, cada uno guiado por un archivo de configuración al estilo grc/grcat. Las configuraciones van incrustadas en el binario, así que funciona en cuanto se instala, y también colorea tuberías (df -h | rgrc -c df). Los alias de shell que colorean automáticamente los comandos habituales son una sola línea en tu ~/.bashrc o ~/.zshrc. El paquete y el comando se llaman rgrc.

🚀 Por qué importa la última versión: rgrc es joven y avanza rápido, con nuevas configuraciones de comandos, opciones y correcciones en cada versión. No está en los archivos de Debian ni de Ubuntu (Debian solo trae el grc original en Python), y upstream publica binarios y un .deb en las releases de GitHub pero ningún repositorio apt, así que una copia instalada a mano nunca se actualiza sola.

⚡ Funciones clave de rgrc

🌈 Unos 97 comandos

Herramientas de sistema, red, contenedores y logs listas para usar: df, free, ps, mount, ping, dig, ip, ss, docker, kubectl, journalctl y muchas más.

⚡ Binario nativo y rápido

Una reescritura en Rust del grc de Python, sin intérprete que arrancar por cada comando que coloreas. El paquete es un único binario enlazado estáticamente.

📦 Configuraciones incluidas

Las configuraciones de comandos van incrustadas en el binario y además se instalan en /usr/share/rgrc, con el mapeo de comandos en /etc/rgrc.conf.

🔀 Funciona con tuberías

Colorea la salida que ya tienes: df -h | rgrc -c df elige una configuración por nombre y colorea lo que llega por la entrada estándar.

🐚 Alias de shell

eval "$(rgrc --aliases)" hace que ping, df o docker salgan en color sin escribir rgrc. Excluye cualquier comando con --except.

🛠️ Reglas al estilo grc

Las reglas usan el conocido formato grc/grcat de líneas regexp= y colours=, y las tuyas van en ~/.config/rgrc/.

🚀 Siempre por delante de los archivos oficiales: Debian y Ubuntu congelan las versiones de los paquetes cuando publican una release; este repositorio publica las nuevas versiones upstream normalmente en cuestión de horas. Un simple apt upgrade te mantiene en la última versión.

# Elige una configuración por nombre y colorea la entrada estándar

Elegir alias y colores:

# Alias para todos los comandos soportados excepto ls y ps
eval "$(rgrc --aliases --except ls,ps)"

# Forzar los colores cuando la salida va a un paginador
rgrc --color on ping -c 4 debian.org | less -R

🔧 Integraciones con otras herramientas

rgrc encaja en un flujo de trabajo de terminal existente:

  • Shells: el paquete instala autocompletado para bash, zsh y fish, y los alias funcionan en cualquier shell que pueda cargarlos con eval
  • grc: el grc de Python de Debian puede seguir instalado: los comandos son grc y rgrc, y rgrc lee el mismo formato de reglas grc/grcat
  • Contenedores: docker ps, docker images y kubectl get pods se leen de un vistazo
  • Logs: salida de journalctl en la que los errores y avisos destacan a primera vista
  • Diagnóstico de red: ping, traceroute, dig, ss, netstat e ip con direcciones, latencias y estados en color

🚀 ¿Por qué elegir deb.griffo.io?

📊 Comparativa de repositorios:
  • Ubuntu oficial: no empaquetado: rgrc no está ni en main ni en universe en ninguna versión de Ubuntu; Ubuntu solo trae el grc original en Python
  • Binario de upstream: actual el día que lo descargas, pero upstream publica binarios y un .deb en las releases de GitHub sin repositorio apt, así que apt upgrade nunca ve una versión nueva y cada release es otra descarga manual
  • Compilar con cargo install: necesita una toolchain de Rust y recompilar en cada actualización, y deja fuera la página de manual, el autocompletado y los archivos de configuración
  • deb.griffo.io: última versión con actualizaciones automáticas
  • ✅ Sin dependencias en tiempo de ejecución: rgrc es un único binario de Rust enlazado estáticamente y sin dependencias, y se instala junto al grc de Python de Debian
  • ✅ Actualizaciones apt para las releases de upstream: upstream publica binarios y un .deb pero ningún repositorio; aquí cada release llega a un repositorio apt firmado con GPG, con una compilación para cada suite de Debian y Ubuntu
  • ✅ Actualizaciones automáticas: los paquetes se actualizan pocas horas después de cada versión upstream
  • ✅ Paquete completo: /usr/bin/rgrc, la página de manual rgrc(1), /etc/rgrc.conf, las 97 configuraciones de comandos en /usr/share/rgrc y autocompletado para bash, zsh y fish
  • ✅ Tres arquitecturas: amd64, arm64 y armhf, así portátiles, servidores y placas Raspberry Pi tienen el mismo rgrc
  • ✅ Multidistribución: funciona en Ubuntu 22.04, 24.04, 25.10 y 26.04
  • ✅ Mantenimiento sencillo: actualizaciones con los comandos apt de siempre

❓ Preguntas frecuentes

¿Está rgrc en los repositorios oficiales de Ubuntu?

No, rgrc no está empaquetado en los archivos oficiales de Ubuntu. Este repositorio es actualmente la única fuente apt y ofrece rgrc 0.6.35.

¿Cómo instalo el último rgrc en Ubuntu?

Añade el repositorio deb.griffo.io una sola vez con las instrucciones de arriba y ejecuta: sudo apt install rgrc. Las nuevas versiones llegan con el sudo apt upgrade habitual.

¿Los paquetes están firmados y cómo se compilan?

Cada paquete está firmado con la clave GPG del repositorio (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) y se compila a partir de versiones upstream en repositorios públicos de GitHub que cualquiera puede inspeccionar.

¿Qué versiones de Ubuntu son compatibles?
