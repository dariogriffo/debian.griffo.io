¿Qué es jjui?

jjui es una interfaz de usuario de terminal para Jujutsu, el sistema de control de versiones compatible con Git que se maneja con el comando jj. Ejecútalo dentro de un repositorio jj y muestra el grafo de revisiones, y te deja trabajar directamente sobre él: cambiar el revset con autocompletado para elegir qué se muestra, hacer rebase de una revisión o de una rama entera, hacer squash, split y abandon de revisiones, mover bookmarks, abrir una revisión para ver sus ficheros y diffs y restaurar ficheros uno a uno, previsualizar la salida de jj show y jj diff junto al grafo, hacer push y fetch desde un menú Git, y recorrer o restaurar el registro de operaciones. Todo funciona con el teclado o con el ratón. jjui está escrito en Go por Ibrahim Dursun y tiene licencia MIT.

🚀 Por qué importa la última versión: jjui avanza al ritmo de Jujutsu: las versiones de jj cambian comandos y salida, y jjui las sigue mientras añade operaciones, mejoras del autocompletado y correcciones en casi cada versión. Debian no empaqueta jjui en absoluto, así que sin este repositorio la única forma de estar al día es descargar a mano cada nueva versión. Aquí basta un apt upgrade normal, que actualiza a la vez jjui y el jj del que depende.

⚡ Funciones clave de jjui

🌳 El grafo de revisiones, en vivo

jjui arranca con el mismo grafo que imprime jj log, pero puedes recorrerlo, seleccionar revisiones y actuar sobre ellas, y el grafo se redibuja tras cada cambio.

🔎 Revsets con autocompletado

Edita el revset de la parte superior de la pantalla para elegir qué revisiones se muestran; las funciones y los alias se completan mientras escribes, así que no tienes que recordar el lenguaje de revsets.

✂️ Rebase, squash, split, abandon

Haz rebase de una sola revisión o de una rama entera sobre otra, fusiona una revisión con su padre (squash), pártela en dos (split), descártala (abandon) o mueve un bookmark, todo desde el grafo, y ve el resultado al instante.

📄 Ficheros, diffs y vistas previas

Abre una revisión para listar los ficheros que cambia, leer sus diffs y restaurar ficheros de forma interactiva, o mantén un panel de vista previa con la salida de jj show o jj diff de lo que tengas seleccionado.

🔄 Menú Git y registro de operaciones

Haz push y fetch desde un menú Git sin salir del grafo, y recorre el registro de operaciones para ver qué cambió y devolver el repositorio a un estado anterior.

🖱️ Teclado, ratón, Lua y temas

Cada acción tiene un atajo de teclado (pulsa ? para verlos todos) y el ratón también funciona. Los scripts en Lua añaden tus propias acciones y los temas cambian los colores.

🚀 Siempre por delante de los archivos oficiales: Debian y Ubuntu congelan las versiones de los paquetes cuando publican una release; este repositorio publica las nuevas versiones upstream normalmente en cuestión de horas. Un simple apt upgrade te mantiene en la última versión.

Cómo funciona el espejo gratuito →

🧩 Sobre la opción extrepo. extrepo es la herramienta propia de Debian para repositorios externos: escribe el archivo de sources e instala la clave de firma por ti, comprobándola antes contra metadatos firmados. Este repositorio está registrado en ella como griffo, y el espejo gratuito para siempre como griffo-free, así que en Debian (bookworm, trixie, forky y sid) los comandos de arriba son toda la configuración.

extrepo solo configura el archivo de sources y la clave: las credenciales de una suscripción siguen yendo en /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu no está cubierto, porque extrepo publica metadatos solo para las suites de Debian: allí usa los comandos con sudo o como root.

🔧 Integraciones

jjui es una interfaz para jj, así que encaja allí donde jj ya lo hace:

  • Jujutsu: cada acción ejecuta el comando jj, así que jjui ve el mismo repositorio, la misma configuración y los mismos alias de revset que el propio jj; el paquete depende de jujutsu (>= 0.37), y deb.griffo.io empaqueta Jujutsu para todas las versiones, así que apt lo instala junto con jjui
  • Remotos Git: en un repositorio colocado, el push y el fetch del menú Git van a tus remotos Git de siempre, con las credenciales que ya usas
  • Tu editor: jjui -config abre el fichero de configuración en $EDITOR, donde viven los atajos de teclado, el tema y las acciones personalizadas
  • Scripts en Lua: escribe tus propias acciones en Lua y asígnalas a teclas, para los comandos jj que usas a menudo
  • Temas: los colores del grafo, de la selección y de los paneles vienen de un tema que puedes cambiar o escribir tú mismo
  • Ratón: haz clic para seleccionar revisiones y desplázate por el grafo y la vista previa, en cualquier terminal con soporte de ratón
  • Documentación: upstream no publica página man, así que la guía completa está en idursun.github.io/jjui, y ? dentro de jjui lista los atajos de teclado

🚀 ¿Por qué elegir deb.griffo.io?

📊 Comparativa de repositorios:
  • Debian oficial: no empaqueta jjui, apt install jjui falla en un sistema recién instalado
  • Descargas de upstream: un zip con un único binario en la página de releases de GitHub, que copias a mano en tu PATH, que hay que volver a bajar en cada versión, y jj instalado aparte
  • Compilar desde el código fuente: una toolchain de Go y un go install en cada versión, y jj todavía por instalar de otra forma
  • deb.griffo.io: última versión con actualizaciones automáticas
  • ✅ La única fuente apt: jjui no está ni en el archivo de Debian ni en el de Ubuntu; este repositorio empaqueta la versión oficial de upstream
  • ✅ jj viene incluido: el paquete depende de jujutsu (>= 0.37), el mínimo de upstream, y deb.griffo.io empaqueta Jujutsu para todas las versiones, así que sudo apt install jjui instala un jj reciente en el mismo paso
  • ✅ Empaquetado honesto: el binario de upstream en /usr/bin/jjui: upstream no publica página man ni autocompletado para la shell, así que el paquete no se inventa ninguno
  • ✅ Actualizaciones automáticas: los paquetes se actualizan pocas horas después de cada versión upstream
  • ✅ Dos arquitecturas: amd64 y arm64 en todas las versiones, así que el mismo jjui funciona en portátiles, servidores y placas ARM como la Raspberry Pi
  • ✅ Multidistribución: funciona en Bookworm, Trixie, Forky y Sid
  • ✅ Mantenimiento sencillo: actualizaciones con los comandos apt de siempre

❓ Preguntas frecuentes

¿Está jjui en los repositorios oficiales de Debian?

No, jjui no está empaquetado en los archivos oficiales de Debian. Este repositorio es actualmente la única fuente apt y ofrece jjui 0.10.12.

¿Cómo instalo el último jjui en Debian?

Añade el repositorio deb.griffo.io una sola vez con las instrucciones de arriba y ejecuta: sudo apt install jjui. Las nuevas versiones llegan con el sudo apt upgrade habitual.

¿Los paquetes están firmados y cómo se compilan?

Cada paquete está firmado con la clave GPG del repositorio (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) y se compila a partir de versiones upstream en repositorios públicos de GitHub que cualquiera puede inspeccionar.

¿Qué versiones de Debian son compatibles?

Debian 12 Bookworm, Debian 13 Trixie, Forky y Sid.
