What is tmux?

tmux is the terminal multiplexer: it runs many shells inside one terminal, split into windows and panes, and keeps them running after you disconnect. A tmux session lives in a server process, not in your terminal window, so you can detach from it, close the window or lose the ssh connection, and attach to it again later with every program still running exactly where you left it. Inside a session you open windows like tabs, split each one into panes side by side or on top of each other, scroll back and copy text with the keyboard, and drive all of it from a config file or from scripts. tmux is written in C, started by Nicholas Marriott, and is ISC licensed.

🚀 Why Latest Versions Matter: tmux keeps adding to what a terminal can do: tmux 3.8 brought floating and modal panes, and each release adds options and fixes terminal handling. Ubuntu 26.04 ships tmux 3.6a and Noble 3.4, each frozen for the life of its release, so a stock system misses everything released since. This repository ships tmux 3.8 under the same package name, so it replaces the distribution's tmux in place on the next apt upgrade.

⚡ Key Features of tmux

🔌 Detach and Reattach

Start a long build or a server process inside tmux, detach, log out or lose the network, and attach again from anywhere: the session and everything in it kept running while you were gone.

🪟 Windows and Panes

Each session holds windows like tabs, and each window splits into panes, so an editor, a shell and a log tail share one screen. Panes resize, zoom to full size and rearrange with a few keys.

🎈 Floating and Modal Panes

tmux 3.8 adds floating panes that sit above the layout and modal panes that take over the window until you close them, for a quick command or a picker without disturbing your splits.

📋 Copy Mode and Clipboard

Scroll back through a pane's history, search it and select text with vi or emacs keys. Copied text reaches your desktop clipboard through OSC 52, even from a tmux running on a remote server.

🖼️ Images in the Terminal

This build has sixel support enabled, so programs that draw sixel images show them inside a tmux pane when your terminal supports sixel too.

🧰 Scriptable and Configurable

Every action is a command: bind it to a key in ~/.tmux.conf, or run it from a shell script to build a whole session layout in one go. Plugin managers and session tools build on exactly that.

🚀 Always ahead of the official archives: Debian and Ubuntu freeze package versions when a release ships. This repository publishes new upstream releases typically within hours. A simple apt upgrade keeps you on the latest version.

🎯 Basic Usage Examples

Sessions, windows and panes:

# List the running sessions
tmux ls

# Inside tmux, the prefix is Ctrl-b, followed by:
# c  new window          n / p   next / previous window
# %  split left/right    "       split top/bottom
# arrows  move between panes     z  zoom the current pane
# [  copy mode, to scroll back and select text
# d  detach

Scripting a layout:

# A detached session with an editor on the left and a shell on the right
tmux new-session -d -s dev -n code
tmux split-window -h -t dev:code
tmux send-keys -t dev:code.0 'nvim' Enter
tmux attach -t dev

# Reload your configuration without restarting anything
tmux source-file ~/.tmux.conf

Keeping it current:

# tmux updates with the rest of the system
sudo apt update && sudo apt upgrade

# Which version is installed, and which is the newest available
apt policy tmux

# Running sessions keep the old server; exit them or stop it to switch
tmux kill-server

🔧 Tool Integrations

Because the package is called tmux, everything built on tmux keeps working after the upgrade:

  • ssh: run tmux on the server, not on your laptop, and a dropped connection only detaches you; ssh -t host tmux attach picks the session up again
  • Plugins: tmux-plugin-manager (tpm) and the plugins it installs load from ~/.tmux.conf exactly as before
  • Session tools: tmuxinator and byobu drive the tmux command, so they get the new version with nothing to reconfigure
  • Clipboard: with OSC 52, text copied in copy mode reaches the clipboard of the terminal you are sitting at, even through ssh
  • Terminal features: ncurses 6.6 is linked statically, so the clipboard, cursor colour and style, and styled underlines behave the same on every supported release
  • systemd: built with systemd support, like the distribution's own package, and its sockets in /tmp are kept safe from systemd-tmpfiles cleanup the same way
  • Documentation: the tmux wiki at github.com/tmux/tmux/wiki covers getting started, the FAQ and every option

❓ Frequently asked questions

Is tmux in the official Ubuntu repositories?

Yes, but the official Ubuntu archive ships tmux 3.6a, while this repository serves tmux 3.8, rebuilt within hours of each upstream release.

How do I install the latest tmux on Ubuntu?

Add the deb.griffo.io repository once using the instructions above, then run: sudo apt install tmux. New releases arrive through the normal sudo apt upgrade.

Are the packages signed and how are they built?

Every package is signed with the repository's GPG key (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) and built from upstream releases in public GitHub packaging repositories that anyone can inspect.

Which Ubuntu releases are supported?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing, 26.04 Resolute and 26.10 Stonking.
