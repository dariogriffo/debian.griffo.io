什么是 rclone？

rclone 是一个面向云存储的命令行文件管理工具。它支持七十多家提供商——S3 及所有兼容 S3 的服务、Google Drive、Dropbox、OneDrive 与 SharePoint、Backblaze B2、Google Cloud Storage、Swift、SFTP、FTP、WebDAV 以及纯 HTTP——都使用同一套命令。它按校验和复制、同步和移动文件，可以把任意远端挂载为文件系统，通过半打协议对外提供服务，还能在两个远端之间直接传输，不必先落到本地。

🚀 为什么最新版本很重要： rclone 对接的是那些不会征求你意见就变更的 API。服务商会更换认证流程、下线接口、新增区域，而修复只会出现在下一个 rclone 版本里；新的存储后端和整套子命令也同样如此。官方源里的版本比这些工作落后好几年，“去年还能用”正是最新版 rclone 要避免的故障。

☁️ 七十多种后端

兼容 S3 的对象存储、消费级网盘、企业套件，以及 SFTP、FTP、WebDAV、HTTP 等传统协议，全都用同一套命令。

🔁 带校验和的同步

copy、sync 与 move 会比较大小、时间和哈希，--dry-run 会在动手之前告诉你到底会改动什么。

🗂️ 挂载为文件系统

rclone mount 把远端挂到某个目录并带 VFS 缓存，普通程序即可直接读写。

🌐 再对外提供

rclone serve 可通过 HTTP、WebDAV、SFTP、FTP、DLNA、NFS 或 S3 接口发布任意远端，非常适合只会一种协议的设备。

🔐 客户端加密

crypt 叠加层在上传前加密文件内容和文件名，而保存令牌的配置文件本身也可以加密。

⚡ 为大批量而生

并行传输与校验、带宽时段表、过滤规则，以及不经过本机中转的服务端直传。

🎯 基本用法示例

复制与同步：

# 上传一个目录，并显示进度
rclone copy -P ~/Documents mydrive:Documents

# 让目标与源保持一致——请务必先试运行

rclone copy s3:bucket/data b2:backup/data

调优、过滤与加密：

# 面对大量小文件时提高并行度

# 设置带宽时段表，别让备份占满工作时间

# 使用过滤规则，而不是整个复制
rclone copy src: dst: --exclude "*.tmp" --filter-from filters.txt

# 为已有远端套上客户端加密
rclone config create secret crypt remote=mydrive:vault

🔧 工具集成

rclone 正是其他工具所依赖的那块基石：

  • FUSE：fuse3（或 fuse）能让 rclone mount 变成真正的目录，供只认文件的程序使用
  • systemd：每个挂载或 serve 一个单元，再用定时器执行每夜的 sync，这是让它无人值守运行的常见做法
  • 备份工具：restic 之类可以把 rclone 当作远端，从而立刻获得 rclone 支持的全部后端
  • 远程控制：rclone rcd --rc-web-gui 提供 HTTP API 和浏览器界面，适合长时间传输
  • 配置文件：~/.config/rclone/rclone.conf 保存所有远端，并且可以加密，凭据不必以明文存放
