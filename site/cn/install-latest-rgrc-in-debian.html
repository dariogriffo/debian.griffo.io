什么是 rgrc？

rgrc，即 Rusty Generic Colouriser，是经典 grc 的快速 Rust 重写版。把它放在一条命令前面，它就会为这条命令的输出着色：ping、df、ls、ps、docker、journalctl、kubectl、dig、mount、ip、netstat 等，总共约 97 个命令，每个命令都由一个 grc/grcat 风格的配置文件驱动。配置文件内嵌在二进制文件中，安装后即可使用；它也能为管道着色（df -h | rgrc -c df）。只需在 ~/.bashrc 或 ~/.zshrc 中加一行，就能启用自动为常用命令着色的 shell 别名。软件包和命令都叫 rgrc。

🚀 为什么最新版本很重要： rgrc 是一个年轻且迭代很快的项目，每个版本都会带来新的命令配置、新选项和修复。Debian 和 Ubuntu 的官方软件源中完全没有它（Debian 只提供原版 Python grc）；上游在 GitHub releases 中发布二进制文件和 .deb，但没有 apt 仓库，所以手动安装的副本永远不会自动更新。

⚡ rgrc 的主要特性

🌈 约 97 个命令

系统、网络、容器和日志工具开箱即用：df、free、ps、mount、ping、dig、ip、ss、docker、kubectl、journalctl 等等。

⚡ 快速的原生二进制

Python 版 grc 的 Rust 重写，每次着色都无需启动解释器。整个软件包就是一个静态链接的二进制文件。

📦 内置配置

命令配置内嵌在二进制文件中，同时安装在 /usr/share/rgrc，命令映射位于 /etc/rgrc.conf。

🔀 支持管道

为已有的输出着色：df -h | rgrc -c df 按名称选择配置，为标准输入中的内容着色。

🐚 Shell 别名

eval "$(rgrc --aliases)" 让 ping、df 或 docker 无需输入 rgrc 就自动着色。可用 --except 排除任意命令。

🛠️ grc 风格规则

规则使用熟悉的 grc/grcat 格式，由 regexp= 和 colours= 行组成，自定义规则放在 ~/.config/rgrc/。

🚀 始终领先于官方软件源： Debian 和 Ubuntu 在发布时冻结软件包版本，而本仓库通常在上游发布后数小时内就发布新版本。一条简单的 apt upgrade 就能让你保持最新。

🎯 基本用法示例

为单条命令着色：

# 在需要着色的命令前加上 rgrc
rgrc ping -c 4 debian.org
rgrc df -h
rgrc docker ps
rgrc journalctl -n 50

为管道输出着色：

# 按名称选择配置，为标准输入着色
df -h | rgrc -c df
mount | rgrc -c mount

选择别名和颜色：

# 为除 ls 和 ps 之外的所有支持命令设置别名
eval "$(rgrc --aliases --except ls,ps)"

# 输出送往分页器时强制着色
rgrc --color on ping -c 4 debian.org | less -R

配置与自定义规则：

# 命令配置和主映射文件
ls /usr/share/rgrc/
cat /etc/rgrc.conf

# 自定义规则放在这里，使用 grc 风格的 regexp= 和 colours= 行
mkdir -p ~/.config/rgrc

# 完整的选项参考
man rgrc

🔧 工具集成

rgrc 可以直接融入现有的终端工作流：

  • Shell： 软件包附带 bash、zsh 和 fish 补全，别名可在任何能 eval 的 shell 中使用
  • grc： Debian 的 Python 版 grc 可以继续保留：两个命令分别是 grc 和 rgrc，rgrc 读取相同的 grc/grcat 规则格式
  • 容器： docker ps、docker images 和 kubectl get pods 的输出更容易浏览
  • 日志： journalctl 输出中的错误和警告一眼就能看到
  • 网络诊断： ping、traceroute、dig、ss、netstat 和 ip 的地址、延迟和状态都带颜色

  • ✅ 完整软件包: /usr/bin/rgrc、rgrc(1) 手册页、/etc/rgrc.conf、/usr/share/rgrc 中的 97 个命令配置，以及 bash、zsh 和 fish 补全
  • ✅ 四种架构: amd64、arm64、armhf 和 i386，笔记本、服务器、树莓派和较旧的 32 位机器都能用上同一个 rgrc

❓ 常见问题

rgrc 在官方 Debian 软件源中吗？

不在, 官方 Debian 源没有打包 rgrc。本仓库目前是唯一的 apt 来源，提供 rgrc 0.6.35。

如何在 Debian 上安装最新版 rgrc？

按上方说明一次性添加 deb.griffo.io 仓库，然后运行：sudo apt install rgrc。之后通过常规的 sudo apt upgrade 获取新版本。

软件包是否有签名？如何构建？

每个软件包都使用仓库的 GPG 密钥（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）签名，并基于上游发布在公开的 GitHub 仓库中构建，任何人都可以审查。

支持哪些 Debian 版本？

Debian 12 Bookworm、Debian 13 Trixie、Forky 和 Sid。
