Spotifast 是什么？

Spotifast 是一款原生的 Spotify 桌面客户端，用 Rust 和 egui 编写，通过 librespot 播放音乐。整个进程里没有任何浏览器引擎，这正是它的意义所在：启动用时远不到一秒，运行期间也一直很轻，而官方客户端在同一台机器上两样都做不到。它本身就是一台 Spotify Connect 设备，既能在这台电脑上播放，也能控制账号下的其他所有设备。你的整个音乐库都在：播放列表、喜欢的歌曲、收藏的专辑、关注的艺人、播客和单集，还有搜索、艺人页、专辑页、播放列表页、播放队列、均衡器、媒体键和托盘图标。

🚀 为什么最新版本很重要： Spotifast 还很年轻，迭代很快，每周都有多个版本，而它对接的两样东西一直在变：Spotify 的 Web API 和 librespot。Spotify 那边的改动弄坏了某个页面或者登录流程，会在本周的版本里修好，而不是在上个月的构建里。Debian 和 Ubuntu 都没有打包它，所以在这里用最新构建不是锦上添花，而是通过 apt 安装它的唯一途径。

⚡ Spotifast 的主要特性

⚡ 原生，而且很小

Rust 加 egui，直接绘制到 GPU。没有 Electron，没有内嵌的 Chromium，也没有 WebView。启动用时远不到一秒，内存占用一直停在起点附近，这才让它在老笔记本或树莓派上真正可用。

🔊 一台 Spotify Connect 设备

通过 librespot 在本机播放，无缝衔接，最高 320 kbps，可选音量归一化和磁盘音频缓存。也可以从手机上选中这台机器。设备选择器能把播放转移到音箱或另一台电脑，并继续在这里控制。

📡 发现局域网里的音箱

网络里待命的 librespot、spotifyd 或硬件接收器，在绑定账号之前对 Spotify 的 API 是不可见的。Spotifast 通过 mDNS 找到它们并替你连接，之后它们就和其他 Connect 设备一样。

📚 完整的音乐库

播放列表、喜欢的歌曲、收藏的专辑、关注的艺人、播客和已保存的单集，都能在侧边栏里过滤。搜索覆盖所有类型，首页有“为你打造”和最近播放，艺人、专辑、播放列表和播客页都能从任意一行开始播放。

🎛️ Winamp 迷你播放器

Ctrl+M 把窗口缩成经典的迷你播放器，能穿上真正的 .wsz 皮肤，以 1 倍到 4 倍逐像素绘制，下面还挂着频谱分析器、播放列表和十段均衡器。MilkDrop 视觉效果通过 projectM 在独立窗口中运行。

🖥️ 真正的桌面集成

基于 D-Bus 的 MPRIS，媒体键、桌面环境和 playerctl 都能像对待其他播放器一样控制它。关闭窗口就是真的关闭，音乐从托盘继续播放；重复启动只会唤起已有窗口；常用操作都有快捷键。

🔧 工具集成

Spotifast 有意建立在桌面已有的组件之上：

  • PulseAudio 与 PipeWire：音频通过会话的声音服务器输出，底层是 ALSA，这也是软件包依赖 libpulse0 和 libasound2t64 的原因
  • 基于 D-Bus 的 MPRIS：键盘上的媒体键、桌面的“正在播放”小部件和 playerctl 都能像控制其他播放器一样控制它
  • 系统托盘：一个状态通知项，关闭窗口后音乐继续播放，点击托盘即可唤回；在 GNOME、KDE 和各种平铺式合成器上表现一致
  • Wayland 与 X11：两者都支持，使用系统上常见的客户端库，软件包依赖它们而不是自带副本
  • Noto 字体：推荐依赖，负责绘制中文、日文、韩文、阿拉伯文、希伯来文、泰文和印度系文字的曲目名，否则会显示成方块

🚀 为什么选择 deb.griffo.io？

📊 仓库对比：
  • 官方 Debian：没有打包 Spotifast，在原始系统上 apt install spotifast 会失败
  • cargo install：版本够新，但要在每台机器上从源码构建 libprojectM，因此需要先准备 CMake、C++ 编译器、libclang，以及 ALSA、PulseAudio 和窗口系统的开发头文件
  • 上游二进制文件：一个需要你自己安放的文件，位于包管理器之外，没有桌面入口、没有图标，也没有依赖检查
  • deb.griffo.io：最新版本，自动更新
  • ✅ 唯一的 apt 来源：Spotifast 既不在 Debian 也不在 Ubuntu 的软件源中；本仓库打包的是官方上游构建
  • ✅ 它迭代很快：每周多个版本，Spotify 那边弄坏某个页面的改动会在几天内于上游修好，所以保持最新确实有意义
  • ✅ 自动更新：上游发布后数小时内更新软件包
  • ✅ 完整的软件包：/usr/bin/spotifast、桌面入口和应用图标，因此它会像其他程序一样出现在应用菜单里
  • ✅ 诚实的依赖：如实声明 ALSA、PulseAudio、OpenGL、X11 和 Wayland 库，Noto 字体只是推荐依赖，不会被悄悄装上
  • ✅ 两种架构：amd64 与 arm64，这也是上游发布的全部 Linux 构建
  • ✅ 多发行版：支持 Trixie、Forky 和 Sid
  • ✅ 维护简单：使用标准 apt 命令更新
ℹ️ 不支持 Bookworm。 上游发布的二进制文件动态链接 glibc，且基于 glibc 2.39 构建，因此软件包声明了 libc6 (>= 2.39)，而 Debian 12 自带的是 glibc 2.36，没有可安装的版本。Trixie、Forky 和 Sid 都没有问题。

Spotifast 在官方 Debian 软件源中吗？

不在, 官方 Debian 源没有打包 Spotifast。本仓库目前是唯一的 apt 来源，提供 Spotifast 0.13.3。

如何在 Debian 上安装最新版 Spotifast？

按上方说明一次性添加 deb.griffo.io 仓库，然后运行：sudo apt install spotifast。之后通过常规的 sudo apt upgrade 获取新版本。

软件包是否有签名？如何构建？
