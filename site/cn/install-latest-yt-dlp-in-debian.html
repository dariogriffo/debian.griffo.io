什么是 yt-dlp？

yt-dlp 是一个命令行音视频下载器，支持远超一千个站点。它最初是 youtube-dl 的分支（经由现已停止维护的 youtube-dlc），如今是两者之中真正活跃维护的项目：格式选择器强大得多，内置 SponsorBlock 集成，原生支持嵌入字幕、章节和元数据，并提供可编写自定义提取器的插件系统。

🚀 为什么最新版本很重要： 这一点在本仓库的所有工具中最为突出。yt-dlp 要与随时更改播放器和 API 的站点打交道，而修复往往在几天之内以新版 yt-dlp 的形式发布。官方源中被冻结的版本不只是少了功能：它的提取器会直接失效，下载会因签名或格式错误而失败，直到你升级为止。保持在当前版本正是关键所在。

⚡ yt-dlp 的主要功能

🌐 数千个站点

超过 1700 个提取器，覆盖视频平台、广播机构、播客托管和新闻网站，另有通用提取器，可在没人专门写过提取器的页面上找到媒体。

🎚️ 精确的格式选择

-f 和 -S 提供了一整套针对分辨率、编码、码率和容器的表达式语言，让你精确指定想要的流，而不是接受默认值。

🎧 提取音频

-x --audio-format mp3 会抽出音轨并重新编码，配合 --embed-thumbnail 和 --embed-metadata 可得到音乐播放器都能识别的带标签文件。

💬 字幕与章节

下载或嵌入任意可用语言的字幕，保留自动生成的字幕，把章节标记直接写入输出文件，或据此切分文件。

⏭️ SponsorBlock

借助 SponsorBlock 数据库，在下载时即可标记或移除赞助片段、片头和自我推广，事后无需再动剪辑软件。

🍪 Cookie 与会话

--cookies-from-browser 直接从 Firefox 或 Chromium 读取已登录的会话，让私享、年龄限制和会员专属内容也能正常下载。

🚀 始终领先于官方软件源： Debian 和 Ubuntu 在发布时冻结软件包版本，而本仓库通常在上游发布后数小时内就发布新版本。一条简单的 apt upgrade 就能让你保持最新。

🎯 基本用法示例

日常下载：

# 以可用的最佳画质下载视频
yt-dlp 'https://example.com/watch?v=...'

# 不超过 1080p 的最佳 MP4
yt-dlp -S 'res:1080,ext:mp4' 'URL'

# 仅音频，输出带标签的 MP3
yt-dlp -x --audio-format mp3 --embed-thumbnail --embed-metadata 'URL'

# 选择之前先查看所有可用格式
yt-dlp -F 'URL'

字幕、章节与赞助片段：

# 嵌入英文字幕，包括自动生成的字幕
yt-dlp --embed-subs --sub-langs en --write-auto-subs 'URL'

# 把章节标记写入文件
yt-dlp --embed-chapters 'URL'

# 下载时直接去掉赞助片段和片头
yt-dlp --sponsorblock-remove sponsor,intro 'URL'

# 只截取其中一段，而不是整个视频
yt-dlp --download-sections '*00:01:30-00:04:00' 'URL'

播放列表、归档与自动化：

# 下载整个播放列表，并按上传者分文件夹整理
yt-dlp -o '%(uploader)s/%(title)s.%(ext)s' 'PLAYLIST_URL'

# 保持频道同步，且不重复下载旧内容
yt-dlp --download-archive seen.txt 'CHANNEL_URL'

# 使用已登录的浏览器会话下载私享或年龄限制内容
yt-dlp --cookies-from-browser firefox 'URL'

# 通过 aria2c 获得更快的下载速度
yt-dlp --downloader aria2c --downloader-args aria2c:'-x 8 -s 8' 'URL'

🔧 工具集成

yt-dlp 是许多其他软件默认依赖的下载后端：

  • ffmpeg：合并、重封装、提取音频和嵌入数据都会调用它
  • mpv：直接播放链接，播放时交给 yt-dlp 解析
  • aria2：可选的外部下载器，支持并行分段传输
  • 媒体服务器：Jellyfin、Kodi 和 Navidrome 的媒体库常用 yt-dlp 的输出模板来填充
  • 配置文件：把常用参数写进 ~/.config/yt-dlp/config，不必每次重复输入
