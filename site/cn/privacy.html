隐私政策

deb.griffo.io 及其 apt 仓库收集什么、为什么收集，以及你可以怎么做

最后更新：2026 年 10 月 20 日

简而言之。本站用两种方式统计访问：一是 Google Analytics， 它会在你的浏览器中设置 Cookie；二是 ttics，一个运行在我们自己服务器上的小型第一方服务， 它不设置 Cookie，也无法在不同日期之间认出你。你可以通过屏蔽其 Cookie、使用广告拦截器或 Google 的停用插件来退出 Google Analytics。如果你开始试用或订阅，仓库会保存为你提供 apt 访问所需的信息：你的邮箱地址、订阅状态和密码的哈希值。银行卡信息直接交给 Stripe，从不经过本站。

1. 谁在运营本站

deb.griffo.io、deb-free.griffo.io 以及背后的 apt 仓库由 Dario Griffo（下文称“我”）运营。关于你的数据的问题和请求，可以通过 GitHub 或项目的 Discord 社区提出。

2. 访问统计

Google Analytics。deb.griffo.io 和 deb-free.griffo.io 的页面使用 Google Analytics 4， 这是 Google Ireland Limited 提供的服务（在欧洲经济区、英国和瑞士以外由 Google LLC 提供）。它会设置第一方 Cookie _ga 和 _ga_<id>，Google 最长保留两年，用于区分回访的浏览器和新的浏览器。 借助它们，它统计访问次数和浏览的页面、访客的来源（包括 utm_ 活动标记）、设备、浏览器和大致位置， 以及几个操作：打开免费试用表单、开始试用和前往付款（附带所选套餐及其价格）。我用它来了解哪些页面对大家有帮助， 并衡量试用注册和付款点击，包括来自广告的那些。据 Google 称，Google Analytics 4 不会记录或存储 IP 地址。 Google 按照其自身的隐私权政策处理这些数据， 数据可能会被传输到你所在国家以外的服务器，包括美国。

你可以使用 Google 的停用浏览器插件退出 Google Analytics。为本站屏蔽 Cookie，或使用广告、跟踪拦截器，同样可以退出；无论哪种方式，网站的功能都完全一样。

ttics。页面浏览量还由 ttics 统计，这是我自己在我们自己的服务器上运行的一个小型统计服务。 它不设置 Cookie，也不在你的设备上存储任何内容，数据不会交给任何第三方。页面加载时，你的浏览器会向它发送该页面的地址以及关于这次访问的几项信息。 它从中记录：

  • 你访问的页面（只记录路径，不含查询字符串）；
  • 把你链接到这里的网站的主机名，从不记录完整地址；
  • 地址中的 utm_ 活动标记（如果有的话；它们标明这次访问来自广告或新闻邮件）；
  • 页面的语言；
  • 设备类别（手机、平板或桌面），根据窗口宽度判断；
  • 浏览器和操作系统的类别，例如 Linux 上的 Firefox，不含版本号；
  • 几个操作：打开免费试用表单、开始试用和前往付款；
  • 一个每日访客哈希值，详见下文。

访客哈希值是对以下内容计算的 SHA-256：一个每天更换的随机值（每日盐值）、你的 IP 地址、浏览器的 User-Agent 以及网站的主机名。它让服务能够统计某一天有多少不同的人访问。每个盐值会在两天后删除， 此后就无法再根据某个地址重新算出该哈希值；而且新一天的哈希值永远不会与旧的相同，因此 你无法在不同日期之间被识别出来。你的 IP 地址和完整的 User-Agent 从不被存储，它们只用于计算这个哈希值。明显的机器人和爬虫会在记录任何内容之前被过滤掉。

我用这些数字来了解哪些页面能帮助大家找到所需内容，以及本站的广告是否有效：带有活动标记的访问， 会被计入同一天开始的试用和付款。

Ahrefs Web Analytics。deb.griffo.io 的页面还会加载 Ahrefs Web Analytics，这是 Ahrefs 提供的不使用 Cookie 的服务，只汇总报告页面统计数据。

3. 免费试用

开始试用时，你需要填写一个邮箱地址。表单由 Cloudflare Turnstile 保护，它的脚本只在你打开表单时才会加载，所以从未打开表单的访问永远不会加载它。为了核验结果， 服务器会把它连同你的 IP 地址一起发送给 Cloudflare。仓库会保存你的邮箱地址，用于发送你的访问凭据、 试用结束前的提醒以及其他与访问有关的消息。你的 IP 地址还会（仅在内存中）用于限制每个地址每天只能申请一次试用。

4. 付款

付款由 Stripe 处理。银行卡信息直接交给 Stripe，从不经过本站或其服务器；你使用 Stripe 时适用其自身的条款和隐私政策。仓库会保存你的邮箱地址、 Stripe 为你和你的订阅分配的编号、套餐、订阅状态及相关日期。购买会通过这个邮箱地址与之前的试用关联起来， 以便我了解有多少试用转化成了订阅。这个邮箱会收到你的访问凭据和与订阅有关的消息，其中包括订阅开始几天后发送的一封、仅此一次的评价邀请。

5. 仓库访问与服务器日志

apt 使用你的登录名（即你的邮箱地址）和为你生成的密码进行认证，密码只以 bcrypt 哈希值的形式保存。与任何 Web 服务器一样，网站和仓库背后的服务器会记录请求日志，包括 IP 地址、User Agent 和所请求的文件，用于维持服务运行和防止滥用。ttics 是个例外：它的日志不包含 IP 地址、User Agent 和来源页面（referrer）。

6. Cookie 与浏览器存储

本站仅有的 Cookie 是 Google Analytics 的 _ga 和 _ga_<id>（见第 2 节）； 你可以在浏览器中屏蔽它们，网站上的任何功能都不会受影响。ttics 和 Ahrefs 不会向你的浏览器写入任何内容。 本站自身另外唯一可能保存在那里的是一项偏好： 如果你在 sudo、root 和 extrepo 之间切换安装命令的形式，你的选择会以 deb-griffo-install-variant 为名保存在浏览器的本地存储中，这样下一个页面会显示相同的形式。 它从不离开你的浏览器，清除网站数据即可将其删除。Cloudflare Turnstile（仅在你打开试用表单时）和 Stripe（仅在你前往付款时）由这两家公司按照各自的政策运营。

7. 你的权利

  • 查询关于你保存了哪些数据，或要求更正、删除，可以通过 GitHub 或 Discord 社区联系。GitHub 的 issue 是公开的，请不要在那里贴出你的邮箱地址；只需说明你有隐私方面的请求，之后会转为私下沟通。删除账号后，你的仓库访问也会随之终止。
  • ttics 无法追溯到你本人。其中不包含姓名、邮箱、IP 地址或 Cookie， 而且每日哈希值在盐值删除后就无法再与具体某个人关联，因此其中没有任何可以针对单个访客查询或删除的内容。
  • 随时退出 Google Analytics：使用 Google 的 停用插件、屏蔽其 Cookie，或使用广告拦截器。 从浏览器中删除 _ga Cookie 后，你会被重新当作一位新访客。
  • 你可以投诉：如果你认为自己的数据被不当处理，可以向你所在地的数据保护机构投诉。
