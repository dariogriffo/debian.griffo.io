隐私与 Cookie

deb.griffo.io 及其 apt 仓库收集什么、为什么收集，以及你可以怎么做

最后更新：2026 年 10 月 19 日

简而言之。除非你同意使用 Google Analytics，否则本站不会设置任何 Cookie，而且你可以随时更改这个选择。如果你开始试用或订阅，仓库只保存为你提供 apt 访问所需的信息：你的邮箱地址、订阅状态和密码的哈希值。银行卡信息直接交给 Stripe，从不经过本站。

1. 谁在运营本站

deb.griffo.io、deb-free.griffo.io 的首页以及背后的 apt 仓库由 Dario Griffo（下文称“我”）运营。关于你的数据的问题和请求，可以通过 GitHub 或项目的 Discord 社区提出。

2. 访问统计

Google Analytics，仅在你同意后启用。在你点击 Cookie 提示中的 接受之前，不会加载任何 Google 脚本，不会设置任何 Google Cookie，你的浏览器也不会向 Google 发送任何内容。如果你同意，Google Analytics 会记录你访问的页面以及其中的几个操作： 打开免费试用表单、开始试用和前往付款。这些数据同样用来判断本站的广告是否有效，因此同意也意味着 Google 可以把一次试用或购买与你点击过的广告关联起来；个性化广告始终保持关闭。

已完成的购买。付款成功后，仓库的服务器会把这笔销售报告给 Google Analytics：套餐、金额、币种以及 Stripe 对该次付款的编号。其中不包含姓名或邮箱地址。只有在你同意了统计 Cookie 的情况下，它才会与你的访问关联。

Ahrefs Web Analytics。deb.griffo.io 的页面还会加载 Ahrefs Web Analytics，它不使用 Cookie，只提供汇总后的页面统计。

3. 免费试用

开始试用时，你需要填写一个邮箱地址。表单由 Cloudflare Turnstile 保护，只在你打开表单时才会加载；服务器会向 Cloudflare 核验其结果，并同时传送你的 IP 地址。仓库会保存你的邮箱地址；只有在你同意了统计 Cookie 的情况下，还会保存 _ga Cookie 中的 Google Analytics 客户端 ID，以便之后的购买能归属到开始试用的那次访问。邮箱地址用于发送你的访问凭据、试用结束前的提醒，以及其他与访问有关的消息。

4. 付款

付款由 Stripe 处理。银行卡信息直接交给 Stripe，从不经过本站或其服务器；你使用 Stripe 时适用其自身的条款和隐私政策。仓库会保存你的邮箱地址、Stripe 为你和你的订阅分配的编号、套餐、订阅状态及起止日期。这个邮箱会收到你的访问凭据和与订阅有关的消息，其中包括订阅开始几天后发送的一封、仅此一次的评价邀请。

5. 仓库访问

apt 使用你的登录名（即你的邮箱地址）和为你生成的密码进行认证，密码只以 bcrypt 哈希值的形式保存。与任何 Web 服务器一样，仓库的服务器会记录请求日志，包括 IP 地址、User Agent 和所请求的文件，用于维持服务运行和防止滥用。

6. Cookie 与浏览器存储

名称类型用途
_gaCookie，Google Analytics区分来自同一浏览器的访问。仅在你同意后设置。
_ga_<id>Cookie，Google Analytics记录当前这次访问。仅在你同意后设置。
dgi-consent本地存储，本站记住你接受还是拒绝了统计 Cookie。
deb-griffo-install-variant本地存储，本站记住你偏好的命令形式：使用 sudo、以 root 身份，还是通过 extrepo。

本站不会设置其他任何 Cookie。这两项本地存储内容始终只保留在你的浏览器中。

7. 你的选择

  • 随时更改 Cookie 选择：点击每个页面底部的 Cookie 设置。选择拒绝会删除 Google Analytics 的 Cookie。
  • 查询关于你保存了哪些数据，或要求更正、删除，可以通过 GitHub 或 Discord 社区联系。GitHub 的 issue 是公开的，请不要在那里贴出你的邮箱地址；只需说明你有隐私方面的请求，之后会转为私下沟通。删除账号后，你的仓库访问也会随之终止。
