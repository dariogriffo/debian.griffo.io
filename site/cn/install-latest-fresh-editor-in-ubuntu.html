什么是 fresh-editor？

fresh-editor 是 Fresh 这款终端 IDE 与文本编辑器的软件包，作者 Noam Lewis，使用 Rust 编写。它把你对 IDE 的期待带进终端：语言服务器支持、语法高亮、多光标，以及一个运行 TypeScript 的插件系统，同时依然容易上手。超大文件也能立即打开；编辑会话由后台守护进程保持，可以用 fresh -a 重新连接；用 fresh --web 甚至可以把编辑器提供给网页浏览器。软件包名为 fresh-editor，你输入的命令是 fresh。

🚀 为什么最新版本很重要： Fresh 是一个年轻且活跃开发中的项目，每个版本都会带来语言服务器、插件 API 和性能方面的改进。Debian 和 Ubuntu 的官方软件源中完全没有它；上游在 GitHub releases 中发布独立的 .deb 文件，却没有 apt 仓库，所以手动安装的 .deb 永远不会自动更新。针对当前 TypeScript API 编写的插件，需要当前版本的编辑器。

⚡ fresh-editor 的主要特性

🧠 语言服务器支持

Fresh 支持 Language Server Protocol，诊断、补全、跳转到定义和悬停信息都来自其他编辑器同样使用的服务器，例如 rust-analyzer、gopls 或 clangd。

🎨 语法高亮

代码一打开就有高亮，就在你平时用的终端里，第一个文件显示正确之前不需要额外的配置步骤。

✏️ 多光标

同时在多个位置放置光标并一起输入，是在代码块中重命名变量、或批量改写一列相似行的快捷方式。

🧩 TypeScript 插件

Fresh 内置用于插件的 TypeScript 运行时：扩展编辑器就是针对其插件 API 编写 TypeScript，而不必学习一门专有的配置语言。

🔌 不会丢失的会话

会话守护进程在终端关闭或 SSH 连接断开时仍保留编辑器及其打开的文件，fresh -a 即可重新连接。

🌐 终端或浏览器

fresh --web 把同一个编辑器提供给网页浏览器，适合那些用浏览器比用终端更容易访问的机器。

🚀 始终领先于官方软件源： Debian 和 Ubuntu 在发布时冻结软件包版本，而本仓库通常在上游发布后数小时内就发布新版本。一条简单的 apt upgrade 就能让你保持最新。

🔧 工具集成

Fresh 可以直接融入现有的终端工作流：

  • Git: git config --global core.editor fresh 让提交信息和交互式 rebase 在 Fresh 中打开
  • Shell: 在 ~/.bashrc 中写入 export EDITOR=fresh，crontab -e、sudoedit 等都会使用它
  • 编译器和 grep: 它们输出的 file:line:col 会直接在报告的位置打开
  • 桌面: 软件包会安装桌面项和图标，因此 Fresh 会出现在应用程序菜单中
  • SSH 和 tmux: 会话守护进程在远程端保持你的工作不中断，fresh -a 即可接着继续

🚀 为什么选择 deb.griffo.io？

📊 仓库对比：
  • 官方 Ubuntu： 未打包：任何 Ubuntu 版本的 main 和 universe 中都没有 Fresh
  • 上游 .deb: 下载当天是最新的，但上游只在 GitHub releases 中发布独立的 .deb 文件，没有 apt 仓库，所以 apt upgrade 永远看不到新版本，每次发布都要再手动下载一次
  • 用 cargo 构建: 需要 Rust 工具链，每次升级都要完整编译，而且没有桌面项、图标和 man 手册页
  • deb.griffo.io：最新版本，自动更新
  • ✅ 软件包 fresh-editor，命令 fresh: sudo apt install fresh-editor，然后运行 fresh；fresh-editor 是上游自己的软件包名，上游的 .deb、AUR、Homebrew 和 winget 都用这个名字，因此已安装上游 .deb 的机器从下一个版本起就能原地升级
  • ✅ 上游版本通过 apt 更新: 上游提供 .deb 文件但没有仓库；这里每个版本都会进入 GPG 签名的 apt 仓库，并为每个 Debian 和 Ubuntu 版本分别构建
  • ✅ 自动更新：上游发布后数小时内更新软件包
  • ✅ 完整软件包: fresh 二进制文件、用于应用程序菜单的桌面项和图标，以及 fresh(1) man 手册页
  • ✅ 两种架构: amd64 和 arm64，笔记本、服务器和 64 位 ARM 开发板都能用上同一个 Fresh
  • ✅ 多发行版：支持 Ubuntu 22.04、24.04、25.10 和 26.04
  • ✅ 易于维护：使用标准 apt 命令即可更新

❓ 常见问题

fresh-editor 在官方 Ubuntu 软件源中吗？

不在, 官方 Ubuntu 源没有打包 fresh-editor。本仓库目前是唯一的 apt 来源，提供 fresh-editor 0.5.2。

如何在 Ubuntu 上安装最新版 fresh-editor？

按上方说明一次性添加 deb.griffo.io 仓库，然后运行：sudo apt install fresh-editor。之后通过常规的 sudo apt upgrade 获取新版本。

软件包是否有签名？如何构建？

每个软件包都使用仓库的 GPG 密钥（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）签名，并基于上游发布在公开的 GitHub 仓库中构建，任何人都可以审查。

支持哪些 Ubuntu 版本？

Ubuntu 22.04 Jammy、24.04 Noble、25.10 Questing 和 26.04 Resolute。
