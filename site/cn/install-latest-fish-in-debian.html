什么是 fish？

fish 是一个聪明且易用的命令行 shell。它会在你输入时根据历史记录和补全建议命令的其余部分，实时高亮语法，从已安装的手册页生成 Tab 补全，并摒弃了其他 shell 继承下来的晦涩引号规则。这一切开箱即用——无需任何配置，fish 就已经很好用。

🚀 为什么最新版本很重要： fish 4 用 Rust 重写，此后迭代很快：启动更快、补全更好，交互体验持续打磨。官方源中冻结的版本早于其中大部分改进。

⚡ fish 的主要特性

💡 自动建议

输入时，fish 会根据历史记录和补全建议命令的其余部分。按 → 即可采纳。

🎨 语法高亮

命令在书写时即着色，因此拼写错误或未闭合的引号在按下回车前就一目了然。

⌨️ 从手册页生成补全

fish 解析已安装的手册页来生成补全，即使冷门工具也能补全其选项。

🧠 合理的脚本语言

没有分词带来的意外，没有 [[ ]] 与 [ ] 之分，并且有真正的列表。脚本读起来就是它运行的样子。

🔍 可搜索的历史

输入前缀后按 ↑，只在匹配的命令中浏览，并内置子串搜索。

🛠️ 在浏览器中配置

fish_config 会打开一个界面来设置提示符、配色、函数和按键绑定——无需翻找配置文件。

🚀 始终领先于官方软件源： Debian 和 Ubuntu 在发布时会冻结软件包版本——本仓库通常在数小时内发布新的上游版本。只需 apt upgrade 即可保持最新。

❓ 常见问题

fish 在官方 Debian 软件源中吗？

在，但官方 Debian 源只提供 fish 4.0.2，而本仓库提供 fish 4.8.1，每次上游发布后数小时内重新构建。

如何在 Debian 上安装最新版 fish？

按上方说明一次性添加 deb.griffo.io 仓库，然后运行：sudo apt install fish。之后通过常规的 sudo apt upgrade 获取新版本。

软件包是否有签名？如何构建？

每个软件包都使用仓库的 GPG 密钥（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）签名，并基于上游发布在公开的 GitHub 仓库中构建，任何人都可以审查。

支持哪些 Debian 版本？

Debian 12 Bookworm、Debian 13 Trixie、Forky 和 Sid。
