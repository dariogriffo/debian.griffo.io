什么是 lazyjira？

lazyjira 是一款以键盘操作为主的 Jira 终端界面，仿照 lazygit 的风格，用 Go 编写。四个面板并排显示你的 issue、项目、当前选中的 issue 及其状态，支持 vim 风格导航和鼠标操作。用 JQL 搜索，然后修改 issue 的流转状态、优先级、经办人或标签，添加评论，在你的 $EDITOR 中编辑描述，或者新建 issue，全程无需打开浏览器。它支持 Jira Cloud 和 Jira Server/Data Center，首次运行时会通过设置向导引导你完成连接。软件包和命令都叫 lazyjira。

🚀 为什么最新版本很重要： lazyjira 是一个年轻且迭代很快的项目，每个版本都会带来新的编辑操作、更多 Jira 字段支持和新的配置选项。Debian 和 Ubuntu 的官方软件源中完全没有它；上游只在 GitHub releases 中发布二进制文件，没有 apt 仓库，所以手动复制到 PATH 里的二进制文件永远不会自动更新。

⚡ lazyjira 的主要特性

🔍 JQL 搜索

输入 JQL 时有自动补全和语法高亮，并能通过持久化的历史记录找回以前的查询。保存的 JQL 标签页让日常视图一键可达。

🗂️ 四面板布局

issue、项目、issue 详情和状态并排显示，终端较窄时也可以上下堆叠。用 vim 风格按键或鼠标导航。

✏️ 直接编辑

修改流转状态、优先级、经办人和标签，添加评论，并在你的 $EDITOR 中编辑描述。新 issue 也在同一界面中创建。

🌿 Git 集成

从选中的 issue 创建 git 分支，或者打开当前分支对应的 issue，让工单和代码始终对得上。

⚙️ 可配置

快捷键、JQL 标签页、issue 列和自定义字段都在 ~/.config/lazyjira/ 中设置，可选默认 ANSI 主题或 Catppuccin 主题。

🔐 Cloud 与 Server

Jira Cloud 使用邮箱和 API 令牌登录，Jira Server 和 Data Center 使用个人访问令牌，同时支持 mTLS 客户端证书。

🚀 始终领先于官方软件源： Debian 和 Ubuntu 在发布时冻结软件包版本，而本仓库通常在上游发布后数小时内就发布新版本。一条简单的 apt upgrade 就能让你保持最新。

🔧 工具集成

lazyjira 可以直接融入现有的终端工作流：

  • Git： 从选中的 issue 创建分支，或跳转到当前分支对应的 issue
  • 编辑器： 描述在 $EDITOR 中打开，Neovim、Helix 或任何其他编辑器都可以负责写作
  • 浏览器： 需要完整的 Jira 网页视图时，通过 xdg-open 在浏览器中打开选中的 issue
  • 剪贴板： 用 xclip 复制，可直接粘贴到提交信息或聊天中
  • 企业 Jira： 个人访问令牌和 mTLS 客户端证书可以应对配置更严格的 Server 和 Data Center 部署

🚀 为什么选择 deb.griffo.io？

📊 仓库对比：
  • 官方 Ubuntu： 未打包：任何 Ubuntu 版本的 main 和 universe 中都没有 lazyjira
  • 上游二进制文件: 下载当天是最新的，但上游只在 GitHub releases 中发布二进制文件，没有 apt 仓库，所以 apt upgrade 永远看不到新版本，每次发布都要再手动下载一次
  • 用 go install 构建: 需要 Go 工具链，每次升级都要重新编译，而且没有更新日志和文档
  • deb.griffo.io：最新版本，自动更新
  • ✅ 无运行时依赖: lazyjira 是单个静态链接的 Go 二进制文件；git、xclip 和 xdg-utils 只是建议安装，分别用于分支、剪贴板和在浏览器中打开 issue
  • ✅ 上游版本通过 apt 更新: 上游提供二进制文件但没有仓库；这里每个版本都会进入 GPG 签名的 apt 仓库，并为每个 Debian 和 Ubuntu 版本分别构建
  • ✅ 自动更新：上游发布后数小时内更新软件包
  • ✅ 完整软件包: lazyjira 二进制文件，外加上游的更新日志以及 Config、Keybindings 和 Custom Fields 文档，位于 /usr/share/doc/lazyjira
  • ✅ 两种架构: 仅 amd64 和 arm64，笔记本、服务器和 64 位 ARM 开发板都能用上同一个 lazyjira
  • ✅ 多发行版：支持 Ubuntu 22.04、24.04、25.10 和 26.04
  • ✅ 易于维护：使用标准 apt 命令即可更新

❓ 常见问题

lazyjira 在官方 Ubuntu 软件源中吗？

不在, 官方 Ubuntu 源没有打包 lazyjira。本仓库目前是唯一的 apt 来源，提供 lazyjira 2.19.2。

如何在 Ubuntu 上安装最新版 lazyjira？

按上方说明一次性添加 deb.griffo.io 仓库，然后运行：sudo apt install lazyjira。之后通过常规的 sudo apt upgrade 获取新版本。

软件包是否有签名？如何构建？

每个软件包都使用仓库的 GPG 密钥（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）签名，并基于上游发布在公开的 GitHub 仓库中构建，任何人都可以审查。

支持哪些 Ubuntu 版本？

Ubuntu 22.04 Jammy、24.04 Noble、25.10 Questing 和 26.04 Resolute。
