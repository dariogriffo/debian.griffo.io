什么是 Herdr？

Herdr 是一款面向终端与编程代理的桌面应用。工作按空间组织，通常一个代码仓库对应一个空间；每个空间有若干标签页，标签页又可以拆分成窗格，于是一个 shell、一个编辑器和两个编程代理可以在同一个窗口里并排运行。代理侧栏列出所有空间中的每个代理及其状态（Working 正在工作、Blocked 等待你回应、Done 已完成、Idle 空闲），一眼就能看出哪个需要你的回答。关闭窗口不会停止任何东西：终端运行在 herdr-core（hc）这个小型后台进程中，再次打开 Herdr 时它们都还在。它用 Rust 编写，采用 Apache-2.0 许可证，主页是 herdr.dev。

🚀 为什么最新版本很重要： Herdr 很年轻，迭代很快：新布局、mod API、远程机器相关的修复以及代理状态的改进，几乎每个版本都会带来。Debian 完全没有打包 Herdr，而且此构建关闭了应用内置的自动更新，所以更新与系统其他软件走同一条路。一条普通的 apt upgrade 就能让你工作的每台机器保持最新。

⚡ Herdr 的主要功能

🗂️ 空间、标签页与窗格

给每个代码仓库一个独立的空间，在里面打开标签页并拆分成窗格。切换项目就是切换空间，每个终端都停留在你离开时的样子。

🤖 代理侧栏

任何空间中运行的每个编程代理都会出现在同一个列表里，并显示状态：Working、Blocked（等待你）、Done 或 Idle。处于 Blocked 的那些最该先看。

♾️ 关掉窗口，终端照常运行

终端运行在 herdr-core（hc）里，而不是窗口里。关闭 Herdr 后，你的 shell、构建和代理仍在继续；再次打开，它们全都回来了。

🌐 通过 SSH 使用远程机器

添加一台可以通过 SSH 访问的机器，空间里的终端就改在那里运行，笔记本休眠或切换网络时，长时间的代理会话也不会中断。

🎨 命令面板、主题与布局

Ctrl+Shift+P 打开可以完成一切操作的命令面板；主题和内置布局（Herdr、Terminals 以及复古风格的 Herdr 98）改变窗口的外观和显示内容。

🧩 JavaScript Mod

用 JavaScript 编写的 mod 可以绘制自己的面板和菜单，应用尚未覆盖的工作流无需等待新版本就能加上。

🚀 始终领先于官方软件源： Debian 和 Ubuntu 在发布时冻结软件包版本，而本仓库通常在上游发布后数小时内就发布新版本。一条简单的 apt upgrade 就能让你保持最新。

🔧 工具集成

Herdr 是你已经在用的命令行工具的家，所以关键在于它所处的机器环境：

  • 桌面会话：Herdr 是图形应用，需要 X11 或 Wayland 会话；在无头服务器上，请改为通过远程机器在那里运行终端
  • Vulkan：窗口用 Vulkan 绘制，因此需要可用的 Vulkan 驱动。软件包推荐 mesa-vulkan-drivers，它覆盖 Intel 和 AMD 显卡；NVIDIA 专有驱动自带 Vulkan 支持
  • herdr-core：hc 位于你主目录下的 ~/.local/bin，由应用在首次运行时安装，而不是由 apt 安装；窗口关闭期间，正是它让终端保持运行
  • 远程机器：添加一台可以通过 SSH 访问的机器，空间里的终端就在它上面运行，笔记本休眠或断网时，长时间的代理会话也能保留下来
  • 编程代理：像运行其他命令一样在窗格中运行你的代理 CLI；代理侧栏会把所有空间中的代理汇总起来，并显示哪个正处于 Blocked 状态等待你
  • 终端里的 herdr：本站的 herdr 软件包是另一个程序，一款终端代理多路复用器；Herdr 是桌面应用，两者可以同时安装
  • 你的工具：一个窗格里是 Neovim 或 Helix，另一个是 lazygit，第三个是代理，全都在同一个空间中
