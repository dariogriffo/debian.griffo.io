什么是 Handy？

Handy 是一款免费开源、完全离线运行的语音转文字应用。它带着托盘图标在后台待命：按下全局快捷键，说出想写的内容，Handy 就在你自己的电脑上完成转写，并把文字粘贴到当前获得焦点的窗口里，无论是编辑器、终端、聊天客户端还是浏览器里的表单。任何内容都不会发送到云服务。语音模型（多种尺寸的 OpenAI Whisper，以及在普通 CPU 上也很快的 NVIDIA Parakeet）只需在应用内下载一次，之后都在本地运行，语音活动检测会在模型处理之前剪掉静音部分。它是 CJ Pais 用 Rust 编写的 Tauri 应用，采用 MIT 许可证，在 X11 和 Wayland 桌面上都能使用。

🚀 为什么最新版本很重要： Handy 很年轻，迭代很快：新模型、更好的准确度设置，以及针对特定麦克风、Wayland 合成器和键盘布局的修复，几乎每个版本都会带来。Ubuntu 完全没有打包 Handy，所以没有这个仓库的话，想保持最新只能每次发布都手动下载。在这里，一条普通的 apt upgrade 就能搞定，在你用来语音输入的每台机器上都是如此。

⚡ Handy 的主要功能

⌨️ 一个快捷键，任何应用

按下全局快捷键，说话，再按一次（或在按住说话模式下按住后松开），转写结果就会粘贴到当前焦点窗口。没有专门的听写输入框；凡是能接受键盘输入的地方，都能接受 Handy。

🔒 完全离线

音频在你自己的电脑上录制、转写，然后丢弃。不需要账号、API 密钥或订阅，模型下载到磁盘之后也不再需要网络。

🧠 Whisper 与 Parakeet

按硬件选择模型：有 GPU 时可用 GPU 加速的 Whisper Small、Medium、Turbo 或 Large，或者选择针对 CPU 优化、能自动识别语言的 Parakeet。

🔇 语音活动检测

Silero VAD 会在音频送入模型之前过滤掉静音和背景噪声，思考时的停顿不会变成多余的字词。

🐧 X11 与 Wayland

两种显示服务器都支持，通过随软件包一起安装的小巧输入辅助工具把结果输入到焦点应用：X11 下是 xdotool，Wayland 下是 wtype 和 wl-clipboard，GNOME 则用 ydotool。

🧩 开放且可扩展

MIT 许可，方便 fork：Rust 后端和 Web 界面都小到可以通读，设置中可以选择麦克风、快捷键、模型和语言。

🚀 始终领先于官方软件源： Debian 和 Ubuntu 在发布时冻结软件包版本，而本仓库通常在上游发布后数小时内就发布新版本。一条简单的 apt upgrade 就能让你保持最新。

🔧 工具集成

Handy 不需要与任何东西集成：只要一个应用能接受键盘输入，它就能接受语音输入。关键在于它所处的桌面环境：

  • X11：xdotool 是软件包的依赖，无需额外安装任何东西，文字就能送到焦点窗口
  • Wayland：wtype 和 wl-clipboard 也随软件包一起安装。有些合成器不会把全局快捷键交给应用；如果快捷键在你的环境里没有反应，请查看合成器的键盘设置
  • Wayland 下的 GNOME：GNOME 是 Ubuntu 26.04 的默认桌面，它不接受 wtype，因此在那里 Handy 需要运行着守护进程的 ydotool。在收录 ydotool 的版本上，软件包会推荐安装它（Debian trixie 没有收录）；如何启动守护进程，见 Handy README 中的 Linux 说明
  • dotool：Handy 也能使用它，但它不在任何 Debian 或 Ubuntu 仓库中：需要自行安装，并把你的用户加入 input 组
  • 音频：Handy 和其他桌面应用一样通过 PipeWire 或 PulseAudio 录音；在设置中选择输入设备，耳机麦克风的准确度通常胜过笔记本内置麦克风
  • 硬件：Whisper 模型在有 GPU 时使用 GPU，大尺寸模型在 CPU 上会变慢；在没有合适 GPU 的笔记本上，Parakeet 是更快的选择
  • 你的工具：在 kitty 或 Ghostty 这样的终端里口述提交信息，在 Zed 里写文字，在 ZapZap 或浏览器里回复消息，给 AI 助手口述提示词，全都用同一个快捷键
