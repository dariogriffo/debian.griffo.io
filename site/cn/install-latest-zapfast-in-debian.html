什么是 ZapFast？

ZapFast 是一款面向 Linux 桌面的快速、轻量的原生 WhatsApp 客户端。它不到一秒就能打开，内存占用约 200 MB，只是它所替代的浏览器标签页或 Electron 封装通常所需的一小部分。和 WhatsApp Web 一样，用手机上的 WhatsApp 扫描二维码即可关联账号，此后聊天、照片、语音消息、通话和通知都在一个带托盘图标的真正桌面窗口里。它用 Rust 和 egui 工具包编写，采用 MIT 许可证，在 X11 和 Wayland 上都能运行。ZapFast 是非官方的第三方客户端，与 WhatsApp 和 Meta 没有任何关联。

🚀 为什么最新版本很重要： ZapFast 很年轻，发布频繁：跟进 WhatsApp 协议变化的修复、投票和通话等新功能，以及桌面集成方面的改进，几乎每个版本都有。Debian 根本没有打包 ZapFast，而应用自带的更新器在本软件包中保持关闭，所以让它保持最新的是本仓库：一次普通的 apt upgrade 就能带来每个新版本。

🔧 工具集成

ZapFast 自己与 WhatsApp 和你的手机通信；在电脑上，它依赖几项标准的桌面服务：

  • 密钥环： 磁盘上的消息存档使用 Secret Service 密钥环（GNOME Keyring、KWallet 或 KeePassXC）中的密钥加密。所有主流桌面都已经在运行一个；在 i3 或 Sway 这类单纯的窗口管理器下，请安装 gnome-keyring 并随会话一起启动
  • X11 和 Wayland： ZapFast 在两种显示服务器上都能运行，在 GNOME、KDE Plasma、Xfce、Cinnamon 和平铺式环境中表现一致
  • 通知和托盘： 新消息以标准桌面通知的形式到达；托盘图标需要带系统托盘的桌面，在 GNOME 上即 AppIndicator 扩展
  • 你的手机： ZapFast 和 WhatsApp Web 一样是已关联的设备：手机上的账号仍是主账号，随时可以在手机的“已关联的设备”中解除关联
  • 更新： 内置的自动更新器只作用于上游的便携版下载，在本软件包中保持关闭；新版本与系统其他部分一起通过 apt 到达
  • 内存： 约 200 MB，轻到可以在笔记本上与浏览器、编辑器和终端一起整天运行
  • 你的工具： 与 Handy 搭配，可以用口述代替打字回复；如果更喜欢 Qt 客户端，也可以继续用 ZapZap
