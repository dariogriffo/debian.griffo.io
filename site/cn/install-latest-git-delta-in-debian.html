什么是 delta？

delta 是一个为 git、diff、grep 和 blame 输出提供语法高亮的分页器。只需把它设为 git 的分页器一次，之后每次 git diff、git show、git log -p、git blame 和 git add -p 的输出都会像在编辑器里一样高亮代码，在每个修改过的行内标出真正改动的单词，可选左右并排和行号显示，还能用 n 和 N 在文件标题之间跳转。它也能读取任意 unified diff、直接比较两个文件，并高亮 ripgrep 的 JSON 输出。delta 由 Dan Davison 用 Rust 编写，使用与 bat 相同的语法定义和配色主题，通过 ~/.gitconfig 配置，采用 MIT 许可证。软件包名为 git-delta，安装的命令是 delta。

🚀 为什么最新版本很重要： delta 每年发布数次，带来新选项、更好的并排视图折行，以及针对 git、终端和分页器之间各种配合问题的修复。Debian trixie 冻结在 0.18.2，Bookworm 则根本没有 git-delta，所以当前手册里的选项在你的版本中可能根本不存在。本仓库使用相同的软件包名 git-delta，因此 apt install git-delta 和 apt upgrade 拿到的是当前版本，而不是官方源里的旧版。

⚡ delta 的主要功能

🎨 语法高亮

diff 中的代码会像在编辑器里一样着色，使用 bat 的语法定义和配色主题。用 syntax-theme 选择主题，或让 delta 跟随终端的浅色或深色背景。

🔍 单词级改动

在每个修改过的行内，delta 精确标出不同的单词，改名的变量或反转的条件一眼就能看到，而不是藏在两行几乎一样的红绿行里。

↔️ 左右并排视图

side-by-side = true 把旧版和新版分成两栏并带行号显示，长行会折行而不是被截断。只想试一次：git -c delta.side-by-side=true diff。

🧭 导航与链接

启用 navigate = true 后，在很长的 git log -p 中可用 n 和 N 在文件之间跳转。启用 hyperlinks = true 后，在支持的终端里文件路径和提交哈希都可以点击。

🧩 blame、grep 与冲突

git blame 会高亮代码并把提交信息分组显示，git grep 和 rg --json 的结果会被高亮并按文件分组，合并时的冲突文件也会以易读的 diff 呈现。

⚙️ 配置都在 ~/.gitconfig

所有选项都写在 git 配置的 [delta] 段中，命名的功能集可以一次切换整套外观。软件包附带上游的 themes.gitconfig，里面是一组现成的主题。

🚀 始终领先于官方软件源： Debian 和 Ubuntu 在发布时冻结软件包版本，而本仓库通常在上游发布后数小时内就发布新版本。一条简单的 apt upgrade 就能让你保持最新。

🎯 基本用法示例

阅读 diff：

# 只在这一条命令中并排显示
git -c delta.side-by-side=true diff

# 或者始终并排，并显示行号
git config --global delta.side-by-side true
git config --global delta.line-numbers true

# 浏览历史；n 和 N 在文件之间跳转
git log -p

# 带高亮地暂存 hunk
git add -p

不只是 git diff：

# 直接比较两个文件
delta old.conf new.conf

# 任意 unified diff
diff -u a.txt b.txt | delta

# ripgrep 的匹配结果，高亮并按文件分组
rg --json -C 2 'TODO' | delta

# git blame 和 git grep 也会经过 delta
git blame src/main.rs
git grep -n 'TODO'

主题与配置：

# 在真实的 diff 上预览所有语法主题
git show | delta --show-syntax-themes

# 加载软件包附带的 delta 主题并预览
git config --global --add include.path /etc/delta/themes.gitconfig
git show | delta --show-themes

# 使用其中一个
git config --global delta.features mellow-barbet

# 查看 delta 实际生效的配置
delta --show-config

🔧 工具集成

delta 是位于 git 和分页器之间的过滤器，所以大部分集成都发生在你的 git 配置和终端里：

  • git： core.pager delta 覆盖 diff、show、log -p、stash show -p、blame 和 grep；interactive.diffFilter 需要加 --color-only，因为 git 要求 hunk 的每一行都对应返回一行
  • less： delta 通过 less 分页输出，软件包将其列为推荐依赖；没有 less 时 delta 直接输出到终端。DELTA_PAGER 或 delta.pager 可指定其他分页器，--paging=never 可关闭分页
  • lazygit： lazygit 可以通过 delta 渲染 diff；把它的分页器设置指向 delta --dark --paging=never 即可
  • difftastic： 两者互补：日常 diff 用 delta 作为 git 分页器，想按语法树比较时用 git difftool 调用 difftastic
  • ripgrep： 把 rg --json 的输出交给 delta，就能得到与 diff 同一主题、高亮且按文件分组的搜索结果
  • 终端： delta 会自行判断背景是浅色还是深色，判断错时用 delta.dark 或 delta.light 纠正；kitty 和 Ghostty 能打开 hyperlinks = true 生成的链接
  • Shell： 软件包附带 bash、zsh 和 fish 的 delta 补全

🚀 为什么选择 deb.griffo.io？

📊 仓库对比：
  • 官方 Debian： trixie 中是 git-delta 0.18.2，Bookworm 中没有，并在整个发行周期内冻结
  • cargo install git-delta： 需要 Rust 工具链和几分钟编译，得到一个只属于单个用户、位于 ~/.cargo/bin 的二进制文件，没有补全，每次发布都要手动重新编译
  • 上游下载： 从 GitHub 发布页下载 .deb 或 tarball，下载当天是最新的，之后每次发布都要再手动下载
  • deb.griffo.io: 最新版本，并自动更新
  • ✅ 与官方源相同的包名： 就是 Debian 和 Ubuntu 使用的 git-delta，所以普通的 sudo apt install git-delta 会选中这个更新的版本，apt upgrade 会就地替换官方源里的旧版
  • ✅ 软件包 git-delta，命令 delta： 安装的是 git-delta，运行的是 delta。两个相似的名字与它无关：官方源中的 delta 软件包是测试用例精简工具（multidelta、singledelta），git-extras 的 git delta 命令则列出与另一分支不同的文件
  • ✅ 官方构建： 上游发布的二进制文件原样放在 /usr/bin/delta，附带 bash、zsh 和 fish 补全，以及位于 /etc/delta/themes.gitconfig 的 themes.gitconfig，与 Debian 自己的软件包位置相同；上游没有 man 手册，参考资料是 delta --help
  • ✅ 依赖轻量： 推荐 git 和 less，但运行时两者都不是必需的：没有 less 时，delta 只是不分页地直接输出
  • ✅ 自动更新： 上游发布后数小时内更新软件包
  • ✅ 四种架构： amd64、arm64 和 armhf 支持 Bookworm、Trixie、Forky 和 Sid；i386 仅支持 Trixie、Forky 和 Sid，因为上游的 i386 构建需要 glibc 2.39，而 Bookworm 只有 2.36；没有 ppc64el、s390x 或 riscv64 构建
  • ✅ 多发行版： 支持 Bookworm、Trixie、Forky 和 Sid
  • ✅ 易于维护： 使用标准 apt 命令即可更新
