什么是 GitUI？

GitUI 是一个用 Rust 编写的 git 终端界面。它把图形化 git 客户端里真正值得用的部分搬进终端——暂存单个代码块和单行、阅读差异、浏览与搜索提交日志、stash、blame、分支管理和推送——而且不会像常见 GUI 那样在大型仓库上卡死。

🚀 为什么最新版本很重要： GitUI 尚未发布 1.0，迭代很快：子模块支持、日志搜索、blame、更好的变基以及一长串修复，都是在普通版本里陆续加入的。Debian 与 Ubuntu 根本没有收录它，所以新版本的替代品不是“旧一点的软件包”，而是根本没有软件包。

✂️ 暂存代码块与单行

对整文件、单个代码块或具体某一行进行暂存、取消暂存、还原和重置——这正是大多数人打开 git 图形界面的理由。

📜 日志与差异

浏览并搜索提交日志、查看任意提交的差异、逐行 blame，全部在同一个键盘驱动的界面里完成。

📦 Stash

在专门的标签页里保存、应用、弹出、丢弃和查看 stash，不用再记 git stash 的各个子命令。

🌿 分支与远程

创建、重命名、删除和切换分支，操作远程仓库，推送或拉取，全程无需回到 shell。

🎯 基本用法示例

打开仓库：

gitui

# 指定某个仓库，无需先 cd 进去
gitui -d ~/src/linux

# 工作目录与 git 目录分离的情况
gitui -d ~/src/project/.git -w ~/src/project

# 启动时就在文件标签页选中某个文件
gitui -f src/main.rs

外观与手感：

# 使用 ~/.config/gitui/ 中的主题文件

# 自定义按键绑定文件

# 自定义按键符号，适配显示方式不同的键盘
gitui -s ~/.config/gitui/key_symbols.ron

# 使用文件系统监视器，而不是定时刷新
gitui --watcher

需要排查问题时：

# 收集环境信息以便提交问题报告
gitui --bugreport

# 复现问题时写出日志
gitui --logging --logfile /tmp/gitui.log

# GitUI 未覆盖的部分，git 命令行依然可用
git rebase -i origin/main

# 通过 HTTPS 推送需要显式配置 credential helper
git config --global credential.helper store

🔧 工具集成

GitUI 建立在你已有的 git 配置之上：

  • 你的仓库：就是普通的 git 仓库，由 Rust 编写的 git 后端读写——里面没有任何 GitUI 专有的东西
  • 钩子：pre-commit、commit-msg、post-commit 和 prepare-commit-msg 的运行方式与命令行完全一致
  • GPG 签名：签名提交可用，但存在上游在问题追踪器中记录的若干限制
  • 主题与按键：~/.config/gitui/ 下的 theme.ron、key_bindings.ron 和 key_symbols.ron
  • 通过 SSH：在远程机器上依然足够快，在服务器上整理提交不再痛苦；amd64 版本不需要任何共享库

🚀 为什么选择 deb.griffo.io？

📊 仓库对比：
  • 官方 Debian：完全没有收录 GitUI——标准系统上 apt install gitui 会失败
  • cargo install gitui：版本较新，但每台机器都要长时间编译 Rust，装在 apt 之外，也不在升级流程内
  • 上游压缩包：官方二进制文件，每个版本都要手动重新下载
  • deb.griffo.io：最新版本，并自动更新
  • ✅ 仍处于 1.0 之前：GitUI 在普通版本里就会加入真正的新功能，用不用最新版，直接决定你有没有子模块支持、日志搜索和 blame
  • ✅ 唯一的 apt 来源：Debian 与 Ubuntu 官方源都没有 GitUI；本仓库打包官方上游构建
  • ✅ 自动更新：上游发布后数小时内更新软件包
  • ✅ 诚实的打包：上游二进制文件安装为 /usr/bin/gitui——上游没有提供手册页和补全，因此本包也不会自行编造
  • ✅ 三种架构：amd64（musl 静态构建）、arm64 和 armhf，并在上游链接 glibc 的地方明确声明依赖
  • ✅ 多发行版：支持 Bookworm、Trixie、Forky 和 Sid
  • ✅ 易于维护：使用标准 apt 命令即可更新

❓ 常见问题

GitUI 在官方 Debian 软件源中吗？

不在, 官方 Debian 源没有打包 GitUI。本仓库目前是唯一的 apt 来源，提供 GitUI 0.28.1。

如何在 Debian 上安装最新版 GitUI？

按上方说明一次性添加 deb.griffo.io 仓库，然后运行：sudo apt install gitui。之后通过常规的 sudo apt upgrade 获取新版本。

软件包是否有签名？如何构建？

每个软件包都使用仓库的 GPG 密钥（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）签名，并基于上游发布在公开的 GitHub 仓库中构建，任何人都可以审查。

支持哪些 Debian 版本？

Debian 12 Bookworm、Debian 13 Trixie、Forky 和 Sid。
