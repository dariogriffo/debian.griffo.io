什么是 lnav？

lnav，即 Logfile Navigator，是一款终端日志查看器，能把来自多个来源的日志文件合并到一个按时间戳排序的视图中。把几个文件、一个目录或一个压缩包交给它，它会自己识别格式（syslog、systemd 日志、Apache 和 nginx 访问日志、JSON lines 等等），按时间交错排列消息，高亮错误和警告，并在文件增长时持续跟踪。之后你可以过滤、搜索、在错误之间跳转；当问题不是一次搜索能回答的时候，还可以用 SQL 查询日志消息。通过 ssh 打开远程日志和打开本地日志一样简单。lnav 由 Tim Stack 用 C++ 编写，采用 BSD-2-Clause 许可证。

🚀 为什么最新版本很重要： lnav 不断增加新的格式、SQL 函数和查看功能，每个版本都会修正某些日志的解析方式。Ubuntu 26.04 冻结在 lnav 0.13.2，Noble 冻结在 0.11.2，Jammy 冻结在 0.9.0，所以默认系统用不上当前版本以及随之而来的格式和修复。本仓库以相同的软件包名提供 lnav 0.14.1，因此下一次 apt upgrade 时就会原地替换发行版自带的 lnav。

⚡ lnav 的主要功能

🔀 一条合并的时间线

同时打开 syslog、应用日志和 Web 服务器日志，lnav 会按时间戳交错排列它们的行，让你按事情发生的顺序阅读整个系统里发生了什么。

🔍 自动识别格式

syslog、journald JSON、Apache 和 nginx 访问日志、JSON lines、logfmt 以及几十种其他格式无需配置即可识别；级别、时间戳和字段都会被解析，错误和警告会被高亮。

🗄️ 用 SQL 查询日志

每种识别出的格式都是一张表。按 ; 就能对日志消息运行 SELECT 查询：按主机统计错误、找出最慢的请求、按状态码分组，结果显示在同一个窗口里。

🌐 通过 ssh 查看远程日志

lnav user@host:/var/log/syslog 借助你平常的 ssh 配置和密钥打开另一台机器上的日志，服务器上无需安装任何代理。

📦 压缩文件与归档

轮转后的 .gz 和 .bz2 日志可以直接打开，.zip 和 .tar 归档也一样，诊断包不用先解压就能阅读。

👀 跟踪、过滤与搜索

文件增长时持续跟踪，过滤器按模式隐藏或保留行，搜索会高亮每一处匹配，单个按键就能跳到下一个错误或警告，重要的内容不会一闪而过。

🔧 工具集成

lnav 能读取任何输出文本的东西：文件、管道以及其他机器：

  • ssh：像 user@host:/var/log/syslog 这样的远程路径会使用你现有的 ssh 配置和密钥；软件包为此推荐安装 openssh-client
  • systemd 日志：把 journalctl -o json（加上 -f 即可持续跟踪）通过管道交给 lnav，日志的每个字段都可以搜索和查询
  • 容器：docker logs -f app 2>&1 | lnav 或 kubectl logs -f pod | lnav 让容器输出同样获得高亮和 SQL
  • 剪贴板：标记若干行后按 c 即可复制；软件包建议为 Wayland 和 X11 安装 wl-clipboard 或 xclip
  • 自定义格式：在 JSON 文件中描述内部日志格式，用 lnav -i myformat.json 安装；之后它就能被识别、高亮，并拥有自己的 SQL 表
  • 脚本与 CI：lnav -n -c 以无界面方式执行命令和查询，交互时回答问题的同一条 SQL 也能在 cron 任务或流水线中运行
  • 文档：man 手册页随软件包提供（man lnav），完整手册位于 docs.lnav.org
