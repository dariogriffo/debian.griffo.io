cliamp 是什么？

cliamp 是为终端重做的 Winamp 2.x：播放列表编辑器、图形均衡器、频谱可视化器，以及代替皮肤的主题系统，全部用字符绘制。它可以播放本地文件（MP3、FLAC、OGG、WAV）、网络电台和播客，也能在同一个界面里从 Spotify、Qobuz、Navidrome、Jellyfin、Emby、Plex、SoundCloud、网易云音乐和 YouTube Music 流式播放。加上 --daemon，同一个可执行文件就变成没有界面的播放器，通过 IPC 套接字接受指令：状态栏、快捷键和脚本都能直接和正在播放的音乐对话。

🚀 为什么最新版本很重要： cliamp 的大部分代码是与不断变动的服务对接的粘合层：Spotify、Qobuz、SoundCloud、网易云音乐和 YouTube Music 都会毫无预警地改动接口，本月坏掉的服务会在本月的版本里修好，而不是在去年的构建里。这正是 cliamp 每周发布多个版本的原因。Debian 和 Ubuntu 都没有打包它，所以在这里用最新构建不是锦上添花，而是通过 apt 安装它的唯一途径。

⚡ cliamp 的主要特性

🎚️ 文字版的 Winamp

播放列表编辑器、图形均衡器和带峰值表的经典布局，用制表字符重新绘制。从 dracula、nord 到 vantablack 的 20 款内置主题，像当年的皮肤一样改变整体外观。

📡 电台与流媒体

带收藏功能的网络电台目录，外加 Spotify、Qobuz、Navidrome、Jellyfin、Emby、Plex、SoundCloud、网易云音乐和 YouTube Music，统一由一个 --provider 选项和交互式向导 cliamp setup 管理。

📊 29 种可视化效果

频谱柱、示波器、立体声场、矩阵雨、火焰、烟花等等，全部由同一套 FFT 驱动。cliamp vis 可在运行时切换；在意续航时用 --low-power 直接关掉。

🎛️ 真正的音频控制

带预设的参量均衡器、0.25 倍到 2 倍的播放速度、单声道混音、无缝播放、输出设备切换，以及采样率、位深和缓冲区大小的显式控制。

🖥️ 无界面守护进程与 IPC

cliamp --daemon 不启动 TUI 也能播放，并通过套接字响应 cliamp status、next 或 volume；cliamp visstream 则以 NDJSON 输出可视化频段，供 Waybar、quickshell 以及任何能读管道的程序使用。

🧩 沙箱中的 Lua 插件

插件 API 提供播放事件、按键映射、通知、HTTP 和存储等钩子，且全部运行在沙箱内。自带示例涵盖“正在播放”文件、Webhook 和按流派自动均衡。

🚀 始终领先于官方软件源： Debian 和 Ubuntu 在发行版发布时会冻结软件包版本。本仓库通常在数小时内发布新的上游版本。只需 apt upgrade 就能保持在最新版本。

🔧 工具集成

cliamp 有意建立在系统已有的组件之上：

  • ALSA：音频通过 libasound 输出，这也是软件包依赖它的原因，因此在没有桌面会话的裸服务器上同样可用
  • ffmpeg：推荐依赖，用于内置解码器覆盖不到的格式和流
  • yt-dlp：建议依赖，播放 YouTube 和 YouTube Music 时必需
  • 基于 D-Bus 的 MPRIS：键盘上的媒体键和桌面的“正在播放”小部件可以像控制其他播放器一样控制 cliamp
  • Waybar、quickshell 与你的 shell：IPC 套接字和 cliamp visstream 驱动状态栏与小部件，本软件包还自带 bash 和 zsh 补全

❓ 常见问题

cliamp 在官方 Ubuntu 软件源中吗？

不在, 官方 Ubuntu 源没有打包 cliamp。本仓库目前是唯一的 apt 来源，提供 cliamp 1.63.2。

如何在 Ubuntu 上安装最新版 cliamp？

按上方说明一次性添加 deb.griffo.io 仓库，然后运行：sudo apt install cliamp。之后通过常规的 sudo apt upgrade 获取新版本。

软件包是否有签名？如何构建？

每个软件包都使用仓库的 GPG 密钥（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）签名，并基于上游发布在公开的 GitHub 仓库中构建，任何人都可以审查。
