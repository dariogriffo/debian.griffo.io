⚡ 简短回答。 可以，deb.griffo.io 支持 elementary OS。在 elementary OS 8、elementary OS 7 上，63 款开发工具可以直接用 apt 安装，配置命令与 Debian 和 Ubuntu 完全相同：它从 /etc/os-release 读取 UBUNTU_CODENAME，并请求对应的套件，在 elementary OS 8（Circe） 上即为 noble。

elementary OS 基于 Ubuntu LTS 构建，它的 AppCenter 以 Flatpak 应用为核心，因此命令行开发工具只能依靠 apt，以及 Ubuntu 基础系统冻结下来的版本。deb.griffo.io 为下列每个工具提供上游最新版本，以针对该基础系统构建的 apt 软件包形式提供。

❓ 常见问题

为什么使用 lsb_release -sc 的教程在 elementary OS 上会失败？

lsb_release -sc 输出的是 elementary 自己的代号（OS 8 上为 circe），没有任何 apt 仓库为它构建软件包。这里的配置命令读取 UBUNTU_CODENAME，elementary OS 会把它设为 Ubuntu 基础版本（noble）。

deb.griffo.io 是 elementary OS 的官方仓库吗？

不是。这是由 Dario Griffo 维护的非官方仓库，与 elementary OS 没有任何关联。每个软件包都根据上游官方发布自动构建，打包代码在 GitHub 上开源，软件源经过 GPG 签名。

需要付费吗？

本仓库采用订阅制（每年 15 欧元，或一次性 150 欧元），并提供免费试用。另有免费镜像 deb-free.griffo.io，以一定延迟提供较少的工具，在这个发行版上的配置方式相同。

如何移除这个仓库？

删除 /etc/apt/sources.list.d/deb.griffo.io.list 和 /etc/apt/keyrings/deb.griffo.io.gpg，然后运行 sudo apt update。已经安装的工具会一直保留，直到你用 apt remove 卸载它们。
