1. 你已经订阅：保存凭据

凭据应放在 /etc/apt/auth.conf.d/，绝不要写进 sources.list 那一行：那样机器上任何用户都能读到，apt 还会在错误信息里把它泄露出来：

运行命令
sudo tee /etc/apt/auth.conf.d/deb.griffo.io.conf > /dev/null <<'EOF'
machine deb.griffo.io
login your-email@example.com
password your-subscription-password
EOF
sudo chmod 600 /etc/apt/auth.conf.d/deb.griffo.io.conf
sudo apt update
tee /etc/apt/auth.conf.d/deb.griffo.io.conf > /dev/null <<'EOF'
machine deb.griffo.io
login your-email@example.com
password your-subscription-password
EOF
chmod 600 /etc/apt/auth.conf.d/deb.griffo.io.conf
apt update

  • machine 行写的是 deb.griffo.io：不带 https://、不带结尾斜杠、不带 /apt 路径。
  • 文件位于 /etc/apt/auth.conf.d/，且文件名以 .conf 结尾。其他扩展名会被 apt 静默忽略。
  • 文件属于 root，权限为 600。apt 拒绝读取其他用户可读的凭据。
  • 密码两侧没有多余的引号，结尾也没有空白字符。

🧩 关于 extrepo 选项。 extrepo 是 Debian 官方用于管理第三方仓库的工具：它会替你写好 sources 文件并安装签名密钥，并在使用前先对照签名元数据校验该密钥。本仓库以 griffo 之名登记其中，永久免费镜像则为 griffo-free，因此在 Debian（bookworm、trixie、forky、sid）上，上面的命令就是全部配置。

Ubuntu 不在覆盖范围内，因为 extrepo 只发布 Debian 各套件的元数据：在 Ubuntu 上请使用 sudo 或 root 的命令。
