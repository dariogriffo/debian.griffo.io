什么是 ripgrep？

ripgrep（即 rg 命令）是由 Andrew Gallant 用 Rust 编写的面向行的搜索工具。它会在当前目录中递归搜索正则表达式，同时遵循你的 .gitignore 规则，并自动跳过隐藏文件、被忽略的文件和二进制文件。它是 VS Code 等编辑器背后的搜索引擎，通常比 GNU grep、The Silver Searcher 和 ack 更快。

🚀 为什么最新版本很重要： ripgrep 在各个版本之间持续获得实质性能力——支持超链接以直接跳转到编辑器、--engine auto 可透明回退到 PCRE2、更丰富的 --json 输出，以及正则引擎持续的吞吐提升。官方源中的版本早于其中大部分改进。

⚡ ripgrep 的主要特性

🚀 极快

有限自动机正则引擎、SIMD 字面量扫描、内存映射和并行目录遍历，使它在大型目录树上比 grep 更快。

🙈 遵循 .gitignore

默认跳过被忽略的文件、隐藏文件和二进制文件，因此结果正是你关心的内容。可用 -u、-uu 或 -uuu 覆盖。

🌍 完整的 Unicode 支持

默认支持 Unicode——字符类、大小写折叠、单词边界和字素处理都能正确工作，且几乎没有速度损失。

🧩 PCRE2 正则

-P 可启用环视和反向引用。此构建已内置 PCRE2，开箱即用并启用了 JIT。

📄 按文件类型过滤

用 -t rust 限定语言，用 -T html 排除，或自定义类型。内置 800 多个匹配规则。

🔁 多行与替换

用 -U 跨行搜索，用 -r 预览替换，用 --json 输出结构化结果。

🚀 始终领先于官方软件源： Debian 和 Ubuntu 在发布时会冻结软件包版本——本仓库通常在数小时内发布新的上游版本。只需 apt upgrade 即可保持最新。

🎯 基本使用示例

日常搜索：

# 搜索当前目录树
rg 'TODO'

# 忽略大小写、全词匹配
rg -i -w 'timeout'

# 显示每个匹配前后 3 行上下文
rg -C 3 'panic!'

# 只列出包含匹配的文件
rg -l 'BurntSushi'

限定搜索范围：

# 仅 Rust 文件
rg -t rust 'unsafe'

# 排除 HTML 和 CSS
rg -T html -T css 'font-size'

# 包含被忽略和隐藏的文件
rg -uu 'password'

# 用 glob 限定
rg -g '*.toml' 'version'

超越普通 grep：

# 通过 PCRE2 使用环视和反向引用
rg -P '(?<=fn )\w+' src/

# 跨行搜索
rg -U 'struct \w+ \{\n[^}]*pub'

# 预览替换（不写入文件）
rg 'v(\d+)\.(\d+)' -r 'v$1.$2.0'

# 供脚本使用的结构化输出
rg --json 'error' | jq -r 'select(.type=="match") | .data.path.text'

按上方说明一次性添加 deb.griffo.io 仓库，然后运行：sudo apt install ripgrep。之后通过常规的 sudo apt upgrade 获取新版本。
