什么是 Rust？

Rust 是一门注重速度、内存安全和可靠并发的系统编程语言，而这个软件包就是官方的 Rust 稳定版工具链：来自 static.rust-lang.org 的二进制文件，与 rustup 安装的完全相同，未经任何修改重新打包。每次构建在打包前都会经过校验：用 Rust 发布签名密钥（指纹 108F 6620 5EAE B0AA A8DD 5E1C 85AB 96E6 FA1B E5FE）验证发布清单的 GPG 签名，并按该清单核对每个 tarball 的 SHA-256。一个软件包 rust-stable 就提供 rustc、cargo、rustdoc、rustfmt、clippy、rust-analyzer 和标准库，并随每个稳定版更新：每六周一次，外加各个修订版本。Debian 和 Ubuntu 以 rustc 的名字打包同一个编译器；这里刻意使用不同的名字，原因见下文。

🚀 为什么最新版本很重要：Rust 每六周发布一个新的稳定版，crate 也随之前进：新的语言特性和库 API 一稳定就会被使用，而声明了更新 rust-version 的 crate 无法用旧编译器构建。Debian 以 rustc 和 cargo 打包 Rust，trixie 冻结在 rustc 1.85.1，所以全新安装的系统每发布一个版本就落后更多。本仓库以 rust-stable 的名字提供 Rust 1.100.0，这是一套完整的工具链，取代发行版的 rustc 和 cargo，并在每次 apt upgrade 时随之更新。

⚡ Rust 的主要功能

🦀 完整的工具链

rustc、cargo、rustdoc、rustfmt、clippy（cargo clippy）、rust-analyzer、rust-gdb 和 rust-lldb 包装脚本，以及本机的标准库，全部来自同一个版本。

🔏 经过校验的官方二进制文件

与 rustup 从 static.rust-lang.org 下载的二进制文件完全相同，未经修改重新打包。构建过程在打包任何内容之前都会校验清单的 GPG 签名和每个 tarball 的 SHA-256。

👥 所有用户共用一次安装

整个系统只有一套工具链，由机器上的所有用户共享，而不是每个主目录里各有一个 ~/.rustup，并由 apt 随系统其他部分一起更新。

🧩 始终配套，绝不混用

rustc、cargo、标准库、clippy 和 rustfmt 是版本锁定的一组。只替换 rustc 会让新编译器配上旧的 std，所以 rust-stable 总是整体更新整套工具链。

🎯 额外目标以软件包提供

用 rust-stable-std-musl 构建静态 Linux 二进制文件，它自带 musl；用 wasm32-unknown-unknown、wasm32-wasip1 和 wasm32-wasip2 构建 WebAssembly，每个都只需一条 apt install。

📚 源代码与离线文档

rust-stable-src 提供 rust-analyzer 读取的标准库源代码，rust-stable-doc 把 The Book、std API 文档和 Cargo 手册放到本地，供离线阅读。

🚀 始终领先于官方软件源： Debian 和 Ubuntu 在发布时冻结软件包版本，而本仓库通常在上游发布后数小时内就发布新版本。一条简单的 apt upgrade 就能让你保持最新。

🔧 工具集成

这套工具链像其他系统软件包一样安装，因此你环境中的其他部分无需配置就能找到它：

  • 目录结构： 所有内容都位于 /usr/lib/rust-stable，自带捆绑的 LLVM，命令链接到 /usr/bin，因此每个用户的 PATH 中都有，无需修改 shell 配置
  • 链接： 软件包依赖一个 C 编译器（gcc 或 clang）和 libc6-dev，rustc 用它们进行链接，所以安装后 cargo build 立即可用
  • 编辑器： rust-analyzer 包含在软件包中，任何带有 language server 客户端的编辑器都能使用它；rust-stable-src 让它可以跳转到标准库内部
  • 调试器： rust-gdb 和 rust-lldb 会在加载 Rust pretty-printer 的情况下启动 gdb 或 lldb，让 Rust 类型显示得清晰易读
  • Shell： cargo 的 man 手册以及 bash 和 zsh 补全会随软件包一起安装
  • 交叉编译目标： musl 和 WebAssembly 的标准库是独立的软件包，用 apt install 添加，而不是 rustup target add
  • 文档： rust-stable-doc 把 HTML 文档安装到 /usr/share/doc/rust-stable-doc/html，全部内容也可以在线访问 doc.rust-lang.org

🚀 为什么选择 deb.griffo.io？

📊 仓库对比：
  • 官方 Debian： 以 rustc 和 cargo 打包 Rust，trixie 中为 1.85.1，在整个发行版生命周期内冻结
  • rustup： 同样的官方二进制文件，但为每个用户分别安装在 ~/.rustup 下，用 rustup update 而不是 apt 更新
  • 从源码构建： 要先用上一个版本的编译器自举 rustc，再构建它的 LLVM，编译耗时长且资源消耗大
  • deb.griffo.io: 最新版本，并自动更新
  • ✅ 配套一致的工具链： 软件包名为 rust-stable 而不是 rustc，因为编译器、cargo、std、clippy 和 rustfmt 必须来自同一个版本，所以它们一起发布、一起升级
  • ✅ 官方二进制文件： 与 rustup 从 static.rust-lang.org 安装的完全相同，未经修改，构建时用 Rust 发布签名密钥和清单中的 SHA-256 校验和进行验证
  • ✅ 完整的软件包： 工具链位于 /usr/lib/rust-stable，自带 LLVM，命令在 /usr/bin，附带 man 手册和 cargo 补全，推荐安装 rust-stable-src，文档以及 musl 和 WebAssembly 目标作为可选软件包
  • ✅ 自动更新： 上游发布后数小时内更新软件包
  • ✅ 两种架构： 每个版本都提供 amd64 和 arm64，包括运行 64 位系统的树莓派 4 和 5
  • ✅ 多发行版： 支持 Bookworm、Trixie、Forky 和 Sid
  • ✅ 易于维护： 使用标准 apt 命令即可更新

❓ 常见问题

Rust 在官方 Debian 软件源中吗？

在，但官方 Debian 源只提供 Rust 1.85.1，而本仓库提供 Rust 1.100.0，每次上游发布后数小时内重新构建。

如何在 Debian 上安装最新版 Rust？

按上方说明一次性添加 deb.griffo.io 仓库，然后运行：sudo apt install rust-stable。之后通过常规的 sudo apt upgrade 获取新版本。

软件包是否有签名？如何构建？

每个软件包都使用仓库的 GPG 密钥（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）签名，并基于上游发布在公开的 GitHub 仓库中构建，任何人都可以审查。
