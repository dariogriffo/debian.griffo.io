什么是 Television？

Television（命令名为 tv）是一个围绕“频道”构建的模糊查找器。频道是一个具名的数据源，拥有自己的预览命令、按键绑定和动作：文件、文件内的文本、目录、git 仓库、环境变量、进程、Docker 容器，或任何你能用几行 TOML 描述出来的东西。它边输入边搜索，为选中项显示预览，并把结果交给 shell、编辑器或你自己的命令。

🚀 为什么最新版本很重要： Television 是一个迭代很快的年轻项目：频道、动作、shell 集成和配置格式都在版本之间不断演进，而 tv update-channels 会从上游拉取最新的频道原型，这些原型需要相匹配的程序版本。Debian 与 Ubuntu 都没有收录它，所以用最新构建不是锦上添花，而是唯一能用上它的方式。

⚡ Television 的主要功能

🔎 频道，不只是文件

文件、文本、目录、git 仓库、环境变量、进程和容器都是频道——tv list-channels 会列出当前构建自带的频道。

👁️ 内建预览

每个频道都可以定义预览命令，于是结果列表旁边就能看到文件内容、日志、差异或容器详情。

🧵 用 TOML 随意改造

一个频道就是一个小小的 TOML 文件，描述数据源命令、预览、按键和动作——新增一套工作流，只是在 ~/.config/television/cable/ 里放一个文件。

⌨️ Shell 集成

tv init 会把智能补全绑到 Ctrl+T，把历史搜索绑到 Ctrl+R，支持 bash、zsh 和 fish。

🚀 天生就快

异步并行的匹配器让面对超大数据源时输入依然跟手，预览按需计算，还可以缓存。

🧰 临时模式

--source-command 与 --preview-command 可以把两条 shell 命令变成一次性的查找器，完全不必先写频道。

🚀 始终领先于官方软件源： Debian 和 Ubuntu 在发布时冻结软件包版本，而本仓库通常在上游发布后数小时内就发布新版本。一条简单的 apt upgrade 就能让你保持最新。

🎯 基本用法示例

日常搜索：

# 默认频道
tv

# 最常用的几个频道
tv files
tv text
tv dirs
tv git-repos

# 从当前目录以外的位置开始
tv files ~/src

# 拉取最新的频道原型
tv update-channels

用任意命令创建临时频道：

# 把任意命令变成模糊查找器
tv --source-command "fd -t f -H"

# 并基于选中的条目生成预览
tv --source-command "git branch --format='%(refname:short)'" \
   --preview-command "git log -20 --oneline {}"

# 保留数据源命令输出的颜色
tv --source-command "rg --color=always -n TODO" --ansi

# 保持数据源自身的顺序，而不是按匹配度排序
tv --source-command "ls -t" --no-sort

Shell、补全与自定义频道：

# 在当前 shell 中启用 Ctrl+T 和 Ctrl+R
eval "$(tv init zsh)"

# 为 tv 自身的子命令启用补全
tv completions fish > ~/.config/fish/completions/tv.fish

# 自定义频道放在 cable 目录中
mkdir -p ~/.config/television/cable
$EDITOR ~/.config/television/cable/tldr.toml

# 升级之后，清理配置里由程序写入的默认值
tv migrate-config

🔧 工具集成

Television 天生就是用来和你其余工具粘在一起的：

  • 你的 shell：tv init bash、zsh 或 fish 会加上智能补全和历史搜索，任何频道都能把结果直接写进命令行
  • 编辑器：社区为 Neovim、Vim、VS Code、JetBrains 系列 IDE 和 Zed 都做了集成，背后都是同一个程序
  • ripgrep 之类：频道就是 shell 命令，因此 rg、fd、git、docker 或你自己的脚本都可以充当数据源
  • 配置：~/.config/television/config.toml 管默认值和按键，cable/*.toml 管频道本身
  • 其他一切：选中的条目会输出到 stdout，因此 tv 能像任何命令一样与管道、别名和脚本组合

  • ✅ 完整软件包：上游二进制文件安装为 /usr/bin/tv，并附带 tv.1 手册页以及 bash、zsh 和 fish 补全

❓ 常见问题

Television 在官方 Ubuntu 软件源中吗？

不在 — 官方 Ubuntu 源没有打包 Television。本仓库目前是唯一的 apt 来源，提供 Television 0.15.9。

如何在 Ubuntu 上安装最新版 Television？

按上方说明一次性添加 deb.griffo.io 仓库，然后运行：sudo apt install television。之后通过常规的 sudo apt upgrade 获取新版本。

软件包是否有签名？如何构建？

每个软件包都使用仓库的 GPG 密钥（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）签名，并基于上游发布在公开的 GitHub 仓库中构建，任何人都可以审查。
