什么是 Forgejo Runner？

Forgejo Runner 是 Forgejo Actions 的CI 运行器。它是一个轻量级守护进程，连接到你的 Forgejo 实例，获取排队中的工作流任务，并在你自己的基础设施上执行——可使用 Docker、LXC 或直接在主机上运行——为你提供完全自托管、兼容 GitHub Actions 的 CI/CD 流水线。

🚀 为什么最新版本很重要：该运行器紧跟 Forgejo 的版本发布，持续加入对新工作流功能的支持、更好的隔离机制以及错误修复。保持最新可确保与最新的 Forgejo Actions 功能兼容。

⚡ Forgejo Runner 的核心功能

🔁 兼容 Actions

使用与 GitHub Actions 相同的语法和 action 生态系统运行工作流。

🐳 灵活执行

可在 Docker 容器、LXC 中执行任务，或直接在主机上运行。

🔐 自托管

将你的 CI/CD 完全保留在自己的基础设施上，无需依赖任何第三方。

⚖️ 可扩展

注册多个带标签的运行器，以分发和定向工作负载。

🎯 为什么选择 Forgejo Runner？

  • 掌控你的 CI：在你掌控的硬件上运行流水线
  • Actions 生态系统：复用现有的 GitHub 风格工作流定义
  • 灵活隔离：Docker、LXC 或主机执行，满足你的不同需求
  • 轻量级：单个 Go 二进制文件，部署简单

🆕 主要亮点

  • 任务执行：运行排队中的 Forgejo Actions 工作流
  • 标签：将任务定向到指定运行器
  • 容器支持：通过 Docker 实现隔离构建
  • 守护进程模式：作为服务持续运行

🧩 关于 extrepo 选项。 extrepo 是 Debian 官方用于管理第三方仓库的工具：它会替你写好 sources 文件并安装签名密钥，并在使用前先对照签名元数据校验该密钥。本仓库以 griffo 之名登记其中，永久免费镜像则为 griffo-free，因此在 Debian（bookworm、trixie、forky、sid）上，上面的命令就是全部配置。

extrepo 只负责 sources 文件和密钥，订阅凭据仍然要写入 /etc/apt/auth.conf.d/deb.griffo.io.conf。Ubuntu 不在覆盖范围内，因为 extrepo 只发布 Debian 各套件的元数据：在 Ubuntu 上请使用 sudo 或 root 的命令。

❓ 常见问题

Forgejo Runner 在官方 Debian 软件源中吗？

不在, 官方 Debian 源没有打包 Forgejo Runner。本仓库目前是唯一的 apt 来源，提供 Forgejo Runner 13.0.0。

如何在 Debian 上安装最新版 Forgejo Runner？

按上方说明一次性添加 deb.griffo.io 仓库，然后运行：sudo apt install forgejo-runner。之后通过常规的 sudo apt upgrade 获取新版本。

软件包是否有签名？如何构建？

每个软件包都使用仓库的 GPG 密钥（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）签名，并基于上游发布在公开的 GitHub 仓库中构建，任何人都可以审查。

支持哪些 Debian 版本？

Debian 12 Bookworm、Debian 13 Trixie、Forky 和 Sid。
