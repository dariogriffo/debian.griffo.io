什么是 tldr？

tldr 是 tldr-pages 的官方 Rust 客户端。tldr-pages 是社区维护的简化版 man 手册：每一页先用一句话说明命令是干什么的，接着列出人们真正会敲的那几条示例。上游项目叫 tlrc，软件包和命令都叫 tldr。它是一个没有任何依赖的静态二进制文件，把整套页面保存在本地缓存里，所以查询瞬间完成、离线也能用，缓存过期后还会自己更新。页面按平台分类（Linux、macOS、Windows、Android、各种 BSD），有几十种语言，输出的颜色和排版都在一个 TOML 文件里，软件包还附带 man 手册和 bash、zsh、fish 的补全。

🚀 为什么最新版本很重要： tlrc 跟着 tldr-pages 的客户端规范一起演进：新的平台目录、语言回退规则、页面搜索、自定义页面目录，以及控制缓存时效和颜色的配置项，都是一个版本接一个版本加进来的，旧的二进制文件要么忽略它们，要么把新页面渲染错。Debian 自己的 tldr 软件包是另一个程序，即 Haskell 客户端 tldr-hs，而 Debian 的 tealdeer 也会装一个 /usr/bin/tldr；两者都不是 tlrc，所以要通过 apt 拿到官方客户端，就得靠这个仓库。

⚡ tldr 的主要功能

📄 示例优先

tldr tar 打印的是你真正会用到的八种 tar 用法，而不是它接受的两百个参数。多个单词的命令照常输入即可：tldr git rebase、tldr docker compose。

⚡ 本地缓存，而不是网络请求

第一次运行会下载整套页面；之后每次查询都只是读一个文件，手指还没离开回车键页面就出来了，在火车上或者代理后面也一样。缓存超过你设定的时效后会自己更新，也可以用 --update 手动刷新。

🖥️ 所有平台，一条命令

页面按平台组织。默认给你 Linux 的那一页，要给面前这台机器以外的系统写说明时，用 -p macos 或 -p windows。

🌍 你的语言

tldr-pages 已被翻译成几十种语言。tlrc 遵循 LANG 和 LANGUAGE，逐页回退到英文，也可以用 -L 为单次查询指定语言。

🔍 找到你还不知道的那一页

--list 打印当前平台的所有页面名称，--search 在名称和描述里查找，--info 告诉你缓存有多旧、包含哪些语言。

🎨 由你来配置

一个 config.toml：渲染页面的每一种颜色和样式、自动更新前的缓存时效、要下载的语言、优先使用的平台，还有一个在缓存之前被查找的自定义页面目录。

🚀 始终领先于官方软件源： Debian 和 Ubuntu 在发布时冻结软件包版本，而本仓库通常在上游发布后数小时内就发布新版本。一条简单的 apt upgrade 就能让你保持最新。

tldr --color never tar

# 即使缓存过期也绝不联网

🔧 工具集成

tldr 只是一个查询工具，所以它和你已经在用的工具配合得很好：

  • 你的 shell： 软件包安装了 bash、zsh 和 fish 的补全，tldr gi<tab> 会从缓存里补全页面名称，客户端本身的手册则是 man tldr
  • fzf： tldr --list | fzf | xargs tldr 一行就是一个模糊页面选择器，--raw 的输出可以喂给预览窗格
  • 修正页面： tldr --edit tar 会打印一个在 GitHub 网页编辑器中打开该页面的链接，修正一个 tldr 页面只差一个 pull request
  • man： tldr 不是用来取代手册的，它是先读的那一个；知道自己要哪个参数之后，完整的手册就在一条 man 之外
  • 脚本和文档： --color never 和 --raw 让输出可以放心地贴进 README、工单或日志

🚀 为什么选择 deb.griffo.io？

📊 仓库对比：
  • 官方 Debian： apt install tldr 装到的是 Haskell 客户端 tldr-hs，tealdeer 则是另一个同名命令的 Rust 客户端；两者都不是官方的 tlrc
  • 自己从源码构建： 版本够新，但每台机器都要一套 Rust 工具链，而且留下一个 apt 完全不知道的二进制文件
  • 上游的发布压缩包： 同样的静态二进制文件，但要手动解压到 PATH 里，没有补全、没有 man 手册、也没有更新
  • deb.griffo.io: 最新版本，并自动更新
  • ✅ 官方客户端： tlrc 是 tldr-pages 项目自己维护的客户端，而不是众多重新实现中的一个
  • ✅ 命令是 tldr： 软件包叫 tldr 是因为命令就叫这个名字，而且它与 tealdeer 冲突并替换它，所以 /usr/bin/tldr 永远不会有争抢
  • ✅ 自动更新： 上游发布后数小时内更新软件包，页面缓存还会在此之上自己更新
  • ✅ 完整的软件包： 二进制文件、man 手册，以及 bash、zsh 和 fish 的补全
  • ✅ 零依赖： 静态链接的 musl 二进制文件，不会再拉进任何别的东西
  • ✅ 两种架构： amd64 和 arm64，同一个静态二进制文件在所有版本上都能运行
  • ✅ 多发行版： 支持 Debian 13 (trixie) 及更新版本：Trixie、Forky 和 Sid
  • ✅ 易于维护： 使用标准 apt 命令即可更新

tldr 在官方 Debian 软件源中吗？

不在, 官方 Debian 源没有打包 tldr。本仓库目前是唯一的 apt 来源，提供 tldr 1.13.1。

如何在 Debian 上安装最新版 tldr？

按上方说明一次性添加 deb.griffo.io 仓库，然后运行：sudo apt install tldr。之后通过常规的 sudo apt upgrade 获取新版本。

软件包是否有签名？如何构建？

每个软件包都使用仓库的 GPG 密钥（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）签名，并基于上游发布在公开的 GitHub 仓库中构建，任何人都可以审查。
