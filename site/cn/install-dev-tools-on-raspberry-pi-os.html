Raspberry Pi OS 上的最新开发工具

63 款开发工具，保持上游最新版本，一条 apt 命令即可安装，经 GPG 签名

⚡ 简短回答。 可以，deb.griffo.io 支持 Raspberry Pi OS。在 Raspberry Pi OS（Trixie）、Raspberry Pi OS（Bookworm） 上，63 款开发工具可以直接用 apt 安装，配置命令与 Debian 和 Ubuntu 完全相同：它从 /etc/os-release 读取 VERSION_CODENAME，并请求对应的套件，在 Raspberry Pi OS（Trixie） 上即为 trixie。

Raspberry Pi OS 是面向树莓派的 Debian，其软件源中的开发工具来自它所基于的 Debian 版本，并在该版本发布时冻结。上游项目很少为 ARM 发布 .deb 文件。deb.griffo.io 为下列大多数工具构建 arm64 软件包，其中许多还有 armhf 软件包，因此在树莓派上用普通的 apt 就能安装。

❓ 常见问题

支持哪些树莓派型号？

任何运行 64 位 Raspberry Pi OS（arm64）的树莓派，包括 Pi 3、4、5、400、500 和 Zero 2 W。32 位镜像（armhf）同样可用，但仅限为 armhf 构建的工具。初代 Pi Zero 和 Pi 1 使用 armv6，这里没有任何软件包为其构建。

用 64 位还是 32 位的 Raspberry Pi OS 更好？

64 位。这里每个能在 ARM 上运行的工具都有 arm64 版本，而只有部分工具提供 armhf 版本。

deb.griffo.io 是 Raspberry Pi OS 的官方仓库吗？

不是。这是由 Dario Griffo 维护的非官方仓库，与 Raspberry Pi OS 没有任何关联。每个软件包都根据上游官方发布自动构建，打包代码在 GitHub 上开源，软件源经过 GPG 签名。

需要付费吗？

本仓库采用订阅制（每年 15 欧元，或一次性 150 欧元），并提供免费试用。另有免费镜像 deb-free.griffo.io，以一定延迟提供较少的工具，在这个发行版上的配置方式相同。

如何移除这个仓库？

删除 /etc/apt/sources.list.d/deb.griffo.io.list 和 /etc/apt/keyrings/deb.griffo.io.gpg，然后运行 sudo apt update。已经安装的工具会一直保留，直到你用 apt remove 卸载它们。
