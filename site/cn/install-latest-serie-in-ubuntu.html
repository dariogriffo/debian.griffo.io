什么是 Serie？

Serie 是一个浏览 Git 仓库历史的终端界面。它展示的内容与 git log --graph --all 相同，但提交图是通过终端模拟器的内联图像协议绘制的，而不是用 ASCII 字符拼凑，因此分支与合并一眼就能看清。图旁边是可滚动、可搜索的提交列表，还有提交详情视图。它有意只做查看器，而不是 Git 客户端：不提交、不建分支、也不推送。

🚀 为什么最新版本很重要： Serie 还是个年轻项目，尚未发布 1.0，新功能都在普通版本里出现：用户自定义命令、可自定义按键、提交图样式与排序选项，以及对 Kitty 图形协议 Unicode 占位符模式的支持。终端对图像的支持本身也在不断变化，因此能在你终端里正确绘制的，通常就是最新版本。

⚡ Serie 的主要功能

🖼️ 真正的提交图

提交图通过 Kitty 或 iTerm2 协议以图像方式渲染，即使几十条分支并行，分支线依然清晰可读。

🔍 可搜索的历史

图旁边就是可滚动、可搜索的提交列表，不必再翻 git log 的输出。

📄 提交详情视图

选中某个提交即可查看提交信息、引用和差异，无需离开提交图。

🎛️ 提交图选项

按时间或拓扑排序、单倍或双倍宽度的单元格、圆角或直角连线——在命令行或配置文件中设置一次即可。

⌨️ 自定义按键

? 会显示当前按键，而所有按键都能在 config.toml 中覆盖。

🧰 用户命令

对选中的提交运行你自己的命令：在专用视图中显示输出、在后台执行，或挂起 Serie 去跑交互式程序。

🚀 始终领先于官方软件源： Debian 和 Ubuntu 在发布时冻结软件包版本，而本仓库通常在上游发布后数小时内就发布新版本。一条简单的 apt upgrade 就能让你保持最新。

🎯 基本用法示例

浏览历史：

# 当前仓库的完整历史
serie

# 只看最近的提交，适合超大仓库
serie -n 5000

# 使用拓扑排序而非时间排序
serie -o topo

# 启动时选中 HEAD，而不是最新的提交
serie -i head

让提交图适配你的终端：

# 自动识别不准时，强制指定图像协议
serie -p kitty
serie -p iterm
serie -p kitty-unicode

# 窗口较小时使用更窄的图形单元格
serie -g single

# 使用直角连线代替圆角
serie -s angular

# 或者在宽终端上使用宽松的圆角外观
serie -g double -s rounded

配置与日常使用：

# 配置文件，用于按键与默认值
mkdir -p ~/.config/serie
$EDITOR ~/.config/serie/config.toml

# 或者让 Serie 使用别处的配置文件
SERIE_CONFIG_FILE=~/dotfiles/serie.toml serie

# Serie 只读取历史——git 仍然是你的客户端
git -C ~/src/project log --oneline -5

# 所以提交依然是 git 的工作
git commit -v

🔧 工具集成

Serie 需要两样东西，并与第三样协作：

  • git：一个普通的 Git 仓库，以及 git 程序本身——软件包已将其列为依赖
  • 你的终端：支持 Kitty 或 iTerm2 内联图像协议的模拟器——Ghostty、Kitty、WezTerm 和 iTerm2 都符合
  • 配置文件：$XDG_CONFIG_HOME/serie/config.toml，或 SERIE_CONFIG_FILE 指向的文件
  • 用户命令：把 git diff、编辑器或自己的脚本绑定到某个按键，对选中的提交执行
  • 你的 git 客户端：Serie 有意不提交也不推送，因此它与 lazygit、GitUI 或原生 git 并存，而不是取代它们

Serie 在官方 Ubuntu 软件源中吗？

不在, 官方 Ubuntu 源没有打包 Serie。本仓库目前是唯一的 apt 来源，提供 Serie 0.8.1。

如何在 Ubuntu 上安装最新版 Serie？

按上方说明一次性添加 deb.griffo.io 仓库，然后运行：sudo apt install serie。之后通过常规的 sudo apt upgrade 获取新版本。

软件包是否有签名？如何构建？

每个软件包都使用仓库的 GPG 密钥（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）签名，并基于上游发布在公开的 GitHub 仓库中构建，任何人都可以审查。
