什么是 Atuin AI？

Atuin AI 是 Atuin 的 shell 智能体。Atuin 在 18.24 及之前的版本中内置了它，并在 18.25 中移除；现在它以独立的二进制文件 atuin-ai 继续存在。在空提示符下按 ?，终端里就会打开一个对话：描述你想做的事，它会建议对应的命令；提出问题，它会给出回答。在你允许的情况下，它还可以搜索你的 Atuin 历史、读取和编辑文件以及运行命令。它连接的是你自己托管的 Atuin AI 服务器（上游以 Docker 镜像形式发布），而该服务器可以对接任何兼容 OpenAI 的端点：Ollama、vLLM 或托管的 API。客户端由 Atuin 团队用 Rust 编写，采用 MIT 许可证。

🚀 为什么最新版本很重要： Atuin AI 还很年轻，发展很快，而且上游完全不发布版本，只有提交到 main 的代码。本仓库每周五在 main 有变化时构建一个快照，版本号为 <客户端版本>.<YYYYMMDD>（例如 0.1.0.20261127），所以 apt upgrade 就能带来本周的更新，无需 Rust 工具链。Ubuntu 完全没有打包 atuin-ai。

❓ 一键即达

在空提示符下按 ? 即可打开智能体。在其他任何位置，? 照常输入问号，所以它不会干扰你正在输入的命令。

💡 命令建议

用普通的话描述任务（“查找本周修改过的大于 1 GB 的文件”），就能得到一条可以阅读、修改并运行的命令，不必再翻 man 手册。

📜 了解你的历史

在你允许后，智能体会搜索你的 Atuin 历史，从而找到你上个月运行过的命令，或者按照你在这台机器上的习惯来做事。

🛠️ 文件与命令

它可以替你读取和编辑文件、运行命令，并且会先征求你的同意。什么能动你的系统，由你决定。

🏠 你自己的服务器

客户端连接的是你自己运行的 Atuin AI 服务器，你的提示词和历史去哪里由你决定。上游以 ghcr.io/atuinsh/atuin-ai-server 的形式发布服务器。

🔌 任何兼容 OpenAI 的模型

服务器可以对接任何兼容 OpenAI 的端点：通过 Ollama 或 vLLM 运行的本地模型，或者托管的 API。在服务器上更换模型，无需改动客户端。

🚀 始终领先于官方软件源： Debian 和 Ubuntu 在发布时冻结软件包版本，而本仓库通常在上游发布后数小时内就发布新版本。一条简单的 apt upgrade 就能让你保持最新。

🔧 工具集成

Atuin AI 位于你的 shell、你的 Atuin 历史和你选择的模型之间：

  • Atuin： 硬依赖，会从 deb.griffo.io 一并安装；智能体搜索的是 atuin search 使用的同一个历史数据库，而且只在你允许时进行
  • Atuin 18.25 及以后： 18.25 移除了内置智能体，所以想在新版 Atuin 上继续使用 ? 对话，就靠这个软件包
  • bash、zsh 和 fish： atuin-ai init bash、zsh 或 fish 会输出按键绑定；把它放在 Atuin 自己的 init 之后加载，两个绑定就能共存
  • Atuin AI 服务器： ghcr.io/atuinsh/atuin-ai-server，用 Docker 或 Podman 运行在同一台机器上，或者客户端能访问到的任何地方；在服务器上设置 AUTH_TOKEN，并在 ~/.atuin/ai.toml 中设置 api_token 来加以保护
  • Ollama 和 vLLM： 让服务器指向本地的兼容 OpenAI 的端点，所有提示词都留在你自己的硬件上
  • 托管 API： 任何支持 OpenAI API 的服务商都以同样方式工作，配置在服务器上，而不是客户端里

🚀 为什么选择 deb.griffo.io？

📊 仓库对比：
  • 官方 Ubuntu： 没有打包 Atuin AI，在全新系统上 apt install atuin-ai 会失败
  • 上游下载： 根本没有：上游没有为客户端发布任何版本、标签或二进制文件
  • 从源码 cargo build： 需要克隆仓库、安装 Rust 工具链并编译几分钟，每次 main 更新都要手动重来
  • deb.griffo.io: 最新版本，并自动更新
  • ✅ 基于上游 main 构建： 用上游自己的 Cargo.lock 从上游源码编译；发布说明和 /usr/share/doc/atuin-ai/changelog.Debian 写明了每个快照对应的上游提交
  • ✅ 自动带上 Atuin： 依赖 atuin，deb.griffo.io 同样提供它，所以一条 apt install atuin-ai 就能装好两者
  • ✅ 仅客户端： 软件包安装 /usr/bin/atuin-ai 和一个示例 ai.toml；服务器留在 Docker 中，也就是上游发布它的方式
  • ✅ 自动更新： 每个新快照都通过一次简单的 apt upgrade 到达
  • ✅ 两种架构： amd64 和 arm64 支持 Ubuntu 22.04、24.04、25.10、26.04 和 26.10，与它所依赖的 Atuin 软件包相同；没有 i386 或 armhf 构建
  • ✅ 多发行版： 支持 Ubuntu 22.04、24.04、25.10、26.04 和 26.10
  • ✅ 易于维护： 使用标准 apt 命令即可更新

Atuin AI 在官方 Ubuntu 软件源中吗？

不在, 官方 Ubuntu 源没有打包 Atuin AI。本仓库目前是唯一的 apt 来源，提供 Atuin AI 0.1.0.20261125。

如何在 Ubuntu 上安装最新版 Atuin AI？

按上方说明一次性添加 deb.griffo.io 仓库，然后运行：sudo apt install atuin-ai。之后通过常规的 sudo apt upgrade 获取新版本。
