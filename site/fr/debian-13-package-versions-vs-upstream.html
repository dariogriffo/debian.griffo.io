📊 Versions des paquets Debian 13 et Ubuntu

Ce que distribuent les archives officielles, face à ce que propose ce dépôt — 2026-09-05

⚡ La réponse courte. Sur les 53 outils de ce dépôt, 38 ne figurent ni dans Debian 13 ni dans Ubuntu 26.04, et les autres sont figés à la version qui était courante à la sortie de ces distributions. Debian et Ubuntu figent les versions des paquets au moment de la publication d'une release et n'y appliquent ensuite guère plus que des correctifs de sécurité, ce qui est un compromis délibéré et souvent judicieux — mais cela veut dire que la version obtenue par apt install sur un système standard est celle qui était courante le jour de la sortie. Ce tableau donne le portrait complet d'un catalogue d'outils de développement, régénéré à chaque paquet publié plutôt que saisi à la main.

📋 Le tableau

Les versions officielles proviennent des archives Debian et Ubuntu elles-mêmes (le service madison), comparées à la version stable actuelle de chacune : Debian 13 « Trixie » et Ubuntu 26.04 « Resolute ». Les backports, testing et unstable sont exclus — la question est de savoir ce que donne un système stable standard. La dernière colonne indique ce que ce dépôt propose aujourd'hui.

🔍 Comment le lire

  • « non empaqueté » signifie que l'archive ne contient aucun paquet portant ce nom, dans la version stable actuelle de cette distribution. Sur un système standard, apt install échoue avec « Unable to locate package ».
  • Les versions sont affichées telles que les archives les rapportent, epochs et révisions Debian retirées, si bien que 1:0.44.1-1ubuntu2 se lit 0.44.1 — le numéro que le projet upstream reconnaîtrait.
  • Un outil peut être dans Ubuntu mais pas dans Debian, ou l'inverse : les deux archives prennent des décisions indépendantes et gèlent à des dates différentes.
  • Rien ici n'est une critique de Debian. Une archive figée est ce qui rend une version stable stable, et pour bon nombre de paquets c'est exactement ce que l'on veut. Cela convient mal aux outils qui publient toutes les deux ou trois semaines, ce qui est précisément la raison d'être de ce dépôt.

✅ Vérifiez n'importe quelle ligne vous-même

Tous les chiffres ci-dessus sont publics. Sur une machine Debian ou Ubuntu :

apt-cache policy ripgrep        # ce que votre système installerait, et depuis quelle source
apt-cache madison ripgrep       # toutes les versions proposées par vos sources configurées
rmadison ripgrep                # ce que distribuent les archives officielles, sans rien installer

rmadison vient du paquet devscripts et interroge le service à partir duquel ce tableau est construit. La colonne deb.griffo.io suit la dernière version publiée par chaque projet, reconstruite dans les heures qui suivent ; le dépôt d'empaquetage de chaque outil est listé sur comment les paquets sont construits.

📦 Obtenir la version actuelle à la place

Une seule ligne de dépôt couvre tous les outils du tableau, reconstruits dans les heures qui suivent chaque version upstream :

Exécuter les commandes
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | sudo tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
sudo apt update
install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
apt update
sudo apt install extrepo
sudo extrepo enable griffo
sudo apt update

🧩 À propos de l'option extrepo. extrepo est l'outil de Debian pour les dépôts externes : il écrit le fichier de sources et installe la clé de signature à votre place, après l'avoir vérifiée face à des métadonnées signées. Ce dépôt y est enregistré sous le nom griffo, et le miroir gratuit à vie sous griffo-free ; sur Debian (bookworm, trixie, forky et sid), les commandes ci-dessus constituent donc toute l'installation.

extrepo ne met en place que le fichier de sources et la clé : les identifiants d'un abonnement vont toujours dans /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu n'est pas couvert, car extrepo ne publie de métadonnées que pour les suites Debian : utilisez-y les commandes avec sudo ou en root.
