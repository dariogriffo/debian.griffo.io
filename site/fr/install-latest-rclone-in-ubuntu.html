Qu'est-ce que rclone ?

rclone est un gestionnaire de fichiers en ligne de commande pour le stockage cloud. Il parle à plus de soixante-dix fournisseurs — S3 et tout ce qui est compatible S3, Google Drive, Dropbox, OneDrive et SharePoint, Backblaze B2, Google Cloud Storage, Swift, SFTP, FTP, WebDAV et HTTP simple — avec un seul jeu de commandes cohérent. Il copie, synchronise et déplace avec des sommes de contrôle, monte n'importe quel dépôt distant comme un système de fichiers, le sert via une demi-douzaine de protocoles et transfère directement entre deux dépôts distants sans passer par votre disque.

🚀 Pourquoi les dernières versions comptent : rclone dialogue avec des API qui changent sans vous demander votre avis. Les fournisseurs modifient les flux d'authentification, suppriment des points d'accès et ajoutent des régions ; le correctif arrive dans la version suivante de rclone, celle où apparaissent aussi de nouveaux backends et des sous-commandes entières. La version des archives officielles est antérieure à plusieurs années de ce travail : « ça marchait l'an dernier » est exactement la panne qu'un rclone à jour évite.

⚡ Fonctionnalités clés de rclone

☁️ Plus de soixante-dix backends

Stockages objet compatibles S3, clouds grand public, suites d'entreprise et les protocoles classiques (SFTP, FTP, WebDAV, HTTP) derrière un même jeu de commandes.

🔁 Synchroniser avec sommes de contrôle

copy, sync et move comparent taille, date et empreintes, et --dry-run montre exactement ce qui changerait avant que quoi que ce soit change.

🗂️ Monter comme système de fichiers

rclone mount place un dépôt distant sous un répertoire, avec un cache VFS, pour que des programmes ordinaires y lisent et y écrivent.

🌐 Le resservir

rclone serve expose n'importe quel dépôt distant en HTTP, WebDAV, SFTP, FTP, DLNA, NFS ou en point d'accès S3 — pratique pour les appareils qui ne parlent qu'un protocole.

🔐 Chiffrement côté client

La surcouche crypt chiffre le contenu et les noms de fichiers avant l'envoi, et le fichier de configuration contenant vos jetons peut lui-même être chiffré.

⚡ Conçu pour le volume

Transferts et vérifications en parallèle, plages horaires de bande passante, filtres et copies côté serveur qui ne font jamais transiter les octets par votre machine.

🚀 Toujours en avance sur les archives officielles : Debian et Ubuntu figent les versions des paquets à la sortie d'une release — ce dépôt publie les nouvelles versions upstream généralement en quelques heures. Un simple apt upgrade vous maintient à jour.

🎯 Exemples d'utilisation de base

Copier et synchroniser :

# Envoyer un dossier, avec affichage de la progression
rclone copy -P ~/Documents mydrive:Documents

# Aligner la destination sur la source — toujours un essai à blanc d'abord
rclone sync --dry-run ~/site remote:bucket/site
rclone sync -P ~/site remote:bucket/site

# D'un cloud à l'autre directement, sans copie locale
rclone copy s3:bucket/data b2:backup/data

# Vérifier que ce qui est arrivé correspond à ce qui a été envoyé
rclone check ~/site remote:bucket/site

Monter et servir :

# Monter un dépôt distant comme système de fichiers (FUSE nécessaire)
sudo apt install fuse3
rclone mount mydrive: ~/mnt/drive --vfs-cache-mode writes

# Servir un dépôt distant sur le réseau local en HTTP ou WebDAV
rclone serve http remote:public --addr :8080
rclone serve webdav remote:docs --addr :8081

# Explorer ce qui occupe la place, façon ncdu
rclone ncdu remote:

# Juste la taille totale d'un bucket
rclone size remote:bucket

Réglages, filtres et chiffrement :

# Plus de parallélisme pour beaucoup de petits fichiers
rclone sync -P --transfers 8 --checkers 16 src: dst:

# Une plage horaire de bande passante, pour que les sauvegardes ne mangent pas la journée
rclone sync -P --bwlimit "08:00,512k 23:00,off" ~/photos remote:photos

# Des filtres plutôt que tout copier
rclone copy src: dst: --exclude "*.tmp" --filter-from filters.txt

# Envelopper un dépôt distant existant dans un chiffrement côté client
rclone config create secret crypt remote=mydrive:vault

🔧 Intégrations avec d'autres outils

rclone est la brique sur laquelle s'appuient d'autres outils :

  • FUSE : fuse3 (ou fuse) transforme rclone mount en vrai répertoire pour les programmes qui ne comprennent que des fichiers
  • systemd : une unité par montage ou par serve, et un timer pour le sync nocturne : c'est ainsi qu'on le fait tourner sans surveillance
  • Outils de sauvegarde : restic et consorts utilisent rclone comme dépôt distant et héritent aussitôt de tous les backends qu'il gère
  • Contrôle à distance : rclone rcd --rc-web-gui expose une API HTTP et une interface web pour les transferts au long cours
  • Fichier de configuration : ~/.config/rclone/rclone.conf contient les dépôts distants et peut être chiffré, pour que les identifiants ne soient jamais en clair

🚀 Pourquoi choisir deb.griffo.io ?

📊 Comparatif des dépôts :
  • Ubuntu officiel : fournit rclone dans universe, figé le jour de la release : les fournisseurs et sous-commandes récents n'y sont tout simplement pas

  • Snap : confiné, ce qui rend les montages FUSE et les chemins hors du dossier personnel plus pénibles qu'ils ne devraient l'être
  • deb.griffo.io : dernière version avec mises à jour automatiques
  • ✅ Des backends qui marchent encore : la version la plus récente, avec les correctifs fournisseurs et les nouveaux backends que la version figée de l'archive n'a jamais reçus
  • ✅ apt le garde à jour : pas de selfupdate, pas de script d'installation qui écrit dans /usr/bin dans le dos du gestionnaire de paquets
  • ✅ Mises à jour automatiques : les paquets sont mis à jour quelques heures après chaque version upstream
  • ✅ Paquet complet : le binaire officiel upstream plus la page de manuel rclone.1 et les complétions bash, zsh et fish
  • ✅ Quatre architectures : amd64, arm64, armhf et i386 : le NAS et le Raspberry Pi reçoivent le même rclone que le poste de travail
  • ✅ Multi-distribution : fonctionne sur Ubuntu 22.04, 24.04, 25.10 et 26.04
  • ✅ Maintenance simple : des mises à jour avec les commandes apt habituelles

❓ Questions fréquentes

rclone est-il dans les dépôts officiels de Ubuntu ?

Oui, mais l'archive officielle de Ubuntu fournit rclone 1.60.1, alors que ce dépôt propose rclone 1.75.0, reconstruit quelques heures après chaque version upstream.

Comment installer le dernier rclone sur Ubuntu ?

Ajoutez le dépôt deb.griffo.io une seule fois (instructions ci-dessus), puis exécutez : sudo apt install rclone. Les nouvelles versions arrivent via le sudo apt upgrade habituel.

Les paquets sont-ils signés et comment sont-ils construits ?

Chaque paquet est signé avec la clé GPG du dépôt (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) et construit à partir des versions upstream dans des dépôts GitHub publics que chacun peut inspecter.

Quelles versions de Ubuntu sont prises en charge ?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing et 26.04 Resolute.
