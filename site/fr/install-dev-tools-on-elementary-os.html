Les derniers outils de développement sur elementary OS

63 outils de développement dans leur dernière version upstream, une seule commande apt, signés GPG

⚡ La réponse courte. Oui, deb.griffo.io fonctionne sur elementary OS. 63 outils de développement s'installent avec un simple apt sur elementary OS 8 et elementary OS 7, avec la même commande de configuration que pour Debian et Ubuntu : elle lit UBUNTU_CODENAME dans /etc/os-release et demande la suite correspondante, noble sur elementary OS 8 (Circe).

elementary OS repose sur Ubuntu LTS, et son AppCenter est pensé pour les applications Flatpak : les outils de développement en ligne de commande sont donc laissés à apt, dans les versions figées par la base Ubuntu. deb.griffo.io fournit la version upstream actuelle de chacun des outils ci-dessous sous forme de paquet apt pour cette base.

elementary OS place son propre nom dans VERSION_CODENAME (circe sur OS 8), qui n'est pas une suite apt. Il renseigne aussi UBUNTU_CODENAME avec la version d'Ubuntu sous-jacente, et la commande de configuration lit celle-ci en premier : elle demande donc noble. C'est pour cette raison que les guides qui utilisent lsb_release -sc échouent sur elementary OS.

❓ Questions fréquentes

Pourquoi un guide qui utilise lsb_release -sc échoue-t-il sur elementary OS ?

lsb_release -sc affiche le nom de code propre à elementary (circe sur OS 8), et aucun dépôt apt n'est construit pour lui. La commande de configuration proposée ici lit UBUNTU_CODENAME, qu'elementary OS renseigne avec la base Ubuntu (noble).

deb.griffo.io est-il un dépôt officiel de elementary OS ?

Non. C'est un dépôt non officiel maintenu par Dario Griffo, sans lien avec elementary OS. Chaque paquet est construit automatiquement à partir de la version upstream officielle, l'empaquetage est open source sur GitHub et l'archive est signée GPG.

Est-ce payant ?

Le dépôt fonctionne par abonnement (15 € par an ou 150 € une seule fois), avec un essai gratuit. Un miroir gratuit, deb-free.griffo.io, propose une sélection plus restreinte d'outils avec un léger décalage, avec la même configuration sur cette distribution.

Comment supprimer le dépôt ?

Supprimez /etc/apt/sources.list.d/deb.griffo.io.list et /etc/apt/keyrings/deb.griffo.io.gpg, puis lancez sudo apt update. Les outils que vous avez installés restent en place jusqu'à ce que vous les supprimiez avec apt remove.
