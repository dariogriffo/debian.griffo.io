Qu'est-ce que ripgrep ?

ripgrep (la commande rg) est un outil de recherche orienté ligne écrit en Rust par Andrew Gallant. Il parcourt récursivement le répertoire courant à la recherche d'un motif d'expression régulière, en respectant vos règles .gitignore et en ignorant automatiquement les fichiers cachés, ignorés et binaires. C'est le moteur de recherche derrière des éditeurs comme VS Code, et il est généralement plus rapide que GNU grep, The Silver Searcher et ack.

🚀 Pourquoi les dernières versions comptent : ripgrep gagne de vraies fonctionnalités d'une version à l'autre — hyperliens pour sauter directement dans votre éditeur, --engine auto pour un repli transparent vers PCRE2, une sortie --json plus riche et des gains de débit réguliers dans son moteur d'expressions régulières. La version des archives est antérieure à la plupart de ces apports.

⚡ Fonctionnalités clés de ripgrep

🚀 Extrêmement rapide

Un moteur d'expressions régulières à automates finis, un balayage SIMD des littéraux, des projections mémoire et un parcours parallèle des répertoires le rendent plus rapide que grep sur les grandes arborescences.

🙈 Respecte .gitignore

Ignore par défaut les fichiers ignorés, cachés et binaires : les résultats sont ceux qui vous intéressent vraiment. Contournable avec -u, -uu ou -uuu.

🌍 Prise en charge complète d'Unicode

Compatible Unicode par défaut — classes de caractères, casse, limites de mots et graphèmes fonctionnent correctement, sans réel coût en vitesse.

🧩 Expressions PCRE2

-P débloque les assertions arrière et les références arrière. PCRE2 est compilé dans ce binaire : cela fonctionne immédiatement, avec le JIT activé.

📄 Filtrage par type de fichier

Limitez la recherche à un langage avec -t rust, excluez avec -T html, ou définissez vos propres types. Plus de 800 motifs sont intégrés.

🔁 Multiligne et remplacement

Cherchez au-delà des sauts de ligne avec -U, prévisualisez des substitutions avec -r et produisez des résultats structurés avec --json.

🚀 Toujours en avance sur les archives officielles : Debian et Ubuntu figent les versions des paquets à la sortie d'une release — ce dépôt publie les nouvelles versions upstream généralement en quelques heures. Un simple apt upgrade vous maintient à jour.

🎯 Exemples d'utilisation de base

Recherche au quotidien :

# Rechercher dans l'arborescence courante
rg 'TODO'

# Insensible à la casse, mot entier
rg -i -w 'timeout'

# Afficher 3 lignes de contexte autour de chaque résultat
rg -C 3 'panic!'

# Lister uniquement les fichiers contenant un résultat
rg -l 'BurntSushi'

Filtrer ce qui est recherché :

# Uniquement les fichiers Rust
rg -t rust 'unsafe'

# Tout sauf HTML et CSS
rg -T html -T css 'font-size'

# Inclure les fichiers ignorés et cachés
rg -uu 'password'

# Restreindre avec un glob
rg -g '*.toml' 'version'

Au-delà de grep :

# Assertions et références arrière via PCRE2
rg -P '(?<=fn )\w+' src/

# Rechercher au-delà des sauts de ligne
rg -U 'struct \w+ \{\n[^}]*pub'

# Prévisualiser une substitution (n'écrit aucun fichier)
rg 'v(\d+)\.(\d+)' -r 'v$1.$2.0'

# Sortie structurée pour les scripts
rg --json 'error' | jq -r 'select(.type=="match") | .data.path.text'

🔧 Intégrations

ripgrep est le moteur de recherche qu'attendent beaucoup d'autres outils :

  • fzf: grep interactif à rechargement continu avec rg comme source
  • Neovim / Telescope: live_grep utilise ripgrep s'il est dans le PATH
  • Helix: la recherche globale repose sur les mêmes bibliothèques
  • bat: aperçus des résultats avec coloration syntaxique
  • Yazi: recherche du gestionnaire de fichiers basée sur ripgrep

❓ Questions fréquentes

ripgrep est-il dans les dépôts officiels de Ubuntu ?

Oui, mais l'archive officielle de Ubuntu fournit ripgrep 15.1.0, alors que ce dépôt propose ripgrep 15.2.0, reconstruit quelques heures après chaque version upstream.

Comment installer le dernier ripgrep sur Ubuntu ?

Ajoutez le dépôt deb.griffo.io une seule fois (instructions ci-dessus), puis exécutez : sudo apt install ripgrep. Les nouvelles versions arrivent via le sudo apt upgrade habituel.

Les paquets sont-ils signés et comment sont-ils construits ?

Chaque paquet est signé avec la clé GPG du dépôt (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) et construit à partir des versions upstream dans des dépôts GitHub publics que chacun peut inspecter.

Quelles versions de Ubuntu sont prises en charge ?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing et 26.04 Resolute.
