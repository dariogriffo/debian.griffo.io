Qu'est-ce que Rust ?

Rust est un langage de programmation système axé sur la vitesse, la sûreté mémoire et une concurrence fiable, et ce paquet est la toolchain Rust stable officielle : les binaires de static.rust-lang.org, exactement ce qu'installe rustup, réempaquetés sans modification. Chaque build est vérifié avant d'être empaqueté : la signature GPG du manifeste de la version avec la clé de signature des versions de Rust (empreinte 108F 6620 5EAE B0AA A8DD 5E1C 85AB 96E6 FA1B E5FE), et le SHA-256 de chaque archive avec ce manifeste. Un seul paquet, rust-stable, vous donne rustc, cargo, rustdoc, rustfmt, clippy, rust-analyzer et la bibliothèque standard, et il est mis à jour à chaque version stable, toutes les six semaines plus les versions correctives. Debian et Ubuntu empaquettent le même compilateur sous le nom rustc ; le nom différent ici est voulu, comme expliqué plus bas.

🚀 Pourquoi les dernières versions comptent : Rust publie une nouvelle version stable toutes les six semaines, et les crates suivent : les nouvelles fonctionnalités du langage et API de la bibliothèque sont utilisées dès leur stabilisation, et une crate qui déclare une rust-version plus récente ne compile pas avec un compilateur plus ancien. Ubuntu empaquette Rust sous les noms rustc et cargo, et la 26.04 est figée sur rustc 1.93.1ubuntu1, un système fraîchement installé prend donc du retard à chaque version. Ce dépôt propose Rust 1.100.1 sous le nom rust-stable, une toolchain complète qui prend la place de rustc et cargo de la distribution et avance à chaque apt upgrade.

⚡ Fonctionnalités clés de Rust

🦀 Toute la toolchain

rustc, cargo, rustdoc, rustfmt, clippy (cargo clippy), rust-analyzer, les wrappers rust-gdb et rust-lldb et la bibliothèque standard pour votre machine, le tout issu de la même version.

🔏 Binaires officiels vérifiés

Exactement les binaires que rustup téléchargerait depuis static.rust-lang.org, réempaquetés sans modification. Le build vérifie la signature GPG du manifeste et le SHA-256 de chaque archive avant d'empaqueter quoi que ce soit.

👥 Une installation pour tous les utilisateurs

Une seule toolchain pour tout le système, partagée par tous les utilisateurs de la machine, au lieu d'un ~/.rustup dans chaque répertoire personnel, et mise à jour par apt avec le reste du système.

🧩 Toujours ensemble, jamais mélangés

rustc, cargo, la bibliothèque standard, clippy et rustfmt forment une famille aux versions liées. Remplacer seulement rustc associerait un compilateur récent à une std ancienne, c'est pourquoi rust-stable fait toujours avancer toute la toolchain d'un coup.

🎯 Des cibles supplémentaires en paquets

Des binaires Linux statiques avec rust-stable-std-musl, qui apporte son propre musl, et WebAssembly avec wasm32-unknown-unknown, wasm32-wasip1 et wasm32-wasip2, chacune à un apt install près.

📚 Sources et documentation hors ligne

rust-stable-src ajoute les sources de la bibliothèque standard que lit rust-analyzer, et rust-stable-doc installe The Book, la documentation de l'API std et le livre de Cargo pour une lecture hors ligne.

🚀 Toujours en avance sur les dépôts officiels : Debian et Ubuntu gèlent les versions des paquets à la sortie d'une release. Ce dépôt publie les nouvelles versions upstream généralement en quelques heures. Un simple apt upgrade vous maintient sur la dernière version.

🔧 Intégrations

La toolchain est installée comme n'importe quel autre paquet système, le reste de votre environnement la trouve donc sans configuration :

  • Organisation : tout se trouve dans /usr/lib/rust-stable avec son propre LLVM embarqué, et les commandes sont liées dans /usr/bin, elles sont donc dans le PATH de chaque utilisateur sans modifier le profil du shell
  • Édition de liens : le paquet dépend d'un compilateur C (gcc ou clang) et de libc6-dev, que rustc utilise pour l'édition de liens, cargo build fonctionne donc dès l'installation
  • Éditeurs : rust-analyzer fait partie du paquet, tout éditeur doté d'un client language server peut donc l'utiliser ; rust-stable-src lui permet de naviguer dans la bibliothèque standard
  • Débogueurs : rust-gdb et rust-lldb lancent gdb ou lldb avec les pretty-printers de Rust chargés, pour que les types Rust s'affichent lisiblement
  • Shell : les pages de manuel de cargo et ses complétions bash et zsh sont installées avec le paquet
  • Cibles croisées : les bibliothèques standard musl et WebAssembly sont des paquets à part, ajoutés avec apt install au lieu de rustup target add
  • Documentation : rust-stable-doc installe la documentation HTML dans /usr/share/doc/rust-stable-doc/html, et tout est aussi en ligne sur doc.rust-lang.org

  • ✅ Les binaires officiels : exactement ce que rustup installe depuis static.rust-lang.org, sans modification, vérifié au build avec la clé de signature des versions de Rust et les sommes SHA-256 du manifeste
  • ✅ Paquet complet : la toolchain dans /usr/lib/rust-stable avec son propre LLVM, les commandes dans /usr/bin, les pages de manuel et les complétions de cargo, avec rust-stable-src recommandé et la documentation et les cibles musl et WebAssembly en paquets optionnels

❓ Questions fréquentes

Rust est-il dans les dépôts officiels de Ubuntu ?

Oui, mais l'archive officielle de Ubuntu fournit Rust 1.93.1ubuntu1, alors que ce dépôt propose Rust 1.100.1, reconstruit quelques heures après chaque version upstream.

Comment installer le dernier Rust sur Ubuntu ?

Ajoutez le dépôt deb.griffo.io une seule fois (instructions ci-dessus), puis exécutez : sudo apt install rust-stable. Les nouvelles versions arrivent via le sudo apt upgrade habituel.

Les paquets sont-ils signés et comment sont-ils construits ?

Chaque paquet est signé avec la clé GPG du dépôt (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) et construit à partir des versions upstream dans des dépôts GitHub publics que chacun peut inspecter.

Quelles versions de Ubuntu sont prises en charge ?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing, 26.04 Resolute et 26.10 Stonking.
