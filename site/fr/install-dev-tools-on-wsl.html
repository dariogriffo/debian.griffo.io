Les derniers outils de développement sur WSL (Sous-système Windows pour Linux)

61 outils de développement dans leur dernière version upstream, une seule commande apt, signés GPG

⚡ La réponse courte. Oui, deb.griffo.io fonctionne sur WSL (Sous-système Windows pour Linux). 61 outils de développement s'installent avec un simple apt sur Ubuntu 24.04 sous WSL et Ubuntu 22.04 sous WSL et Debian sous WSL, avec la même commande de configuration que pour Debian et Ubuntu : elle lit UBUNTU_CODENAME / VERSION_CODENAME dans /etc/os-release et demande la suite correspondante, noble sur Ubuntu 24.04 sous WSL.

WSL fait tourner une vraie Ubuntu ou une vraie Debian sous Windows, ce qui veut dire qu'il hérite aussi de leurs archives, où la plupart des outils de développement restent figés dans la version livrée avec chaque version. deb.griffo.io fournit la version upstream actuelle de chacun des outils ci-dessous sous forme de paquet apt : un terminal WSL dispose ainsi de la même chaîne d'outils à jour qu'un poste Linux.

📦 Ajouter le dépôt

Étape 1 : ajouter le dépôt et la clé

Exécuter les commandes
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(. /etc/os-release; echo ${DEBIAN_CODENAME:-${UBUNTU_CODENAME:-$VERSION_CODENAME}}) main" | sudo tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
sudo apt update

❓ Questions fréquentes

Les outils fonctionnent-ils sous WSL 1 et WSL 2 ?

Ce sont des binaires Linux ordinaires : ils tournent donc sous WSL 2. WSL 1 traduit les appels système, et certains outils qui s'appuient sur des fonctionnalités récentes du noyau peuvent ne pas y fonctionner ; WSL 2 est la version par défaut et celle à utiliser.

deb.griffo.io est-il un dépôt officiel de WSL ?

Non. C'est un dépôt non officiel maintenu par Dario Griffo, sans lien avec WSL. Chaque paquet est construit automatiquement à partir de la version upstream officielle, l'empaquetage est open source sur GitHub et l'archive est signée GPG.

Est-ce payant ?

Le dépôt fonctionne par abonnement (15 € par an ou 150 € une seule fois), avec un essai gratuit. Un miroir gratuit, deb-free.griffo.io, propose une sélection plus restreinte d'outils avec un léger décalage, avec la même configuration sur cette distribution.

Comment supprimer le dépôt ?

Supprimez /etc/apt/sources.list.d/deb.griffo.io.list et /etc/apt/keyrings/deb.griffo.io.gpg, puis lancez sudo apt update. Les outils que vous avez installés restent en place jusqu'à ce que vous les supprimiez avec apt remove.
