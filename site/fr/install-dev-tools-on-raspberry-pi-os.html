Les derniers outils de développement sur Raspberry Pi OS

63 outils de développement dans leur dernière version upstream, une seule commande apt, signés GPG

⚡ La réponse courte. Oui, deb.griffo.io fonctionne sur Raspberry Pi OS. 63 outils de développement s'installent avec un simple apt sur Raspberry Pi OS (Trixie) et Raspberry Pi OS (Bookworm), avec la même commande de configuration que pour Debian et Ubuntu : elle lit VERSION_CODENAME dans /etc/os-release et demande la suite correspondante, trixie sur Raspberry Pi OS (Trixie).

Raspberry Pi OS est la Debian du Raspberry Pi, et son archive contient les outils de développement de la version de Debian sur laquelle elle repose, figés à cette version. Les projets upstream publient rarement des fichiers .deb pour ARM. deb.griffo.io construit des paquets arm64 pour la plupart des outils ci-dessous, et des paquets armhf pour beaucoup d'entre eux : ils s'installent donc sur un Pi avec un simple apt.

Un Raspberry Pi 3, 4, 5 ou Zero 2 W sous Raspberry Pi OS 64 bits utilise arm64, l'architecture la mieux couverte par ce dépôt. L'image 32 bits utilise armhf, pour laquelle moins d'outils sont construits. Lancez dpkg --print-architecture pour savoir laquelle vous avez. ❓ Questions fréquentes

Quels modèles de Raspberry Pi sont pris en charge ?

Tout Pi sous Raspberry Pi OS 64 bits (arm64), ce qui couvre les Pi 3, 4, 5, 400, 500 et Zero 2 W. L'image 32 bits (armhf) fonctionne aussi, pour les outils construits pour armhf. Le Pi Zero d'origine et le Pi 1 utilisent armv6, pour lequel aucun paquet n'est construit ici.

Vaut-il mieux Raspberry Pi OS 64 bits ou 32 bits pour cela ?

64 bits. Tous les outils d'ici qui tournent sur ARM sont construits pour arm64, et seulement une partie d'entre eux pour armhf.

deb.griffo.io est-il un dépôt officiel de Raspberry Pi OS ?

Non. C'est un dépôt non officiel maintenu par Dario Griffo, sans lien avec Raspberry Pi OS. Chaque paquet est construit automatiquement à partir de la version upstream officielle, l'empaquetage est open source sur GitHub et l'archive est signée GPG.

Est-ce payant ?

Le dépôt fonctionne par abonnement (15 € par an ou 150 € une seule fois), avec un essai gratuit. Un miroir gratuit, deb-free.griffo.io, propose une sélection plus restreinte d'outils avec un léger décalage, avec la même configuration sur cette distribution.

Comment supprimer le dépôt ?

Supprimez /etc/apt/sources.list.d/deb.griffo.io.list et /etc/apt/keyrings/deb.griffo.io.gpg, puis lancez sudo apt update. Les outils que vous avez installés restent en place jusqu'à ce que vous les supprimiez avec apt remove.
