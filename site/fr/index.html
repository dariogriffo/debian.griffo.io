Comment fonctionne le miroir gratuit →

🧩 À propos de l'option extrepo. extrepo est l'outil de Debian pour les dépôts externes : il écrit le fichier de sources et installe la clé de signature à votre place, après l'avoir vérifiée face à des métadonnées signées. Ce dépôt y est enregistré sous le nom griffo, et le miroir gratuit à vie sous griffo-free ; sur Debian (bookworm, trixie, forky et sid), les commandes ci-dessus constituent donc toute l'installation.

extrepo ne met en place que le fichier de sources et la clé : les identifiants d'un abonnement vont toujours dans /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu n'est pas couvert, car extrepo ne publie de métadonnées que pour les suites Debian : utilisez-y les commandes avec sudo ou en root.

📦 Paquets sources

En plus des paquets binaires .deb, ce dépôt fournit aussi des paquets sources Debian pour tous les outils pris en charge. Les paquets sources vous permettent d'inspecter l'empaquetage, de reconstruire les binaires localement ou d'appliquer vos propres correctifs — le tout avec les outils Debian standard. Un paquet source se compose de trois fichiers :

  • .dsc — fichier de description avec les sommes de contrôle et les métadonnées
  • .orig.tar.gz — archive source upstream non modifiée
  • .debian.tar.xz — surcouche d'empaquetage spécifique à Debian (répertoire debian/)

Télécharger et construire

# Télécharger les sources d'un paquet (crée un répertoire dans le dossier courant)
apt-get source zig

# Ou télécharger sans décompresser — juste le .dsc et les archives
apt-get source --download-only zig

# Entrer dans le répertoire source décompressé (le numéro de version varie)
cd zig-stable-0.14.0

# Construire un .deb binaire sans signature (adapté à un usage local)
dpkg-buildpackage -b --no-sign

# Le .deb produit apparaît un niveau au-dessus
ls ../zig-stable_*.deb

Pourquoi deb.griffo.ioConçu pour celles et ceux qui veulent la dernière version

Ce dépôt non officiel se spécialise dans la fourniture des versions les plus récentes des outils de développement populaires, sous forme de paquets Debian correctement empaquetés. Alors que les dépôts officiels sont souvent en retard sur les versions upstream, nous vous garantissons :

  • Les dernières versions stables en quelques heures après la publication upstream
  • Des builds nightly pour les fonctionnalités de pointe (Zig, ZLS)
  • Un empaquetage Debian correct avec les bonnes dépendances
  • La prise en charge de plusieurs distributions — Debian (Bookworm, Trixie, Forky, Sid) & Ubuntu (Jammy, Noble, Questing, Resolute)
  • Des paquets sources — téléchargez, inspectez et reconstruisez n'importe quel paquet localement avec apt-get source
  • Des mises à jour automatisées qui garantissent une disponibilité continue

Informations importantesLes questions qu'on nous pose le plus souvent

Vous ne payez pas pour le logiciel. Chaque outil présenté ici est open source, et rien dans ce dépôt ne change sa licence ni ce qu'il vous en coûterait de le compiler vous-même. L'abonnement paie l'empaquetage qui l'entoure : produire de vrais paquets Debian pour des outils dont les auteurs n'en fournissent aucun, les reconstruire automatiquement en quelques heures après chaque version upstream, et rendre ces constructions disponibles sur des versions de Debian et d'Ubuntu plus anciennes, qui resteraient sinon des années en arrière. C'est de la maintenance et de l'infrastructure continues, pas une licence logicielle. Et si vous préférez ne pas payer, chaque .deb reste téléchargeable gratuitement depuis GitHub — vous vous chargez simplement des mises à jour.
En deux minutes, vous recevez un e-mail avec un identifiant — l'adresse utilisée au paiement — et un mot de passe généré. Ils vont dans /etc/apt/auth.conf.d/deb.griffo.io.conf, et apt les envoie en HTTPS à chaque téléchargement : de l'authentification HTTP Basic, prise en charge nativement par apt depuis des années. Pas d'espace client, pas de jeton à faire tourner, aucune limite au nombre de machines utilisant les mêmes identifiants. Le renouvellement est silencieux et ne change rien ; en cas de résiliation, l'accès court jusqu'à la fin de la période déjà payée. Comment fonctionne l'abonnement, en détail →
Rien n'est cassé sur votre système et rien de ce que vous avez déjà installé n'est affecté — les paquets installés n'expirent jamais et ne vérifient aucune licence. À partir du 1er octobre 2026, télécharger des paquets nécessite un abonnement : apt update, apt policy et la consultation du dépôt restent gratuits pour tout le monde, tandis que apt install et apt upgrade demandent des identifiants stockés dans /etc/apt/auth.conf.d/. Trois solutions s'offrent à vous, avec les commandes exactes : ajouter vos identifiants, basculer sur le miroir gratuit pour toujours deb-free.griffo.io, ou télécharger le .deb directement depuis la release publique GitHub, gratuite et qui le restera. Ce dépôt se concentre exclusivement sur l'empaquetage Debian non officiel. Pour les problèmes liés aux outils eux-mêmes, contactez les projets upstream concernés. Nous ne traitons que les questions d'empaquetage.
Les paquets sont mis à jour automatiquement dès qu'une nouvelle version paraît en upstream, généralement en quelques heures, ce qui vous garantit un accès permanent aux dernières fonctionnalités et aux correctifs de sécurité.
Ce dépôt fonctionne avec reprepro, configuré pour ne conserver que la dernière version de chaque paquet ; apt install zig=0.15.2 cesse donc de fonctionner dès la sortie de 0.16.0. Les paquets Zig sont par conséquent nommés par niveau de stabilité : zig est un méta-paquet qui installe toujours zig-stable, zig-oldstable contient la stable précédente et peut être installé en parallèle, et zig-0 est obsolète. Avec les deux installés, sudo update-alternatives --config zig détermine celui vers lequel pointe /usr/bin/zig.
