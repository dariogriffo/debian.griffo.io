Qu'est-ce que rgrc ?

rgrc, le Rusty Generic Colouriser, est une réécriture rapide en Rust du classique grc. Placez-le devant une commande et il colore sa sortie : ping, df, ls, ps, docker, journalctl, kubectl, dig, mount, ip, netstat et environ 97 commandes au total, chacune pilotée par un fichier de configuration au format grc/grcat. Les configurations sont intégrées au binaire, il fonctionne donc dès l'installation, et il colore aussi les pipes (df -h | rgrc -c df). Les alias de shell qui colorent automatiquement les commandes habituelles tiennent en une ligne dans votre ~/.bashrc ou ~/.zshrc. Le paquet et la commande s'appellent tous deux rgrc.

🚀 Pourquoi les dernières versions comptent : rgrc est jeune et évolue vite : chaque version apporte de nouvelles configurations de commandes, des options et des corrections. Il est absent des archives Debian et Ubuntu (Debian ne fournit que le grc original en Python), et upstream publie des binaires et un .deb dans les releases GitHub mais aucun dépôt apt : une copie installée à la main ne se met jamais à jour.

⚡ Fonctions clés de rgrc

🌈 Environ 97 commandes

Outils système, réseau, conteneurs et journaux prêts à l'emploi : df, free, ps, mount, ping, dig, ip, ss, docker, kubectl, journalctl et bien d'autres.

⚡ Binaire natif et rapide

Une réécriture en Rust du grc en Python : aucun interpréteur à lancer pour chaque commande colorée. Le paquet est un unique binaire lié statiquement.

📦 Configurations intégrées

Les configurations de commandes sont intégrées au binaire et installées aussi dans /usr/share/rgrc, avec la correspondance des commandes dans /etc/rgrc.conf.

🔀 Fonctionne avec les pipes

Colorez une sortie que vous avez déjà : df -h | rgrc -c df choisit une configuration par son nom et colore ce qui arrive sur l'entrée standard.

🐚 Alias de shell

eval "$(rgrc --aliases)" fait sortir ping, df ou docker en couleur sans taper rgrc. Excluez n'importe quelle commande avec --except.

🛠️ Règles au format grc

Les règles utilisent le format grc/grcat bien connu, en lignes regexp= et colours=, et les vôtres vont dans ~/.config/rgrc/.

🚀 Toujours en avance sur les archives officielles : Debian et Ubuntu figent les versions des paquets à la sortie d'une release — ce dépôt publie les nouvelles versions upstream généralement en quelques heures. Un simple apt upgrade vous maintient à jour.

🎯 Exemples d'utilisation de base

Colorer une seule commande :

# Placez rgrc devant la commande à colorer
rgrc ping -c 4 debian.org
rgrc df -h
rgrc docker ps
rgrc journalctl -n 50

Colorer la sortie d'un pipe :

# Choisir une configuration par son nom et colorer l'entrée standard
df -h | rgrc -c df
mount | rgrc -c mount

Choisir les alias et les couleurs :

# Des alias pour toutes les commandes prises en charge sauf ls et ps
eval "$(rgrc --aliases --except ls,ps)"

# Forcer les couleurs quand la sortie part vers un pager
rgrc --color on ping -c 4 debian.org | less -R

Configuration et règles personnelles :

# Les configurations de commandes et la correspondance principale
ls /usr/share/rgrc/
cat /etc/rgrc.conf

# Vos propres règles vont ici, en lignes regexp= et colours= au format grc
mkdir -p ~/.config/rgrc

# Référence complète des options

🔧 Intégrations avec d'autres outils

rgrc s'intègre à un flux de travail existant dans le terminal :

  • Shells : les complétions bash, zsh et fish sont installées avec le paquet, et les alias fonctionnent dans tout shell capable de les charger avec eval
  • grc : le grc en Python de Debian peut rester installé : les commandes sont grc et rgrc, et rgrc lit le même format de règles grc/grcat
  • Conteneurs : docker ps, docker images et kubectl get pods se lisent d'un coup d'œil
  • Journaux : une sortie journalctl où les erreurs et les avertissements sautent aux yeux
  • Diagnostic réseau : ping, traceroute, dig, ss, netstat et ip avec adresses, latences et états en couleur

❓ Questions fréquentes

rgrc est-il dans les dépôts officiels de Ubuntu ?

Non, rgrc n'est pas empaqueté dans les archives officielles de Ubuntu. Ce dépôt est actuellement la seule source apt et propose rgrc 0.6.35.

Comment installer le dernier rgrc sur Ubuntu ?

Ajoutez le dépôt deb.griffo.io une seule fois (instructions ci-dessus), puis exécutez : sudo apt install rgrc. Les nouvelles versions arrivent via le sudo apt upgrade habituel.

Les paquets sont-ils signés et comment sont-ils construits ?

Chaque paquet est signé avec la clé GPG du dépôt (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) et construit à partir des versions upstream dans des dépôts GitHub publics que chacun peut inspecter.

Quelles versions de Ubuntu sont prises en charge ?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing et 26.04 Resolute.
