1. Vous avez un abonnement : enregistrez les identifiants

Les identifiants vont dans /etc/apt/auth.conf.d/, jamais dans la ligne de sources.list, où tout utilisateur de la machine pourrait les lire et où apt les divulguerait dans ses messages d'erreur :

Exécuter les commandes
sudo tee /etc/apt/auth.conf.d/deb.griffo.io.conf > /dev/null <<'EOF'
machine deb.griffo.io
login your-email@example.com
password your-subscription-password
EOF
sudo chmod 600 /etc/apt/auth.conf.d/deb.griffo.io.conf
sudo apt update
tee /etc/apt/auth.conf.d/deb.griffo.io.conf > /dev/null <<'EOF'
machine deb.griffo.io
login your-email@example.com
password your-subscription-password
EOF
chmod 600 /etc/apt/auth.conf.d/deb.griffo.io.conf
apt update

Ensuite, sudo apt install <package> fonctionne exactement comme avant. Si vous obtenez encore un 401, vérifiez les points suivants dans l'ordre :

Pas encore abonné et vous vous demandez à quoi vous vous engagez ? Comment fonctionne l'abonnement détaille tout le parcours : identifiants par e-mail, machines illimitées, renouvellement, résiliation et remboursements.

  • La ligne machine contient deb.griffo.io : sans https://, sans barre oblique finale et sans chemin /apt.
  • Le fichier se trouve dans /etc/apt/auth.conf.d/ et son nom se termine par .conf. apt ignore silencieusement toute autre extension.
  • Le fichier appartient à root, en mode 600. apt refuse de lire des identifiants que d'autres utilisateurs peuvent lire.
  • Pas de guillemets parasites autour du mot de passe, ni d'espace en fin de ligne.
  • Toujours bloqué ? Demandez sur Discord. C'est le moyen le plus rapide de régler le problème.

2. Passer au miroir toujours gratuit

deb-free.griffo.io ne demande ni compte ni paiement, jamais. Il sert la version la plus récente qui a au moins deux mois, et publie immédiatement les correctifs de sécurité et de maintenance pour cette version. Il propose actuellement cliamp, Ghostty, lazydocker, Oh My Posh, Uncloud et Zed : tout autre outil peut y être ajouté sur demande, alors demandez sur Discord s'il vous en manque un.

Exécuter les commandes
sudo rm -f /etc/apt/sources.list.d/deb.griffo.io.list
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb-free.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb-free.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb-free.griffo.io.gpg] https://deb-free.griffo.io/apt $(. /etc/os-release; echo ${DEBIAN_CODENAME:-${UBUNTU_CODENAME:-$VERSION_CODENAME}}) main" | sudo tee /etc/apt/sources.list.d/deb-free.griffo.io.list > /dev/null
sudo apt update
rm -f /etc/apt/sources.list.d/deb.griffo.io.list
install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb-free.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | gpg --dearmor --yes -o /etc/apt/keyrings/deb-free.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb-free.griffo.io.gpg] https://deb-free.griffo.io/apt $(. /etc/os-release; echo ${DEBIAN_CODENAME:-${UBUNTU_CODENAME:-$VERSION_CODENAME}}) main" | tee /etc/apt/sources.list.d/deb-free.griffo.io.list > /dev/null
apt update
sudo apt install extrepo
sudo extrepo enable griffo-free
sudo apt update

🧩 À propos de l'option extrepo. extrepo est l'outil de Debian pour les dépôts externes : il écrit le fichier de sources et installe la clé de signature à votre place, après l'avoir vérifiée face à des métadonnées signées. Ce dépôt y est enregistré sous le nom griffo, et le miroir gratuit à vie sous griffo-free ; sur Debian (bookworm, trixie, forky et sid), les commandes ci-dessus constituent donc toute l'installation.

Ubuntu n'est pas couvert, car extrepo ne publie de métadonnées que pour les suites Debian : utilisez-y les commandes avec sudo ou en root.

N'activez pas les deux dépôts en même temps. apt installerait la version la plus élevée (celle de l'abonnement) et vous retomberiez sur un 401. Tous les détails sur le miroir gratuit →

3. Récupérer le .deb sur GitHub

Chaque paquet est compilé publiquement, et les artefacts de build sont joints à une release GitHub publique. Ces téléchargements sont gratuits et sans authentification, aujourd'hui comme après le 1er octobre :

wget https://github.com/dariogriffo/ghostty-debian/releases/latest/download/ghostty_1.3.1-5~trixie_amd64.deb
sudo apt install ./ghostty_1.3.1-5~trixie_amd64.deb
wget https://github.com/dariogriffo/ghostty-debian/releases/latest/download/ghostty_1.3.1-5~trixie_amd64.deb
apt install ./ghostty_1.3.1-5~trixie_amd64.deb

Vous perdez les mises à jour automatiques (c'est précisément ce que l'abonnement finance), mais vous ne perdez jamais l'accès au logiciel. Le dépôt d'empaquetage de chaque outil est indiqué sur la page comment les paquets sont compilés.
