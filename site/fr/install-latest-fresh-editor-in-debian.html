Qu'est-ce que fresh-editor ?

fresh-editor est le paquet de Fresh, un IDE et éditeur de texte pour le terminal créé par Noam Lewis et écrit en Rust. Il apporte dans le terminal ce qu'on attend d'un IDE : prise en charge des serveurs de langage, coloration syntaxique, curseurs multiples et un système de plugins qui exécute du TypeScript, tout en restant facile à prendre en main. Il ouvre les fichiers énormes sans vous faire attendre, garde votre session d'édition en vie dans un démon en arrière-plan auquel vous vous rattachez avec fresh -a, et peut même se servir dans un navigateur web avec fresh --web. Le paquet s'appelle fresh-editor, et la commande que vous tapez est fresh.

🚀 Pourquoi les dernières versions comptent : Fresh est jeune et activement développé : chaque version apporte du travail sur les serveurs de langage, l'API de plugins et les performances. Il est absent des archives Debian et Ubuntu, et upstream publie des fichiers .deb isolés dans les releases GitHub mais aucun dépôt apt, si bien qu'un .deb installé à la main ne se met jamais à jour. Les plugins écrits pour l'API TypeScript actuelle attendent l'éditeur actuel.

⚡ Fonctions clés de fresh-editor

🧠 Serveurs de langage

Fresh parle le Language Server Protocol : diagnostics, complétion, aller à la définition et infobulles viennent des mêmes serveurs que ceux des autres éditeurs, comme rust-analyzer, gopls ou clangd.

🎨 Coloration syntaxique

Le code est coloré dès que vous l'ouvrez, dans le terminal que vous utilisez déjà, sans étape de configuration à part avant que le premier fichier s'affiche correctement.

✏️ Curseurs multiples

Placez des curseurs à plusieurs endroits à la fois et tapez partout en même temps, le moyen rapide de renommer une variable dans un bloc ou de remanier une colonne de lignes semblables.

🧩 Plugins TypeScript

Fresh embarque un environnement d'exécution TypeScript pour les plugins : étendre l'éditeur, c'est écrire du TypeScript avec son API de plugins, pas apprendre un langage de configuration maison.

🔌 Des sessions qui survivent

Un démon de session garde l'éditeur et ses fichiers ouverts en vie quand le terminal se ferme ou qu'une connexion SSH tombe. fresh -a s'y rattache.

🌐 Terminal ou navigateur

fresh --web sert le même éditeur dans un navigateur web, pratique quand une machine est plus facile à joindre par navigateur que par terminal.

🚀 Toujours en avance sur les archives officielles : Debian et Ubuntu figent les versions des paquets à la sortie d'une release — ce dépôt publie les nouvelles versions upstream généralement en quelques heures. Un simple apt upgrade vous maintient à jour.

Exécuter les commandes

Étape 1 : ajouter le dépôt

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | sudo tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
sudo apt update

Comment fonctionne le miroir gratuit →

🧩 À propos de l'option extrepo. extrepo est l'outil de Debian pour les dépôts externes : il écrit le fichier de sources et installe la clé de signature à votre place, après l'avoir vérifiée face à des métadonnées signées. Ce dépôt y est enregistré sous le nom griffo, et le miroir gratuit à vie sous griffo-free ; sur Debian (bookworm, trixie, forky et sid), les commandes ci-dessus constituent donc toute l'installation.

extrepo ne met en place que le fichier de sources et la clé : les identifiants d'un abonnement vont toujours dans /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu n'est pas couvert, car extrepo ne publie de métadonnées que pour les suites Debian : utilisez-y les commandes avec sudo ou en root.

🔧 Intégrations avec d'autres outils

Fresh s'intègre à un flux de travail existant dans le terminal :

  • Git: git config --global core.editor fresh ouvre les messages de commit et les rebase interactifs dans Fresh
  • Shell: export EDITOR=fresh dans ~/.bashrc fait que crontab -e, sudoedit et compagnie l'utilisent
  • Compilateurs et grep: leur sortie file:line:col s'ouvre pile à l'endroit signalé
  • Bureau: le paquet installe une entrée de bureau et des icônes, Fresh apparaît donc dans le menu des applications
  • SSH et tmux: le démon de session garde votre travail ouvert côté distant, et fresh -a le reprend

🚀 Pourquoi choisir deb.griffo.io ?

📊 Comparatif des dépôts :
  • Debian officiel : non empaqueté : Fresh n'est dans aucune version de Debian, de Bookworm à Sid
  • .deb upstream: à jour le jour du téléchargement, mais upstream publie des fichiers .deb isolés dans les releases GitHub sans dépôt apt : apt upgrade ne voit jamais de nouvelle version, et chaque release est un nouveau téléchargement manuel
  • Compiler avec cargo: demande une chaîne d'outils Rust et une compilation complète à chaque mise à jour, et laisse de côté l'entrée de bureau, les icônes et la page de manuel
  • deb.griffo.io : dernière version avec mises à jour automatiques
  • ✅ Paquet fresh-editor, commande fresh: sudo apt install fresh-editor, puis lancez fresh ; fresh-editor est le nom de paquet d'upstream lui-même, celui de son .deb, d'AUR, de Homebrew et de winget, donc une machine où le .deb upstream est installé se met à jour sur place dès la prochaine release
  • ✅ Mises à jour apt pour les releases upstream: upstream fournit des fichiers .deb mais aucun dépôt ; ici chaque release arrive dans un dépôt apt signé GPG, avec une compilation pour chaque suite Debian et Ubuntu
  • ✅ Mises à jour automatiques : les paquets sont mis à jour quelques heures après chaque version upstream
  • ✅ Paquet complet: le binaire fresh, une entrée de bureau et des icônes pour le menu des applications, et la page de manuel fresh(1)
  • ✅ Deux architectures: amd64 et arm64 : portables, serveurs et cartes ARM 64 bits ont le même Fresh
  • ✅ Multi-distribution : fonctionne sur Bookworm, Trixie, Forky et Sid
  • ✅ Maintenance simple : des mises à jour avec les commandes apt habituelles

❓ Questions fréquentes

fresh-editor est-il dans les dépôts officiels de Debian ?

Non, fresh-editor n'est pas empaqueté dans les archives officielles de Debian. Ce dépôt est actuellement la seule source apt et propose fresh-editor 0.5.2.

Comment installer le dernier fresh-editor sur Debian ?

Ajoutez le dépôt deb.griffo.io une seule fois (instructions ci-dessus), puis exécutez : sudo apt install fresh-editor. Les nouvelles versions arrivent via le sudo apt upgrade habituel.

Les paquets sont-ils signés et comment sont-ils construits ?

Chaque paquet est signé avec la clé GPG du dépôt (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) et construit à partir des versions upstream dans des dépôts GitHub publics que chacun peut inspecter.

Quelles versions de Debian sont prises en charge ?

Debian 12 Bookworm, Debian 13 Trixie, Forky et Sid.
