Qu'est-ce que lazyjira ?

lazyjira est une interface terminal pour Jira pilotée au clavier, dans le style de lazygit et écrite en Go. Quatre panneaux affichent côte à côte vos tickets, vos projets, le ticket sélectionné et son statut, avec une navigation façon vim et la prise en charge de la souris. Cherchez en JQL, puis changez la transition, la priorité, l'assigné ou les labels d'un ticket, ajoutez des commentaires, modifiez la description dans votre $EDITOR ou créez un nouveau ticket sans ouvrir de navigateur. lazyjira fonctionne avec Jira Cloud et Jira Server/Data Center, et au premier lancement un assistant de configuration vous guide pour la connexion. Le paquet et la commande s'appellent tous deux lazyjira.

🚀 Pourquoi les dernières versions comptent : lazyjira est jeune et évolue vite : chaque version apporte de nouvelles actions d'édition, la prise en charge de champs Jira supplémentaires et de nouvelles options de configuration. Il est absent des archives Debian et Ubuntu, et upstream publie des binaires dans les releases GitHub mais aucun dépôt apt : un binaire copié à la main dans votre PATH ne se met jamais à jour.

⚡ Fonctions clés de lazyjira

🔍 Recherche JQL

Saisissez du JQL avec autocomplétion et coloration syntaxique, et retrouvez vos requêtes précédentes grâce à un historique persistant. Les onglets JQL enregistrés gardent vos vues quotidiennes à une touche.

🗂️ Disposition en quatre panneaux

Tickets, projets, détail du ticket et statut côte à côte, ou empilés sur un terminal étroit. Naviguez avec des touches façon vim ou à la souris.

✏️ Édition directe

Changez transitions, priorité, assigné et labels, ajoutez des commentaires et modifiez les descriptions dans votre $EDITOR. Les nouveaux tickets se créent depuis le même écran.

🌿 Intégration git

Créez une branche git à partir du ticket sélectionné, ou ouvrez le ticket associé à la branche courante, pour que ticket et code restent alignés.

⚙️ Configurable

Raccourcis clavier, onglets JQL, colonnes de tickets et champs personnalisés se règlent dans ~/.config/lazyjira/, avec le thème ANSI par défaut ou l'un des thèmes Catppuccin.

🔐 Cloud et Server

Jira Cloud se connecte avec un e-mail et un jeton d'API, Jira Server et Data Center avec un jeton d'accès personnel, et les certificats client mTLS sont pris en charge.

🚀 Toujours en avance sur les archives officielles : Debian et Ubuntu figent les versions des paquets à la sortie d'une release — ce dépôt publie les nouvelles versions upstream généralement en quelques heures. Un simple apt upgrade vous maintient à jour.

🔧 Intégrations avec d'autres outils

lazyjira s'intègre à un flux de travail existant dans le terminal :

  • Git : créer une branche depuis le ticket sélectionné, ou sauter au ticket derrière la branche courante
  • Éditeur : les descriptions s'ouvrent dans $EDITOR, Neovim, Helix ou tout autre éditeur se charge donc de l'écriture
  • Navigateur : ouvrir le ticket sélectionné dans le navigateur via xdg-open quand il vous faut l'interface web complète de Jira
  • Presse-papiers : copier avec xclip, prêt à coller dans un message de commit ou une discussion
  • Jira d'entreprise : les jetons d'accès personnels et les certificats client mTLS couvrent les installations Server et Data Center aux règles plus strictes

❓ Questions fréquentes

lazyjira est-il dans les dépôts officiels de Ubuntu ?

Non, lazyjira n'est pas empaqueté dans les archives officielles de Ubuntu. Ce dépôt est actuellement la seule source apt et propose lazyjira 2.19.2.

Comment installer le dernier lazyjira sur Ubuntu ?

Ajoutez le dépôt deb.griffo.io une seule fois (instructions ci-dessus), puis exécutez : sudo apt install lazyjira. Les nouvelles versions arrivent via le sudo apt upgrade habituel.

Les paquets sont-ils signés et comment sont-ils construits ?

Chaque paquet est signé avec la clé GPG du dépôt (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) et construit à partir des versions upstream dans des dépôts GitHub publics que chacun peut inspecter.

Quelles versions de Ubuntu sont prises en charge ?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing et 26.04 Resolute.
