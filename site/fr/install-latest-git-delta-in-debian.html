Qu'est-ce que delta ?

delta est un pager avec coloration syntaxique pour la sortie de git, diff, grep et blame. Déclarez-le une fois comme pager de git et chaque git diff, git show, git log -p, git blame et git add -p s'affiche avec le code coloré comme dans votre éditeur, les mots modifiés marqués à l'intérieur de chaque ligne changée, des colonnes côte à côte et des numéros de ligne en option, et des en-têtes de fichier entre lesquels on saute avec n et N. Il lit aussi n'importe quel diff unifié, compare deux fichiers directement et colore la sortie JSON de ripgrep. Il est écrit en Rust par Dan Davison, utilise les mêmes définitions de syntaxe et thèmes de couleurs que bat, se configure depuis votre ~/.gitconfig et est sous licence MIT. Le paquet s'appelle git-delta ; la commande qu'il installe est delta.

🚀 Pourquoi la dernière version compte : delta sort plusieurs versions par an, avec de nouvelles options, un meilleur retour à la ligne en vue côte à côte et des corrections pour les nombreuses façons dont git, les terminaux et les pagers interagissent. Debian trixie est figé à 0.18.2 et Bookworm n'a pas de git-delta du tout : des options du manuel actuel peuvent tout simplement manquer dans votre copie. Ce dépôt utilise le même nom de paquet, git-delta, donc apt install git-delta et apt upgrade vous donnent la version actuelle au lieu de celle de l'archive.

⚡ Fonctionnalités clés de delta

🎨 Coloration syntaxique

Le code d'un diff est coloré comme dans votre éditeur, avec les définitions de syntaxe et les thèmes de couleurs de bat. Choisissez-en un avec syntax-theme, ou laissez delta suivre le fond clair ou sombre du terminal.

🔍 Changements au mot près

Dans chaque ligne modifiée, delta marque exactement les mots qui diffèrent : une variable renommée ou une condition inversée saute aux yeux au lieu de se cacher dans deux lignes rouge et verte presque identiques.

↔️ Vue côte à côte

side-by-side = true place l'ancienne et la nouvelle version dans deux colonnes avec numéros de ligne, en repliant les longues lignes au lieu de les couper. Pour une seule commande : git -c delta.side-by-side=true diff.

🧭 Navigation et liens

Avec navigate = true, n et N sautent de fichier en fichier dans un long git log -p. Avec hyperlinks = true, chemins de fichiers et hashes de commit deviennent cliquables dans les terminaux qui le gèrent.

🧩 Blame, grep et conflits

git blame affiche le code coloré avec les informations de commit regroupées, les résultats de git grep et rg --json sont colorés et regroupés par fichier, et les fichiers en conflit pendant un merge apparaissent comme des diffs lisibles.

⚙️ Tout dans ~/.gitconfig

Chaque option se trouve dans une section [delta] de votre configuration git, et des ensembles d'options nommés changent tout un style d'un coup. Le paquet fournit le themes.gitconfig d'upstream, une collection de thèmes prêts à l'emploi.

🚀 Toujours en avance sur les dépôts officiels : Debian et Ubuntu gèlent les versions des paquets à la sortie d'une release. Ce dépôt publie les nouvelles versions upstream généralement en quelques heures. Un simple apt upgrade vous garde sur la dernière version.

🧩 À propos de l'option extrepo. extrepo est l'outil de Debian pour les dépôts externes : il écrit le fichier de sources et installe la clé de signature à votre place, après l'avoir vérifiée face à des métadonnées signées. Ce dépôt y est enregistré sous le nom griffo, et le miroir gratuit à vie sous griffo-free ; sur Debian (bookworm, trixie, forky et sid), les commandes ci-dessus constituent donc toute l'installation.

extrepo ne met en place que le fichier de sources et la clé : les identifiants d'un abonnement vont toujours dans /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu n'est pas couvert, car extrepo ne publie de métadonnées que pour les suites Debian : utilisez-y les commandes avec sudo ou en root.

# Faire de delta le pager de git : diff, show, log -p, blame et grep passent par lui
git config --global core.pager delta

# git add -p avec la même coloration
git config --global interactive.diffFilter 'delta --color-only'

# n et N sautent d'un fichier à l'autre
git config --global delta.navigate true

# Les conflits montrent aussi l'ancêtre commun
git config --global merge.conflictStyle zdiff3

# Essayer
git diff

🎯 Exemples d'utilisation de base

Lire des diffs :

# Côte à côte, pour une seule commande
git -c delta.side-by-side=true diff

# Ou toujours, avec numéros de ligne
git config --global delta.side-by-side true
git config --global delta.line-numbers true

# Parcourir l'historique ; n et N sautent d'un fichier à l'autre
git log -p

# Indexer des hunks avec coloration
git add -p

Au-delà de git diff :

# Comparer deux fichiers directement
delta old.conf new.conf

# N'importe quel diff unifié
diff -u a.txt b.txt | delta

# Résultats de ripgrep, colorés et regroupés par fichier
rg --json -C 2 'TODO' | delta

# git blame et git grep passent aussi par delta
git blame src/main.rs
git grep -n 'TODO'

Thèmes et configuration :

# Prévisualiser chaque thème de syntaxe sur un vrai diff
git show | delta --show-syntax-themes

# Charger les thèmes delta fournis par le paquet et les prévisualiser
git config --global --add include.path /etc/delta/themes.gitconfig
git show | delta --show-themes

# En utiliser un
git config --global delta.features mellow-barbet

# La configuration que delta applique réellement
delta --show-config

🔧 Intégrations

delta est un filtre entre git et votre pager, l'essentiel de l'intégration se passe donc dans votre configuration git et votre terminal :

  • git : core.pager delta couvre diff, show, log -p, stash show -p, blame et grep ; interactive.diffFilter demande --color-only, car git attend une ligne en retour pour chaque ligne du hunk
  • less : delta pagine sa sortie avec less, que le paquet recommande ; sans lui, delta écrit directement dans le terminal. DELTA_PAGER ou delta.pager choisit un autre pager, et --paging=never désactive la pagination
  • lazygit : lazygit peut afficher ses diffs à travers delta ; réglez son pager sur delta --dark --paging=never
  • difftastic : les deux se complètent : delta comme pager de git au quotidien, difftastic via git difftool quand vous voulez un diff par arbre syntaxique
  • ripgrep : rg --json envoyé à delta donne des résultats de recherche colorés et regroupés par fichier, dans le même thème que vos diffs
  • Votre terminal : delta détecte lui-même si le fond est clair ou sombre, et delta.dark ou delta.light corrige une mauvaise détection ; kitty et Ghostty ouvrent les liens produits par hyperlinks = true
  • Votre shell : les complétions de delta pour bash, zsh et fish sont installées avec le paquet

🚀 Pourquoi choisir deb.griffo.io ?

📊 Comparaison des dépôts :
  • Debian officiel : fournit git-delta 0.18.2 dans trixie et rien du tout dans Bookworm, figé pour toute la durée de vie de la version
  • cargo install git-delta : une toolchain Rust et quelques minutes de compilation pour un binaire dans ~/.cargo/bin pour un seul utilisateur, sans complétions, recompilé à la main à chaque version
  • Téléchargements upstream : un .deb ou une archive depuis la page des versions GitHub, à jour le jour où vous le récupérez, puis à récupérer à la main pour chaque version suivante
  • deb.griffo.io: dernière version avec mises à jour automatiques
  • ✅ Même nom de paquet que les archives : git-delta, exactement comme Debian et Ubuntu l'appellent, donc un simple sudo apt install git-delta prend cette version plus récente et apt upgrade remplace sur place une copie plus ancienne de l'archive
  • ✅ Paquet git-delta, commande delta : vous installez git-delta et lancez delta. Deux noms proches n'ont rien à voir : le paquet delta de l'archive est un réducteur de cas de test (multidelta, singledelta), et la commande git delta de git-extras liste les fichiers qui diffèrent d'une autre branche
  • ✅ Le build officiel : le binaire de la version upstream dans /usr/bin/delta, inchangé, avec les complétions bash, zsh et fish et themes.gitconfig dans /etc/delta/themes.gitconfig, là où le paquet Debian lui-même le place ; upstream ne fournit pas de page de manuel, la référence est delta --help
  • ✅ Dépendances légères : recommande git et less et n'a besoin d'aucun des deux pour fonctionner : sans less, delta affiche simplement sa sortie sans pagination
  • ✅ Mises à jour automatiques : les paquets sont mis à jour quelques heures après chaque version upstream
  • ✅ Quatre architectures : amd64, arm64 et armhf sur Bookworm, Trixie, Forky et Sid ; i386 uniquement sur Trixie, Forky et Sid, car le build i386 d'upstream exige la glibc 2.39 et Bookworm a la 2.36 ; pas de build ppc64el, s390x ni riscv64
  • ✅ Multi-distribution : fonctionne sur Bookworm, Trixie, Forky et Sid
  • ✅ Maintenance simple : des mises à jour avec les commandes apt habituelles

❓ Questions fréquentes

delta est-il dans les dépôts officiels de Debian ?

Oui, mais l'archive officielle de Debian fournit delta 0.18.2, alors que ce dépôt propose delta 0.22.0, reconstruit quelques heures après chaque version upstream.

Comment installer le dernier delta sur Debian ?

Ajoutez le dépôt deb.griffo.io une seule fois (instructions ci-dessus), puis exécutez : sudo apt install git-delta. Les nouvelles versions arrivent via le sudo apt upgrade habituel.

Les paquets sont-ils signés et comment sont-ils construits ?

Chaque paquet est signé avec la clé GPG du dépôt (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) et construit à partir des versions upstream dans des dépôts GitHub publics que chacun peut inspecter.

Quelles versions de Debian sont prises en charge ?

Debian 12 Bookworm, Debian 13 Trixie, Forky et Sid.
