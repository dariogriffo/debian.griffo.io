Qu'est-ce que Serie ?

Serie est une interface terminal pour parcourir l'historique d'un dépôt Git. Elle montre ce que montre git log --graph --all, mais le graphe est dessiné avec le protocole d'images en ligne de l'émulateur de terminal au lieu d'être approximé en art ASCII : branches et fusions se lisent d'un coup d'œil. À côté du graphe, une liste de commits défilante et cherchable, avec une vue de détail. C'est délibérément une visionneuse, pas un client Git : elle ne commite pas, ne crée pas de branches et ne pousse pas.

🚀 Pourquoi les dernières versions comptent : Serie est un projet jeune, encore avant la 1.0, et les fonctionnalités arrivent dans des versions ordinaires : commandes utilisateur, raccourcis personnalisables, options de style et d'ordre du graphe, prise en charge de la variante à placeholders Unicode du protocole graphique de Kitty. Le support des images dans les terminaux bouge lui aussi : la version qui s'affiche correctement chez vous est généralement la plus récente.

⚡ Fonctionnalités clés de Serie

🖼️ Un vrai graphe de commits

Le graphe est rendu en images via le protocole Kitty ou iTerm2 : les lignes de branches restent lisibles même avec des dizaines de branches parallèles.

🔍 Historique cherchable

Une liste de commits à côté du graphe, qui défile et se cherche, au lieu de paginer la sortie de git log.

📄 Vue de détail

Sélectionnez un commit pour voir son message, ses références et son diff sans quitter le graphe.

🎛️ Options de graphe

Ordre chronologique ou topologique, cellules simple ou double largeur, arêtes arrondies ou angulaires — en ligne de commande ou dans la configuration.

⌨️ Raccourcis personnalisables

? affiche les raccourcis courants, et tous se redéfinissent dans config.toml.

🧰 Commandes utilisateur

Lancez vos propres commandes sur le commit sélectionné : dans une vue dédiée, en arrière-plan, ou en suspendant Serie pour un programme interactif.

🚀 Toujours en avance sur les archives officielles : Debian et Ubuntu figent les versions des paquets à la sortie d'une release — ce dépôt publie les nouvelles versions upstream généralement en quelques heures. Un simple apt upgrade vous maintient à jour.

🎯 Exemples d'utilisation de base

Parcourir l'historique :

# L'historique complet du dépôt courant
serie

# Seulement les commits récents, pour un très gros dépôt
serie -n 5000

# Ordre topologique plutôt que chronologique
serie -o topo

# Démarrer avec HEAD sélectionné plutôt que le commit le plus récent
serie -i head

Adapter le graphe à votre terminal :

# Forcer un protocole d'images quand la détection se trompe
serie -p kitty
serie -p iterm
serie -p kitty-unicode

# Des cellules de graphe plus étroites pour une petite fenêtre
serie -g single

# Des arêtes angulaires plutôt qu'arrondies
serie -s angular

# Ou l'affichage large et arrondi sur un terminal spacieux
serie -g double -s rounded

Configuration et usage quotidien :

# Le fichier de configuration, pour raccourcis et valeurs par défaut
mkdir -p ~/.config/serie
$EDITOR ~/.config/serie/config.toml

# Ou pointer Serie vers une configuration ailleurs
SERIE_CONFIG_FILE=~/dotfiles/serie.toml serie

# Serie ne fait que lire l'historique — git reste votre client
git -C ~/src/project log --oneline -5

# Committer reste donc l'affaire de git
git commit -v

🔧 Intégrations avec d'autres outils

Serie a besoin de deux choses et coopère avec une troisième :

  • git : un dépôt Git ordinaire et le binaire git, que le paquet installe comme dépendance
  • Votre terminal : un émulateur qui parle le protocole d'images de Kitty ou d'iTerm2 — Ghostty, Kitty, WezTerm et iTerm2 conviennent
  • Fichier de configuration : $XDG_CONFIG_HOME/serie/config.toml, ou ce que désigne SERIE_CONFIG_FILE
  • Commandes utilisateur : associez git diff, un éditeur ou votre script à une touche et exécutez-le sur le commit sélectionné
  • Votre client git : Serie ne commite ni ne pousse volontairement : elle accompagne lazygit, GitUI ou git tout court au lieu de les remplacer

🚀 Pourquoi choisir deb.griffo.io ?

📊 Comparatif des dépôts :
  • Debian officiel : n'empaquette pas Serie — un système standard n'a rien à installer
  • cargo install --locked serie : à jour, mais il faut une chaîne Rust et une compilation sur chaque machine, hors d'apt
  • Archive upstream : le binaire officiel, à retélécharger à la main à chaque version
  • deb.griffo.io : dernière version avec mises à jour automatiques
  • ✅ Jeune et en mouvement : commandes utilisateur, raccourcis personnalisables et options de graphe sont arrivés dans des versions ordinaires : la version courante n'est plus le même outil qu'il y a un an
  • ✅ La seule source apt : Serie n'est ni dans les archives Debian ni dans celles d'Ubuntu ; ce dépôt empaquette la construction officielle upstream
  • ✅ Mises à jour automatiques : les paquets sont mis à jour quelques heures après chaque version upstream
  • ✅ Empaquetage honnête : le binaire upstream dans /usr/bin/serie, avec git déclaré en dépendance ; upstream ne fournit ni page de manuel ni complétions, le paquet n'en invente donc pas
  • ✅ Deux architectures : amd64 et arm64, deux builds musl statiques sans dépendances
  • ✅ Multi-distribution : fonctionne sur Bookworm, Trixie, Forky et Sid
  • ✅ Maintenance simple : des mises à jour avec les commandes apt habituelles

❓ Questions fréquentes

Serie est-il dans les dépôts officiels de Debian ?

Non, Serie n'est pas empaqueté dans les archives officielles de Debian. Ce dépôt est actuellement la seule source apt et propose Serie 0.8.1.

Comment installer le dernier Serie sur Debian ?

Ajoutez le dépôt deb.griffo.io une seule fois (instructions ci-dessus), puis exécutez : sudo apt install serie. Les nouvelles versions arrivent via le sudo apt upgrade habituel.

Les paquets sont-ils signés et comment sont-ils construits ?

Chaque paquet est signé avec la clé GPG du dépôt (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) et construit à partir des versions upstream dans des dépôts GitHub publics que chacun peut inspecter.

Quelles versions de Debian sont prises en charge ?

Debian 12 Bookworm, Debian 13 Trixie, Forky et Sid.
