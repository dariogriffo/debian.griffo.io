Qu'est-ce que fish ?

fish est un shell en ligne de commande intelligent et convivial. Il suggère la suite de la commande pendant que vous tapez, à partir de votre historique et des complétions, colore la syntaxe au fil de la frappe, génère les complétions par Tab depuis vos pages de manuel installées et abandonne les règles de guillemets ésotériques héritées par les autres shells. Tout fonctionne immédiatement : rien à configurer pour que fish soit agréable.

🚀 Pourquoi les dernières versions comptent : fish 4 a été réécrit en Rust et évolue vite depuis : démarrage plus rapide, meilleures complétions et un flot régulier d'améliorations d'ergonomie. La version figée dans les archives est antérieure à une grande partie de tout cela.

⚡ Fonctionnalités clés de fish

💡 Autosuggestions

Pendant la frappe, fish propose la suite de la commande depuis votre historique et les complétions. Appuyez sur → pour l'accepter.

🎨 Coloration syntaxique

Les commandes sont colorées à mesure que vous les écrivez : une faute de frappe ou un guillemet non fermé saute aux yeux avant Entrée.

⌨️ Complétions issues des pages de manuel

fish analyse vos pages de manuel installées pour générer les complétions : même les outils obscurs complètent leurs options.

🧠 Scripting sensé

Pas de surprises de découpage de mots, pas de [[ ]] contre [ ], et de vraies listes. Les scripts se lisent comme ils se comportent.

🔍 Historique consultable

Tapez un préfixe puis ↑ pour parcourir uniquement les commandes correspondantes, recherche par sous-chaîne incluse.

🛠️ Configuration dans le navigateur

fish_config ouvre une interface pour les invites, couleurs, fonctions et raccourcis — sans fouiller dans les dotfiles.

🚀 Toujours en avance sur les archives officielles : Debian et Ubuntu figent les versions des paquets à la sortie d'une release — ce dépôt publie les nouvelles versions upstream généralement en quelques heures. Un simple apt upgrade vous maintient à jour.

❓ Questions fréquentes

fish est-il dans les dépôts officiels de Debian ?

Oui, mais l'archive officielle de Debian fournit fish 4.0.2, alors que ce dépôt propose fish 4.8.1, reconstruit quelques heures après chaque version upstream.

Comment installer le dernier fish sur Debian ?

Ajoutez le dépôt deb.griffo.io une seule fois (instructions ci-dessus), puis exécutez : sudo apt install fish. Les nouvelles versions arrivent via le sudo apt upgrade habituel.

Les paquets sont-ils signés et comment sont-ils construits ?

Chaque paquet est signé avec la clé GPG du dépôt (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) et construit à partir des versions upstream dans des dépôts GitHub publics que chacun peut inspecter.

Quelles versions de Debian sont prises en charge ?

Debian 12 Bookworm, Debian 13 Trixie, Forky et Sid.
