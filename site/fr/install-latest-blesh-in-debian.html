Qu'est-ce que ble.sh ?

ble.sh, le Bash Line Editor, est un éditeur de ligne écrit en pur Bash qui remplace GNU Readline dans les sessions Bash interactives. Vous gardez Bash, votre ~/.bashrc, vos alias et vos scripts, et vous gagnez ce qui oblige d'habitude à changer de shell : coloration syntaxique pendant la saisie, suggestions automatiques tirées de l'historique à la manière de fish, un mode vim complet à côté des raccourcis emacs, une complétion avec menus et descriptions, des abréviations et l'intégration avec bash-completion et fzf. Il est écrit par Koichi Murase et publié sous licence BSD-3-Clause. Il n'y a aucun binaire à lancer : le paquet installe le script dans /usr/share/blesh/ble.sh, et deux lignes dans votre ~/.bashrc l'activent.

🚀 Pourquoi les dernières versions comptent : ble.sh est développé en continu sur sa branche master et les versions stables étiquetées sont rares et espacées, si bien que les instructions d'installation upstream renvoient vers la build nightly ou un checkout git. Debian et Ubuntu empaquettent un instantané figé pour toute la durée de vie de la release (Debian stable ne le fournit même pas). Ce dépôt suit les instantanés nightly upstream : les correctifs pour les nouvelles versions de Bash, les terminaux et les intégrations de complétion vous arrivent par apt upgrade.

⚡ Fonctionnalités clés de ble.sh

🎨 Coloration syntaxique

Commandes, mots-clés, chaînes, variables, redirections et noms de fichiers sont colorés pendant la saisie, et une commande inconnue ou une erreur de syntaxe se voit avant d'appuyer sur Entrée.

💡 Suggestions automatiques

Des suggestions à la fish, issues de l'historique et de la complétion, s'affichent en gris après le curseur. Acceptez-les en entier avec la flèche droite ou C-f, ou mot par mot avec M-f.

⌨️ Modes vim et emacs

Raccourcis emacs par défaut, et un mode vi/vim complet avec set -o vi : modes normal, insertion et visuel, objets texte, registres et une ligne d'état facultative façon vim-airline.

📋 Complétion par menu

Tab ouvre un menu de candidats que l'on parcourt avec les flèches, avec des descriptions quand elles existent et une correspondance ambiguë (floue).

✂️ Abréviations

ble-sabbrev définit des abréviations qui se développent pendant la saisie, comme les abréviations de fish ou les alias globaux de zsh : L devient | less.

🐚 Pur Bash, sans binaire

Rien à compiler et rien de propre à une architecture : ble.sh est un script Bash qui tourne partout où tourne Bash 3.0 ou plus récent, et il reste à l'écart des shells non interactifs et des scripts.

🚀 Toujours en avance sur les archives officielles : Debian et Ubuntu figent les versions des paquets à la sortie d'une release — ce dépôt publie les nouvelles versions upstream généralement en quelques heures. Un simple apt upgrade vous maintient à jour.

🧩 À propos de l'option extrepo. extrepo est l'outil de Debian pour les dépôts externes : il écrit le fichier de sources et installe la clé de signature à votre place, après l'avoir vérifiée face à des métadonnées signées. Ce dépôt y est enregistré sous le nom griffo, et le miroir gratuit à vie sous griffo-free ; sur Debian (bookworm, trixie, forky et sid), les commandes ci-dessus constituent donc toute l'installation.

extrepo ne met en place que le fichier de sources et la clé : les identifiants d'un abonnement vont toujours dans /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu n'est pas couvert, car extrepo ne publie de métadonnées que pour les suites Debian : utilisez-y les commandes avec sudo ou en root.

Étape 3 : activer ble.sh dans votre ~/.bashrc

# ble.sh n'a pas de commande à lancer : Bash le charge depuis ~/.bashrc.
# Placez cette ligne vers le DÉBUT de ~/.bashrc :
[[ $- == *i* ]] && source /usr/share/blesh/ble.sh --noattach

# ...le reste de votre ~/.bashrc ne change pas...

# Et cette ligne tout à la FIN de ~/.bashrc :
[[ ${BLE_VERSION-} ]] && ble-attach

# Ouvrez un nouveau terminal, puis :
# Vérifier l'installation
echo $BLE_VERSION

🎯 Exemples d'utilisation de base

Au quotidien :

# Vérifier que ble.sh est actif dans ce shell
echo $BLE_VERSION

# Recharger ble.sh après avoir modifié ses réglages
ble-reload

# Les mises à jour passent par apt ; ble-update vous y renvoie
sudo apt update && sudo apt upgrade
# Vérifier que ble.sh est actif dans ce shell
echo $BLE_VERSION

# Recharger ble.sh après avoir modifié ses réglages
ble-reload

# Les mises à jour passent par apt ; ble-update vous y renvoie
apt update && apt upgrade

Réglages dans ~/.blerc :

# ble.sh lit ses réglages dans ~/.blerc (ou ~/.config/blesh/init.sh)
# Raccourcis vim au lieu d'emacs
set -o vi

# Attendre 300 ms avant d'afficher une suggestion
bleopt complete_auto_delay=300

# Désactiver complètement les suggestions automatiques
bleopt complete_auto_complete=

# Changer la couleur du texte suggéré
ble-face auto_complete='fg=242'

Abréviations, raccourcis clavier et intégrations :

# Développer « L » en « | less » pendant la saisie
ble-sabbrev L='| less'

# Faire que Ctrl+C abandonne la ligne en cours
ble-bind -f 'C-c' discard-line

# Complétion et raccourcis fzf, adaptés à ble.sh
ble-import -d integration/fzf-completion
ble-import -d integration/fzf-key-bindings

# Ligne d'état façon vim-airline (nécessite ble.sh-airline-themes)
ble-import vim-airline
bleopt vim_airline_theme=dark

🔧 Intégrations avec d'autres outils

ble.sh se glisse sous votre configuration Bash au lieu de la remplacer :

  • bash-completion: les complétions du paquet bash-completion sont reprises automatiquement et affichées dans le menu
  • fzf: ble-import charge des versions de la complétion et des raccourcis fzf adaptées à ble.sh
  • Atuin: l'intégration Bash d'Atuin prend en charge ble.sh, qui lui fournit des hooks preexec fiables pour enregistrer l'historique
  • Starship / Oh My Posh: les invites qu'ils génèrent continuent de fonctionner sans changement
  • Fichier de configuration: ~/.blerc regroupe vos réglages bleopt, ble-face et ble-bind, séparément de ~/.bashrc

❓ Questions fréquentes

ble.sh est-il dans les dépôts officiels de Debian ?

Non, ble.sh n'est pas empaqueté dans les archives officielles de Debian. Ce dépôt est actuellement la seule source apt et propose ble.sh 0.4.0.

Comment installer le dernier ble.sh sur Debian ?

Ajoutez le dépôt deb.griffo.io une seule fois (instructions ci-dessus), puis exécutez : sudo apt install ble.sh. Les nouvelles versions arrivent via le sudo apt upgrade habituel.

Les paquets sont-ils signés et comment sont-ils construits ?

Chaque paquet est signé avec la clé GPG du dépôt (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) et construit à partir des versions upstream dans des dépôts GitHub publics que chacun peut inspecter.

Quelles versions de Debian sont prises en charge ?

Debian 12 Bookworm, Debian 13 Trixie, Forky et Sid.
