O que é o DuckDB?

O DuckDB é um banco de dados SQL analítico rápido e em processo — pense em um "SQLite para análises". Ele roda dentro do processo que o chama, sem servidor para configurar, consulta arquivos CSV, Parquet e JSON diretamente (SELECT * FROM 'data.parquet') e fala um dialeto SQL rico e amigável, com excelente desempenho em cargas analíticas. Este pacote traz o CLI oficial duckdb.

⚠️ Sem servidor, sem daemon: o DuckDB é um banco de dados embutido — ele roda dentro do seu processo (ou do CLI), então não há serviço para configurar, porta para abrir nem unidade do systemd. Instale e execute duckdb. Pelo mesmo motivo, um arquivo de banco de dados pertence a um processo por vez.
🚀 Sempre à frente dos repositórios oficiais: Debian e Ubuntu congelam as versões dos pacotes a cada lançamento — este repositório publica novas versões upstream normalmente em poucas horas, para todas as versões suportadas, incluindo a stable. Um simples apt upgrade mantém você sempre na versão mais recente.

⚡ Principais Recursos do DuckDB

📊 Feito para Análises

Um motor colunar e vetorizado processa milhões de linhas por segundo — agregações, joins e funções de janela em velocidade OLAP.

📁 Consulte Arquivos Diretamente

SELECT * FROM 'events.parquet' — CSV, Parquet e JSON podem ser consultados (e gravados) sem nenhuma etapa de importação.

🪶 Zero Configuração

Em processo como o SQLite: um único binário, um único arquivo de banco de dados opcional, nada para administrar.

🔌 Extensões em Tempo de Execução

INSTALL httpfs; baixa extensões assinadas do repositório oficial — acesso S3/HTTP, dados espaciais, busca em texto completo e mais.

🗣️ SQL Amigável

SELECT * EXCLUDE, GROUP BY ALL, tipos list/struct, PIVOT — um dialeto moderno que elimina o boilerplate das consultas do dia a dia.

🤝 Convive Bem com Outros

Lê SQLite, PostgreSQL e MySQL por meio de extensões; exporta Parquet/CSV/JSON — a cola ideal para pipelines de dados.

🏆 Por que instalar com o apt?

  • Extensões simplesmente funcionam: este pacote usa o build glibc oficial do upstream, então INSTALL httpfs; casa com o repositório oficial de extensões linux_amd64/linux_arm64
  • Todas as versões, incluindo a stable: os arquivos oficiais trazem o DuckDB apenas em testing/unstable — aqui Bookworm e Trixie recebem a mesma versão atual
  • Sem curl-para-bin: um repositório assinado com GPG em vez de baixar binários manualmente para /usr/local/bin
  • Atualizações automáticas: novos lançamentos upstream chegam com o seu apt upgrade de sempre
  • Multi-arquitetura: amd64 e arm64 — as arquiteturas para as quais o upstream publica binários Linux do CLI

Como funciona o espelho gratuito →

🧩 Sobre a opção extrepo. extrepo é a ferramenta do próprio Debian para repositórios externos: ela escreve o arquivo de sources e instala a chave de assinatura para você, conferindo a chave contra metadados assinados antes de usá-la. Este repositório está registrado nela como griffo, e o espelho gratuito para sempre como griffo-free, então no Debian (bookworm, trixie, forky e sid) os comandos acima são toda a configuração.

O extrepo configura apenas o arquivo de sources e a chave: as credenciais de uma assinatura continuam indo em /etc/apt/auth.conf.d/deb.griffo.io.conf. O Ubuntu não é coberto, porque o extrepo publica metadados só para as suítes do Debian: lá, use os comandos com sudo ou como root.

Passo 2: Instalar o DuckDB

sudo apt install -y duckdb
apt install -y duckdb

🚀 Primeira execução

duckdb                                        # in-memory interactive shell
duckdb mydb.duckdb                            # persistent database file
duckdb -c "SELECT * FROM 'events.parquet' LIMIT 10;"   # query files directly
duckdb -c "INSTALL httpfs; LOAD httpfs;"      # extensions from the official repo

❓ Perguntas frequentes

O DuckDB está nos repositórios oficiais do Debian?

Não, DuckDB não está empacotado nos arquivos oficiais do Debian. Este repositório é atualmente a única fonte apt, oferecendo DuckDB 1.5.5.

Como instalo o DuckDB mais recente no Debian?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install duckdb. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Debian são suportadas?

Debian 12 Bookworm, Debian 13 Trixie, Forky e Sid.
