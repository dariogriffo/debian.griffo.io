O que é o rclone?

O rclone é um gerenciador de arquivos em nuvem para a linha de comando. Ele fala com mais de setenta provedores — S3 e tudo que é compatível com S3, Google Drive, Dropbox, OneDrive e SharePoint, Backblaze B2, Google Cloud Storage, Swift, SFTP, FTP, WebDAV e HTTP puro — com um único conjunto de comandos. Ele copia, sincroniza e move com somas de verificação, monta qualquer remoto como sistema de arquivos, serve-o por meia dúzia de protocolos e transfere direto entre dois remotos sem passar os dados pelo seu disco.

🚀 Por que a versão mais recente importa: o rclone conversa com APIs que mudam sem pedir licença. Provedores trocam fluxos de autenticação, desativam endpoints e acrescentam regiões, e a correção sai no próximo lançamento do rclone — que é também onde surgem novos backends e subcomandos inteiros. A versão dos arquivos oficiais antecede vários anos desse trabalho, então "ano passado funcionava" é exatamente a falha que um rclone atualizado evita.

⚡ Principais recursos do rclone

☁️ Mais de setenta backends

Object storages compatíveis com S3, nuvens de consumo, suítes corporativas e os protocolos de sempre (SFTP, FTP, WebDAV, HTTP) atrás do mesmo conjunto de comandos.

🔁 Sincronizar com somas de verificação

copy, sync e move comparam tamanho, data e hashes, e --dry-run mostra exatamente o que mudaria antes de mudar.

🗂️ Montar como sistema de arquivos

rclone mount coloca um remoto sob um diretório, com cache VFS, para que programas comuns leiam e escrevam nele.

🌐 Servir de volta

rclone serve publica qualquer remoto por HTTP, WebDAV, SFTP, FTP, DLNA, NFS ou um endpoint S3 — útil para aparelhos que só falam um protocolo.

🔐 Criptografia no cliente

A camada crypt criptografa conteúdo e nomes antes do upload, e o arquivo de configuração com seus tokens também pode ser criptografado.

⚡ Feito para volume

Transferências e verificações em paralelo, tabelas de banda, filtros e cópias no lado do servidor que nunca puxam os bytes pela sua máquina.

🚀 Sempre à frente dos arquivos oficiais: Debian e Ubuntu congelam as versões dos pacotes quando lançam uma release — este repositório publica novas versões upstream normalmente em poucas horas. Um simples apt upgrade mantém você na versão mais recente.

🎯 Exemplos básicos de uso

Copiando e sincronizando:

# Enviar uma pasta, com indicador de progresso
rclone copy -P ~/Documents mydrive:Documents

# Deixar o destino igual à origem — sempre com um teste antes
rclone sync --dry-run ~/site remote:bucket/site
rclone sync -P ~/site remote:bucket/site

# De uma nuvem para outra direto, sem cópia local
rclone copy s3:bucket/data b2:backup/data

# Conferir que o que chegou bate com o que foi enviado
rclone check ~/site remote:bucket/site

Montando e servindo:

# Montar um remoto como sistema de arquivos (precisa de FUSE)
sudo apt install fuse3
rclone mount mydrive: ~/mnt/drive --vfs-cache-mode writes

# Servir um remoto na rede local por HTTP ou WebDAV
rclone serve http remote:public --addr :8080
rclone serve webdav remote:docs --addr :8081

# Explorar o que ocupa espaço, no estilo ncdu
rclone ncdu remote:

# Apenas o tamanho total de um bucket
rclone size remote:bucket

Ajustes, filtros e criptografia:

# Mais paralelismo para muitos arquivos pequenos
rclone sync -P --transfers 8 --checkers 16 src: dst:

# Uma tabela de banda, para o backup não comer o dia de trabalho
rclone sync -P --bwlimit "08:00,512k 23:00,off" ~/photos remote:photos

# Filtros em vez de copiar tudo
rclone copy src: dst: --exclude "*.tmp" --filter-from filters.txt

# Envolver um remoto existente em criptografia no cliente
rclone config create secret crypt remote=mydrive:vault

🔧 Integrações com outras ferramentas

o rclone é a peça em que outras ferramentas se apoiam:

  • FUSE: fuse3 (ou fuse) transforma o rclone mount em um diretório de verdade para programas que só entendem arquivos
  • systemd: uma unit por montagem ou por serve, e um timer para o sync noturno: é assim que ele roda sem supervisão
  • Ferramentas de backup: restic e afins falam com o rclone como remoto, o que lhes dá na hora todos os backends que ele suporta
  • Controle remoto: rclone rcd --rc-web-gui expõe uma API HTTP e uma interface de navegador para transferências longas
  • Arquivo de configuração: ~/.config/rclone/rclone.conf guarda os remotos e pode ser criptografado, para as credenciais nunca ficarem em texto puro

❓ Perguntas frequentes

O rclone está nos repositórios oficiais do Debian?

Sim, mas o arquivo oficial do Debian traz rclone 1.60.1, enquanto este repositório oferece rclone 1.75.0, recompilado poucas horas após cada lançamento upstream.

Como instalo o rclone mais recente no Debian?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install rclone. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Debian são suportadas?

Debian 12 Bookworm, Debian 13 Trixie, Forky e Sid.
