O que é o Television?

O Television — o comando é tv — é um fuzzy finder construído em torno de canais. Um canal é uma fonte de dados nomeada, com comando de pré-visualização, atalhos e ações próprios: arquivos, texto dentro de arquivos, diretórios, repositórios git, variáveis de ambiente, processos, contêineres Docker ou qualquer coisa que você descreva em algumas linhas de TOML. Ele busca enquanto você digita, pré-visualiza o item selecionado e entrega o resultado ao shell, a um editor ou ao seu próprio comando.

🚀 Por que a versão mais recente importa: o Television é um projeto jovem que anda rápido: canais, ações, integração com o shell e o formato de configuração evoluíram lançamento a lançamento, e o tv update-channels baixa os protótipos de canal mais recentes, que esperam um binário compatível. Nem o Debian nem o Ubuntu o empacotam, então uma build atual não é luxo: é a única forma de tê-lo.

⚡ Principais recursos do Television

🔎 Canais, não só arquivos

Arquivos, texto, diretórios, repositórios git, variáveis de ambiente, processos e contêineres são canais — tv list-channels mostra o que esta build traz.

👁️ Pré-visualização embutida

Cada canal pode definir um comando de pré-visualização, então você vê o arquivo, o log, o diff ou os detalhes do contêiner ao lado da lista de resultados.

🧵 Hackeável em TOML

Um canal é um pequeno arquivo TOML com comando de origem, pré-visualização, atalhos e ações — um fluxo novo é um arquivo em ~/.config/television/cable/.

⌨️ Integração com o shell

tv init liga o autocompletar inteligente ao Ctrl+T e a busca no histórico ao Ctrl+R, para bash, zsh e fish.

🚀 Rápido por projeto

Um matcher assíncrono e paralelo mantém a digitação fluida em fontes enormes, e as pré-visualizações são calculadas sob demanda e podem ser cacheadas.

🧰 Modo improvisado

--source-command e --preview-command transformam duas linhas de shell em um finder pontual, sem escrever canal nenhum.

🚀 Sempre à frente dos arquivos oficiais: Debian e Ubuntu congelam as versões dos pacotes quando lançam uma release — este repositório publica novas versões upstream normalmente em poucas horas. Um simples apt upgrade mantém você na versão mais recente.

🎯 Exemplos básicos de uso

Buscas do dia a dia:

# O canal padrão
tv

# Os canais que você mais vai usar

tv git-repos

# Começar em outro diretório

Canais improvisados a partir de qualquer comando:

# Transformar qualquer comando em um fuzzy finder
tv --source-command "fd -t f -H"

# Com uma pré-visualização construída a partir do item selecionado
tv --source-command "git branch --format='%(refname:short)'" \
   --preview-command "git log -20 --oneline {}"

# Manter as cores que o comando de origem emite
tv --source-command "rg --color=always -n TODO" --ansi

# Preservar a ordem da origem em vez do ranking de correspondência
tv --source-command "ls -t" --no-sort

Shell, conclusões e canais próprios:

# Ativar Ctrl+T e Ctrl+R neste shell
eval "$(tv init zsh)"

# Conclusão por Tab para os subcomandos do próprio tv
tv completions fish > ~/.config/fish/completions/tv.fish

# Canais próprios ficam no diretório cable
mkdir -p ~/.config/television/cable
$EDITOR ~/.config/television/cable/tldr.toml

# Depois de uma atualização, limpe da configuração os padrões escritos pela máquina
tv migrate-config

🔧 Integrações com outras ferramentas

o Television foi feito para ser colado ao resto do seu ambiente:

  • Seu shell: tv init bash, zsh ou fish adiciona autocompletar inteligente e busca no histórico, e qualquer canal pode escrever direto na linha de comando
  • Editores: há integrações para Neovim, Vim, VS Code, IDEs da JetBrains e Zed, todas usando o mesmo binário
  • ripgrep e afins: canais são comandos de shell, então rg, fd, git, docker ou seu próprio script podem ser a origem
  • Configuração: ~/.config/television/config.toml para padrões e atalhos, cable/*.toml para os canais
  • Todo o resto: o item selecionado é impresso na stdout, então o tv combina com pipes, aliases e scripts como qualquer outro comando

🚀 Por que escolher o deb.griffo.io?

📊 Comparativo de repositórios:
  • Debian oficial: não empacota o Television — apt install television falha em um sistema padrão
  • cargo install television: atualizado, mas é compilar Rust em cada máquina, fora do apt e sem página de manual ou conclusões
  • O script de instalação upstream: conveniente, mas escreve no sistema por trás do gerenciador de pacotes e se atualiza no ritmo dele
  • deb.griffo.io: versão mais recente com atualizações automáticas
  • ✅ Canais no compasso do binário: os protótipos de canal evoluem junto com a ferramenta, então é a build atual que torna o tv update-channels útil em vez de confuso
  • ✅ A única fonte apt: o Television não está nos arquivos do Debian nem do Ubuntu; este repositório empacota a build oficial upstream
  • ✅ Atualizações automáticas: os pacotes são atualizados poucas horas após cada lançamento upstream
  • ✅ Pacote completo: o binário upstream como /usr/bin/tv, a página de manual tv.1 e as conclusões de bash, zsh e fish
  • ✅ Três arquiteturas, um conflito declarado: amd64, arm64 e i386 — e o pacote declara conflito com o treeviewx, dono do mesmo caminho /usr/bin/tv, para o apt te avisar em vez de dois pacotes brigarem por ele
  • ✅ Multi-distribuição: funciona no Bookworm, Trixie, Forky e Sid
  • ✅ Manutenção simples: atualizações com os comandos apt de sempre

❓ Perguntas frequentes

O Television está nos repositórios oficiais do Debian?

Não, Television não está empacotado nos arquivos oficiais do Debian. Este repositório é atualmente a única fonte apt, oferecendo Television 0.15.9.

Como instalo o Television mais recente no Debian?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install television. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Debian são suportadas?

Debian 12 Bookworm, Debian 13 Trixie, Forky e Sid.
