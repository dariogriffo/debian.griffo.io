O que é o Herdr?

O Herdr é um app de desktop para terminais e agentes de programação. O trabalho fica organizado em espaços, normalmente um por repositório, e cada espaço tem abas divididas em painéis, então um shell, um editor e dois agentes de programação podem ficar lado a lado numa única janela. Uma barra lateral de agentes lista todos os agentes de todos os seus espaços com o status (Working, Blocked quando está esperando por você, Done ou Idle), para você ver num relance qual precisa de resposta. Fechar a janela não para nada: os terminais rodam no herdr-core (hc), um pequeno processo em segundo plano, e continuam lá quando você abre o Herdr de novo. É escrito em Rust, com licença Apache-2.0, e fica em herdr.dev.

🚀 Por que a versão mais recente importa: O Herdr é novo e evolui rápido: novos layouts, APIs de mods, correções para máquinas remotas e melhorias no status dos agentes chegam na maioria das versões. O Debian não empacota o Herdr, e o atualizador embutido do app vem desligado neste build, então as atualizações chegam do mesmo jeito que as do resto do sistema. Um apt upgrade normal mantém em dia toda máquina onde você trabalha.

⚡ Principais recursos do Herdr

🗂️ Espaços, abas e painéis

Dê a cada repositório o seu próprio espaço, abra abas nele e divida-as em painéis. Trocar de projeto é trocar de espaço, e cada terminal fica onde você deixou.

🤖 Barra lateral de agentes

Cada agente de programação rodando em qualquer espaço aparece numa única lista com o status: Working, Blocked (esperando por você), Done ou Idle. Os bloqueados são os primeiros a olhar.

♾️ Terminais que sobrevivem à janela

Os terminais rodam no herdr-core (hc), não na janela. Feche o Herdr e seus shells, builds e agentes continuam rodando; abra de novo e está tudo de volta.

🌐 Máquinas remotas via SSH

Adicione uma máquina que você acessa por SSH e os terminais de um espaço passam a rodar nela, então uma sessão longa de um agente continua mesmo quando o notebook entra em suspensão ou troca de rede.

🎨 Paleta, temas e layouts

Ctrl+Shift+P abre uma paleta de comandos para tudo; temas e layouts embutidos (Herdr, Terminals e o retrô Herdr 98) mudam a aparência da janela e o que ela mostra.

🧩 Mods em JavaScript

Mods escritos em JavaScript desenham seus próprios painéis e menus, então um fluxo de trabalho que o app ainda não cobre pode ser adicionado sem esperar uma nova versão.

🚀 Sempre à frente dos arquivos oficiais: Debian e Ubuntu congelam as versões dos pacotes quando lançam uma release — este repositório publica novas versões upstream normalmente em poucas horas. Um simples apt upgrade mantém você na versão mais recente.

Como funciona o espelho gratuito →

🧩 Sobre a opção extrepo. extrepo é a ferramenta do próprio Debian para repositórios externos: ela escreve o arquivo de sources e instala a chave de assinatura para você, conferindo a chave contra metadados assinados antes de usá-la. Este repositório está registrado nela como griffo, e o espelho gratuito para sempre como griffo-free, então no Debian (bookworm, trixie, forky e sid) os comandos acima são toda a configuração.

O extrepo configura apenas o arquivo de sources e a chave: as credenciais de uma assinatura continuam indo em /etc/apt/auth.conf.d/deb.griffo.io.conf. O Ubuntu não é coberto, porque o extrepo publica metadados só para as suítes do Debian: lá, use os comandos com sudo ou como root.

🔧 Integrações

O Herdr é uma casa para as ferramentas de linha de comando que você já usa, então quase tudo o que importa é a máquina ao redor dele:

  • Sessão de desktop: o Herdr é um app gráfico e precisa de uma sessão X11 ou Wayland; num servidor sem tela, rode os terminais lá como máquina remota
  • Vulkan: a janela é desenhada com Vulkan, então é preciso um driver Vulkan funcionando. O pacote recomenda mesa-vulkan-drivers, que cobre placas Intel e AMD; o driver proprietário da NVIDIA traz o seu
  • herdr-core: o hc fica em ~/.local/bin no seu diretório pessoal, instalado pelo app na primeira execução e não pelo apt; é o processo que mantém os terminais vivos enquanto a janela está fechada
  • Máquinas remotas: adicione uma máquina que você acessa por SSH e os terminais de um espaço rodam nela, então sessões longas de agentes sobrevivem ao notebook suspender ou perder a conexão
  • Agentes de programação: rode as CLIs dos seus agentes em painéis como qualquer outro comando; a barra de agentes reúne todos eles de todos os espaços e mostra qual está bloqueado esperando por você
  • herdr no terminal: o pacote herdr deste site é outro programa, um multiplexador de agentes para o terminal; o Herdr é o app de desktop, e os dois se instalam lado a lado
  • Suas ferramentas: Neovim ou Helix num painel, lazygit em outro e um agente num terceiro, tudo no mesmo espaço

🚀 Por que escolher o deb.griffo.io?

📊 Comparativo de repositórios:
  • Debian oficial: não empacota o Herdr, apt install herdr-app falha num sistema padrão
  • Downloads do upstream: builds de releases.herdr.dev que se atualizam sozinhos por fora do apt, em cada máquina separadamente
  • Compilar do código-fonte: uma toolchain Rust, os pacotes de desenvolvimento gráficos e de janelas, e uma compilação longa
  • deb.griffo.io: versão mais recente com atualizações automáticas
  • ✅ A única fonte apt: o Herdr não está nos arquivos do Debian nem nos do Ubuntu; este repositório empacota a versão oficial do upstream
  • ✅ Um nome só: o pacote se chama herdr-app e o comando também: sudo apt install herdr-app e depois herdr-app ou o atalho no menu
  • ✅ Atualizações pelo apt: o atualizador embutido vem desligado neste build, então a versão em disco é sempre a que o apt instalou e nada a reescreve pelas costas do gerenciador de pacotes
  • ✅ Pacote completo: o app de desktop Herdr com as dependências declaradas para instalar em todas as versões suportadas e o driver Vulkan recomendado; o herdr-core é configurado pelo próprio app na primeira execução
  • ✅ Atualizações automáticas: os pacotes são atualizados poucas horas após cada lançamento upstream
  • ✅ Duas arquiteturas: amd64 e arm64 igualmente no Bookworm, Trixie, Forky e Sid; não há build para i386, armhf ou riscv64
  • ✅ Multi-distribuição: funciona no Bookworm, Trixie, Forky e Sid
  • ✅ Manutenção simples: atualizações com os comandos apt de sempre

❓ Perguntas frequentes

O Herdr Desktop está nos repositórios oficiais do Debian?

Não, Herdr Desktop não está empacotado nos arquivos oficiais do Debian. Este repositório é atualmente a única fonte apt, oferecendo Herdr Desktop 0.1.9.

Como instalo o Herdr Desktop mais recente no Debian?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install herdr-app. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Debian são suportadas?

Debian 12 Bookworm, Debian 13 Trixie, Forky e Sid.
