O que é o tmux?

O tmux é o multiplexador de terminal: ele roda vários shells dentro de um único terminal, divididos em janelas e painéis, e os mantém rodando depois que você se desconecta. Uma sessão do tmux vive em um processo servidor, não na sua janela de terminal, então você pode se desanexar dela, fechar a janela ou perder a conexão ssh e anexar de novo mais tarde, com todos os programas ainda rodando exatamente onde você os deixou. Dentro de uma sessão você abre janelas como abas, divide cada uma em painéis lado a lado ou um sobre o outro, rola o histórico e copia texto pelo teclado, e controla tudo a partir de um arquivo de configuração ou de scripts. O tmux é escrito em C, foi criado por Nicholas Marriott e tem licença ISC.

🚀 Por que a versão mais recente importa: O tmux não para de ampliar o que um terminal consegue fazer: o tmux 3.8 trouxe painéis flutuantes e modais, e cada versão adiciona opções e corrige o tratamento do terminal. O Ubuntu 26.04 traz o tmux 3.6a e o Noble o 3.4, cada um congelado por toda a vida da sua versão, então um sistema padrão fica sem tudo o que foi lançado desde então. Este repositório publica o tmux 3.8 com o mesmo nome de pacote, então ele substitui o tmux da distribuição no próximo apt upgrade.

⚡ Principais recursos do tmux

🔌 Desanexar e anexar de novo

Comece uma compilação longa ou um processo servidor dentro do tmux, desanexe, saia da sessão ou perca a rede, e anexe de novo de qualquer lugar: a sessão e tudo o que há nela continuaram rodando enquanto você esteve fora.

🪟 Janelas e painéis

Cada sessão tem janelas como abas, e cada janela se divide em painéis, então um editor, um shell e um log acompanhado dividem uma única tela. Os painéis mudam de tamanho, ampliam para a tela inteira e se reorganizam com poucas teclas.

🎈 Painéis flutuantes e modais

O tmux 3.8 adiciona painéis flutuantes que ficam acima do layout e painéis modais que ocupam a janela até você fechá-los, para um comando rápido ou um seletor sem bagunçar as suas divisões.

📋 Modo de cópia e área de transferência

Role o histórico de um painel, pesquise nele e selecione texto com as teclas do vi ou do emacs. O texto copiado chega à área de transferência do seu desktop via OSC 52, mesmo de um tmux rodando em um servidor remoto.

🖼️ Imagens no terminal

Este build tem o suporte a sixel ativado, então programas que desenham imagens sixel as mostram dentro de um painel do tmux quando o seu terminal também suporta sixel.

🧰 Programável e configurável

Toda ação é um comando: associe a uma tecla no ~/.tmux.conf, ou rode a partir de um script shell para montar o layout de uma sessão inteira de uma vez. Gerenciadores de plugins e ferramentas de sessão se apoiam exatamente nisso.

🚀 Sempre à frente dos arquivos oficiais: Debian e Ubuntu congelam as versões dos pacotes quando lançam uma release — este repositório publica novas versões upstream normalmente em poucas horas. Um simples apt upgrade mantém você na versão mais recente.

🎯 Exemplos básicos de uso

Sessões, janelas e painéis:

# Listar as sessões em execução
tmux ls

# Dentro do tmux, o prefixo é Ctrl-b, seguido de:
# c  nova janela               n / p   janela seguinte / anterior
# %  dividir esquerda/direita  "       dividir em cima/embaixo
# setas  mover entre painéis   z  ampliar o painel atual
# [  modo de cópia, para rolar o histórico e selecionar texto
# d  desanexar

Montando um layout por script:

# Uma sessão desanexada com um editor à esquerda e um shell à direita
tmux new-session -d -s dev -n code
tmux split-window -h -t dev:code
tmux send-keys -t dev:code.0 'nvim' Enter
tmux attach -t dev

# Recarregar a sua configuração sem reiniciar nada
tmux source-file ~/.tmux.conf

🔧 Integrações

Como o pacote se chama tmux, tudo o que é construído sobre o tmux continua funcionando depois da atualização:

  • ssh: rode o tmux no servidor, não no seu notebook, e uma conexão caída só desanexa você; ssh -t host tmux attach retoma a sessão
  • Plugins: o tmux-plugin-manager (tpm) e os plugins que ele instala são carregados do ~/.tmux.conf exatamente como antes
  • Ferramentas de sessão: tmuxinator e byobu controlam o comando tmux, então recebem a nova versão sem nada para reconfigurar
  • Área de transferência: com OSC 52, o texto copiado no modo de cópia chega à área de transferência do terminal em que você está sentado, mesmo através de ssh
  • Recursos do terminal: o ncurses 6.6 é ligado estaticamente, então a área de transferência, a cor e o estilo do cursor e os sublinhados estilizados se comportam igual em todas as versões suportadas
  • systemd: compilado com suporte a systemd, como o próprio pacote da distribuição, e os seus sockets em /tmp ficam protegidos da limpeza do systemd-tmpfiles da mesma forma
  • Documentação: a wiki do tmux em github.com/tmux/tmux/wiki cobre os primeiros passos, o FAQ e todas as opções

📊 Comparativo de repositórios:
  • Ubuntu oficial: traz o tmux 3.6a no 26.04 e o 3.4 no Noble, cada um congelado por toda a vida da sua versão
  • Downloads do upstream: o tmux publica apenas o código-fonte, então não há binário pronto para baixar para nenhuma versão
  • Compilar do código-fonte: uma toolchain C mais os pacotes de desenvolvimento de libevent e ncurses, um configure e um make a cada versão, e nada que o atualize por você
  • deb.griffo.io: versão mais recente com atualizações automáticas
  • ✅ O mesmo nome de pacote do Ubuntu: o pacote se chama tmux, exatamente como no arquivo do Ubuntu, então este repositório atualiza o tmux padrão no lugar com apt upgrade
  • ✅ Compilado a partir de cada versão com tag: construído a partir do tarball da release com suporte a systemd, jemalloc e imagens sixel ativado, como o próprio build da distribuição, e registrado em /etc/shells
  • ✅ Um só tmux do Jammy ao Resolute: a mesma versão em todos os Ubuntu suportados, então um único ~/.tmux.conf se comporta igual em todas as suas máquinas
  • ✅ Atualizações automáticas: os pacotes são atualizados poucas horas após cada lançamento upstream
  • ✅ Duas arquiteturas: amd64 e arm64 em todas as versões, então o mesmo tmux roda em servidores, notebooks e placas ARM como o Raspberry Pi
  • ✅ Multi-distribuição: funciona no Ubuntu 22.04, 24.04, 25.10 e 26.04
  • ✅ Manutenção simples: atualizações com os comandos apt de sempre

❓ Perguntas frequentes

O tmux está nos repositórios oficiais do Ubuntu?

Sim, mas o arquivo oficial do Ubuntu traz tmux 3.6a, enquanto este repositório oferece tmux 3.8, recompilado poucas horas após cada lançamento upstream.

Como instalo o tmux mais recente no Ubuntu?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install tmux. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Ubuntu são suportadas?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing, 26.04 Resolute e 26.10 Stonking.
