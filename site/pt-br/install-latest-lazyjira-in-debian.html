O que é o lazyjira?

O lazyjira é uma interface de terminal para o Jira guiada pelo teclado, no estilo do lazygit e escrita em Go. Quatro painéis mostram suas issues, seus projetos, a issue selecionada e o status dela lado a lado, com navegação no estilo vim e suporte a mouse. Pesquise com JQL e depois mude a transição, a prioridade, o responsável ou os rótulos de uma issue, adicione comentários, edite a descrição no seu $EDITOR ou crie uma issue nova sem abrir o navegador. Funciona com Jira Cloud e Jira Server/Data Center, e na primeira execução um assistente de configuração guia a conexão. O pacote e o comando se chamam lazyjira.

🚀 Por que a versão mais recente importa: O lazyjira é jovem e evolui rápido, com novas ações de edição, suporte a mais campos do Jira e opções de configuração a cada versão. Ele não está nos arquivos do Debian nem do Ubuntu, e o upstream publica binários nas releases do GitHub, mas nenhum repositório apt, então um binário copiado à mão para o seu PATH nunca se atualiza sozinho.

⚡ Principais recursos do lazyjira

🔍 Busca JQL

Digite JQL com autocompletar e destaque de sintaxe, e volte a consultas anteriores por um histórico persistente. Abas JQL salvas deixam as visões do dia a dia a uma tecla de distância.

🗂️ Layout de quatro painéis

Issues, projetos, detalhes da issue e status ficam lado a lado, ou empilhados em um terminal estreito. Navegue com teclas no estilo vim ou com o mouse.

✏️ Edição direta

Mude transições, prioridade, responsável e rótulos, adicione comentários e edite descrições no seu $EDITOR. Issues novas são criadas na mesma tela.

🌿 Integração com git

Crie um branch do git a partir da issue selecionada, ou abra a issue que corresponde ao branch atual, para que ticket e código fiquem alinhados.

⚙️ Configurável

Atalhos, abas JQL, colunas de issues e campos personalizados são definidos em ~/.config/lazyjira/, com o tema ANSI padrão ou um dos temas Catppuccin.

🔐 Cloud e Server

O Jira Cloud entra com e-mail e token de API, o Jira Server e o Data Center com um token de acesso pessoal, e certificados de cliente mTLS são suportados.

🚀 Sempre à frente dos arquivos oficiais: Debian e Ubuntu congelam as versões dos pacotes quando lançam uma release — este repositório publica novas versões upstream normalmente em poucas horas. Um simples apt upgrade mantém você na versão mais recente.

Como funciona o espelho gratuito →

🧩 Sobre a opção extrepo. extrepo é a ferramenta do próprio Debian para repositórios externos: ela escreve o arquivo de sources e instala a chave de assinatura para você, conferindo a chave contra metadados assinados antes de usá-la. Este repositório está registrado nela como griffo, e o espelho gratuito para sempre como griffo-free, então no Debian (bookworm, trixie, forky e sid) os comandos acima são toda a configuração.

O extrepo configura apenas o arquivo de sources e a chave: as credenciais de uma assinatura continuam indo em /etc/apt/auth.conf.d/deb.griffo.io.conf. O Ubuntu não é coberto, porque o extrepo publica metadados só para as suítes do Debian: lá, use os comandos com sudo ou como root.

🔧 Integrações com outras ferramentas

O lazyjira se encaixa em um fluxo de trabalho de terminal existente:

  • Git: crie um branch a partir da issue selecionada, ou vá para a issue por trás do branch atual
  • Editor: as descrições abrem no $EDITOR, então Neovim, Helix ou qualquer outro editor cuida da escrita
  • Navegador: abra a issue selecionada no navegador via xdg-open quando precisar da visão web completa do Jira
  • Área de transferência: copie com xclip, pronto para colar em uma mensagem de commit ou em um chat
  • Jira corporativo: tokens de acesso pessoal e certificados de cliente mTLS atendem instalações Server e Data Center com configurações mais rígidas

🚀 Por que escolher o deb.griffo.io?

📊 Comparativo de repositórios:
  • Debian oficial: não empacotado: o lazyjira não está em nenhuma versão do Debian, do Bookworm ao Sid
  • Binário do upstream: atual no dia em que você baixa, mas o upstream publica binários nas releases do GitHub sem repositório apt, então o apt upgrade nunca vê uma versão nova e cada release é mais um download manual
  • Compilar com go install: exige uma toolchain Go e uma recompilação a cada atualização, e deixa de fora o changelog e a documentação
  • deb.griffo.io: versão mais recente com atualizações automáticas
  • ✅ Sem dependências em tempo de execução: o lazyjira é um único binário Go com linkagem estática; git, xclip e xdg-utils são apenas sugeridos, para branches, a área de transferência e abrir issues no navegador
  • ✅ Atualizações apt para as releases do upstream: o upstream distribui binários, mas nenhum repositório; aqui cada release chega a um repositório apt assinado com GPG, com uma build para cada suíte do Debian e do Ubuntu
  • ✅ Atualizações automáticas: os pacotes são atualizados poucas horas após cada lançamento upstream
  • ✅ Pacote completo: o binário lazyjira mais o changelog do upstream e os documentos Config, Keybindings e Custom Fields em /usr/share/doc/lazyjira
  • ✅ Duas arquiteturas: apenas amd64 e arm64, então notebooks, servidores e placas ARM de 64 bits têm o mesmo lazyjira
  • ✅ Multi-distribuição: funciona no Bookworm, Trixie, Forky e Sid
  • ✅ Manutenção simples: atualizações com os comandos apt de sempre

❓ Perguntas frequentes

O lazyjira está nos repositórios oficiais do Debian?

Não, lazyjira não está empacotado nos arquivos oficiais do Debian. Este repositório é atualmente a única fonte apt, oferecendo lazyjira 2.19.2.

Como instalo o lazyjira mais recente no Debian?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install lazyjira. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Debian são suportadas?

Debian 12 Bookworm, Debian 13 Trixie, Forky e Sid.
