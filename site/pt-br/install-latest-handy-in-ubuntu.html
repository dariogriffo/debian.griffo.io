O que é o Handy?

Handy é um aplicativo de voz para texto gratuito e de código aberto que funciona totalmente offline. Ele espera em segundo plano com um ícone na bandeja; você aperta um atalho de teclado global, fala o que quer escrever, e o Handy transcreve na sua própria máquina e cola o texto na janela que estiver em foco: um editor, um terminal, um cliente de chat, um formulário no navegador. Nada é enviado para um serviço na nuvem. Os modelos de voz (o Whisper da OpenAI em vários tamanhos e o Parakeet da NVIDIA, rápido até numa CPU comum) são baixados uma vez de dentro do aplicativo e depois rodam localmente, com detecção de atividade de voz cortando o silêncio antes que o modelo o ouça. É um aplicativo Tauri escrito em Rust por CJ Pais, sob licença MIT, e funciona tanto em desktops X11 quanto Wayland.

🚀 Por que a versão mais recente importa: O Handy é novo e evolui rápido: novos modelos, ajustes de precisão melhores e correções para microfones, compositores e layouts de teclado específicos chegam na maioria das versões. O Ubuntu não empacota o Handy, então sem este repositório o único jeito de ficar em dia é baixar cada nova versão na mão. Aqui um apt upgrade normal resolve, em toda máquina onde você dita.

⚡ Principais recursos do Handy

⌨️ Um atalho, qualquer aplicativo

Aperte o atalho global, fale e aperte de novo (ou segure no modo aperte para falar e solte) e a transcrição é colada na janela em foco. Não há caixa especial para ditar; tudo que aceita digitação aceita o Handy.

🔒 Totalmente offline

O áudio é gravado, transcrito e descartado no seu próprio computador. Sem conta, sem chave de API, sem assinatura e sem rede depois que o modelo está no disco.

🧠 Whisper e Parakeet

Escolha o modelo conforme o hardware: Whisper Small, Medium, Turbo ou Large, acelerados por GPU quando houver uma, ou o Parakeet, ajustado para rodar rápido na CPU e capaz de detectar o idioma sozinho.

🔇 Detecção de atividade de voz

O Silero VAD filtra o silêncio e o ruído de fundo antes que o áudio chegue ao modelo, então as pausas para pensar não viram palavras soltas.

🐧 X11 e Wayland

Funciona nos dois servidores gráficos e digita o resultado no aplicativo em foco através de pequenos utilitários de entrada que o pacote instala: xdotool no X11, wtype e wl-clipboard no Wayland, e ydotool para o GNOME.

🧩 Aberto e extensível

Licença MIT e feito para receber forks: o backend em Rust e a interface web são pequenos o bastante para ler, e as configurações cobrem o microfone, o atalho, o modelo e o idioma.

🚀 Sempre à frente dos arquivos oficiais: Debian e Ubuntu congelam as versões dos pacotes quando lançam uma release — este repositório publica novas versões upstream normalmente em poucas horas. Um simples apt upgrade mantém você na versão mais recente.

🔧 Integrações

O Handy não precisa de integração com nada: se um aplicativo aceita texto digitado, aceita ditado. O que importa é o desktop ao redor:

  • X11: o xdotool é uma dependência do pacote, então o texto chega à janela em foco sem instalar mais nada
  • Wayland: o wtype e o wl-clipboard também vêm com o pacote. Alguns compositores não repassam atalhos globais aos aplicativos; se o atalho não faz nada no seu, veja as configurações de teclado do compositor
  • GNOME no Wayland: o GNOME, padrão no Ubuntu 26.04, não aceita o wtype, então ali o Handy precisa do ydotool com o daemon rodando. O pacote recomenda o ydotool nas versões que o trazem (o Debian trixie não traz); as notas de Linux no README do Handy explicam como iniciar o daemon
  • dotool: o Handy também pode usá-lo, mas ele não está em nenhum arquivo do Debian ou do Ubuntu: instale você mesmo e adicione seu usuário ao grupo input
  • Áudio: o Handy grava pelo PipeWire ou PulseAudio como qualquer aplicativo de desktop; escolha o dispositivo de entrada nas configurações, e um microfone de headset ganha do embutido do notebook em precisão
  • Hardware: os modelos Whisper usam a GPU quando há uma e ficam lentos na CPU nos tamanhos maiores; num notebook sem uma GPU capaz, o Parakeet é a escolha rápida
  • Suas ferramentas: dite mensagens de commit num terminal como kitty ou Ghostty, texto no Zed, respostas no ZapZap ou no navegador e prompts para um assistente de IA, tudo com o mesmo atalho

🚀 Por que escolher o deb.griffo.io?

📊 Comparativo de repositórios:
  • Ubuntu oficial: não empacota o Handy, apt install handy falha num sistema padrão
  • Downloads do upstream: um .deb ou AppImage da página de releases do GitHub, atual no dia em que você baixa, e a ser baixado de novo na mão a cada versão
  • Compilar do código-fonte: uma toolchain Rust, uma toolchain JavaScript para a interface, os pacotes de desenvolvimento do WebKitGTK e de áudio de que o Tauri precisa, e uma compilação longa
  • deb.griffo.io: versão mais recente com atualizações automáticas
  • ✅ A única fonte apt: o Handy não está nos arquivos do Debian nem nos do Ubuntu; este repositório empacota a versão oficial do upstream
  • ✅ Um nome só: o pacote se chama handy e o comando também: sudo apt install handy e depois handy ou o atalho no menu
  • ✅ Privado por construção: o pacote traz o aplicativo, não um modelo nem um serviço; sua voz nunca sai da máquina, e a rede só é usada para baixar o modelo escolhido
  • ✅ Pacote completo: o build oficial do upstream para Linux (binário, bibliotecas embutidas, entrada de desktop, ícones) com as dependências declaradas para instalar em todas as versões suportadas, os utilitários de entrada de texto puxados junto, e só a categoria de menu vazia do lançador preenchida
  • ✅ Atualizações automáticas: os pacotes são atualizados poucas horas após cada lançamento upstream
  • ✅ Duas arquiteturas: amd64 no Ubuntu 22.04, 24.04, 25.10 e 26.04; arm64 só no 24.04, 25.10 e 26.04, porque o upstream compila arm64 contra a glibc 2.39 e o 22.04 tem a 2.35; não há build para i386, armhf ou riscv64
  • ✅ Multi-distribuição: funciona no Ubuntu 22.04, 24.04, 25.10 e 26.04
  • ✅ Manutenção simples: atualizações com os comandos apt de sempre

❓ Perguntas frequentes

O Handy está nos repositórios oficiais do Ubuntu?

Não, Handy não está empacotado nos arquivos oficiais do Ubuntu. Este repositório é atualmente a única fonte apt, oferecendo Handy 0.9.8.

Como instalo o Handy mais recente no Ubuntu?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install handy. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Ubuntu são suportadas?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing e 26.04 Resolute.
