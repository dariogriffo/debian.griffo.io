O que é o ZapZap?

ZapZap é um cliente desktop não oficial do WhatsApp para Linux, escrito em Python com PyQt6 e QtWebEngine. Ele encapsula o WhatsApp Web em uma janela desktop com aparência realmente nativa, com integração à bandeja do sistema, notificações de desktop, verificação ortográfica, temas e suporte a múltiplas contas — uma experiência muito melhor que uma aba do navegador.

🚀 Por que as últimas versões são importantes: o ZapZap lança versões frequentes com novos recursos, opções de aparência, trabalho de desempenho e correções que o mantêm em sintonia com o WhatsApp Web. As versões mais recentes trazem notificações aprimoradas, melhor suporte a Wayland e temas renovados — este repositório as recompila poucas horas após cada lançamento upstream.

⚡ Principais Recursos do ZapZap

🔔 Bandeja e Notificações

Ícone na bandeja do sistema com contador de não lidas e notificações nativas de desktop, para que as mensagens cheguem até você sem manter um navegador aberto.

👥 Múltiplas Contas

Execute várias contas do WhatsApp lado a lado em uma única janela, cada uma mantida em sua própria sessão isolada.

🎨 Temas e Aparência

Temas claro, escuro e personalizados, com controles de aparência que fazem o WhatsApp Web combinar com seu desktop.

✍️ Verificação Ortográfica

Verificação ortográfica integrada em vários idiomas enquanto você digita suas mensagens.

🖥️ Wayland e X11

Executa nativamente em sessões Wayland modernas assim como no X11, com integração de desktop Qt6.

🔒 Controles de Privacidade

Ajuste as prévias de notificação, o comportamento da bandeja e a integração com o sistema para que o WhatsApp se comporte do jeito que você quer.

🚀 Sempre à frente dos repositórios oficiais: Debian e Ubuntu congelam as versões dos pacotes a cada lançamento — este repositório publica novas versões upstream normalmente em poucas horas. Um simples apt upgrade mantém você sempre na versão mais recente.

Como funciona o espelho gratuito →

🧩 Sobre a opção extrepo. extrepo é a ferramenta do próprio Debian para repositórios externos: ela escreve o arquivo de sources e instala a chave de assinatura para você, conferindo a chave contra metadados assinados antes de usá-la. Este repositório está registrado nela como griffo, e o espelho gratuito para sempre como griffo-free, então no Debian (bookworm, trixie, forky e sid) os comandos acima são toda a configuração.

O extrepo configura apenas o arquivo de sources e a chave: as credenciais de uma assinatura continuam indo em /etc/apt/auth.conf.d/deb.griffo.io.conf. O Ubuntu não é coberto, porque o extrepo publica metadados só para as suítes do Debian: lá, use os comandos com sudo ou como root.

  • ✅ Integração Correta: Entrada de desktop, ícone, bandeja e notificações funcionam imediatamente
  • ✅ Multi-Distribuição: Funciona no Bookworm, Trixie, Forky e Sid

❓ Perguntas frequentes

O ZapZap está nos repositórios oficiais do Debian?

Não, ZapZap não está empacotado nos arquivos oficiais do Debian. Este repositório é atualmente a única fonte apt, oferecendo ZapZap 7.4.3.

Como instalo o ZapZap mais recente no Debian?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install zapzap. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Debian são suportadas?

Debian 12 Bookworm, Debian 13 Trixie, Forky e Sid.
