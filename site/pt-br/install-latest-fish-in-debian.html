O que é o fish?

O fish é um shell de linha de comando inteligente e amigável. Ele sugere o restante do comando enquanto você digita, a partir do histórico e das completações, destaca a sintaxe em tempo real, gera completações por Tab a partir das páginas de manual instaladas e dispensa as regras de aspas herdadas por outros shells. Tudo funciona de imediato: não é preciso configurar nada para que o fish seja agradável.

🚀 Por que as versões mais recentes importam: O fish 4 foi reescrito em Rust e evolui rápido desde então: inicialização mais veloz, completações melhores e um fluxo constante de refinamentos na experiência interativa. A versão congelada no arquivo oficial é anterior a boa parte disso.

⚡ Principais recursos do fish

💡 Sugestões automáticas

Enquanto você digita, o fish sugere o restante do comando com base no histórico e nas completações. Pressione → para aceitar.

🎨 Realce de sintaxe

Os comandos são coloridos conforme você escreve, então um erro de digitação ou uma aspa não fechada fica evidente antes do Enter.

⌨️ Completações a partir das páginas de manual

O fish analisa as páginas de manual instaladas para gerar completações — até ferramentas obscuras completam suas opções.

🧠 Scripts sensatos

Sem surpresas de divisão de palavras, sem [[ ]] versus [ ], e com listas de verdade. Os scripts se leem como se comportam.

🔍 Histórico pesquisável

Digite um prefixo e pressione ↑ para percorrer apenas os comandos correspondentes, com busca por substring embutida.

🛠️ Configurável no navegador

O fish_config abre uma interface para prompts, cores, funções e atalhos — sem arqueologia de dotfiles.

🚀 Sempre à frente dos arquivos oficiais: Debian e Ubuntu congelam as versões dos pacotes quando uma release é publicada — este repositório publica novas versões upstream normalmente em questão de horas. Um simples apt upgrade mantém você na versão mais recente.

Scripts sem armadilhas:

# Listas são listas de verdade — sem divisão de palavras
set files *.txt; echo (count $files) arquivos

# A substituição de comandos dispensa crases
echo "hoje é "(date +%A)

# As condições se leem naturalmente
if test -f /etc/os-release; echo encontrado; end

# Percorrer uma lista
for f in *.md; echo processando $f; end

Deixando do seu jeito:

# Definir uma função e salvá-la para a próxima vez
function ll; ls -lh $argv; end; funcsave ll

# Abreviações se expandem enquanto você digita, ao contrário dos aliases
abbr -a gco git checkout

# Adicionar ao PATH de forma permanente, sem editar um dotfile
fish_add_path ~/.local/bin

# Definir uma variável universal, compartilhada por todas as sessões
set -U EDITOR nvim

🔧 Combina bem com

O fish é cidadão de primeira classe no ferramental moderno de terminal:

  • starship: prompt multi-shell com suporte nativo ao fish
  • zoxide: zoxide init fish e salte entre diretórios por frequência
  • fzf: traz atalhos de teclado do fish para histórico e busca de arquivos
  • atuin: substitui o histórico do fish por um banco pesquisável e sincronizado
  • Oh My Posh: outro motor de prompt com inicializador para fish

🚀 Por que escolher o deb.griffo.io?

📊 Comparação de repositórios:
  • Debian oficial: disponível, mas congelado na versão que saiu junto com a release
  • Instalação manual: exige uma toolchain Rust e CMake, ou gerenciar um binário manualmente
  • deb.griffo.io: versão mais recente com atualizações automáticas
  • ✅ Recursos mais recentes: as melhorias de interatividade e desempenho mais novas
  • ✅ Sem configuração manual: binários pré-compilados, sem precisar compilar com cargo
  • ✅ Atualizações automáticas: pacotes atualizados poucas horas após os lançamentos upstream
  • ✅ Pacote completo: fish, fish_indent, fish_key_reader e as páginas de manual
  • ✅ Sem dependências: build musl com link estático; funções e completações são embutidas, então não há fish-common a instalar
  • ✅ Multidistribuição: funciona em Bookworm, Trixie, Forky e Sid
  • ✅ Manutenção simples: comandos apt padrão para atualizar

❓ Perguntas frequentes

O fish está nos repositórios oficiais do Debian?

Sim, mas o arquivo oficial do Debian traz fish 4.0.2, enquanto este repositório oferece fish 4.8.1, recompilado poucas horas após cada lançamento upstream.

Como instalo o fish mais recente no Debian?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install fish. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Debian são suportadas?

Debian 12 Bookworm, Debian 13 Trixie, Forky e Sid.
