O que é o Garage?

O Garage é um serviço de armazenamento de objetos distribuído, leve e compatível com S3. Projetado para rodar em várias máquinas geograficamente distribuídas, ele oferece armazenamento de objetos resiliente e auto-hospedado com uma API compatível com S3, tornando-se uma forte alternativa de código aberto aos serviços de armazenamento de objetos hospedados para backups, sites estáticos e dados de aplicações.

🚀 Por que as últimas versões são importantes: O Garage é desenvolvido ativamente com melhorias em replicação, desempenho e cobertura da API S3. Executar a versão mais recente garante os recursos de armazenamento mais novos e correções de confiabilidade.

⚡ Principais Recursos do Garage

☁️ API compatível com S3

Compatibilidade direta com clientes, SDKs e ferramentas S3 existentes.

🌐 Geodistribuído

Replique dados entre múltiplos nós e sites para maior resiliência.

🪶 Leve

Implementação eficiente em Rust que roda bem em hardware modesto.

🔒 Auto-hospedado

Mantenha total propriedade sobre seus dados na sua própria infraestrutura.

🎯 Por que o Garage?

  • Seu próprio armazenamento: Armazenamento de objetos auto-hospedado no seu próprio hardware
  • Ecossistema S3: Funciona com a vasta gama de ferramentas S3 existentes
  • Resiliente: Replicação entre múltiplos nós sobrevive a falhas de nós
  • Eficiente: Baixo consumo de recursos, ideal para clusters pequenos

🆕 Destaques

  • Armazenamento de Objetos: Buckets e objetos compatíveis com S3
  • Replicação: Redundância configurável entre nós
  • Multi-datacenter: Reconhecimento de zonas para posicionamento
  • Hospedagem Estática: Sirva sites estáticos diretamente dos buckets

Como funciona o espelho gratuito →

🧩 Sobre a opção extrepo. extrepo é a ferramenta do próprio Debian para repositórios externos: ela escreve o arquivo de sources e instala a chave de assinatura para você, conferindo a chave contra metadados assinados antes de usá-la. Este repositório está registrado nela como griffo, e o espelho gratuito para sempre como griffo-free, então no Debian (bookworm, trixie, forky e sid) os comandos acima são toda a configuração.

O extrepo configura apenas o arquivo de sources e a chave: as credenciais de uma assinatura continuam indo em /etc/apt/auth.conf.d/deb.griffo.io.conf. O Ubuntu não é coberto, porque o extrepo publica metadados só para as suítes do Debian: lá, use os comandos com sudo ou como root.

❓ Perguntas frequentes

O Garage está nos repositórios oficiais do Debian?

Não, Garage não está empacotado nos arquivos oficiais do Debian. Este repositório é atualmente a única fonte apt, oferecendo Garage 2.4.1.

Como instalo o Garage mais recente no Debian?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install garage. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Debian são suportadas?

Debian 12 Bookworm, Debian 13 Trixie, Forky e Sid.
