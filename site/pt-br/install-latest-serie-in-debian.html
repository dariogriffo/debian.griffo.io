O que é o Serie?

O Serie é uma interface de terminal para navegar pelo histórico de um repositório Git. Ele mostra o que o git log --graph --all mostra, mas o grafo é desenhado com o protocolo de imagens do emulador de terminal em vez de ser aproximado em arte ASCII — então branches e merges são legíveis de relance. Ao lado do grafo há uma lista de commits que rola e é pesquisável, com uma visão de detalhe. É deliberadamente um visualizador, não um cliente Git: não faz commit, branch nem push.

🚀 Por que a versão mais recente importa: o Serie é um projeto jovem, ainda antes do 1.0, e os recursos chegam em lançamentos comuns: comandos de usuário, atalhos personalizáveis, opções de estilo e ordenação do grafo e suporte à variante com placeholders Unicode do protocolo gráfico do Kitty. O suporte a imagens nos terminais também muda, então a build que desenha certo no seu terminal costuma ser a atual.

⚡ Principais recursos do Serie

🖼️ Um grafo de commits de verdade

O grafo é renderizado como imagens pelo protocolo do Kitty ou do iTerm2, então as linhas de branch continuam legíveis com dezenas de branches em paralelo.

🔍 Histórico pesquisável

Uma lista de commits ao lado do grafo que rola e busca, em vez de paginar a saída do git log.

📄 Visão de detalhe

Selecione um commit e veja mensagem, refs e diff sem sair do grafo.

🎛️ Opções do grafo

Ordem cronológica ou topológica, células de largura simples ou dupla, arestas arredondadas ou angulares — na linha de comando ou na configuração.

⌨️ Atalhos personalizáveis

? mostra os atalhos atuais, e todos podem ser redefinidos em config.toml.

🧰 Comandos de usuário

Rode seus próprios comandos sobre o commit selecionado: numa visão dedicada, em segundo plano ou suspendendo o Serie para algo interativo.

🚀 Sempre à frente dos arquivos oficiais: Debian e Ubuntu congelam as versões dos pacotes quando lançam uma release — este repositório publica novas versões upstream normalmente em poucas horas. Um simples apt upgrade mantém você na versão mais recente.

🎯 Exemplos básicos de uso

Navegando pelo histórico:

# O histórico completo do repositório atual
serie

# Só os commits mais recentes, para um repositório muito grande
serie -n 5000

# Ordem topológica em vez de cronológica
serie -o topo

# Começar com o HEAD selecionado, não com o commit mais novo
serie -i head

Ajustando o grafo ao seu terminal:

# Forçar um protocolo de imagem quando a detecção erra
serie -p kitty
serie -p iterm
serie -p kitty-unicode

# Células de grafo mais estreitas para uma janela pequena
serie -g single

# Arestas angulares em vez de arredondadas
serie -s angular

# Ou o visual folgado e arredondado num terminal largo
serie -g double -s rounded

Configuração e uso diário:

# O arquivo de configuração, para atalhos e padrões
mkdir -p ~/.config/serie
$EDITOR ~/.config/serie/config.toml

# Ou apontar o Serie para uma configuração em outro lugar
SERIE_CONFIG_FILE=~/dotfiles/serie.toml serie

# O Serie só lê o histórico — o git continua sendo seu cliente
git -C ~/src/project log --oneline -5

# Então commitar continua sendo trabalho do git
git commit -v

🔧 Integrações com outras ferramentas

o Serie precisa de duas coisas e coopera com uma terceira:

  • git: um repositório Git comum e o binário git, que o pacote instala como dependência
  • Seu terminal: um emulador que fale o protocolo de imagens do Kitty ou do iTerm2 — Ghostty, Kitty, WezTerm e iTerm2 servem
  • Arquivo de configuração: $XDG_CONFIG_HOME/serie/config.toml, ou o que SERIE_CONFIG_FILE apontar
  • Comandos de usuário: ligue git diff, um editor ou seu script a uma tecla e rode sobre o commit selecionado
  • Seu cliente git: o Serie de propósito não commita nem faz push, então ele convive com lazygit, GitUI ou git puro em vez de substituí-los

🚀 Por que escolher o deb.griffo.io?

📊 Comparativo de repositórios:
  • Debian oficial: não empacota o Serie — um sistema padrão não tem nada para instalar
  • cargo install --locked serie: atualizado, mas exige toolchain Rust e compilação em cada máquina, fora do apt
  • Tarball upstream: o binário oficial, baixado na mão a cada lançamento
  • deb.griffo.io: versão mais recente com atualizações automáticas
  • ✅ Jovem e em movimento: comandos de usuário, atalhos personalizáveis e as opções do grafo chegaram em lançamentos comuns — a build atual é outra ferramenta comparada à de um ano atrás
  • ✅ A única fonte apt: o Serie não está nos arquivos do Debian nem do Ubuntu; este repositório empacota a build oficial upstream
  • ✅ Atualizações automáticas: os pacotes são atualizados poucas horas após cada lançamento upstream
  • ✅ Empacotamento honesto: o binário upstream em /usr/bin/serie, com git declarado como dependência; o upstream não publica página de manual nem conclusões, então o pacote não inventa nenhuma
  • ✅ Duas arquiteturas: amd64 e arm64, ambas builds musl estáticas e sem dependências
  • ✅ Multi-distribuição: funciona no Bookworm, Trixie, Forky e Sid
  • ✅ Manutenção simples: atualizações com os comandos apt de sempre

❓ Perguntas frequentes

O Serie está nos repositórios oficiais do Debian?

Não, Serie não está empacotado nos arquivos oficiais do Debian. Este repositório é atualmente a única fonte apt, oferecendo Serie 0.8.1.

Como instalo o Serie mais recente no Debian?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install serie. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Debian são suportadas?

Debian 12 Bookworm, Debian 13 Trixie, Forky e Sid.
