O que é o cliamp?

O cliamp é o Winamp 2.x refeito para o terminal: um editor de playlists, um equalizador gráfico, um visualizador de espectro e um sistema de temas no lugar das skins, tudo desenhado em texto. Ele toca arquivos locais (MP3, FLAC, OGG, WAV), rádio pela internet e podcasts, e transmite de Spotify, Qobuz, Navidrome, Jellyfin, Emby, Plex, SoundCloud, NetEase e YouTube Music em uma única interface. Com --daemon, o mesmo binário vira um player sem interface controlado por um socket IPC: sua barra de status, seus atalhos e seus scripts conversam com a música que já está tocando.

🚀 Por que as versões mais recentes importam: A maior parte do cliamp é cola para serviços que não param de mudar: Spotify, Qobuz, SoundCloud, NetEase e YouTube Music trocam seus endpoints sem aviso, e um provedor que quebrou neste mês é consertado na versão deste mês, não em um build do ano passado. É exatamente por isso que o cliamp publica várias versões por semana. Nem o Debian nem o Ubuntu o empacotam, então um build atual aqui não é conforto: é a única forma de tê-lo pelo apt.

⚡ Principais recursos do cliamp

🎚️ Winamp, em texto

O editor de playlists, o equalizador gráfico e o layout clássico com medidores de pico, redesenhados com caracteres de bloco. 20 temas embutidos, de dracula e nord a vantablack, mudam a aparência inteira como as skins faziam.

📡 Rádio e streaming

Um catálogo de rádio pela internet com favoritos, mais Spotify, Qobuz, Navidrome, Jellyfin, Emby, Plex, SoundCloud, NetEase e YouTube Music atrás de uma única opção --provider e do assistente interativo cliamp setup.

📊 29 visualizadores

Barras de espectro, osciloscópio, campo estéreo, chuva do Matrix, chamas, fogos de artifício e mais, todos alimentados pela mesma FFT. cliamp vis troca de um para outro em tempo real; --low-power desliga tudo quando a bateria importa.

🎛️ Controles de áudio de verdade

Equalizador paramétrico com presets, velocidade de reprodução de 0,25× a 2×, mixagem mono, reprodução sem intervalos, troca do dispositivo de saída e controle explícito de taxa de amostragem, profundidade de bits e buffer.

🖥️ Daemon sem interface e IPC

cliamp --daemon toca sem TUI e responde a cliamp status, next ou volume pelo seu socket, enquanto cliamp visstream emite as bandas do visualizador em NDJSON para Waybar, quickshell e qualquer coisa que leia um pipe.

🧩 Plugins Lua em sandbox

Uma API de plugins com hooks para eventos de reprodução, atalhos, notificações, HTTP e armazenamento, tudo dentro de um sandbox. Os exemplos incluídos cobrem o arquivo de «tocando agora», webhooks e equalização automática por gênero.

🚀 Sempre à frente dos repositórios oficiais: Debian e Ubuntu congelam as versões dos pacotes quando uma release sai. Este repositório publica as novas versões upstream normalmente em algumas horas. Um simples apt upgrade mantém você na versão mais recente.

Como funciona o espelho gratuito →

🧩 Sobre a opção extrepo. extrepo é a ferramenta do próprio Debian para repositórios externos: ela escreve o arquivo de sources e instala a chave de assinatura para você, conferindo a chave contra metadados assinados antes de usá-la. Este repositório está registrado nela como griffo, e o espelho gratuito para sempre como griffo-free, então no Debian (bookworm, trixie, forky e sid) os comandos acima são toda a configuração.

O extrepo configura apenas o arquivo de sources e a chave: as credenciais de uma assinatura continuam indo em /etc/apt/auth.conf.d/deb.griffo.io.conf. O Ubuntu não é coberto, porque o extrepo publica metadados só para as suítes do Debian: lá, use os comandos com sudo ou como root.

🎯 Exemplos de uso básico

Tocar coisas:

# Um arquivo, uma pasta ou a URL de um stream
cliamp ~/Músicas/albuns/1997
cliamp https://stream.example.org/radio.mp3

# Começar a tocar já, embaralhado
cliamp ~/Músicas --auto-play --shuffle

# Uma playlist salva, pelo nome
cliamp --playlist roadtrip

# Uma URL do YouTube Music (precisa do yt-dlp)
cliamp "https://music.youtube.com/watch?v=..."

# O que eu ouvi?
cliamp history

Aparência e som:

# Listar e trocar de tema
cliamp theme list
cliamp theme tokyo-night

# Listar e trocar de visualizador
cliamp vis list
cliamp vis Stereo

# Presets do equalizador e velocidade de reprodução
cliamp eq Rock
cliamp speed 1.25

# Escolher um dispositivo de saída
cliamp --audio-device list
cliamp device "USB Audio"

# Layout de 80 colunas para um terminal pequeno
cliamp --compact

Sem interface e via script:

# Rodar sem TUI, servindo IPC
cliamp --daemon ~/Músicas

# Controlar o player em execução de qualquer lugar
cliamp toggle
cliamp next
cliamp volume -3
cliamp seek 90
cliamp status

# Alimentar uma barra de status com as bandas do visualizador
cliamp visstream | jq -c .

# Gerenciar os plugins Lua
cliamp plugins list

🔧 Integrações

O cliamp se apoia de propósito no que o seu sistema já tem:

  • ALSA: o áudio sai pelo libasound, daí a dependência do pacote e o fato de funcionar em um servidor pelado, sem sessão gráfica
  • ffmpeg: recomendado, e usado para os formatos e streams que os decodificadores internos não cobrem
  • yt-dlp: sugerido, e necessário para reproduzir YouTube e YouTube Music
  • MPRIS sobre D-Bus: as teclas de mídia do seu teclado e o widget de «tocando agora» do seu desktop controlam o cliamp como qualquer outro player
  • Waybar, quickshell e o seu shell: o socket IPC e o cliamp visstream alimentam barras de status e widgets, e as completações de bash e zsh vêm com este pacote

🚀 Por que escolher o deb.griffo.io?

📊 Comparação de repositórios:
  • Debian oficial: não empacota o cliamp, apt install cliamp falha em um sistema padrão
  • go install: atual, mas é uma compilação cgo em cada máquina, que antes exige os headers de desenvolvimento de ALSA, FLAC, Ogg e Vorbis
  • O script de instalação upstream: conveniente, mas larga um binário em ~/.local/bin por trás do gerenciador de pacotes, e depois o cliamp upgrade substitui esse binário no ritmo dele
  • deb.griffo.io: versão mais recente com atualizações automáticas
  • ✅ A única fonte apt: o cliamp não está nem nos repositórios do Debian nem nos do Ubuntu; este repositório empacota o build oficial upstream
  • ✅ Streaming quebra e é consertado upstream: os serviços de música com que o cliamp conversa mudam o tempo todo, então estar na versão deste mês é a diferença entre um provedor funcionar ou não
  • ✅ Atualizações automáticas: pacotes atualizados poucas horas depois de cada versão upstream
  • ✅ Pacote completo: /usr/bin/cliamp, uma página de manual, um atalho de desktop com o ícone do aplicativo e as completações de bash e zsh
  • ✅ Dependências honestas: depende do ALSA, recomenda o ffmpeg e sugere o yt-dlp, então uma instalação mínima continua mínima
  • ✅ Duas arquiteturas: amd64 e arm64, o mesmo pacote cobre o seu notebook e o seu Raspberry Pi
  • ✅ Multi-distribuição: funciona no Bookworm, Trixie, Forky e Sid
  • ✅ Manutenção fácil: comandos apt padrão para atualizar

❓ Perguntas frequentes

O cliamp está nos repositórios oficiais do Debian?

Não, cliamp não está empacotado nos arquivos oficiais do Debian. Este repositório é atualmente a única fonte apt, oferecendo cliamp 1.63.2.

Como instalo o cliamp mais recente no Debian?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install cliamp. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Debian são suportadas?

Debian 12 Bookworm, Debian 13 Trixie, Forky e Sid.
