1. Você tem assinatura: guarde as credenciais

As credenciais ficam em /etc/apt/auth.conf.d/, nunca na linha do sources.list, onde qualquer usuário da máquina poderia lê-las e o apt as vazaria em mensagens de erro:

Executar os comandos
sudo tee /etc/apt/auth.conf.d/deb.griffo.io.conf > /dev/null <<'EOF'
machine deb.griffo.io
login your-email@example.com
password your-subscription-password
EOF
sudo chmod 600 /etc/apt/auth.conf.d/deb.griffo.io.conf
sudo apt update
tee /etc/apt/auth.conf.d/deb.griffo.io.conf > /dev/null <<'EOF'
machine deb.griffo.io
login your-email@example.com
password your-subscription-password
EOF
chmod 600 /etc/apt/auth.conf.d/deb.griffo.io.conf
apt update

Depois disso, sudo apt install <package> funciona exatamente como antes. Se ainda retornar 401, verifique estes pontos, nesta ordem:

Ainda não assinou e quer saber o que está contratando? Como a assinatura funciona explica o fluxo inteiro: credenciais por e-mail, máquinas ilimitadas, renovação, cancelamento e reembolsos.

  • A linha machine é deb.griffo.io: sem https://, sem barra no fim e sem o caminho /apt.
  • O arquivo está em /etc/apt/auth.conf.d/ e o nome termina em .conf. O apt ignora silenciosamente qualquer outra extensão.
  • O arquivo pertence ao root e tem modo 600. O apt se recusa a ler credenciais que outros usuários possam ler.
  • Sem aspas sobrando em volta da senha e sem espaços no fim.
  • Ainda travado? Pergunte no Discord. É o jeito mais rápido de resolver.

2. Mude para o espelho sempre gratuito

O deb-free.griffo.io não pede conta nem pagamento, nunca. Ele serve o lançamento mais recente que tenha pelo menos dois meses, e publica correções de segurança e de patch desse lançamento imediatamente. Hoje ele traz cliamp, Ghostty, lazydocker, Oh My Posh, Uncloud e Zed: qualquer outra ferramenta pode ser incluída sob pedido, então pergunte no Discord se precisar de uma.

Executar os comandos
sudo rm -f /etc/apt/sources.list.d/deb.griffo.io.list
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb-free.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb-free.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb-free.griffo.io.gpg] https://deb-free.griffo.io/apt $(. /etc/os-release; echo ${DEBIAN_CODENAME:-${UBUNTU_CODENAME:-$VERSION_CODENAME}}) main" | sudo tee /etc/apt/sources.list.d/deb-free.griffo.io.list > /dev/null
sudo apt update
rm -f /etc/apt/sources.list.d/deb.griffo.io.list
install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb-free.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | gpg --dearmor --yes -o /etc/apt/keyrings/deb-free.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb-free.griffo.io.gpg] https://deb-free.griffo.io/apt $(. /etc/os-release; echo ${DEBIAN_CODENAME:-${UBUNTU_CODENAME:-$VERSION_CODENAME}}) main" | tee /etc/apt/sources.list.d/deb-free.griffo.io.list > /dev/null
apt update
sudo apt install extrepo
sudo extrepo enable griffo-free
sudo apt update

🧩 Sobre a opção extrepo. extrepo é a ferramenta do próprio Debian para repositórios externos: ela escreve o arquivo de sources e instala a chave de assinatura para você, conferindo a chave contra metadados assinados antes de usá-la. Este repositório está registrado nela como griffo, e o espelho gratuito para sempre como griffo-free, então no Debian (bookworm, trixie, forky e sid) os comandos acima são toda a configuração.

O Ubuntu não é coberto, porque o extrepo publica metadados só para as suítes do Debian: lá, use os comandos com sudo ou como root.

Não ative os dois repositórios ao mesmo tempo. O apt instalaria a versão que for mais alta (a da assinatura) e você voltaria ao 401. Todos os detalhes do espelho gratuito →

3. Pegue o .deb no GitHub

Todo pacote daqui é compilado em público, e os artefatos de build ficam anexados a um release público no GitHub. Esses downloads são grátis e sem autenticação, hoje e depois de 1º de outubro:

wget https://github.com/dariogriffo/ghostty-debian/releases/latest/download/ghostty_1.3.1-5~trixie_amd64.deb
sudo apt install ./ghostty_1.3.1-5~trixie_amd64.deb
wget https://github.com/dariogriffo/ghostty-debian/releases/latest/download/ghostty_1.3.1-5~trixie_amd64.deb
apt install ./ghostty_1.3.1-5~trixie_amd64.deb

Você perde as atualizações automáticas (é justamente isso que a assinatura paga), mas nunca perde o acesso ao software. O repositório de empacotamento de cada ferramenta está listado em como os pacotes são compilados.
