O que é o yt-dlp?

O yt-dlp é um baixador de áudio e vídeo por linha de comando que dá conta de bem mais de mil sites. Começou como um fork do youtube-dl (passando pelo já inativo youtube-dlc) e hoje é o projeto de fato mantido entre os dois, com um seletor de formatos muito mais rico, integração com o SponsorBlock, suporte nativo para embutir legendas, capítulos e metadados, e um sistema de plugins para extratores próprios.

🚀 Por que a versão mais recente importa: mais do que em qualquer outra ferramenta deste repositório. O yt-dlp conversa com sites que mudam seus players e APIs sem aviso, e a correção chega como uma nova versão do yt-dlp — muitas vezes em poucos dias. Uma versão congelada do arquivo oficial não apenas fica sem recursos: seus extratores param de funcionar e os downloads falham com erros de assinatura ou de formato até você atualizar. Estar na versão atual é justamente o ponto.

⚡ Principais recursos do yt-dlp

🌐 Milhares de sites

Mais de 1.700 extratores cobrindo plataformas de vídeo, emissoras, hospedagens de podcast e sites de notícias, além de um extrator genérico que encontra mídia em páginas para as quais ninguém escreveu um extrator.

🎚️ Seleção precisa de formato

-f e -S oferecem toda uma linguagem de expressões sobre resolução, codec, taxa de bits e contêiner, para pedir exatamente o fluxo que você quer em vez do padrão.

🎧 Extração de áudio

-x --audio-format mp3 retira a trilha de áudio e a recodifica; com --embed-thumbnail e --embed-metadata você obtém arquivos com tags que qualquer player entende.

💬 Legendas e capítulos

Baixe ou embuta legendas em qualquer idioma disponível, mantenha as automáticas e grave marcadores de capítulo direto no arquivo de saída — ou divida o arquivo por eles.

⏭️ SponsorBlock

Marque ou remova trechos patrocinados, aberturas e autopromoção já no download, usando a base do SponsorBlock, sem precisar de um editor depois.

🍪 Cookies e sessões

--cookies-from-browser lê uma sessão autenticada direto do Firefox ou do Chromium, para que conteúdo privado, com restrição de idade ou exclusivo para membros funcione.

🚀 Sempre à frente dos arquivos oficiais: Debian e Ubuntu congelam as versões dos pacotes quando lançam uma release — este repositório publica novas versões upstream normalmente em poucas horas. Um simples apt upgrade mantém você na versão mais recente.

Como funciona o espelho gratuito →

🧩 Sobre a opção extrepo. extrepo é a ferramenta do próprio Debian para repositórios externos: ela escreve o arquivo de sources e instala a chave de assinatura para você, conferindo a chave contra metadados assinados antes de usá-la. Este repositório está registrado nela como griffo, e o espelho gratuito para sempre como griffo-free, então no Debian (bookworm, trixie, forky e sid) os comandos acima são toda a configuração.

O extrepo configura apenas o arquivo de sources e a chave: as credenciais de uma assinatura continuam indo em /etc/apt/auth.conf.d/deb.griffo.io.conf. O Ubuntu não é coberto, porque o extrepo publica metadados só para as suítes do Debian: lá, use os comandos com sudo ou como root.

🎯 Exemplos básicos de uso

Downloads do dia a dia:

# Baixar um vídeo na melhor qualidade disponível
yt-dlp 'https://example.com/watch?v=...'

# O melhor MP4 até 1080p
yt-dlp -S 'res:1080,ext:mp4' 'URL'

# Somente áudio, como MP3 com tags
yt-dlp -x --audio-format mp3 --embed-thumbnail --embed-metadata 'URL'

# Ver todos os formatos oferecidos antes de escolher
yt-dlp -F 'URL'

Legendas, capítulos e patrocínios:

# Embutir legendas em inglês, incluindo as automáticas
yt-dlp --embed-subs --sub-langs en --write-auto-subs 'URL'

# Gravar marcadores de capítulo no arquivo
yt-dlp --embed-chapters 'URL'

# Remover trechos patrocinados e aberturas já no download
yt-dlp --sponsorblock-remove sponsor,intro 'URL'

# Pegar apenas um trecho em vez do vídeo inteiro
yt-dlp --download-sections '*00:01:30-00:04:00' 'URL'

Playlists, arquivos e automação:

# Uma playlist inteira, em pastas organizadas por autor
yt-dlp -o '%(uploader)s/%(title)s.%(ext)s' 'PLAYLIST_URL'

# Manter um canal sincronizado sem rebaixar o que já veio
yt-dlp --download-archive seen.txt 'CHANNEL_URL'

# Conteúdo privado ou com restrição de idade, usando a sessão do navegador
yt-dlp --cookies-from-browser firefox 'URL'

# Downloads mais rápidos via aria2c
yt-dlp --downloader aria2c --downloader-args aria2c:'-x 8 -s 8' 'URL'

🔧 Integrações com outras ferramentas

O yt-dlp é o backend de download que muitos outros softwares esperam encontrar:

  • ffmpeg: junção, remux, extração de áudio e embutimento dependem dele
  • mpv: reproduz uma URL direto, entregando-a ao yt-dlp na hora
  • aria2: baixador externo opcional para transferências paralelas e segmentadas
  • Servidores de mídia: bibliotecas do Jellyfin, Kodi e Navidrome costumam ser preenchidas com modelos de saída do yt-dlp
  • Arquivos de configuração: coloque suas opções habituais em ~/.config/yt-dlp/config e pare de redigitá-las

🚀 Por que escolher o deb.griffo.io?

📊 Comparativo de repositórios:
  • Debian oficial: disponível, mas congelado na versão que veio com a release — meses atrás em correções de extratores
  • pip / pipx: atualizado, mas fora do apt, e a PEP 668 torna o pip install de sistema desconfortável no Debian
  • deb.griffo.io: versão mais recente com atualizações automáticas
  • ✅ Extratores funcionando: a versão mais nova, que é o que faz os downloads continuarem dando certo
  • ✅ Sem configuração manual: sem pip, sem virtualenv, sem autoatualização escrevendo em /usr/local/bin
  • ✅ Atualizações automáticas: pacotes atualizados poucas horas após cada release upstream
  • ✅ Pacote completo: a build oficial do upstream, a página de manual yt-dlp.1 e autocompletes de bash, zsh e fish
  • ✅ Todas as arquiteturas: publicado como Architecture: all, então amd64, arm64, armhf, riscv64 e as demais instalam o mesmo pacote
  • ✅ Multi-distribuição: funciona em Bookworm, Trixie, Forky e Sid
  • ✅ Manutenção simples: comandos apt de sempre para atualizar

❓ Perguntas frequentes

O yt-dlp está nos repositórios oficiais do Debian?

Sim, mas o arquivo oficial do Debian traz yt-dlp 2025.04.30, enquanto este repositório oferece yt-dlp 2026.08.19, recompilado poucas horas após cada lançamento upstream.

Como instalo o yt-dlp mais recente no Debian?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install yt-dlp. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Debian são suportadas?

Debian 12 Bookworm, Debian 13 Trixie, Forky e Sid.
