Como funciona o espelho gratuito →

🧩 Sobre a opção extrepo. extrepo é a ferramenta do próprio Debian para repositórios externos: ela escreve o arquivo de sources e instala a chave de assinatura para você, conferindo a chave contra metadados assinados antes de usá-la. Este repositório está registrado nela como griffo, e o espelho gratuito para sempre como griffo-free, então no Debian (bookworm, trixie, forky e sid) os comandos acima são toda a configuração.

O extrepo configura apenas o arquivo de sources e a chave: as credenciais de uma assinatura continuam indo em /etc/apt/auth.conf.d/deb.griffo.io.conf. O Ubuntu não é coberto, porque o extrepo publica metadados só para as suítes do Debian: lá, use os comandos com sudo ou como root.

📦 Pacotes fonte

Além dos pacotes binários .deb, este repositório também fornece pacotes fonte Debian para todas as ferramentas suportadas. Os pacotes fonte permitem inspecionar o empacotamento, recompilar os binários localmente ou aplicar patches próprios — sempre com as ferramentas padrão do Debian. Um pacote fonte é composto por três arquivos:

  • .dsc — arquivo de descrição com checksums e metadados
  • .orig.tar.gz — tarball do código-fonte upstream, sem modificações
  • .debian.tar.xz — camada de empacotamento específica do Debian (diretório debian/)

Baixar e compilar

# Baixar o código-fonte de um pacote (cria um diretório na pasta atual)
apt-get source zig

# Ou baixar sem desempacotar — apenas o .dsc e os tarballs
apt-get source --download-only zig

# Entrar no diretório do código-fonte desempacotado (o número da versão varia)
cd zig-stable-0.14.0

# Compilar um .deb binário sem assinatura (adequado para uso local)
dpkg-buildpackage -b --no-sign

# O .deb resultante aparece um nível acima
ls ../zig-stable_*.deb
Executar os comandos

Alternativa: apenas as dependências de compilação

# Instalar automaticamente todas as dependências de compilação de um pacote
sudo apt-get build-dep zig

# Depois compilar com dpkg-buildpackage ou debuild
debuild -b --no-sign

Por que deb.griffo.ioFeito para quem quer o mais recente

Este repositório não oficial se especializa em fornecer as versões mais atualizadas de ferramentas de desenvolvimento populares como pacotes Debian corretamente empacotados. Enquanto os repositórios oficiais frequentemente ficam atrás dos lançamentos upstream, aqui você tem:

  • Versões estáveis mais recentes poucas horas após a publicação upstream
  • Builds noturnos para recursos de ponta (Zig, ZLS)
  • Empacotamento Debian adequado com dependências corretas
  • Suporte a múltiplas distribuições — Debian (Bookworm, Trixie, Forky, Sid) & Ubuntu (Jammy, Noble, Questing, Resolute)
  • Pacotes fonte — baixe, inspecione e recompile qualquer pacote localmente com apt-get source
  • Atualizações automatizadas garantindo disponibilidade contínua

Por que existe uma assinatura

Não é uma licença do software. Toda ferramenta aqui é de código aberto e todo .deb continua livre para baixar. O que a assinatura paga é a maquinaria em volta — e ela cresceu bastante.

Informações importantesAs perguntas que mais recebemos

Você não está pagando pelo software. Toda ferramenta aqui é de código aberto, e nada neste repositório muda a licença dela nem o que custa para você compilá-la por conta própria. A assinatura paga o empacotamento em volta disso: produzir pacotes Debian adequados para ferramentas cujos autores não distribuem nenhum, reconstruí-los automaticamente poucas horas após cada nova versão upstream e disponibilizar essas builds em versões antigas de Debian e Ubuntu que de outra forma ficariam anos para trás. Isso é manutenção contínua e infraestrutura, não uma licença de software. E se você preferir não pagar, todo .deb continua gratuito para baixar no GitHub — você só atualiza por conta própria.
Em poucos minutos você recebe um e-mail com um login — o endereço com que pagou — e uma senha gerada. Eles vão em /etc/apt/auth.conf.d/deb.griffo.io.conf, e o apt os envia por HTTPS a cada download: autenticação HTTP Basic simples, que o apt suporta nativamente há anos. Não há portal para acessar, nem token para rotacionar, nem limite de quantas máquinas usam as mesmas credenciais. A renovação é silenciosa e não muda nada; ao cancelar, você mantém o acesso até o fim do período que já pagou. Como a assinatura funciona, em detalhe →
Nada no seu sistema está quebrado e nada do que você já instalou é afetado — pacotes instalados nunca expiram nem verificam licença. A partir de 1º de outubro de 2026, baixar pacotes exige uma assinatura: apt update, apt policy e navegar pelo repositório continuam gratuitos para todos, enquanto apt install e apt upgrade passam a exigir credenciais em /etc/apt/auth.conf.d/. Há três caminhos possíveis, com os comandos exatos: adicionar suas credenciais, migrar para o espelho grátis para sempre em deb-free.griffo.io ou baixar o .deb direto da release pública no GitHub, que é gratuita e sempre será. Este repositório se concentra exclusivamente em empacotamento não oficial para Debian. Para problemas com as ferramentas em si, entre em contato com os respectivos projetos upstream. Cuidamos apenas de questões relacionadas ao empacotamento.
Os pacotes são atualizados automaticamente quando novas versões são publicadas upstream, normalmente em poucas horas, garantindo que você sempre tenha acesso às funcionalidades mais recentes e correções de segurança.
Este repositório é movido pelo reprepro, configurado para manter apenas a versão mais recente de cada pacote, então apt install zig=0.15.2 deixa de funcionar assim que a 0.16.0 é publicada. Por isso os pacotes do Zig são nomeados por nível de estabilidade: zig é um metapacote que sempre instala o zig-stable, zig-oldstable mantém a estável anterior e pode ser instalado junto, e zig-0 está obsoleto. Com os dois instalados, sudo update-alternatives --config zig escolhe para qual deles o /usr/bin/zig aponta.
