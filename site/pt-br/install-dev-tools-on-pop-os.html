⚡ A resposta curta. Sim, o deb.griffo.io funciona no Pop!_OS. 61 ferramentas de desenvolvimento se instalam com o apt puro no Pop!_OS 24.04 LTS e Pop!_OS 22.04 LTS, com o mesmo comando de configuração do Debian e do Ubuntu: ele lê UBUNTU_CODENAME de /etc/os-release e pede a suíte correspondente, noble no Pop!_OS 24.04 LTS.

O Pop!_OS é a distribuição da System76 baseada no Ubuntu LTS, e uma escolha comum para estações de trabalho de desenvolvimento. O seu arquivo acompanha o Ubuntu LTS por baixo, então as ferramentas de desenvolvimento que ele traz são as versões que aquela versão do Ubuntu congelou. O deb.griffo.io oferece a versão upstream atual de cada ferramenta abaixo, compilada para essa mesma base Ubuntu.

❓ Perguntas frequentes

Esses pacotes entram em conflito com os repositórios do COSMIC ou da System76?

Não. As ferramentas daqui são ferramentas de desenvolvimento que nem a System76 nem o Ubuntu reempacotam em versões atuais, e todo pacote leva o sufixo ~griffo na versão, então, se existir um pacote oficial da mesma versão, o apt dá preferência ao oficial.

O deb.griffo.io é um repositório oficial do Pop!_OS?

Não. É um repositório não oficial mantido por Dario Griffo, sem vínculo com o Pop!_OS. Cada pacote é compilado automaticamente a partir da versão upstream oficial, o empacotamento é de código aberto no GitHub e o arquivo é assinado com GPG.

Tem algum custo?

O repositório funciona por assinatura (€15 por ano ou €150 uma única vez), com teste grátis. Um espelho grátis, o deb-free.griffo.io, oferece um conjunto menor de ferramentas com algum atraso, com a mesma configuração nesta distribuição.

Como removo o repositório?

Apague /etc/apt/sources.list.d/deb.griffo.io.list e /etc/apt/keyrings/deb.griffo.io.gpg e rode sudo apt update. As ferramentas que você instalou continuam lá até você removê-las com apt remove.
