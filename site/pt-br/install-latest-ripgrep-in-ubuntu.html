O que é o ripgrep?

O ripgrep (o comando rg) é uma ferramenta de busca orientada a linhas escrita em Rust por Andrew Gallant. Ele busca recursivamente no diretório atual por um padrão de expressão regular, respeitando as regras do seu .gitignore e pulando automaticamente arquivos ocultos, ignorados e binários. É o mecanismo de busca por trás de editores como o VS Code e costuma ser mais rápido que o GNU grep, o The Silver Searcher e o ack.

🚀 Por que as versões mais recentes importam: O ripgrep ganha capacidades reais entre lançamentos — hyperlinks para pular direto para o editor, --engine auto para recorrer ao PCRE2 de forma transparente, saída --json mais rica e ganhos constantes de desempenho no motor de expressões regulares. A versão do arquivo oficial é anterior à maior parte disso.

⚡ Principais recursos do ripgrep

🚀 Extremamente rápido

Um motor de expressões regulares baseado em autômatos finitos, varredura SIMD de literais, mapeamento de memória e percurso paralelo de diretórios o tornam mais rápido que o grep em árvores grandes.

🙈 Respeita o .gitignore

Pula por padrão arquivos ignorados, ocultos e binários, então os resultados são os que realmente interessam. Pode ser sobreposto com -u, -uu ou -uuu.

🌍 Suporte completo a Unicode

Compatível com Unicode por padrão — classes de caracteres, dobramento de maiúsculas, limites de palavra e grafemas funcionam corretamente, sem custo real de velocidade.

🧩 Expressões PCRE2

-P habilita look-around e retrorreferências. Esta compilação já inclui o PCRE2, então funciona de imediato e com JIT.

📄 Filtro por tipo de arquivo

Restrinja a busca a uma linguagem com -t rust, exclua com -T html ou defina seus próprios tipos. Mais de 800 padrões vêm embutidos.

🔁 Multilinha e substituição

Busque através de quebras de linha com -U, pré-visualize substituições com -r e gere resultados estruturados com --json.

🚀 Sempre à frente dos arquivos oficiais: Debian e Ubuntu congelam as versões dos pacotes quando uma release é publicada — este repositório publica novas versões upstream normalmente em questão de horas. Um simples apt upgrade mantém você na versão mais recente.

🎯 Exemplos de uso básico

Busca do dia a dia:

# Buscar na árvore de diretórios atual
rg 'TODO'

# Ignorando maiúsculas, palavra inteira
rg -i -w 'timeout'

# Mostrar 3 linhas de contexto em cada ocorrência
rg -C 3 'panic!'

# Listar apenas os arquivos com ocorrências
rg -l 'BurntSushi'

Filtrando o que será buscado:

# Somente arquivos Rust
rg -t rust 'unsafe'

# Tudo exceto HTML e CSS
rg -T html -T css 'font-size'

# Incluir arquivos ignorados e ocultos
rg -uu 'password'

# Restringir com um glob
rg -g '*.toml' 'version'

Além do grep comum:

# Look-around e retrorreferências via PCRE2
rg -P '(?<=fn )\w+' src/

# Buscar através de quebras de linha
rg -U 'struct \w+ \{\n[^}]*pub'

# Pré-visualizar uma substituição (não grava arquivos)
rg 'v(\d+)\.(\d+)' -r 'v$1.$2.0'

# Saída estruturada para scripts
rg --json 'error' | jq -r 'select(.type=="match") | .data.path.text'

🔧 Integrações

O ripgrep é o backend de busca que muitas outras ferramentas esperam:

  • fzf: grep interativo com recarga ao vivo usando rg como origem
  • Neovim / Telescope: o live_grep usa o ripgrep quando ele está no PATH
  • Helix: a busca global é construída sobre as mesmas bibliotecas
  • bat: prévias com realce de sintaxe dos resultados
  • Yazi: busca do gerenciador de arquivos baseada no ripgrep

❓ Perguntas frequentes

O ripgrep está nos repositórios oficiais do Ubuntu?

Sim, mas o arquivo oficial do Ubuntu traz ripgrep 15.1.0, enquanto este repositório oferece ripgrep 15.2.0, recompilado poucas horas após cada lançamento upstream.

Como instalo o ripgrep mais recente no Ubuntu?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install ripgrep. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Ubuntu são suportadas?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing e 26.04 Resolute.
