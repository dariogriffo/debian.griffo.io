📊 Versões de pacotes no Debian 13 e no Ubuntu

O que os arquivos oficiais distribuem, ao lado do que este repositório serve — 2026-08-18

⚡ A resposta curta. Das 48 ferramentas deste repositório, 33 não estão nem no Debian 13 nem no Ubuntu 26.04, e as demais estão congeladas na versão que era atual quando essas distribuições foram lançadas. Debian e Ubuntu congelam as versões dos pacotes no lançamento e depois recebem quase só correções de segurança, o que é uma troca deliberada e muitas vezes acertada — mas significa que a versão que você obtém com apt install num sistema padrão é a que era atual no dia do lançamento. Esta tabela é o quadro completo de um catálogo de ferramentas de desenvolvimento, regenerada a cada publicação de pacote em vez de escrita à mão.

📋 A tabela

As versões oficiais vêm dos próprios arquivos do Debian e do Ubuntu (o serviço madison), comparadas com a versão estável atual de cada um: Debian 13 “Trixie” e Ubuntu 26.04 “Resolute”. Backports, testing e unstable ficam de fora — a pergunta é o que um sistema estável padrão oferece. A última coluna é o que este repositório serve hoje.

🔍 Como ler a tabela

  • “não empacotado” significa que o arquivo não tem nenhum pacote com esse nome, na versão estável atual daquela distribuição. Num sistema padrão, apt install falha com “Unable to locate package”.
  • As versões aparecem como os arquivos as reportam, sem epochs e sem as revisões do Debian, então 1:0.44.1-1ubuntu2 vira 0.44.1 — o número que o projeto upstream reconheceria.
  • Uma ferramenta pode estar no Ubuntu e não no Debian, ou o contrário: os dois arquivos tomam decisões independentes e congelam em datas diferentes.
  • Nada aqui é uma crítica ao Debian. Um arquivo congelado é o que torna estável uma versão estável, e para muitos e muitos pacotes é exatamente o que você quer. É uma escolha ruim para ferramentas que lançam a cada poucas semanas, que é toda a razão de existir deste repositório.

✅ Confira você mesmo qualquer linha

Todos os números acima são públicos. Numa máquina Debian ou Ubuntu:

apt-cache policy ripgrep        # o que o seu sistema instalaria, e de onde
apt-cache madison ripgrep       # todas as versões que suas fontes configuradas oferecem
rmadison ripgrep                # o que os arquivos oficiais distribuem, sem instalar nada

rmadison vem do pacote devscripts e consulta o mesmo serviço a partir do qual esta tabela é construída. A coluna deb.griffo.io acompanha a versão mais recente de cada projeto, reconstruída poucas horas depois dela; o repositório de empacotamento de cada ferramenta está listado em como os pacotes são construídos.

📦 Como obter a versão atual

Uma única linha de repositório cobre todas as ferramentas da tabela, reconstruídas poucas horas após cada versão upstream:

Executar os comandos
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | sudo tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
sudo apt update
