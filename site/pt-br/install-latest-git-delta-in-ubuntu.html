O que é o delta?

O delta é um paginador com realce de sintaxe para a saída de git, diff, grep e blame. Configure-o uma vez como paginador do git e todo git diff, git show, git log -p, git blame e git add -p sai com o código colorido como no seu editor, as palavras alteradas marcadas dentro de cada linha modificada, colunas lado a lado e números de linha opcionais, e cabeçalhos de arquivo entre os quais você pula com n e N. Ele também lê qualquer diff unificado, compara dois arquivos diretamente e realça a saída JSON do ripgrep. É escrito em Rust por Dan Davison, usa as mesmas definições de sintaxe e temas de cores do bat, é configurado pelo seu ~/.gitconfig e tem licença MIT. O pacote se chama git-delta; o comando que ele instala é delta.

🚀 Por que a versão mais recente importa: O delta lança várias versões por ano, com opções novas, melhor quebra de linha na visão lado a lado e correções para as muitas formas como git, terminais e paginadores interagem. O Ubuntu 26.04 está congelado na 0.18.2, o 24.04 LTS na 0.16.5, e o 22.04 não tem git-delta nenhum, então opções do manual atual podem simplesmente não existir na sua cópia. Este repositório usa o mesmo nome de pacote, git-delta, então apt install git-delta e apt upgrade entregam a versão atual em vez da do arquivo.

⚡ Principais recursos do delta

🎨 Realce de sintaxe

O código dentro de um diff é colorido como no seu editor, com as definições de sintaxe e os temas de cores do bat. Escolha um com syntax-theme ou deixe o delta seguir o fundo claro ou escuro do terminal.

🔍 Mudanças por palavra

Dentro de cada linha modificada o delta marca exatamente as palavras que mudaram, então uma variável renomeada ou uma condição invertida salta aos olhos em vez de se esconder em duas linhas vermelha e verde quase iguais.

↔️ Visão lado a lado

side-by-side = true coloca a versão antiga e a nova em duas colunas com números de linha, quebrando linhas longas em vez de cortá-las. Experimente em um só comando com git -c delta.side-by-side=true diff.

🧭 Navegação e links

Com navigate = true, n e N pulam de arquivo em arquivo num git log -p longo. Com hyperlinks = true, caminhos de arquivo e hashes de commit viram links clicáveis nos terminais que suportam.

🧩 Blame, grep e conflitos

git blame ganha código colorido com os dados do commit agrupados, os resultados de git grep e rg --json são realçados e agrupados por arquivo, e arquivos em conflito durante um merge aparecem como diffs legíveis.

⚙️ Mora no ~/.gitconfig

Cada opção fica numa seção [delta] da sua configuração do git, e conjuntos de opções com nome trocam o visual inteiro de uma vez. O pacote traz o themes.gitconfig do upstream, uma coleção de temas prontos.

🚀 Sempre à frente dos arquivos oficiais: Debian e Ubuntu congelam as versões dos pacotes quando lançam uma release — este repositório publica novas versões upstream normalmente em poucas horas. Um simples apt upgrade mantém você na versão mais recente.

🎯 Exemplos básicos de uso

Lendo diffs:

# Lado a lado, para um comando
git -c delta.side-by-side=true diff

# Ou sempre, com números de linha
git config --global delta.side-by-side true
git config --global delta.line-numbers true

# Percorrer o histórico; n e N pulam entre arquivos
git log -p

# Preparar hunks com realce
git add -p

Além do git diff:

# Comparar dois arquivos diretamente
delta old.conf new.conf

# Qualquer diff unificado
diff -u a.txt b.txt | delta

# Resultados do ripgrep, realçados e agrupados por arquivo
rg --json -C 2 'TODO' | delta

# git blame e git grep também passam pelo delta
git blame src/main.rs
git grep -n 'TODO'

Temas e configuração:

# Ver cada tema de sintaxe num diff de verdade
git show | delta --show-syntax-themes

# Carregar os temas do delta que vêm no pacote e vê-los
git config --global --add include.path /etc/delta/themes.gitconfig
git show | delta --show-themes

# Usar um deles
git config --global delta.features mellow-barbet

# A configuração com que o delta realmente trabalha
delta --show-config

🔧 Integrações

O delta é um filtro entre o git e o seu paginador, então quase toda a integração acontece na sua configuração do git e no seu terminal:

  • git: core.pager delta cobre diff, show, log -p, stash show -p, blame e grep; interactive.diffFilter precisa de --color-only, porque o git espera receber uma linha para cada linha do hunk
  • less: o delta pagina a saída com o less, que o pacote recomenda; sem ele, o delta escreve direto no terminal. DELTA_PAGER ou delta.pager escolhem outro paginador, e --paging=never desliga a paginação
  • lazygit: o lazygit pode exibir seus diffs através do delta; aponte a configuração de paginador dele para delta --dark --paging=never
  • difftastic: os dois se completam: o delta como paginador do git no dia a dia, o difftastic via git difftool quando você quer um diff por árvore sintática
  • ripgrep: rg --json enviado ao delta dá resultados de busca realçados e agrupados por arquivo, no mesmo tema dos seus diffs
  • Seu terminal: o delta descobre sozinho se o fundo é claro ou escuro, e delta.dark ou delta.light corrigem um palpite errado; kitty e Ghostty abrem os links que hyperlinks = true produz
  • Seu shell: os autocompletares de delta para bash, zsh e fish vêm com o pacote

🚀 Por que escolher o deb.griffo.io?

📊 Comparativo de repositórios:
  • Ubuntu oficial: traz o git-delta 0.18.2 no 26.04, 0.16.5 no 24.04 e nenhum no 22.04, cada um congelado por toda a vida da sua versão
  • cargo install git-delta: uma toolchain Rust e alguns minutos de compilação para um binário em ~/.cargo/bin de um só usuário, sem autocompletar, recompilado à mão a cada versão
  • Downloads do upstream: um .deb ou tarball da página de releases do GitHub, atual no dia em que você baixa, e baixado de novo à mão a cada versão seguinte
  • deb.griffo.io: versão mais recente com atualizações automáticas
  • ✅ O mesmo nome de pacote dos arquivos: git-delta, exatamente como o Debian e o Ubuntu o chamam, então um simples sudo apt install git-delta escolhe esta versão mais nova e o apt upgrade substitui no lugar uma cópia mais antiga do arquivo
  • ✅ Pacote git-delta, comando delta: você instala git-delta e executa delta. Dois nomes parecidos não têm relação: o pacote delta do arquivo é um redutor de casos de teste (multidelta, singledelta), e o comando git delta do git-extras lista arquivos que diferem de outro branch
  • ✅ O build oficial: o binário da release do upstream em /usr/bin/delta, sem alterações, com autocompletar para bash, zsh e fish e o themes.gitconfig em /etc/delta/themes.gitconfig, onde o próprio pacote do Debian o coloca; o upstream não publica página de manual, a referência é delta --help
  • ✅ Dependências leves: recomenda git e less e não precisa de nenhum dos dois para rodar: sem o less, o delta simplesmente imprime a saída sem paginar
  • ✅ Atualizações automáticas: os pacotes são atualizados poucas horas após cada lançamento upstream
  • ✅ Três arquiteturas: amd64, arm64 e armhf no Ubuntu 22.04, 24.04, 25.10, 26.04 e 26.10; não há build para i386, ppc64el, s390x ou riscv64
  • ✅ Multi-distribuição: funciona no Ubuntu 22.04, 24.04, 25.10, 26.04 e 26.10
  • ✅ Manutenção simples: atualizações com os comandos apt de sempre

❓ Perguntas frequentes

O delta está nos repositórios oficiais do Ubuntu?

Sim, mas o arquivo oficial do Ubuntu traz delta 0.18.2, enquanto este repositório oferece delta 0.22.0, recompilado poucas horas após cada lançamento upstream.

Como instalo o delta mais recente no Ubuntu?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install git-delta. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Ubuntu são suportadas?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing, 26.04 Resolute e 26.10 Stonking.
