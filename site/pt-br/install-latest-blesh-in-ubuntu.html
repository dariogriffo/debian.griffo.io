O que é o ble.sh?

O ble.sh, o Bash Line Editor, é um editor de linha escrito em Bash puro que substitui o GNU Readline nas sessões interativas do Bash. Você mantém o Bash, seu ~/.bashrc, seus aliases e scripts, e ganha o que normalmente exigiria trocar de shell: realce de sintaxe enquanto digita, sugestões automáticas do histórico no estilo do fish, um modo vim completo ao lado dos atalhos do emacs, autocompletar com menus e descrições, abreviações e integração com bash-completion e fzf. É escrito por Koichi Murase e distribuído sob a licença BSD-3-Clause. Não há binário para executar: o pacote instala o script em /usr/share/blesh/ble.sh, e duas linhas no seu ~/.bashrc o ativam.

🚀 Por que a versão mais recente importa: O ble.sh é desenvolvido continuamente no branch master, e versões estáveis com tag são raras e espaçadas, por isso as instruções de instalação do upstream apontam para a build nightly ou um checkout do git. Debian e Ubuntu empacotam um snapshot que fica congelado durante toda a vida da release (o Debian estável nem o inclui). Este repositório acompanha os snapshots nightly do upstream, então correções para novas versões do Bash, terminais e integrações de autocompletar chegam até você com apt upgrade.

⚡ Principais recursos do ble.sh

🎨 Realce de sintaxe

Comandos, palavras-chave, strings, variáveis, redirecionamentos e nomes de arquivo são coloridos enquanto você digita, e um comando desconhecido ou um erro de sintaxe aparece antes de você apertar Enter.

💡 Sugestões automáticas

Sugestões no estilo do fish, vindas do histórico e do autocompletar, aparecem em cinza depois do cursor. Aceite a sugestão inteira com a seta para a direita ou C-f, ou palavra por palavra com M-f.

⌨️ Modos vim e emacs

Atalhos do emacs por padrão e um modo vi/vim completo com set -o vi: modos normal, inserção e visual, objetos de texto, registradores e uma linha de status opcional no estilo do vim-airline.

📋 Autocompletar com menu

Tab abre um menu de candidatos que você percorre com as setas, com descrições quando existem e correspondência ambígua (fuzzy).

✂️ Abreviações

ble-sabbrev define abreviações que se expandem enquanto você digita, como as abreviações do fish ou os aliases globais do zsh, então L vira | less.

🐚 Bash puro, sem binário

Nada para compilar e nada específico de arquitetura: o ble.sh é um script Bash que roda onde quer que rode o Bash 3.0 ou mais novo, e fica fora de shells não interativos e de scripts.

🚀 Sempre à frente dos arquivos oficiais: Debian e Ubuntu congelam as versões dos pacotes quando lançam uma release — este repositório publica novas versões upstream normalmente em poucas horas. Um simples apt upgrade mantém você na versão mais recente.

Passo 3: Ativar o ble.sh no seu ~/.bashrc

# O ble.sh não tem um comando próprio: o Bash o carrega a partir do ~/.bashrc.
# Coloque esta linha perto do INÍCIO do ~/.bashrc:
[[ $- == *i* ]] && source /usr/share/blesh/ble.sh --noattach

# ...o resto do seu ~/.bashrc continua como está...

# E esta linha bem no FINAL do ~/.bashrc:
[[ ${BLE_VERSION-} ]] && ble-attach

# Abra um terminal novo e depois:
# Verificar a instalação
echo $BLE_VERSION

🎯 Exemplos básicos de uso

Uso do dia a dia:

# Verificar se o ble.sh está ativo neste shell
echo $BLE_VERSION

# Recarregar o ble.sh depois de mudar as configurações
ble-reload

# As atualizações vêm pelo apt; o ble-update aponta para ele
sudo apt update && sudo apt upgrade
# Verificar se o ble.sh está ativo neste shell
echo $BLE_VERSION

# Recarregar o ble.sh depois de mudar as configurações
ble-reload

# As atualizações vêm pelo apt; o ble-update aponta para ele
apt update && apt upgrade

Configurações no ~/.blerc:

# O ble.sh lê suas configurações do ~/.blerc (ou ~/.config/blesh/init.sh)
# Atalhos do vim em vez do emacs
set -o vi

# Esperar 300 ms antes de mostrar uma sugestão
bleopt complete_auto_delay=300

# Desativar totalmente as sugestões automáticas
bleopt complete_auto_complete=

# Mudar a cor do texto sugerido
ble-face auto_complete='fg=242'

Abreviações, atalhos de teclado e integrações:

# Expandir "L" para "| less" enquanto você digita
ble-sabbrev L='| less'

# Fazer o Ctrl+C descartar a linha atual
ble-bind -f 'C-c' discard-line

# Autocompletar e atalhos do fzf, adaptados ao ble.sh
ble-import -d integration/fzf-completion
ble-import -d integration/fzf-key-bindings

# Linha de status no estilo do vim-airline (requer ble.sh-airline-themes)
ble-import vim-airline
bleopt vim_airline_theme=dark

🔧 Integrações com outras ferramentas

O ble.sh fica por baixo da sua configuração do Bash em vez de substituí-la:

  • bash-completion: os autocompletes do pacote bash-completion são detectados automaticamente e exibidos no menu
  • fzf: o ble-import carrega versões do autocompletar e dos atalhos do fzf adaptadas ao ble.sh
  • Atuin: a integração do Atuin com o Bash suporta o ble.sh, que fornece hooks preexec confiáveis para registrar o histórico
  • Starship / Oh My Posh: os prompts gerados por eles continuam funcionando sem mudanças
  • Arquivo de configuração: o ~/.blerc guarda suas configurações de bleopt, ble-face e ble-bind, separadas do ~/.bashrc

❓ Perguntas frequentes

O ble.sh está nos repositórios oficiais do Ubuntu?

Sim, mas o arquivo oficial do Ubuntu traz ble.sh 0.4.0, enquanto este repositório oferece ble.sh 0.4.0, recompilado poucas horas após cada lançamento upstream.

Como instalo o ble.sh mais recente no Ubuntu?

Adicione o repositório deb.griffo.io uma única vez com as instruções acima e execute: sudo apt install ble.sh. Novos lançamentos chegam pelo sudo apt upgrade normal.

Os pacotes são assinados e como são construídos?

Cada pacote é assinado com a chave GPG do repositório (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) e construído a partir de lançamentos upstream em repositórios públicos do GitHub que qualquer pessoa pode inspecionar.

Quais versões do Ubuntu são suportadas?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing e 26.04 Resolute.
