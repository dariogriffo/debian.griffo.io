📦 apt install unregistry

Install the latest unregistry (v0.2.1+) on Debian - push Docker images directly to remote servers without external registry. Get up-to-date packages with SSH transfer and efficient layer deduplication from deb.griffo.io.

⚡ The short answer. On a stock system apt install unregistry fails outright — unregistry is not in the official Debian or Ubuntu archives at all. Add the deb.griffo.io repository below and sudo apt install unregistry gives you the current release on Debian and Ubuntu alike — currently unregistry 0.4.3 (updated 2026-08-13).

📦 Add the repository, then apt install unregistry

Step 1: Add repository & key

sudo install -d -m 0755 /etc/apt/keyrings curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc) main" | sudo tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null sudo apt update

🔄 How to apt install the latest unregistry

Once the repository is added there is no separate "install latest" command — apt already resolves to the newest version this repository serves, and that is rebuilt within hours of every upstream unregistry release. To move an existing install up to the latest version:

sudo apt update && sudo apt install --only-upgrade unregistry

Or upgrade everything on the machine at once with sudo apt update && sudo apt upgrade. To see which version you would get before installing, run apt policy unregistry.

❓ Common questions

Does apt-get install unregistry work too?

Yes. apt and apt-get read the same sources, so sudo apt-get install unregistry is equivalent. apt is the friendlier front-end; apt-get is the stable one to prefer inside scripts.

Why doesn't apt install unregistry work out of the box?

unregistry is not packaged in the official Debian or Ubuntu archives, so a stock system has nothing to install and apt install unregistry fails with "Unable to locate package". Adding this repository gives apt a source that carries unregistry and keeps it current.

Which Debian and Ubuntu releases are supported?

Every currently supported release listed in the table above. The $(lsb_release -sc) in the setup command picks the right suite for the machine you run it on, so the same three lines work everywhere.

Is this repository trustworthy?

It's an unofficial repository maintained by Dario Griffo. Packages are built automatically from official upstream unregistry releases, the packaging is open source at dariogriffo/unregistry-debian, and the whole archive is GPG-signed. Several upstream projects link to it from their official installation docs.
