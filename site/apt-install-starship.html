📦 apt install starship

Official Debian ships Starship 1.22.1 — this repo has Starship 1.26.0. One apt command for Bookworm, Trixie, Forky and Sid; GPG-signed, rebuilt within hours of every release.

⚡ The short answer. On a stock system apt install starship works, but installs a frozen version (Debian ships 1.22.1, Ubuntu ships 1.22.1) rather than the current 1.26.0. Add the deb.griffo.io repository below and sudo apt install starship gives you the current release on Debian and Ubuntu alike — currently starship 1.26.0 (updated 2026-08-19).

🔄 How to apt install the latest starship

Once the repository is added there is no separate "install latest" command — apt already resolves to the newest version this repository serves, and that is rebuilt within hours of every upstream starship release. To move an existing install up to the latest version:

sudo apt update && sudo apt install --only-upgrade starship
apt update && apt install --only-upgrade starship

Or upgrade everything on the machine at once with sudo apt update && sudo apt upgrade. To see which version you would get before installing, run apt policy starship.

❓ Common questions

Does apt-get install starship work too?

Yes. apt and apt-get read the same sources, so sudo apt-get install starship is equivalent. apt is the friendlier front-end; apt-get is the stable one to prefer inside scripts.

Why doesn't apt install starship work out of the box?

It does work, but not with the version most people want: Debian ships 1.22.1, Ubuntu ships 1.22.1, because Debian and Ubuntu freeze package versions when a release ships and afterwards take mostly security fixes. This repository tracks upstream starship releases instead, rebuilding within hours of each one.

Which Debian and Ubuntu releases are supported?

Every currently supported release listed in the table above. The $(lsb_release -sc) in the setup command picks the right suite for the machine you run it on, so the same three lines work everywhere.

Is this repository trustworthy?

It's an unofficial repository maintained by Dario Griffo. Packages are built automatically from official upstream starship releases, the packaging is open source at dariogriffo/starship-debian, and the whole archive is GPG-signed. Several upstream projects link to it from their official installation docs.
