Что такое Helix?

Helix — это постмодернистский модальный текстовый редактор, написанный на Rust. Вдохновлённый Kakoune и Vim, он использует модель редактирования «сначала выделение», а также поставляется с подсветкой синтаксиса на основе tree-sitter и поддержкой Language Server Protocol из коробки — не требуется никаких плагинов или настройки, чтобы получить современный опыт в стиле IDE прямо в терминале. Команда для запуска — hx.

🚀 Почему важны последние версии: Helix активно разрабатывается, с частыми релизами, добавляющими поддержку новых языков, функции редактора и улучшения производительности. Последние версии приносят улучшенную интеграцию с LSP, больше встроенных тем и доработанные команды редактирования.

⚡ Ключевые возможности Helix

🌲 Встроенный tree-sitter

Быстрая, точная подсветка синтаксиса и структурные выделения на основе грамматик tree-sitter.

🧠 Языковые серверы включены

Автодополнение, диагностика и переход к определению работают из коробки через LSP.

🎯 Редактирование «сначала выделение»

Модель множественного выделения, которая делает сложные правки интуитивными и воспроизводимыми.

⚙️ Без настройки

Разумные значения по умолчанию и встроенные темы — продуктивность с момента установки.

🎯 Почему Helix?

  • Всё включено: Подсветка синтаксиса и поддержка LSP без настройки плагинов
  • Быстрый и лёгкий: Написан на Rust, единый бинарный файл, отзывчив на больших файлах
  • Модальная эргономика: Отточенная модель редактирования «выделение → действие»
  • Отличные настройки по умолчанию: Понятные раскладки клавиш и интерактивная палитра команд

🆕 Основные особенности

  • Встроенный LSP: Функции IDE без внешних плагинов
  • Множественные выделения: Редактируйте сразу несколько мест с лёгкостью
  • Темы: Десятки встроенных цветовых тем
  • Единый бинарный файл: Никаких зависимостей времени выполнения для управления

❓ Часто задаваемые вопросы

Есть ли Helix в официальных репозиториях Ubuntu?

Нет, Helix не упакован в официальных архивах Ubuntu. Этот репозиторий сейчас единственный источник apt и предлагает Helix 25.07.1.

Как установить последнюю версию Helix в Ubuntu?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install helix. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Ubuntu поддерживаются?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing и 26.04 Resolute.
