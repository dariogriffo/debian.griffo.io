Что такое delta?

delta — это пейджер с подсветкой синтаксиса для вывода git, diff, grep и blame. Один раз назначьте его пейджером git, и каждый git diff, git show, git log -p, git blame и git add -p выводится с кодом, подсвеченным как в вашем редакторе, с отмеченными изменёнными словами внутри каждой изменённой строки, с колонками рядом и номерами строк по желанию и с заголовками файлов, между которыми можно прыгать клавишами n и N. Он также читает любой унифицированный diff, сравнивает два файла напрямую и подсвечивает JSON-вывод ripgrep. Написан на Rust Дэном Дэвисоном, использует те же определения синтаксиса и цветовые темы, что и bat, настраивается в вашем ~/.gitconfig, лицензия MIT. Пакет называется git-delta, а команда, которую он устанавливает, — delta.

🚀 Почему важна последняя версия: delta выходит несколько раз в год: новые опции, лучший перенос строк в режиме рядом и исправления для множества способов, которыми взаимодействуют git, терминалы и пейджеры. Ubuntu 26.04 заморожена на 0.18.2, 24.04 LTS на 0.16.5, а в 22.04 git-delta нет вовсе, так что опций из актуального руководства в вашей копии может просто не быть. Этот репозиторий использует то же имя пакета, git-delta, поэтому apt install git-delta и apt upgrade дают текущий релиз вместо архивного.

⚡ Ключевые возможности delta

🎨 Подсветка синтаксиса

Код внутри diff подсвечивается так же, как в вашем редакторе, с определениями синтаксиса и цветовыми темами bat. Выберите тему через syntax-theme или дайте delta следовать светлому или тёмному фону терминала.

🔍 Изменения на уровне слов

Внутри каждой изменённой строки delta отмечает именно те слова, что отличаются, так что переименованная переменная или перевёрнутое условие сразу видны, а не прячутся в двух почти одинаковых красной и зелёной строках.

↔️ Режим рядом

side-by-side = true показывает старую и новую версии в двух колонках с номерами строк и переносит длинные строки вместо обрезки. Для одной команды: git -c delta.side-by-side=true diff.

🧭 Навигация и ссылки

С navigate = true клавиши n и N прыгают от файла к файлу по длинному git log -p. С hyperlinks = true пути к файлам и хеши коммитов становятся кликабельными в терминалах, которые это поддерживают.

🧩 Blame, grep и конфликты

git blame получает подсвеченный код со сгруппированными данными коммитов, результаты git grep и rg --json подсвечиваются и группируются по файлам, а файлы с конфликтами при слиянии показываются как читаемые diff.

⚙️ Живёт в ~/.gitconfig

Каждая опция находится в секции [delta] вашей конфигурации git, а именованные наборы опций меняют весь внешний вид разом. Пакет включает themes.gitconfig из upstream, коллекцию готовых тем.

🚀 Всегда впереди официальных архивов: Debian и Ubuntu замораживают версии пакетов при выпуске релиза — этот репозиторий публикует новые версии обычно в течение нескольких часов. Простое apt upgrade держит вас на последней версии.

Шаг 3: Первый запуск

# Сделать delta пейджером git: diff, show, log -p, blame и grep идут через него
git config --global core.pager delta

# git add -p с той же подсветкой
git config --global interactive.diffFilter 'delta --color-only'

# n и N прыгают между файлами
git config --global delta.navigate true

# Конфликты показывают и общего предка
git config --global merge.conflictStyle zdiff3

# Попробовать
git diff

🎯 Базовые примеры использования

Чтение diff:

# Рядом, для одной команды
git -c delta.side-by-side=true diff

# Или всегда, с номерами строк
git config --global delta.side-by-side true
git config --global delta.line-numbers true

# Пройти по истории; n и N прыгают между файлами
git log -p

# Добавлять hunk-и с подсветкой
git add -p

Не только git diff:

# Сравнить два файла напрямую
delta old.conf new.conf

# Любой унифицированный diff
diff -u a.txt b.txt | delta

# Совпадения ripgrep, подсвеченные и сгруппированные по файлам
rg --json -C 2 'TODO' | delta

# git blame и git grep тоже идут через delta
git blame src/main.rs
git grep -n 'TODO'

Темы и настройка:

# Посмотреть каждую тему синтаксиса на настоящем diff
git show | delta --show-syntax-themes

# Подключить темы delta из пакета и посмотреть их
git config --global --add include.path /etc/delta/themes.gitconfig
git show | delta --show-themes

# Использовать одну из них
git config --global delta.features mellow-barbet

# Конфигурация, с которой delta реально работает
delta --show-config

🔧 Интеграции

delta — фильтр между git и вашим пейджером, поэтому почти вся интеграция происходит в конфигурации git и в терминале:

  • git: core.pager delta охватывает diff, show, log -p, stash show -p, blame и grep; для interactive.diffFilter нужен --color-only, потому что git ждёт ровно одну строку в ответ на каждую строку hunk-а
  • less: delta листает вывод через less, который пакет рекомендует; без него delta пишет прямо в терминал. DELTA_PAGER или delta.pager выбирают другой пейджер, а --paging=never отключает листание
  • lazygit: lazygit умеет показывать свои diff через delta; укажите в его настройке пейджера delta --dark --paging=never
  • difftastic: они дополняют друг друга: delta как пейджер git для повседневных diff, difftastic через git difftool, когда нужен diff по синтаксическому дереву
  • ripgrep: rg --json, переданный в delta, даёт подсвеченные результаты поиска, сгруппированные по файлам, в той же теме, что и ваши diff
  • Ваш терминал: delta сам определяет, светлый фон или тёмный, а delta.dark или delta.light исправляют ошибку; kitty и Ghostty открывают ссылки, которые создаёт hyperlinks = true
  • Ваша оболочка: автодополнение delta для bash, zsh и fish ставится вместе с пакетом

🚀 Почему стоит выбрать deb.griffo.io?

📊 Сравнение репозиториев:
  • Официальная Ubuntu: поставляет git-delta 0.18.2 в 26.04, 0.16.5 в 24.04 и ничего в 22.04, каждый заморожен на всё время жизни выпуска
  • cargo install git-delta: тулчейн Rust и несколько минут компиляции ради бинарника в ~/.cargo/bin для одного пользователя, без автодополнения, пересобираемого вручную к каждому релизу
  • Загрузки upstream: .deb или tarball со страницы релизов GitHub, актуальный в день загрузки и скачиваемый вручную заново к каждому следующему релизу
  • deb.griffo.io: последняя версия с автоматическими обновлениями
  • ✅ То же имя пакета, что в архивах: git-delta, ровно как его называют Debian и Ubuntu, поэтому простой sudo apt install git-delta берёт эту более новую версию, а apt upgrade заменяет старую архивную копию на месте
  • ✅ Пакет git-delta, команда delta: вы устанавливаете git-delta и запускаете delta. Два похожих имени ни при чём: архивный пакет delta — это минимизатор тестовых случаев (multidelta, singledelta), а команда git delta из git-extras перечисляет файлы, отличающиеся от другой ветки
  • ✅ Официальная сборка: бинарник из релиза upstream в /usr/bin/delta без изменений, с автодополнением для bash, zsh и fish и themes.gitconfig в /etc/delta/themes.gitconfig, там же, где его кладёт собственный пакет Debian; man-страницы upstream не выпускает, справка — delta --help
  • ✅ Лёгкие зависимости: рекомендует git и less и не требует ни того, ни другого: без less delta просто выводит результат без листания
  • ✅ Автоматические обновления: пакеты обновляются в течение нескольких часов после релиза upstream
  • ✅ Три архитектуры: amd64, arm64 и armhf на Ubuntu 22.04, 24.04, 25.10, 26.04 и 26.10; сборок для i386, ppc64el, s390x и riscv64 нет
  • ✅ Много дистрибутивов: работает на Ubuntu 22.04, 24.04, 25.10, 26.04 и 26.10
  • ✅ Простое обслуживание: обновления обычными командами apt

❓ Часто задаваемые вопросы

Есть ли delta в официальных репозиториях Ubuntu?

Да, но официальный архив Ubuntu поставляет delta 0.18.2, тогда как этот репозиторий предлагает delta 0.22.0, пересобирается через несколько часов после каждого релиза.

Как установить последнюю версию delta в Ubuntu?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install git-delta. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Ubuntu поддерживаются?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing, 26.04 Resolute и 26.10 Stonking.
