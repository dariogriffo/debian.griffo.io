📦 Пакеты с исходным кодом

Помимо бинарных пакетов .deb, этот репозиторий предоставляет пакеты с исходным кодом Debian для всех поддерживаемых инструментов. Они позволяют изучить упаковку, пересобрать бинарники локально или наложить свои патчи — и всё это стандартными средствами Debian. Пакет с исходным кодом состоит из трёх файлов:

  • .dsc — файл описания с контрольными суммами и метаданными
  • .orig.tar.gz — неизменённый архив исходного кода upstream
  • .debian.tar.xz — слой упаковки, специфичный для Debian (каталог debian/)

Скачать и собрать

# Скачать исходный код пакета (создаёт каталог в текущей папке)
apt-get source zig

# Или скачать без распаковки — только сам .dsc и архивы
apt-get source --download-only zig

# Перейти в распакованный каталог с исходным кодом (номер версии может отличаться)
cd zig-stable-0.14.0

# Собрать бинарный .deb без подписи (подходит для локального использования)
dpkg-buildpackage -b --no-sign

# Готовый .deb появится уровнем выше
ls ../zig-stable_*.deb

Почему deb.griffo.ioСделано для тех, кому нужны свежие версии

Этот неофициальный репозиторий специализируется на самых актуальных версиях популярных инструментов разработки в виде правильно собранных пакетов Debian. Пока официальные репозитории нередко отстают от выпусков upstream, вы получаете:

  • Последние стабильные версии в течение нескольких часов после публикации upstream
  • Ночные сборки для самых передовых возможностей (Zig, ZLS)
  • Правильную упаковку Debian с корректными зависимостями
  • Поддержку нескольких дистрибутивов — Debian (Bookworm, Trixie, Forky, Sid) и Ubuntu (Jammy, Noble, Questing, Resolute)
  • Пакеты с исходным кодом — скачайте, изучите и пересоберите любой пакет локально с помощью apt-get source
  • Автоматические обновления, гарантирующие непрерывную доступность

Важная информацияВопросы, которые задают чаще всего

Вы платите не за программы. Каждый инструмент здесь — с открытым исходным кодом, и репозиторий никак не меняет ни его лицензию, ни то, во сколько вам обойдётся собрать его самостоятельно. Подписка оплачивает упаковку вокруг него: создание полноценных пакетов Debian для инструментов, авторы которых их не выпускают, автоматическую пересборку в течение нескольких часов после каждого выпуска upstream и доступность этих сборок на старых выпусках Debian и Ubuntu, которые иначе отставали бы на годы. Это постоянное сопровождение и инфраструктура, а не лицензия на программу. А если платить не хочется, каждый .deb по-прежнему можно бесплатно скачать с GitHub — просто обновлять их придётся самостоятельно.
За пару минут вы получите письмо с логином — это адрес, с которого вы оплачивали — и сгенерированным паролем. Они кладутся в /etc/apt/auth.conf.d/deb.griffo.io.conf, и apt отправляет их по HTTPS при каждой загрузке: обычная HTTP Basic-аутентификация, которую apt поддерживает штатно уже много лет. Нет личного кабинета, нет токенов для ротации и нет ограничения на число машин с одними и теми же данными. Продление происходит молча и ничего не меняет; при отмене доступ сохраняется до конца уже оплаченного периода. Как устроена подписка, полностью →
В вашей системе ничего не сломалось, и уже установленные пакеты не затронуты — установленные пакеты не истекают и не проверяют лицензию. С 1 октября 2026 года для скачивания пакетов нужна подписка: apt update, apt policy и просмотр репозитория остаются бесплатными для всех, а apt install и apt upgrade требуют учётных данных в /etc/apt/auth.conf.d/. Есть три пути, и для каждого есть точные команды: добавить свои учётные данные, перейти на вечно бесплатное зеркало deb-free.griffo.io или скачать .deb напрямую из публичного релиза на GitHub — это бесплатно и будет бесплатным всегда. Этот репозиторий сосредоточен исключительно на неофициальной упаковке Debian. По вопросам, связанным с самими инструментами, обращайтесь к соответствующим проектам upstream. Мы занимаемся только вопросами упаковки.
Пакеты обновляются автоматически при выходе новых версий в upstream, обычно в течение нескольких часов, так что у вас всегда есть доступ к последним возможностям и исправлениям безопасности.
Репозиторий работает на reprepro, настроенном хранить только последнюю версию каждого пакета, поэтому apt install zig=0.15.2 перестаёт работать, как только выходит 0.16.0. Поэтому пакеты Zig названы по уровню стабильности: zig — метапакет, который всегда устанавливает zig-stable; zig-oldstable содержит предыдущий стабильный выпуск и может стоять рядом с ним; zig-0 устарел. Если установлены оба, команда sudo update-alternatives --config zig определяет, на какой из них указывает /usr/bin/zig.
