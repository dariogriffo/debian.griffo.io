Что такое Herdr?

Herdr — это настольное приложение для терминалов и агентов программирования. Работа разложена по пространствам, обычно по одному на репозиторий, и в каждом пространстве есть вкладки, разделённые на панели, так что оболочка, редактор и два агента программирования помещаются рядом в одном окне. Боковая панель агентов показывает всех агентов из всех пространств с их статусом (Working, Blocked, когда агент ждёт вас, Done или Idle), и сразу видно, кому нужен ответ. Закрытие окна ничего не останавливает: терминалы работают в herdr-core (hc), небольшом фоновом процессе, и остаются на месте, когда вы снова открываете Herdr. Приложение написано на Rust, распространяется под лицензией Apache-2.0, а его сайт herdr.dev.

🚀 Почему важна последняя версия: Herdr молод и быстро развивается: новые раскладки, API модов, исправления для удалённых машин и улучшения статусов агентов приходят почти в каждом релизе. Debian вообще не пакетирует Herdr, а встроенное автообновление приложения в этой сборке отключено, поэтому обновления приходят так же, как для остальной системы. Обычный apt upgrade держит в актуальном состоянии каждую машину, на которой вы работаете.

⚡ Ключевые возможности Herdr

🗂️ Пространства, вкладки и панели

Дайте каждому репозиторию своё пространство, откройте в нём вкладки и разделите их на панели. Переключиться на другой проект значит переключить пространство, и каждый терминал остаётся там, где вы его оставили.

🤖 Боковая панель агентов

Каждый агент программирования из любого пространства попадает в один список со своим статусом: Working, Blocked (ждёт вас), Done или Idle. Смотреть в первую очередь стоит на заблокированных.

♾️ Терминалы переживают окно

Терминалы работают в herdr-core (hc), а не в окне. Закройте Herdr, и ваши оболочки, сборки и агенты продолжат работать; откройте снова, и всё будет на месте.

🌐 Удалённые машины по SSH

Добавьте машину, доступную по SSH, и терминалы пространства будут работать на ней, так что долгая сессия агента продолжается, даже когда ноутбук засыпает или меняет сеть.

🎨 Палитра, темы и раскладки

Ctrl+Shift+P открывает палитру команд для всего; темы и встроенные раскладки (Herdr, Terminals и ретро-раскладка Herdr 98) меняют вид окна и то, что в нём показано.

🧩 Моды на JavaScript

Моды на JavaScript рисуют собственные панели и меню, так что сценарий, который приложение пока не поддерживает, можно добавить, не дожидаясь релиза.

🚀 Всегда впереди официальных архивов: Debian и Ubuntu замораживают версии пакетов при выпуске релиза — этот репозиторий публикует новые версии обычно в течение нескольких часов. Простое apt upgrade держит вас на последней версии.

Как работает бесплатное зеркало →

🧩 О варианте extrepo. extrepo — штатный инструмент Debian для внешних репозиториев: он создаёт файл sources и устанавливает ключ подписи, предварительно сверив его с подписанными метаданными. Этот репозиторий зарегистрирован в нём как griffo, а бесплатное навсегда зеркало — как griffo-free, поэтому в Debian (bookworm, trixie, forky и sid) команды выше и есть вся настройка.

extrepo настраивает только файл sources и ключ — учётные данные подписки по-прежнему прописываются в /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu не поддерживается, так как extrepo публикует метаданные только для выпусков Debian: там используйте команды с sudo или от root.

🔧 Интеграции

Herdr служит домом для консольных инструментов, которыми вы уже пользуетесь, поэтому важнее всего окружение машины:

  • Сеанс рабочего стола: Herdr графическое приложение, ему нужен сеанс X11 или Wayland; на сервере без монитора запускайте терминалы там через удалённую машину
  • Vulkan: окно рисуется через Vulkan, поэтому нужен рабочий драйвер Vulkan. Пакет рекомендует mesa-vulkan-drivers, который покрывает графику Intel и AMD; проприетарный драйвер NVIDIA приносит свой
  • herdr-core: hc живёт в ~/.local/bin в вашем домашнем каталоге, его ставит приложение при первом запуске, а не apt; именно этот процесс держит терминалы живыми, пока окно закрыто
  • Удалённые машины: добавьте машину, доступную по SSH, и терминалы пространства будут работать на ней, так что долгие сессии агентов переживут сон ноутбука или потерю связи
  • Агенты программирования: запускайте CLI агентов в панелях, как любую другую команду; боковая панель агентов собирает их со всех пространств и показывает, кто заблокирован в ожидании вас
  • herdr в терминале: пакет herdr на этом сайте это другая программа, терминальный мультиплексор агентов; Herdr это настольное приложение, и оба ставятся рядом
  • Ваши инструменты: Neovim или Helix в одной панели, lazygit в другой и агент в третьей, всё в одном пространстве

🚀 Почему стоит выбрать deb.griffo.io?

📊 Сравнение репозиториев:
  • Официальный Debian: не пакетирует Herdr, apt install herdr-app на чистой системе завершается ошибкой
  • Загрузки из upstream: сборки релизов с releases.herdr.dev, которые обновляют себя сами в обход apt, на каждой машине по отдельности
  • Сборка из исходников: тулчейн Rust, пакеты разработки для графики и оконной системы и долгая сборка
  • deb.griffo.io: последняя версия с автоматическими обновлениями
  • ✅ Единственный источник для apt: Herdr нет ни в архивах Debian, ни в архивах Ubuntu; этот репозиторий пакетирует официальный upstream-релиз
  • ✅ Одно имя везде: пакет называется herdr-app, и команда тоже: sudo apt install herdr-app, затем herdr-app или ярлык в меню
  • ✅ Обновления через apt: встроенное автообновление в этой сборке отключено, поэтому версия на диске всегда та, что поставил apt, и ничто не переписывает её за спиной менеджера пакетов
  • ✅ Полный пакет: настольное приложение Herdr с объявленными зависимостями, чтобы оно ставилось на любую поддерживаемую версию, и рекомендованным драйвером Vulkan; herdr-core приложение настраивает само при первом запуске
  • ✅ Автоматические обновления: пакеты обновляются в течение нескольких часов после релиза upstream
  • ✅ Две архитектуры: amd64 и arm64 одинаково на Bookworm, Trixie, Forky и Sid; сборок для i386, armhf и riscv64 нет
  • ✅ Много дистрибутивов: работает на Bookworm, Trixie, Forky и Sid
  • ✅ Простое обслуживание: обновления обычными командами apt

❓ Часто задаваемые вопросы

Есть ли Herdr Desktop в официальных репозиториях Debian?

Нет, Herdr Desktop не упакован в официальных архивах Debian. Этот репозиторий сейчас единственный источник apt и предлагает Herdr Desktop 0.1.10.

Как установить последнюю версию Herdr Desktop в Debian?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install herdr-app. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Debian поддерживаются?

Debian 12 Bookworm, Debian 13 Trixie, Forky и Sid.
