Что такое Jujutsu?

Jujutsu — это Git-совместимая система контроля версий, которая предлагает более простую и мощную модель, чем Git, оставаясь при этом обратно совместимой с существующими репозиториями Git. Она использует команду jj, рассматривает рабочую копию как коммит, обеспечивает полноценную обработку конфликтов и отмену для каждой операции — позволяя вам продолжать использовать Git-хостинги вроде GitHub или Forgejo под капотом.

🚀 Почему важны последние версии: Jujutsu быстро развивается — с новыми командами, доработками рабочего процесса и улучшениями производительности. Использование последней версии означает доступ к новейшим функциям и исправлениям взаимодействия с Git.

⚡ Ключевые возможности Jujutsu

🔄 Совместимость с Git

Работает напрямую с существующими репозиториями и удалёнными репозиториями Git, такими как GitHub и Forgejo.

↩️ Универсальная отмена

Каждая операция записывается и может быть отменена одной командой.

🧩 Полноценные конфликты

Конфликты фиксируются в коммитах и могут быть разрешены в любой момент, а не только во время слияний.

📄 Рабочая копия как коммит

Рабочая копия сама является коммитом, что убирает область подготовки и упрощает рабочие процессы.

🎯 Почему Jujutsu?

  • Более простая модель: Отсутствие области подготовки и последовательный, предсказуемый рабочий процесс
  • Безопасные эксперименты: Отмена любой операции, включая перебазирование и слияния
  • Совместимость с Git: Продолжайте использовать Git-хостинги и сотрудничать с пользователями Git
  • Мощное редактирование истории: Лёгкое перебазирование и переписывание коммитов

🆕 Основные возможности

  • Команда jj: Современный CLI поверх репозиториев Git
  • Журнал операций: Полная история операций репозитория с возможностью отмены
  • Обработка конфликтов: Конфликты хранятся в коммитах, разрешимы в любой момент
  • Движок Git: Взаимодействует с существующими удалёнными репозиториями Git

curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | sudo tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
sudo apt update

🧩 Или доверьте это extrepo. В Debian — bookworm, trixie, forky и sid — этот репозиторий зарегистрирован в extrepo, штатном инструменте Debian, который сам создаёт файл sources и устанавливает проверенный ключ подписи:

sudo apt install extrepo
sudo extrepo enable griffo
sudo apt update
apt install extrepo
extrepo enable griffo
apt update

Укажите griffo-free вместо griffo, чтобы подключить бесплатное навсегда зеркало. extrepo настраивает только файл sources и ключ — учётные данные подписки по-прежнему прописываются в /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu не поддерживается: extrepo публикует метаданные только для выпусков Debian, поэтому там используйте команды выше.

🎯 Примеры базового использования

# Show version
jj --version

# Initialize jj in an existing Git repo
jj git init --colocate

# Clone a Git repository
jj git clone https://github.com/user/repo.git

# Show the working-copy status
jj status

# Describe the current change
jj describe -m "My change"

# Undo the last operation
jj undo

❓ Часто задаваемые вопросы

Есть ли Jujutsu в официальных репозиториях Debian?

Нет, Jujutsu не упакован в официальных архивах Debian. Этот репозиторий сейчас единственный источник apt и предлагает Jujutsu 0.44.0.

Как установить последнюю версию Jujutsu в Debian?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install jujutsu. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Debian поддерживаются?

Debian 12 Bookworm, Debian 13 Trixie, Forky и Sid.
