Что такое Handy?

Handy — это бесплатное приложение с открытым исходным кодом для перевода речи в текст, которое работает полностью офлайн. Оно ждёт в фоне со значком в трее: вы нажимаете глобальное сочетание клавиш, произносите то, что хотите написать, и Handy расшифровывает речь на вашем же компьютере и вставляет текст в окно, на котором фокус: редактор, терминал, мессенджер, форму в браузере. Ничего не уходит в облачный сервис. Речевые модели (Whisper от OpenAI в нескольких размерах и Parakeet от NVIDIA, быстрый даже на обычном CPU) скачиваются один раз из самого приложения и дальше работают локально, а детектор голосовой активности отрезает тишину до того, как её услышит модель. Это приложение на Tauri, написанное на Rust автором CJ Pais, под лицензией MIT, и оно работает как на X11, так и на Wayland.

🚀 Почему важна последняя версия: Handy молод и быстро развивается: новые модели, улучшенные настройки точности и исправления для отдельных микрофонов, композиторов и раскладок клавиатуры приходят почти в каждом релизе. Ubuntu вообще не пакетирует Handy, так что без этого репозитория остаётся только скачивать каждый новый релиз вручную. Здесь это делает обычный apt upgrade, на каждой машине, где вы диктуете.

⚡ Ключевые возможности Handy

⌨️ Одно сочетание, любое приложение

Нажмите глобальное сочетание, говорите, нажмите ещё раз (или держите его в режиме push-to-talk и отпустите), и расшифровка вставится в активное окно. Особого поля для диктовки нет: всё, что принимает ввод с клавиатуры, принимает и Handy.

🔒 Полностью офлайн

Звук записывается, расшифровывается и удаляется на вашем компьютере. Ни аккаунта, ни API-ключа, ни подписки, и сеть не нужна, когда модель уже на диске.

🧠 Whisper и Parakeet

Выберите модель под своё железо: Whisper Small, Medium, Turbo или Large с ускорением на GPU, если он есть, или Parakeet, настроенный на быструю работу на CPU и сам определяющий язык.

🔇 Детектор голосовой активности

Silero VAD отфильтровывает тишину и фоновый шум до того, как звук попадёт в модель, поэтому паузы на размышление не превращаются в случайные слова.

🐧 X11 и Wayland

Работает на обоих дисплейных серверах и печатает результат в активное приложение через небольшие утилиты ввода, которые ставятся вместе с пакетом: xdotool на X11, wtype и wl-clipboard на Wayland и ydotool для GNOME.

🧩 Открытый и расширяемый

Лицензия MIT и проект, который удобно форкать: бэкенд на Rust и веб-интерфейс достаточно компактны, чтобы их прочитать, а настройки охватывают микрофон, сочетание клавиш, модель и язык.

🚀 Всегда впереди официальных архивов: Debian и Ubuntu замораживают версии пакетов при выпуске релиза — этот репозиторий публикует новые версии обычно в течение нескольких часов. Простое apt upgrade держит вас на последней версии.

🔧 Интеграции

Handy не нужна интеграция ни с чем: если приложение принимает набранный текст, оно принимает и диктовку. Важно окружение рабочего стола:

  • X11: xdotool входит в зависимости пакета, так что текст попадает в активное окно без дополнительных установок
  • Wayland: wtype и wl-clipboard тоже ставятся вместе с пакетом. Некоторые композиторы не передают глобальные сочетания приложениям; если у вас сочетание ничего не делает, загляните в настройки клавиатуры композитора
  • GNOME на Wayland: GNOME, окружение по умолчанию в Ubuntu 26.04, не принимает wtype, поэтому там Handy нужен ydotool с запущенным демоном. Пакет рекомендует ydotool в тех версиях, где он есть (в Debian trixie его нет); как запустить демон, описано в разделе о Linux в README Handy
  • dotool: Handy умеет работать и с ним, но его нет ни в одном архиве Debian или Ubuntu: установите его сами и добавьте своего пользователя в группу input
  • Звук: Handy записывает через PipeWire или PulseAudio, как любое настольное приложение; выберите устройство ввода в настройках, и микрофон гарнитуры даст точность лучше встроенного микрофона ноутбука
  • Железо: модели Whisper используют GPU, если он есть, а в больших размерах на CPU работают медленно; на ноутбуке без подходящего GPU быстрый выбор это Parakeet
  • Ваши инструменты: диктуйте сообщения коммитов в терминале вроде kitty или Ghostty, тексты в Zed, ответы в ZapZap или браузере и промпты для ИИ-ассистента, всё одним и тем же сочетанием

🚀 Почему стоит выбрать deb.griffo.io?

📊 Сравнение репозиториев:
  • Официальная Ubuntu: не пакетирует Handy, apt install handy на чистой системе завершается ошибкой
  • Загрузки из upstream: .deb или AppImage со страницы релизов GitHub, свежие в день скачивания, и скачивать их вручную придётся для каждого следующего релиза
  • Сборка из исходников: тулчейн Rust, тулчейн JavaScript для интерфейса, пакеты разработки WebKitGTK и аудио, нужные Tauri, и долгая сборка
  • deb.griffo.io: последняя версия с автоматическими обновлениями
  • ✅ Единственный источник для apt: Handy нет ни в архивах Debian, ни в архивах Ubuntu; этот репозиторий пакетирует официальный upstream-релиз
  • ✅ Одно имя везде: пакет называется handy, и команда тоже: sudo apt install handy, затем handy или ярлык в меню
  • ✅ Приватность по устройству: пакет содержит приложение, а не модель или сервис; ваш голос никогда не покидает машину, а сеть нужна только для скачивания выбранной модели
  • ✅ Полный пакет: официальная upstream-сборка для Linux (бинарник, встроенные библиотеки, ярлык рабочего стола, иконки) с объявленными зависимостями, чтобы она ставилась на любую поддерживаемую версию, утилиты ввода текста подтягиваются автоматически, а дополнена только пустая категория меню в ярлыке
  • ✅ Автоматические обновления: пакеты обновляются в течение нескольких часов после релиза upstream
  • ✅ Две архитектуры: amd64 на Ubuntu 22.04, 24.04, 25.10 и 26.04; arm64 только на 24.04, 25.10 и 26.04, потому что upstream собирает arm64 под glibc 2.39, а в 22.04 2.35; сборок для i386, armhf и riscv64 нет
  • ✅ Много дистрибутивов: работает на Ubuntu 22.04, 24.04, 25.10 и 26.04
  • ✅ Простое обслуживание: обновления обычными командами apt

❓ Часто задаваемые вопросы

Есть ли Handy в официальных репозиториях Ubuntu?

Нет, Handy не упакован в официальных архивах Ubuntu. Этот репозиторий сейчас единственный источник apt и предлагает Handy 0.9.8.

Как установить последнюю версию Handy в Ubuntu?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install handy. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Ubuntu поддерживаются?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing и 26.04 Resolute.
