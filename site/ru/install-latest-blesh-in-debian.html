Что такое ble.sh?

ble.sh, Bash Line Editor, — это редактор командной строки, написанный на чистом Bash, который заменяет GNU Readline в интерактивных сеансах Bash. Вы сохраняете Bash, свой ~/.bashrc, алиасы и скрипты и получаете то, ради чего обычно меняют оболочку: подсветку синтаксиса прямо при вводе, автоподсказки из истории в стиле fish, полноценный режим vim наряду с привязками emacs, автодополнение с меню и описаниями, аббревиатуры и интеграцию с bash-completion и fzf. Автор — Koichi Murase, лицензия BSD-3-Clause. Запускать нечего: пакет устанавливает скрипт в /usr/share/blesh/ble.sh, а включают его две строки в вашем ~/.bashrc.

🚀 Почему важна последняя версия: ble.sh непрерывно развивается в ветке master, а помеченные стабильные релизы выходят редко и с большими перерывами, поэтому инструкции по установке от авторов указывают на ночную сборку или git checkout. Debian и Ubuntu упаковывают снимок, который заморожен на весь срок жизни релиза (в стабильном Debian его нет вовсе). Этот репозиторий следует ночным снимкам проекта, так что исправления для новых версий Bash, терминалов и интеграций автодополнения приходят к вам через apt upgrade.

⚡ Ключевые возможности ble.sh

🎨 Подсветка синтаксиса

Команды, ключевые слова, строки, переменные, перенаправления и имена файлов подсвечиваются при вводе, а неизвестная команда или синтаксическая ошибка видна ещё до нажатия Enter.

💡 Автоподсказки

Подсказки в стиле fish из истории и автодополнения появляются серым после курсора. Примите всю подсказку стрелкой вправо или C-f, либо по одному слову через M-f.

⌨️ Режимы vim и emacs

По умолчанию привязки emacs, а с set -o vi полноценный режим vi/vim: нормальный режим, режим вставки и визуальный, текстовые объекты, регистры и необязательная строка состояния в стиле vim-airline.

📋 Автодополнение с меню

Tab открывает меню вариантов, по которому можно перемещаться стрелками, с описаниями, где они есть, и неоднозначным (нечётким) сопоставлением.

✂️ Аббревиатуры

ble-sabbrev задаёт аббревиатуры, которые раскрываются при вводе, как аббревиатуры fish или глобальные алиасы zsh: L превращается в | less.

🐚 Чистый Bash, без бинарника

Нечего компилировать и нет ничего, зависящего от архитектуры: ble.sh — это скрипт Bash, который работает везде, где есть Bash 3.0 или новее, и не вмешивается в неинтерактивные оболочки и скрипты.

🚀 Всегда впереди официальных архивов: Debian и Ubuntu замораживают версии пакетов при выпуске релиза — этот репозиторий публикует новые версии обычно в течение нескольких часов. Простое apt upgrade держит вас на последней версии.

Как работает бесплатное зеркало →

🧩 О варианте extrepo. extrepo — штатный инструмент Debian для внешних репозиториев: он создаёт файл sources и устанавливает ключ подписи, предварительно сверив его с подписанными метаданными. Этот репозиторий зарегистрирован в нём как griffo, а бесплатное навсегда зеркало — как griffo-free, поэтому в Debian (bookworm, trixie, forky и sid) команды выше и есть вся настройка.

extrepo настраивает только файл sources и ключ — учётные данные подписки по-прежнему прописываются в /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu не поддерживается, так как extrepo публикует метаданные только для выпусков Debian: там используйте команды с sudo или от root.

Шаг 3: Включить ble.sh в ~/.bashrc

# У ble.sh нет отдельной команды: Bash загружает его из ~/.bashrc.
# Эту строку поставьте ближе к НАЧАЛУ ~/.bashrc:
[[ $- == *i* ]] && source /usr/share/blesh/ble.sh --noattach

# ...остальная часть ~/.bashrc остаётся как есть...

# А эту строку — в самый КОНЕЦ ~/.bashrc:
[[ ${BLE_VERSION-} ]] && ble-attach

# Откройте новый терминал, затем:
# Проверить установку
echo $BLE_VERSION

🎯 Базовые примеры использования

Повседневное использование:

# Проверить, что ble.sh активен в этой оболочке
echo $BLE_VERSION

# Перезагрузить ble.sh после изменения настроек
ble-reload

# Обновления приходят через apt; ble-update отсылает туда же
sudo apt update && sudo apt upgrade
# Проверить, что ble.sh активен в этой оболочке
echo $BLE_VERSION

# Перезагрузить ble.sh после изменения настроек
ble-reload

# Обновления приходят через apt; ble-update отсылает туда же
apt update && apt upgrade

Настройки в ~/.blerc:

# ble.sh читает настройки из ~/.blerc (или ~/.config/blesh/init.sh)
# Привязки vim вместо emacs
set -o vi

# Ждать 300 мс перед показом автоподсказки
bleopt complete_auto_delay=300

# Полностью отключить автоподсказки
bleopt complete_auto_complete=

# Изменить цвет текста подсказки
ble-face auto_complete='fg=242'

Аббревиатуры, привязки клавиш и интеграции:

# Раскрывать «L» в «| less» при вводе
ble-sabbrev L='| less'

# Ctrl+C сбрасывает текущую строку
ble-bind -f 'C-c' discard-line

# Автодополнение и привязки fzf, адаптированные под ble.sh
ble-import -d integration/fzf-completion
ble-import -d integration/fzf-key-bindings

# Строка состояния в стиле vim-airline (нужен ble.sh-airline-themes)
ble-import vim-airline
bleopt vim_airline_theme=dark

🔧 Интеграция с другими инструментами

ble.sh встраивается под вашу настройку Bash, а не заменяет её:

  • bash-completion: дополнения из пакета bash-completion подхватываются автоматически и показываются в меню
  • fzf: ble-import загружает версии автодополнения и привязок fzf, адаптированные под ble.sh
  • Atuin: интеграция Atuin с Bash поддерживает ble.sh и получает через него надёжные хуки preexec для записи истории
  • Starship / Oh My Posh: созданные ими приглашения продолжают работать без изменений
  • Файл настроек: ~/.blerc хранит ваши настройки bleopt, ble-face и ble-bind отдельно от ~/.bashrc

🚀 Почему стоит выбрать deb.griffo.io?

📊 Сравнение репозиториев:
  • Официальный Debian: только в testing и unstable; стабильные релизы (bookworm и trixie) его не содержат
  • git clone + make: свежая версия, но собирается и ставится вручную в ~/.local, а обновлять её через ble-update приходится самому
  • deb.griffo.io: последняя версия с автоматическими обновлениями
  • ✅ Свежие снимки: ночные снимки проекта с исправлениями для новых версий Bash и терминалов
  • ✅ Без ручной настройки: ни git clone, ни make, ни копии ble.sh в домашнем каталоге, которую нужно обновлять
  • ✅ Автоматические обновления: пакеты обновляются в течение часов после выхода версии
  • ✅ Полный пакет: полное дерево ble.sh в /usr/share/blesh, документация и необязательный пакет ble.sh-airline-themes
  • ✅ Любая архитектура: пакет собран как Architecture: all, поэтому amd64, arm64, armhf, riscv64 и остальные ставят один и тот же пакет
  • ✅ Много дистрибутивов: работает на Bookworm, Trixie, Forky и Sid
  • ✅ Простое обслуживание: обновления обычными командами apt

❓ Часто задаваемые вопросы

Есть ли ble.sh в официальных репозиториях Debian?

Нет, ble.sh не упакован в официальных архивах Debian. Этот репозиторий сейчас единственный источник apt и предлагает ble.sh 0.4.0.

Как установить последнюю версию ble.sh в Debian?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install ble.sh. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Debian поддерживаются?

Debian 12 Bookworm, Debian 13 Trixie, Forky и Sid.
