Что такое rgrc?

rgrc, Rusty Generic Colouriser, — быстрая переработка классического grc на Rust. Поставьте его перед командой, и он раскрасит её вывод: ping, df, ls, ps, docker, journalctl, kubectl, dig, mount, ip, netstat и всего около 97 команд, каждая со своим конфигурационным файлом в формате grc/grcat. Конфигурации встроены в бинарник, поэтому rgrc работает сразу после установки, а ещё он раскрашивает конвейеры (df -h | rgrc -c df). Псевдонимы оболочки, автоматически раскрашивающие привычные команды, — это одна строка в ~/.bashrc или ~/.zshrc. И пакет, и команда называются rgrc.

🚀 Почему важна последняя версия: rgrc — молодой и быстро развивающийся проект: каждый выпуск приносит новые конфигурации команд, параметры и исправления. В архивах Debian и Ubuntu его нет совсем (в Debian есть только оригинальный grc на Python), а upstream публикует бинарники и .deb в релизах GitHub, но не apt-репозиторий, поэтому установленная вручную копия никогда не обновится сама.

⚡ Ключевые возможности rgrc

🌈 Около 97 команд

Системные, сетевые, контейнерные утилиты и журналы из коробки: df, free, ps, mount, ping, dig, ip, ss, docker, kubectl, journalctl и многие другие.

⚡ Быстрый нативный бинарник

Переработка grc с Python на Rust: не нужно запускать интерпретатор ради каждой раскрашенной команды. Пакет — это один статически слинкованный бинарник.

📦 Встроенные конфигурации

Конфигурации команд встроены в бинарник и дополнительно установлены в /usr/share/rgrc, а соответствие команд задаётся в /etc/rgrc.conf.

🔀 Работает с конвейерами

Раскрашивайте уже готовый вывод: df -h | rgrc -c df выбирает конфигурацию по имени и раскрашивает всё, что приходит на стандартный ввод.

🐚 Псевдонимы оболочки

eval "$(rgrc --aliases)" — и ping, df или docker выводят цветной текст без набора rgrc. Любую команду можно исключить через --except.

🛠️ Правила в стиле grc

Правила записываются в привычном формате grc/grcat строками regexp= и colours=, а собственные кладутся в ~/.config/rgrc/.

🚀 Всегда впереди официальных архивов: Debian и Ubuntu замораживают версии пакетов при выпуске релиза — этот репозиторий публикует новые версии обычно в течение нескольких часов. Простое apt upgrade держит вас на последней версии.

Как работает бесплатное зеркало →

🧩 О варианте extrepo. extrepo — штатный инструмент Debian для внешних репозиториев: он создаёт файл sources и устанавливает ключ подписи, предварительно сверив его с подписанными метаданными. Этот репозиторий зарегистрирован в нём как griffo, а бесплатное навсегда зеркало — как griffo-free, поэтому в Debian (bookworm, trixie, forky и sid) команды выше и есть вся настройка.

extrepo настраивает только файл sources и ключ — учётные данные подписки по-прежнему прописываются в /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu не поддерживается, так как extrepo публикует метаданные только для выпусков Debian: там используйте команды с sudo или от root.

🎯 Базовые примеры использования

Раскрасить одну команду:

# Поставьте rgrc перед командой, которую нужно раскрасить
rgrc ping -c 4 debian.org
rgrc df -h
rgrc docker ps
rgrc journalctl -n 50

Раскрасить вывод конвейера:

# Выбрать конфигурацию по имени и раскрасить стандартный ввод
df -h | rgrc -c df
mount | rgrc -c mount

Выбор псевдонимов и цветов:

# Псевдонимы для всех поддерживаемых команд, кроме ls и ps
eval "$(rgrc --aliases --except ls,ps)"

# Принудительно включить цвета, когда вывод идёт в пейджер
rgrc --color on ping -c 4 debian.org | less -R

Настройки и собственные правила:

# Конфигурации команд и основное соответствие
ls /usr/share/rgrc/
cat /etc/rgrc.conf

# Собственные правила кладутся сюда, строками regexp= и colours= в стиле grc
mkdir -p ~/.config/rgrc

# Полный справочник по параметрам
man rgrc

🔧 Интеграция с другими инструментами

rgrc встраивается в привычную работу в терминале:

  • Оболочки: автодополнение для bash, zsh и fish устанавливается вместе с пакетом, а псевдонимы работают в любой оболочке, которая умеет загрузить их через eval
  • grc: grc на Python из Debian можно оставить: команды называются grc и rgrc, а rgrc читает тот же формат правил grc/grcat
  • Контейнеры: вывод docker ps, docker images и kubectl get pods читается с одного взгляда
  • Журналы: вывод journalctl, в котором ошибки и предупреждения сразу бросаются в глаза
  • Сетевая диагностика: ping, traceroute, dig, ss, netstat и ip с цветными адресами, задержками и состояниями

🚀 Почему стоит выбрать deb.griffo.io?

📊 Сравнение репозиториев:
  • Официальный Debian: нет пакета: rgrc нет ни в одном выпуске Debian, от Bookworm до Sid; в Debian есть только оригинальный grc на Python
  • Бинарник от upstream: свежий в день загрузки, но upstream публикует бинарники и .deb в релизах GitHub без apt-репозитория, поэтому apt upgrade никогда не видит новую версию, и каждый релиз — это ещё одна ручная загрузка
  • Сборка через cargo install: нужны Rust-тулчейн и пересборка при каждом обновлении, а man-страницы, автодополнения и конфигурационных файлов не будет
  • deb.griffo.io: последняя версия с автоматическими обновлениями
  • ✅ Без зависимостей времени выполнения: rgrc — один статически слинкованный бинарник на Rust без каких-либо зависимостей, и он устанавливается рядом с grc на Python из Debian
  • ✅ Обновления через apt для релизов upstream: upstream выпускает бинарники и .deb, но не репозиторий; здесь каждый релиз попадает в apt-репозиторий с подписью GPG, со сборкой для каждого выпуска Debian и Ubuntu
  • ✅ Автоматические обновления: пакеты обновляются в течение нескольких часов после релиза upstream
  • ✅ Полный пакет: /usr/bin/rgrc, man-страница rgrc(1), /etc/rgrc.conf, 97 конфигураций команд в /usr/share/rgrc и автодополнение для bash, zsh и fish
  • ✅ Четыре архитектуры: amd64, arm64, armhf и i386 — ноутбуки, серверы, платы Raspberry Pi и старые 32-битные машины получают один и тот же rgrc
  • ✅ Много дистрибутивов: работает на Bookworm, Trixie, Forky и Sid
  • ✅ Простое обслуживание: обновления обычными командами apt

❓ Часто задаваемые вопросы

Есть ли rgrc в официальных репозиториях Debian?

Нет, rgrc не упакован в официальных архивах Debian. Этот репозиторий сейчас единственный источник apt и предлагает rgrc 0.6.35.

Как установить последнюю версию rgrc в Debian?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install rgrc. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Debian поддерживаются?

Debian 12 Bookworm, Debian 13 Trixie, Forky и Sid.
