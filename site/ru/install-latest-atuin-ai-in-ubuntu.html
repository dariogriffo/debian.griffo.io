Что такое Atuin AI?

Atuin AI — это агент оболочки для Atuin. Atuin поставлял его встроенным до версии 18.24 и убрал в 18.25; теперь он живёт как отдельный бинарный файл, atuin-ai. Нажмите ? в пустой строке приглашения, и прямо в терминале откроется чат: опишите, что хотите сделать, и он предложит команду, или задайте вопрос, и он ответит. С вашего разрешения он также может искать по истории Atuin, читать и редактировать файлы и запускать команды. Он работает с сервером Atuin AI, который вы размещаете сами (upstream публикует его как Docker-образ), а этот сервер может стоять перед любой OpenAI-совместимой конечной точкой: Ollama, vLLM или облачным API. Клиент написан на Rust командой Atuin и распространяется под лицензией MIT.

🚀 Почему важна последняя версия: Atuin AI молод и быстро развивается, а upstream вообще не выпускает релизов, только коммиты в main. Этот репозиторий каждую пятницу собирает снимок, если main изменился, с версией вида <версия клиента>.<ГГГГММДД> (например, 0.1.0.20261127), так что apt upgrade приносит изменения недели без инструментария Rust. Ubuntu не пакетирует atuin-ai вовсе.

⚡ Ключевые возможности Atuin AI

❓ Одна клавиша

Нажмите ? в пустой строке приглашения, чтобы открыть агента. В любом другом месте ? как обычно печатает вопросительный знак, поэтому он не мешает команде, которую вы набираете.

💡 Подсказки команд

Опишите задачу простыми словами («найди файлы больше 1 ГБ, изменённые на этой неделе») и получите команду, которую можно прочитать, поправить и выполнить, вместо того чтобы рыться в man-страницах.

📜 Знает вашу историю

С разрешения агент ищет по вашей истории Atuin, поэтому может найти команду, запущенную в прошлом месяце, или опереться на то, как вы обычно делаете что-то на этой машине.

🛠️ Файлы и команды

Он может читать и редактировать файлы и запускать команды за вас, но сначала спрашивает. Что трогает вашу систему, решаете вы.

🏠 Ваш собственный сервер

Клиент общается с сервером Atuin AI, который запускаете вы сами, так что ваши запросы и история идут туда, куда решите вы. Upstream распространяет сервер как ghcr.io/atuinsh/atuin-ai-server.

🔌 Любая OpenAI-совместимая модель

Сервер работает с любой OpenAI-совместимой конечной точкой: локальной моделью через Ollama или vLLM либо облачным API. Модель меняется на сервере, клиент трогать не нужно.

🚀 Всегда впереди официальных архивов: Debian и Ubuntu замораживают версии пакетов при выпуске релиза — этот репозиторий публикует новые версии обычно в течение нескольких часов. Простое apt upgrade держит вас на последней версии.

Шаг 3: Первый запуск

# Указать клиенту ваш сервер Atuin AI
# (пример с комментариями: /usr/share/doc/atuin-ai/examples/ai.example.toml)
mkdir -p ~/.atuin
cat > ~/.atuin/ai.toml <<'EOF'
endpoint = "http://localhost:8080"
# api_token = "..."   # только если сервер задаёт AUTH_TOKEN
EOF

# Назначить ? в оболочке, после строки init самого Atuin
echo 'eval "$(atuin-ai init bash)"' >> ~/.bashrc

# Открыть новую оболочку и нажать ? в пустой строке приглашения
exec bash

🎯 Базовые примеры использования

Настройка оболочки:

# bash, в ~/.bashrc
eval "$(atuin init bash)"
eval "$(atuin-ai init bash)"

# zsh, в ~/.zshrc
eval "$(atuin init zsh)"
eval "$(atuin-ai init zsh)"

# fish, в ~/.config/fish/config.fish
atuin init fish | source
atuin-ai init fish | source

Запуск сервера:

# В пакете только клиент; сервер — это Docker-образ upstream
docker pull ghcr.io/atuinsh/atuin-ai-server

# Настройте его на вашу OpenAI-совместимую точку (Ollama, vLLM, облачный API)
# по руководству Self-Hosting от upstream, затем проверьте, что он отвечает
curl http://localhost:8080/api/cli/models

Каждый день:

# В пустой строке приглашения нажмите ? и спросите, например:
#   какой процесс слушает порт 5432?
#   сожми все .log-файлы в этом каталоге старше 7 дней
#   какой командой rsync я делал резервные копии?

# Всё, что умеет клиент

# Код оболочки, который он подключает

🔧 Интеграции

Atuin AI стоит между вашей оболочкой, историей Atuin и выбранной вами моделью:

  • Atuin: жёсткая зависимость, устанавливается вместе с ним из deb.griffo.io; агент ищет в той же базе истории, что и atuin search, и только когда вы разрешаете
  • Atuin 18.25 и новее: в 18.25 встроенного агента убрали, так что этот пакет позволяет сохранить чат по ? на актуальном Atuin
  • bash, zsh и fish: atuin-ai init bash, zsh или fish выводит привязку клавиши; загружайте её после init самого Atuin, чтобы обе привязки работали вместе
  • Сервер Atuin AI: ghcr.io/atuinsh/atuin-ai-server, запускается в Docker или Podman на той же машине или где угодно, куда дотянется клиент; задайте там AUTH_TOKEN, а в ~/.atuin/ai.toml задайте api_token, чтобы закрыть доступ
  • Ollama и vLLM: все запросы остаются на вашем собственном железе, если направить сервер на локальную OpenAI-совместимую точку
  • Облачные API: любой провайдер с OpenAI API работает так же, настраивается на сервере, а не в клиенте

🚀 Почему стоит выбрать deb.griffo.io?

📊 Сравнение репозиториев:
  • Официальная Ubuntu: не пакетирует Atuin AI, apt install atuin-ai на чистой системе завершается ошибкой
  • Загрузки upstream: их нет: upstream не публикует для клиента ни релизов, ни тегов, ни бинарных файлов
  • cargo build из исходников: клонирование, инструментарий Rust и несколько минут компиляции, вручную заново каждый раз, когда меняется main
  • deb.griffo.io: последняя версия с автоматическими обновлениями
  • ✅ Собран из main upstream: скомпилирован из исходников upstream с его собственным Cargo.lock; в примечаниях к выпуску и в /usr/share/doc/atuin-ai/changelog.Debian указан точный коммит upstream для каждого снимка
  • ✅ Подтягивает Atuin: зависит от atuin, который тоже есть в deb.griffo.io, так что один apt install atuin-ai ставит оба
  • ✅ Только клиент: пакет устанавливает /usr/bin/atuin-ai и пример ai.toml; сервер остаётся в Docker, где его распространяет upstream
  • ✅ Автоматические обновления: каждый новый снимок приходит обычным apt upgrade
  • ✅ Две архитектуры: amd64 и arm64 на Ubuntu 22.04, 24.04, 25.10, 26.04 и 26.10, те же две, что и у пакета Atuin, от которого он зависит; сборок для i386 и armhf нет
  • ✅ Много дистрибутивов: работает на Ubuntu 22.04, 24.04, 25.10, 26.04 и 26.10
  • ✅ Простое обслуживание: обновления обычными командами apt

❓ Часто задаваемые вопросы

Есть ли Atuin AI в официальных репозиториях Ubuntu?

Нет, Atuin AI не упакован в официальных архивах Ubuntu. Этот репозиторий сейчас единственный источник apt и предлагает Atuin AI 0.1.0.20261125.

Как установить последнюю версию Atuin AI в Ubuntu?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install atuin-ai. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Ubuntu поддерживаются?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing, 26.04 Resolute и 26.10 Stonking.
