Что такое difftastic?

difftastic — команда называется difft — это структурный diff. Вместо построчного сравнения он разбирает оба файла с помощью tree-sitter, строит синтаксическое дерево для каждой стороны и показывает, какие именно части синтаксиса изменились. Переформатирование блока, перенос списка аргументов или сдвинутая скобка перестают быть изменением, а переименованная переменная среди переформатированного кода сразу бросается в глаза.

🚀 Почему важна последняя версия: difftastic понимает код через грамматики tree-sitter, а они поставляются вместе с каждым выпуском. Годовалая сборка разбирает языки прошлого года: новый синтаксис превращается в ошибки разбора, а файл со слишком многими ошибками молча откатывается к обычному построчному diff — ровно то, от чего вы и ставили difftastic. Каждый выпуск также улучшает алгоритм и расход памяти на больших файлах.

⚡ Ключевые возможности difftastic

🌳 Diff с учётом синтаксиса

Обе стороны разбираются в синтаксические деревья и сравниваются как структура: шум форматирования исчезает, реальные изменения видны.

🧩 Более 30 языков

Rust, Python, TypeScript, Go, C, C++, Java, Ruby, YAML, JSON, HTML, CSS, Markdown и многие другие — difft --list-languages печатает полный список с расширениями.

🪟 Рядом или в одну колонку

--display выбирает side-by-side, side-by-side-show-both, inline или машиночитаемый JSON.

🔗 Прямая замена в Git

Работает как внешняя команда diff для git, а также для Mercurial, Jujutsu и Fossil.

🚦 Честный откат

Неизвестное расширение, огромный файл или слишком много ошибок разбора — вместо отказа будет построчный diff с подсветкой по словам.

🗂️ Каталоги и конфликты

Сравнивайте два каталога одной командой или передайте файл с маркерами конфликта слияния и читайте конфликт как diff.

🚀 Всегда впереди официальных архивов: Debian и Ubuntu замораживают версии пакетов при выпуске релиза — этот репозиторий публикует новые версии обычно в течение нескольких часов. Простое apt upgrade держит вас на последней версии.

Как работает бесплатное зеркало →

🧩 О варианте extrepo. extrepo — штатный инструмент Debian для внешних репозиториев: он создаёт файл sources и устанавливает ключ подписи, предварительно сверив его с подписанными метаданными. Этот репозиторий зарегистрирован в нём как griffo, а бесплатное навсегда зеркало — как griffo-free, поэтому в Debian (bookworm, trixie, forky и sid) команды выше и есть вся настройка.

extrepo настраивает только файл sources и ключ — учётные данные подписки по-прежнему прописываются в /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu не поддерживается, так как extrepo публикует метаданные только для выпусков Debian: там используйте команды с sudo или от root.

🎯 Базовые примеры использования

Сравнение файлов и каталогов:

# Два файла, рядом
difft before.rs after.rs

# Одна колонка, ближе к традиционному diff
difft --display inline before.ts after.ts

# Два каталога, пропуская неизменившиеся файлы
difft old/ new/ --skip-unchanged --sort-paths

# Какие языки понимает эта сборка?
difft --list-languages

В роли git diff:

# Разово: difftastic только для этого diff
GIT_EXTERNAL_DIFF=difft git diff

# Структурные diff по всей истории
GIT_EXTERNAL_DIFF=difft git log -p --ext-diff

# Зарегистрировать как difftool
git config --global difftool.difftastic.cmd 'difft "$LOCAL" "$REMOTE"'
git difftool --tool difftastic

# Псевдоним git для структурного лога
git config --global alias.dlog '!GIT_EXTERNAL_DIFF=difft git log -p --ext-diff'

Настройка вывода:

# Игнорировать изменения только в комментариях
difft --ignore-comments a.go b.go

# Больше контекста и табуляция в два пробела
difft --context 5 --tab-width 2 a.py b.py

# Для скриптов: было ли синтаксическое изменение?
difft --check-only --exit-code a.json b.json

# Значения по умолчанию для каждого запуска — из окружения
export DFT_DISPLAY=inline DFT_BACKGROUND=light

🔧 Интеграция с другими инструментами

difftastic встраивается в инструменты, которые и так показывают вам diff:

  • git: GIT_EXTERNAL_DIFF, diff.external или запись difftool — с --ext-diff это работает и для git log -p, и для git show
  • Jujutsu: задайте его командой diff в jj и получите структурные diff в Git-совместимом процессе
  • Mercurial и Fossil: оба принимают внешнюю команду diff, так что один бинарник обслуживает все ваши репозитории
  • Переменные окружения: DFT_DISPLAY, DFT_BACKGROUND, DFT_WIDTH и прочие задают ваши значения по умолчанию
  • CI и скрипты: --check-only с --exit-code отвечает «изменился ли синтаксис?» без вывода diff, а --display json сделан для разбора

🚀 Почему стоит выбрать deb.griffo.io?

📊 Сравнение репозиториев:
  • Официальный Debian: вообще не содержит difftastic — на стандартной системе устанавливать нечего
  • cargo install difftastic: свежая версия, но это долгая сборка с множеством грамматик tree-sitter, вне apt и без man-страницы
  • Архив upstream: официальный бинарник, который придётся скачивать вручную к каждому выпуску
  • deb.griffo.io: последняя версия с автоматическими обновлениями
  • ✅ Актуальные грамматики: самый свежий выпуск с грамматиками tree-sitter, которые понимают версии языков, на которых вы пишете сейчас
  • ✅ Единственный источник apt: difftastic нет ни в архивах Debian, ни в архивах Ubuntu; этот репозиторий пакует официальную сборку upstream
  • ✅ Автоматические обновления: пакеты обновляются в течение нескольких часов после релиза upstream
  • ✅ Полный пакет: бинарник upstream как /usr/bin/difft плюс man-страница difft.1
  • ✅ Две архитектуры: amd64 (статическая сборка musl без зависимостей) и arm64
  • ✅ Много дистрибутивов: работает на Bookworm, Trixie, Forky и Sid
  • ✅ Простое обслуживание: обновления обычными командами apt

❓ Часто задаваемые вопросы

Есть ли difftastic в официальных репозиториях Debian?

Нет, difftastic не упакован в официальных архивах Debian. Этот репозиторий сейчас единственный источник apt и предлагает difftastic 0.70.0.

Как установить последнюю версию difftastic в Debian?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install difftastic. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Debian поддерживаются?

Debian 12 Bookworm, Debian 13 Trixie, Forky и Sid.
