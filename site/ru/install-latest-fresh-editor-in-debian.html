Что такое fresh-editor?

fresh-editor — пакет с Fresh, терминальной IDE и текстовым редактором от Noam Lewis, написанным на Rust. Он приносит в терминал то, чего ждёшь от IDE: поддержку языковых серверов, подсветку синтаксиса, несколько курсоров и систему плагинов на TypeScript — и при этом остаётся простым в освоении. Огромные файлы открываются без ожидания, сессию редактирования держит фоновый демон, к которому можно снова подключиться командой fresh -a, а с fresh --web редактор работает даже в браузере. Пакет называется fresh-editor, а команда, которую вы набираете, — fresh.

🚀 Почему важна последняя версия: Fresh — молодой и активно развивающийся проект: каждый выпуск приносит работу над языковыми серверами, API плагинов и скоростью. В архивах Debian и Ubuntu его нет вовсе, а upstream публикует отдельные .deb-файлы в релизах GitHub, но без apt-репозитория, поэтому установленный вручную .deb никогда не обновляется сам. Плагины, написанные под сегодняшний TypeScript API, ждут сегодняшний редактор.

⚡ Ключевые возможности fresh-editor

🧠 Языковые серверы

Fresh говорит на Language Server Protocol: диагностика, автодополнение, переход к определению и подсказки приходят от тех же серверов, что используют другие редакторы, — rust-analyzer, gopls или clangd.

🎨 Подсветка синтаксиса

Код подсвечен сразу при открытии, в том терминале, которым вы и так пользуетесь, без отдельного шага настройки перед первым файлом.

✏️ Несколько курсоров

Поставьте курсоры сразу в несколько мест и печатайте во всех одновременно — быстрый способ переименовать переменную в блоке или переделать столбец похожих строк.

🧩 Плагины на TypeScript

В Fresh встроена среда выполнения TypeScript для плагинов: расширить редактор — значит написать TypeScript под его API плагинов, а не учить собственный язык конфигурации.

🔌 Сессии, которые выживают

Демон сессий сохраняет редактор и открытые файлы, когда закрывается терминал или обрывается SSH-соединение. fresh -a подключается к нему снова.

🌐 Терминал или браузер

fresh --web отдаёт тот же редактор в веб-браузер — удобно, когда до машины проще добраться через браузер, чем через терминал.

🚀 Всегда впереди официальных архивов: Debian и Ubuntu замораживают версии пакетов при выпуске релиза — этот репозиторий публикует новые версии обычно в течение нескольких часов. Простое apt upgrade держит вас на последней версии.

Шаг 1: Добавить репозиторий

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | sudo tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
sudo apt update

🆓 Есть вечно бесплатное зеркало. deb-free.griffo.io раздаёт пакеты бесплатно навсегда — без аккаунта, без подписки, не более 2 месяцев позади upstream, исправления безопасности сразу. Сейчас там cliamp, Ghostty, lazydocker, Oh My Posh, Uncloud и Zed; fresh-editor среди них нет, поэтому репозиторий выше — единственный способ установить его сегодня; попросите, и его можно добавить.

Как работает бесплатное зеркало →

🧩 О варианте extrepo. extrepo — штатный инструмент Debian для внешних репозиториев: он создаёт файл sources и устанавливает ключ подписи, предварительно сверив его с подписанными метаданными. Этот репозиторий зарегистрирован в нём как griffo, а бесплатное навсегда зеркало — как griffo-free, поэтому в Debian (bookworm, trixie, forky и sid) команды выше и есть вся настройка.

extrepo настраивает только файл sources и ключ — учётные данные подписки по-прежнему прописываются в /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu не поддерживается, так как extrepo публикует метаданные только для выпусков Debian: там используйте команды с sudo или от root.

🔧 Интеграция с другими инструментами

Fresh встраивается в привычную работу в терминале:

  • Git: git config --global core.editor fresh открывает сообщения коммитов и интерактивный rebase в Fresh
  • Shell: export EDITOR=fresh в ~/.bashrc — и crontab -e, sudoedit и им подобные используют его
  • Компиляторы и grep: их вывод file:line:col открывается ровно в указанном месте
  • Рабочий стол: пакет ставит desktop-файл и иконки, так что Fresh появляется в меню приложений
  • SSH и tmux: демон сессий держит вашу работу открытой на удалённой стороне, а fresh -a подхватывает её снова

🚀 Почему стоит выбрать deb.griffo.io?

📊 Сравнение репозиториев:
  • Официальный Debian: нет пакета: Fresh нет ни в одном выпуске Debian, от Bookworm до Sid
  • .deb от upstream: свежий в день загрузки, но upstream публикует отдельные .deb-файлы в релизах GitHub без apt-репозитория, поэтому apt upgrade никогда не видит новую версию, а каждый релиз — очередная ручная загрузка
  • Сборка через cargo: нужны Rust-тулчейн и полная компиляция при каждом обновлении, а desktop-файла, иконок и man-страницы не будет
  • deb.griffo.io: последняя версия с автоматическими обновлениями
  • ✅ Пакет fresh-editor, команда fresh: sudo apt install fresh-editor, затем запускайте fresh; fresh-editor — это имя пакета у самого upstream, его используют .deb, AUR, Homebrew и winget, поэтому машина с установленным .deb от upstream обновится на месте начиная со следующего релиза
  • ✅ Обновления через apt для релизов upstream: upstream выпускает .deb-файлы, но не репозиторий; здесь каждый релиз попадает в apt-репозиторий с GPG-подписью, со сборкой для каждого выпуска Debian и Ubuntu
  • ✅ Автоматические обновления: пакеты обновляются в течение нескольких часов после релиза upstream
  • ✅ Полный пакет: бинарник fresh, desktop-файл и иконки для меню приложений и man-страница fresh(1)
  • ✅ Две архитектуры: amd64 и arm64 — ноутбуки, серверы и 64-битные ARM-платы получают один и тот же Fresh
  • ✅ Много дистрибутивов: работает на Bookworm, Trixie, Forky и Sid
  • ✅ Простое обслуживание: обновления обычными командами apt

❓ Часто задаваемые вопросы

Есть ли fresh-editor в официальных репозиториях Debian?

Нет, fresh-editor не упакован в официальных архивах Debian. Этот репозиторий сейчас единственный источник apt и предлагает fresh-editor 0.5.2.

Как установить последнюю версию fresh-editor в Debian?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install fresh-editor. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Debian поддерживаются?

Debian 12 Bookworm, Debian 13 Trixie, Forky и Sid.
