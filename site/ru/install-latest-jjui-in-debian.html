Что такое jjui?

jjui — это терминальный интерфейс для Jujutsu, Git-совместимой системы контроля версий, которой управляют командой jj. Запустите его внутри репозитория jj, и он покажет граф ревизий, а затем позволит работать с ним напрямую: менять revset с автодополнением, чтобы выбрать, что показывать, делать rebase отдельной ревизии или целой ветки, выполнять squash, split и abandon ревизий, перемещать закладки, открывать ревизию, чтобы увидеть её файлы и диффы и восстанавливать файлы по одному, смотреть вывод jj show и jj diff рядом с графом, выполнять push и fetch через меню Git, а также просматривать журнал операций и восстанавливать состояние из него. Всё работает с клавиатуры или мышью. jjui написан на Go автором Ibrahim Dursun и распространяется под лицензией MIT.

🚀 Почему важна последняя версия: jjui развивается вместе с Jujutsu: выпуски jj меняют команды и вывод, и jjui следует за ними, добавляя в большинстве релизов новые операции, улучшения автодополнения и исправления. Debian вообще не пакует jjui, поэтому без этого репозитория единственный способ оставаться в актуальном состоянии — скачивать каждый новый релиз вручную. Здесь обычный apt upgrade обновляет jjui вместе с jj, от которого он зависит.

⚡ Ключевые возможности jjui

🌳 Живой граф ревизий

jjui открывается на том же графе, что печатает jj log, но по нему можно перемещаться, выбирать ревизии и выполнять над ними действия, а граф перерисовывается после каждого изменения.

🔎 Revset с автодополнением

Редактируйте revset в верхней части экрана, чтобы выбрать, какие ревизии показывать; функции и псевдонимы дополняются по мере ввода, так что язык revset не нужно держать в голове.

✂️ Rebase, squash, split, abandon

Переносите одну ревизию или целую ветку на другую, вливайте ревизию в родителя через squash, разбивайте её на две, отбрасывайте её или перемещайте закладку, всё прямо из графа, и сразу видьте результат.

📄 Файлы, диффы и предпросмотр

Откройте ревизию, чтобы увидеть список изменённых в ней файлов, прочитать их диффы и интерактивно восстановить файлы, или держите панель предпросмотра с выводом jj show или jj diff для выбранной ревизии.

🔄 Меню Git и журнал операций

Выполняйте push и fetch через меню Git, не покидая граф, и просматривайте журнал операций, чтобы увидеть, что изменилось, и вернуть репозиторий в более раннее состояние.

🖱️ Клавиатура, мышь, Lua и темы

У каждого действия есть сочетание клавиш (нажмите ?, чтобы увидеть их список), и мышь тоже работает. Скрипты на Lua добавляют ваши собственные действия, а темы меняют цвета.

🚀 Всегда впереди официальных архивов: Debian и Ubuntu замораживают версии пакетов при выпуске релиза — этот репозиторий публикует новые версии обычно в течение нескольких часов. Простое apt upgrade держит вас на последней версии.

Как работает бесплатное зеркало →

🧩 О варианте extrepo. extrepo — штатный инструмент Debian для внешних репозиториев: он создаёт файл sources и устанавливает ключ подписи, предварительно сверив его с подписанными метаданными. Этот репозиторий зарегистрирован в нём как griffo, а бесплатное навсегда зеркало — как griffo-free, поэтому в Debian (bookworm, trixie, forky и sid) команды выше и есть вся настройка.

extrepo настраивает только файл sources и ключ — учётные данные подписки по-прежнему прописываются в /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu не поддерживается, так как extrepo публикует метаданные только для выпусков Debian: там используйте команды с sudo или от root.

🔧 Интеграции

jjui — это интерфейс к jj, поэтому он подходит везде, где уже используется jj:

  • Jujutsu: каждое действие запускает команду jj, поэтому jjui видит тот же репозиторий, конфигурацию и псевдонимы revset, что и сам jj; пакет зависит от jujutsu (>= 0.37), а deb.griffo.io пакует Jujutsu для всех версий, так что apt устанавливает его вместе с jjui
  • Удалённые репозитории Git: в совмещённом (colocated) репозитории push и fetch из меню Git идут в ваши обычные удалённые репозитории Git с уже используемыми учётными данными
  • Ваш редактор: jjui -config открывает файл конфигурации в $EDITOR, где хранятся сочетания клавиш, тема и собственные действия
  • Скрипты на Lua: пишите собственные действия на Lua и назначайте им клавиши для команд jj, которые вы запускаете часто
  • Темы: цвета графа, выделения и панелей берутся из темы, которую можно поменять или написать самому
  • Мышь: щёлкайте, чтобы выбирать ревизии, и прокручивайте граф и предпросмотр в любом терминале с поддержкой мыши
  • Документация: upstream не выпускает man-страницу, поэтому полное руководство находится на idursun.github.io/jjui, а ? внутри jjui показывает список клавиш

🚀 Почему стоит выбрать deb.griffo.io?

📊 Сравнение репозиториев:
  • Официальный Debian: не пакует jjui — apt install jjui на стандартной системе завершится ошибкой
  • Загрузки из upstream: zip с одним бинарником со страницы релизов GitHub, который копируется в PATH вручную и скачивается заново для каждого релиза, а jj устанавливается отдельно
  • Сборка из исходников: тулчейн Go и go install для каждого релиза, а jj всё равно нужно устанавливать каким-то другим способом
  • deb.griffo.io: последняя версия с автоматическими обновлениями
  • ✅ Единственный источник apt: jjui нет ни в архивах Debian, ни в архивах Ubuntu; этот репозиторий пакует официальный релиз upstream
  • ✅ jj идёт в комплекте: пакет зависит от jujutsu (>= 0.37), минимальной версии upstream, а deb.griffo.io пакует Jujutsu для всех версий, так что sudo apt install jjui за один шаг устанавливает свежий jj
  • ✅ Честная упаковка: бинарник upstream в /usr/bin/jjui — upstream не выпускает ни man-страницы, ни дополнений для оболочки, поэтому пакет их не выдумывает
  • ✅ Автоматические обновления: пакеты обновляются в течение нескольких часов после релиза upstream
  • ✅ Две архитектуры: amd64 и arm64 на всех версиях, так что один и тот же jjui работает на ноутбуках, серверах и ARM-платах вроде Raspberry Pi
  • ✅ Много дистрибутивов: работает на Bookworm, Trixie, Forky и Sid
  • ✅ Простое обслуживание: обновления обычными командами apt

❓ Часто задаваемые вопросы

Есть ли jjui в официальных репозиториях Debian?

Нет, jjui не упакован в официальных архивах Debian. Этот репозиторий сейчас единственный источник apt и предлагает jjui 0.10.12.

Как установить последнюю версию jjui в Debian?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install jjui. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Debian поддерживаются?

Debian 12 Bookworm, Debian 13 Trixie, Forky и Sid.
