Что такое ripgrep?

ripgrep (команда rg) — это построчный инструмент поиска, написанный на Rust Эндрю Галлантом. Он рекурсивно ищет в текущем каталоге по регулярному выражению, соблюдая правила .gitignore и автоматически пропуская скрытые, игнорируемые и бинарные файлы. Это поисковый движок, лежащий в основе редакторов вроде VS Code, и он обычно быстрее, чем GNU grep, The Silver Searcher и ack.

🚀 Почему важны свежие версии: От релиза к релизу ripgrep получает реальные возможности — гиперссылки для перехода прямо в редактор, --engine auto для прозрачного переключения на PCRE2, более богатый вывод --json и стабильный рост производительности движка регулярных выражений. Версия из архива старше большинства из этого.

⚡ Ключевые возможности ripgrep

🚀 Очень быстрый

Движок регулярных выражений на конечных автоматах, SIMD-поиск литералов, отображение файлов в память и параллельный обход каталогов делают его быстрее grep на больших деревьях.

🙈 Учитывает .gitignore

По умолчанию пропускает игнорируемые, скрытые и бинарные файлы, поэтому в результатах только то, что вам нужно. Отключается через -u, -uu или -uuu.

🌍 Полная поддержка Unicode

Поддержка Unicode по умолчанию — классы символов, регистр, границы слов и графемы работают корректно и практически без потери скорости.

🧩 Регулярные выражения PCRE2

-P включает опережающие/ретроспективные проверки и обратные ссылки. В этой сборке PCRE2 скомпилирован внутрь, поэтому всё работает сразу и с JIT.

📄 Фильтрация по типу файлов

Ограничьте поиск языком через -t rust, исключите через -T html или задайте свои типы. Встроено более 800 шаблонов.

🔁 Многострочный поиск и замена

Ищите через границы строк с -U, просматривайте замены с -r и выводите структурированные результаты через --json.

🚀 Всегда впереди официальных архивов: Debian и Ubuntu замораживают версии пакетов на момент выпуска — этот репозиторий публикует новые релизы upstream обычно в течение нескольких часов. Обычный apt upgrade держит вас на последней версии.

Как работает бесплатное зеркало →

🧩 О варианте extrepo. extrepo — штатный инструмент Debian для внешних репозиториев: он создаёт файл sources и устанавливает ключ подписи, предварительно сверив его с подписанными метаданными. Этот репозиторий зарегистрирован в нём как griffo, а бесплатное навсегда зеркало — как griffo-free, поэтому в Debian (bookworm, trixie, forky и sid) команды выше и есть вся настройка.

extrepo настраивает только файл sources и ключ — учётные данные подписки по-прежнему прописываются в /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu не поддерживается, так как extrepo публикует метаданные только для выпусков Debian: там используйте команды с sudo или от root.

🎯 Примеры базового использования

Повседневный поиск:

# Поиск по текущему дереву каталогов
rg 'TODO'

# Без учёта регистра, целое слово
rg -i -w 'timeout'

# Показать 3 строки контекста вокруг совпадения
rg -C 3 'panic!'

# Вывести только файлы с совпадениями
rg -l 'BurntSushi'

Ограничение области поиска:

# Только файлы Rust
rg -t rust 'unsafe'

# Всё, кроме HTML и CSS
rg -T html -T css 'font-size'

# Включить игнорируемые и скрытые файлы
rg -uu 'password'

# Ограничить шаблоном glob
rg -g '*.toml' 'version'

Больше, чем grep:

# Проверки и обратные ссылки через PCRE2
rg -P '(?<=fn )\w+' src/

# Поиск через границы строк
rg -U 'struct \w+ \{\n[^}]*pub'

# Предпросмотр замены (файлы не изменяются)
rg 'v(\d+)\.(\d+)' -r 'v$1.$2.0'

# Структурированный вывод для скриптов
rg --json 'error' | jq -r 'select(.type=="match") | .data.path.text'

🔧 Интеграции

ripgrep — поисковый бэкенд, на который рассчитывают многие другие инструменты:

  • fzf: интерактивный grep с живой перезагрузкой и rg в качестве источника
  • Neovim / Telescope: live_grep использует ripgrep, если он есть в PATH
  • Helix: глобальный поиск построен на тех же библиотеках
  • bat: предпросмотр совпадений с подсветкой синтаксиса
  • Yazi: поиск в файловом менеджере на основе ripgrep

❓ Часто задаваемые вопросы

Есть ли ripgrep в официальных репозиториях Debian?

Да, но официальный архив Debian поставляет ripgrep 14.1.1, тогда как этот репозиторий предлагает ripgrep 15.2.0, пересобирается через несколько часов после каждого релиза.

Как установить последнюю версию ripgrep в Debian?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install ripgrep. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Debian поддерживаются?

Debian 12 Bookworm, Debian 13 Trixie, Forky и Sid.
