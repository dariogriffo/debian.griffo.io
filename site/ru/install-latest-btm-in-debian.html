Что такое bottom?

bottom — команда называется btm — это графический монитор процессов и системы для терминала, написанный на Rust и вдохновлённый gtop, gotop и htop. По умолчанию он ведёт себя как дашборд: CPU, память, сеть, диски, температуры и процессы делят один экран, а любой виджет можно отсортировать, приблизить или развернуть на всё окно.

🚀 Почему важна последняя версия: официальные архивы отстают на несколько минорных выпусков, а именно в них произошло всё интересное: отдельный учёт кеша и буферов, загрузка GPU в виджете памяти, встроенные цветовые темы, скрытие потоков ядра и длинный список исправлений для новых ядер и датчиков. Монитор, который неверно читает железо, хуже, чем его отсутствие, — такой инструмент стоит держать свежим.

⚡ Ключевые возможности bottom

📈 Живые графики

CPU (по ядрам или в среднем), память, сетевой трафик, дисковый ввод-вывод и температуры в виде бегущих графиков, которые масштабируются клавишами + и -.

🔍 Поиск процессов

/ фильтрует таблицу процессов — с переключателями регулярных выражений, целого слова и регистра, и по одной клавише на сортировку по CPU, памяти, PID или имени.

🌲 Режим дерева

t превращает таблицу процессов в дерево, и сорвавшийся воркер видно под родителем, который его запустил, а не отдельной строкой в списке.

🎛️ Свои раскладки

Файл конфигурации описывает строки, столбцы и пропорции виджетов, поэтому дашборд показывает те четыре вещи, за которыми вы реально следите.

🎨 Встроенные темы

--theme gruvbox, nord и их светлые варианты уже в бинарнике, а любой цвет можно переопределить в bottom.toml.

🖥️ Базовый режим

btm --basic убирает графики и оставляет компактные числа, которые читаются даже через медленный SSH или в маленькой панели tmux.

🚀 Всегда впереди официальных архивов: Debian и Ubuntu замораживают версии пакетов при выпуске релиза — этот репозиторий публикует новые версии обычно в течение нескольких часов. Простое apt upgrade держит вас на последней версии.

Шаг 3: Первый запуск и настройка

# Запустить дашборд
btm

# Компактный вывод без графиков — для маленьких терминалов и медленных каналов
btm --basic

# Указать bottom файл конфигурации: он создаётся со значениями по умолчанию
mkdir -p ~/.config/bottom
btm --config_location ~/.config/bottom/bottom.toml

# Man-страница и дополнения для bash, zsh и fish входят в пакет
man btm

🎯 Базовые примеры использования

Повседневный мониторинг:

# Полный дашборд
btm

# Обновлять дважды в секунду и хранить десять минут истории
btm --rate 500ms --retention 10m

# Запуск сразу в виджете процессов, уже развёрнутом
btm --default_widget_type proc --expanded

# Дерево процессов, с группировкой и полными командными строками
btm --tree --process_command

Внутри дашборда:

# Клавиши, которые делают работу
#   ?        встроенная справка со всеми сочетаниями
#   e        развернуть выбранный виджет на весь терминал
#   f        заморозить экран, пока вы его читаете
#   +  -  =  приблизить, отдалить или сбросить масштаб графика
#   /        поиск в таблице процессов
#   c m p n  сортировка по CPU, памяти, PID или имени
#   dd       остановить выбранный процесс
#   t        переключить дерево процессов

Подгонка под свою машину:

# Фаренгейты, без средней строки CPU, точечные маркеры вместо брайля
btm --fahrenheit --hide_avg_cpu --dot_marker

# Считать кеш и буферы отдельной строкой памяти
btm --enable_cache_memory

# Виджет батареи на ноутбуке
btm --battery

# Цветовая тема под остальной терминал
btm --theme gruvbox

🔧 Интеграция с другими инструментами

bottom рассчитан на окружение, где всё живёт в терминале:

  • Файл конфигурации: ~/.config/bottom/bottom.toml держит раскладку, пропорции виджетов, цвета и привычные опции в одном месте
  • Файл .desktop: пакет ставит bottom.desktop и иконку, так что bottom появляется и в меню приложений как системный монитор
  • tmux и Zellij: нормально живёт в узкой панели; --basic оставляет его читаемым, когда панель становится маленькой
  • GPU: загрузка NVIDIA и AMD появляется в виджете памяти при установленных драйверах, а --disable_gpu отключает сбор
  • Серверы: сборка amd64 статическая — чистой машине с Debian или Ubuntu не нужно ничего, кроме пакета

🚀 Почему стоит выбрать deb.griffo.io?

📊 Сравнение репозиториев:
  • Официальный Debian: содержит btm, но замороженный на несколько минорных выпусков назад: новые виджеты, темы и исправления датчиков приходят только со следующим релизом Debian
  • cargo install bottom: свежая версия, но компилируется несколько минут, ставится вне apt и не приносит ни man-страницы, ни дополнений, ни файла .desktop
  • Архив upstream: официальный бинарник, который придётся скачивать вручную к каждому выпуску
  • deb.griffo.io: последняя версия с автоматическими обновлениями
  • ✅ Актуальные виджеты: самый свежий выпуск со всеми виджетами, темами и исправлениями датчиков, добавленными после заморозки архива
  • ✅ Прямая замена bottom: пакет назван по команде — btm — и объявляет Provides/Replaces для bottom, поэтому встаёт туда, где был архивный пакет
  • ✅ Автоматические обновления: пакеты обновляются в течение нескольких часов после релиза upstream
  • ✅ Полный пакет: бинарник upstream плюс man-страница btm.1, дополнения для bash, zsh и fish, файл .desktop и иконка
  • ✅ Пять архитектур: amd64, arm64, armhf, i386 и riscv64 — один и тот же монитор на ноутбуке, Raspberry Pi и плате RISC-V
  • ✅ Много дистрибутивов: работает на Bookworm, Trixie, Forky и Sid
  • ✅ Простое обслуживание: обновления обычными командами apt

❓ Часто задаваемые вопросы

Есть ли bottom в официальных репозиториях Debian?

Да, но официальный архив Debian поставляет bottom 0.10.2, тогда как этот репозиторий предлагает bottom 0.14.8, пересобирается через несколько часов после каждого релиза.

Как установить последнюю версию bottom в Debian?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install btm. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Debian поддерживаются?

Debian 12 Bookworm, Debian 13 Trixie, Forky и Sid.
