Свежие инструменты разработчика для WSL (подсистема Windows для Linux)

Инструменты разработчика в свежих версиях upstream (61 шт.): одна команда apt, подпись GPG

⚡ Коротко. Да, deb.griffo.io работает на WSL (подсистема Windows для Linux). Инструменты разработчика (61 шт.) ставятся обычным apt на Ubuntu 24.04 в WSL и Ubuntu 22.04 в WSL и Debian в WSL той же командой настройки, что и для Debian и Ubuntu: она читает UBUNTU_CODENAME / VERSION_CODENAME из /etc/os-release и запрашивает соответствующий набор — noble на Ubuntu 24.04 в WSL.

WSL запускает настоящий Ubuntu или Debian в Windows, а значит, наследует и их архивы, где большинство инструментов разработчика заморожены в версии, вышедшей вместе с выпуском. deb.griffo.io раздаёт актуальный выпуск upstream каждого инструмента из списка ниже в виде пакета apt, так что терминал WSL получает такой же свежий набор инструментов, как рабочая станция на Linux.

WSL ничего не меняет в настройке: дистрибутивы Ubuntu и Debian из Microsoft Store содержат обычный /etc/os-release, поэтому команда сама выбирает noble, jammy или набор Debian. Запускайте её в оболочке WSL, а не в PowerShell.

Шаг 1: Добавить репозиторий и ключ

Запуск команд
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(. /etc/os-release; echo ${DEBIAN_CODENAME:-${UBUNTU_CODENAME:-$VERSION_CODENAME}}) main" | sudo tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
sudo apt update

❓ Частые вопросы

Работают ли инструменты в WSL 1 и WSL 2?

Это обычные исполняемые файлы Linux, поэтому они работают в WSL 2. WSL 1 транслирует системные вызовы, и некоторые инструменты, которым нужны более новые возможности ядра, там могут не запуститься; WSL 2 используется по умолчанию, и стоит выбрать именно его.

deb.griffo.io — официальный репозиторий WSL?

Нет. Это неофициальный репозиторий, который ведёт Dario Griffo, и он не связан с WSL. Каждый пакет автоматически собирается из официального выпуска upstream, упаковка открыта на GitHub, а архив подписан GPG.

Это платно?

Репозиторий работает по подписке (€15 в год или €150 один раз) с бесплатным пробным периодом. Бесплатное зеркало deb-free.griffo.io раздаёт меньший набор инструментов с задержкой, а настройка на этом дистрибутиве та же.

Как удалить репозиторий?

Удалите /etc/apt/sources.list.d/deb.griffo.io.list и /etc/apt/keyrings/deb.griffo.io.gpg, затем выполните sudo apt update. Установленные инструменты останутся, пока вы не удалите их через apt remove.
