Что такое superfile?

superfile — это файловый менеджер для терминала, построенный вокруг панелей, которые остаются открытыми. Несколько каталогов стоят рядом, боковая панель держит ярлыки домашнего каталога, закреплённые папки и смонтированные диски, а панель предпросмотра рисует то, что сейчас под курсором: исходник с подсветкой, обычный текст, содержимое каталога, картинку. Копирование, перемещение и упаковка идут в фоне и отчитываются в строке процессов, поэтому большая передача никогда не подвешивает панель, по которой вы ходите. Удалённые файлы попадают в корзину и возвращаются оттуда, архивы распаковываются и собираются на месте, а каждая клавиша, цвет, символ рамки и ширина панели — это строка в TOML-файле. Это один статически слинкованный бинарник на Go, и команда, которую вы набираете, называется spf.

🚀 Почему важна последняя версия: superfile до сих пор добирает базовые возможности от выпуска к выпуску: панель метаданных, переставляемые секции боковой панели, дополнительные колонки в файловой панели, естественная сортировка, постраничная прокрутка, приглашение > и список плагинов, который продолжает расти. Каждая из них приходит с новыми ключами в config.toml и hotkeys.toml, а старый бинарник молча игнорирует ровно те настройки, которые нынешняя документация советует выставить. Ни Debian, ни Ubuntu не пакуют superfile вообще, так что свежая сборка здесь не роскошь: это единственный способ получить его через apt.

⚡ Ключевые возможности superfile

🪟 Панели, а не один каталог

n открывает ещё одну файловую панель, tab переключает между ними, у каждой свой путь, своя сортировка и свой выбор. Копирование между двумя деревьями превращается в два нажатия вместо двух длинных путей.

👀 Предпросмотр, который следует за курсором

Боковая панель рисует выделенный файл прямо по ходу движения: код с подсветкой встроенным chroma или через bat, содержимое каталогов и картинки в терминалах, которые умеют их рисовать. f сворачивает панель, когда нужна ширина.

♻️ Удаление, которое можно отменить

ctrl+d отправляет файлы в корзину, а не уничтожает их, так что промах по клавише поправим. D — отдельная и осознанная команда безвозвратного удаления, для случаев, когда вы этого действительно хотите.

📊 Строка процессов для долгих задач

Копирование, перемещение и упаковка идут как отслеживаемые фоновые задачи со своим прогрессом и перечислены в панели процессов на p. Файловая панель остаётся рабочей, пока пара гигабайт едет с диска на диск.

🗜️ Искать, прыгать, паковать, распаковывать

/ фильтрует текущий каталог прямо при вводе, z передаёт прыжок zoxide, если он установлен, ctrl+a упаковывает выделение, а ctrl+e распаковывает архив там же, где он лежит.

🎨 Настраивается под вас

Один config.toml и один hotkeys.toml: любую клавишу можно переназначить, рядом с раскладкой по умолчанию лежит вариант для Vim, темы — это файлы, которые вы можете написать сами, а ширина боковой панели, символы рамок, сортировка по умолчанию и ширина предпросмотра просто настройки.

🚀 Всегда впереди официальных архивов: Debian и Ubuntu замораживают версии пакетов при выпуске релиза — этот репозиторий публикует новые версии обычно в течение нескольких часов. Простое apt upgrade держит вас на последней версии.

Как работает бесплатное зеркало →

🧩 О варианте extrepo. extrepo — штатный инструмент Debian для внешних репозиториев: он создаёт файл sources и устанавливает ключ подписи, предварительно сверив его с подписанными метаданными. Этот репозиторий зарегистрирован в нём как griffo, а бесплатное навсегда зеркало — как griffo-free, поэтому в Debian (bookworm, trixie, forky и sid) команды выше и есть вся настройка.

extrepo настраивает только файл sources и ключ — учётные данные подписки по-прежнему прописываются в /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu не поддерживается, так как extrepo публикует метаданные только для выпусков Debian: там используйте команды с sudo или от root.

Шаг 3: Первый запуск

# Открыть каталог, в котором вы находитесь
spf

# Или начать в другом месте
spf ~/Downloads

# Два пути в командной строке — это две панели
spf ~/src ~/Downloads

# Где лежат конфиг, горячие клавиши, тема, лог и данные
spf path-list

# Внутри superfile клавиша ? открывает полный список клавиш
spf --help

🎯 Базовые примеры использования

Запуск:

# Текущий каталог
spf

# Каталог, который вы назвали
spf /var/log

# По панели на каждый путь, открытые рядом
spf ~/src ~/Downloads /mnt/backup

# Попробовать настройки, не трогая свои файлы
spf --config-file /tmp/spf.toml --hotkey-file /tmp/spf-keys.toml

# Какая версия установлена?
spf --version

Поддерживать конфигурацию свежей:

# Добавить поля и клавиши, появившиеся в новом выпуске,
# не трогая то, что вы уже поменяли
spf --fix-config-file
spf --fix-hotkeys

# Вывести все пути, которыми пользуется superfile
spf path-list

# Окружение, терминал и версия для отчёта об ошибке
spf --debug-info

Вписать в свою оболочку:

# Поставьте cd_on_quit = true в config.toml и добавьте это в
# ~/.bashrc или ~/.zshrc: выход по Q оставит вас в том каталоге,
# который показывала панель
spf() {
    export SPF_LAST_DIR="${XDG_STATE_HOME:-$HOME/.local/state}/superfile/lastdir"
    command spf "$@"
    [ ! -f "$SPF_LAST_DIR" ] || { . "$SPF_LAST_DIR"; rm -f -- "$SPF_LAST_DIR"; }
}

# Путь, который читает эта функция
spf path-list --lastdir-file

# superfile как выбор файла для другой программы: он записывает
# выбранный путь в файл и завершается
spf --chooser-file /tmp/picked

🔧 Интеграции

superfile намеренно оставляет специализированные задачи инструментам, которые у вас уже есть:

  • Ваш редактор: e открывает выделенный файл в $EDITOR, а E открывает каталог в dir_editor, так что редактором остаётся Neovim или Helix, а superfile остаётся навигатором
  • zoxide: с zoxide_support = true клавиша z прыгает по той же базе, которую ваша оболочка собирает месяцами
  • exiftool: с установленным libimage-exiftool-perl и metadata = true панель метаданных показывает полные поля EXIF и медиа, а не только основное
  • bat и chroma: предпросмотр подсвечивает встроенный chroma или bat, если вам ближе его темы и вы указали code_previewer = "bat"
  • Ваш терминал и оболочка: предпросмотр картинок использует графический протокол самого терминала, xdg-open берёт на себя типы файлов, не описанные в [open_with], а cd_on_quit возвращает последний каталог в bash, zsh или fish

🚀 Почему стоит выбрать deb.griffo.io?

📊 Сравнение репозиториев:
  • Официальный Debian: не содержит superfile — apt install superfile на стандартной системе не сработает
  • Сборка из исходников: свежо, но требует тулчейн Go на каждой машине и оставляет бинарник, о котором apt ничего не знает
  • Скрипт установки от разработчика: один curl с superfile.dev, удобно, но он пишет в систему мимо пакетного менеджера, а потом бинарник сам напоминает вам о своих обновлениях
  • deb.griffo.io: последняя версия с автоматическими обновлениями
  • ✅ Единственный источник apt: superfile нет ни в архивах Debian, ни в архивах Ubuntu; этот репозиторий пакует официальный выпуск upstream
  • ✅ Команда называется spf: пакет назван superfile, потому что так называется проект, а в PATH он кладёт /usr/bin/spf — ту самую команду, которой пользуются все руководства и все страницы горячих клавиш
  • ✅ Автоматические обновления: пакеты обновляются в течение нескольких часов после релиза upstream, так что auto_check_update можно выключить и оставить проверку apt
  • ✅ Полный пакет: официальная сборка upstream для Linux, установленная как /usr/bin/spf, ничего не добавлено и не пропатчено
  • ✅ Честные зависимости: самому бинарнику не нужно ничего, xdg-utils лишь рекомендуется, а exiftool, zoxide, ffmpeg, poppler-utils и инструмент для буфера обмена предложены для тех необязательных возможностей, которые их используют
  • ✅ Две архитектуры: amd64 и arm64, оба статически слинкованные бинарники на Go, поэтому один и тот же пакет работает на любом выпуске
  • ✅ Много дистрибутивов: работает на Bookworm, Trixie, Forky и Sid
  • ✅ Простое обслуживание: обновления обычными командами apt

❓ Часто задаваемые вопросы

Есть ли superfile в официальных репозиториях Debian?

Нет, superfile не упакован в официальных архивах Debian. Этот репозиторий сейчас единственный источник apt и предлагает superfile 1.6.0.

Как установить последнюю версию superfile в Debian?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install superfile. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Debian поддерживаются?

Debian 12 Bookworm, Debian 13 Trixie, Forky и Sid.
