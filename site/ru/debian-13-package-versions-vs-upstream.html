📊 Версии пакетов Debian 13 и Ubuntu

Что поставляют официальные архивы, рядом с версиями этого репозитория — 2026-09-04

⚡ Коротко. Из 53 инструментов этого репозитория 38 нет ни в Debian 13, ни в Ubuntu 26.04, а остальные заморожены на тех версиях, которые были актуальны на момент выхода этих выпусков. Debian и Ubuntu замораживают версии пакетов при выходе выпуска и после этого принимают в основном исправления безопасности — это осознанный и часто правильный компромисс, но он означает, что версия, которую вы получаете командой apt install на стандартной системе, актуальна на день выхода выпуска. Эта таблица — полная картина по одному каталогу инструментов разработчика, она перегенерируется при каждой публикации пакета, а не заполняется вручную.

🔍 Как читать таблицу

  • «не упакован» означает, что в архиве вообще нет пакета с таким именем в текущем стабильном выпуске этого дистрибутива. На стандартной системе apt install завершается ошибкой «Unable to locate package».
  • Версии приводятся так, как их сообщают архивы, но без эпох и ревизий Debian, поэтому 1:0.44.1-1ubuntu2 выглядит как 0.44.1 — номер, который узнает сам проект upstream.
  • Инструмент может быть в Ubuntu, но отсутствовать в Debian, или наоборот: архивы принимают решения независимо друг от друга и замораживаются в разные даты.
  • Ничто здесь не является критикой Debian. Именно замороженный архив делает стабильный выпуск стабильным, и для очень многих пакетов это именно то, что нужно. Он плохо подходит инструментам, которые выходят каждые несколько недель, и ровно поэтому существует этот репозиторий.

✅ Проверьте любую строку сами

Все числа выше общедоступны. На машине с Debian или Ubuntu:

apt-cache policy ripgrep        # что установит ваша система и откуда
apt-cache madison ripgrep       # все версии, доступные из настроенных источников
rmadison ripgrep                # что поставляют официальные архивы, ничего не устанавливая

rmadison входит в пакет devscripts и обращается к тому же сервису, на основе которого построена эта таблица. Столбец deb.griffo.io отслеживает новейший выпуск каждого проекта и пересобирается в течение нескольких часов после него; репозиторий упаковки каждого инструмента перечислен на странице как собираются пакеты.

📦 Как получить актуальную версию

Одна строка репозитория покрывает все инструменты из таблицы, и каждый пересобирается в течение нескольких часов после выпуска upstream:

Запуск команд
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | sudo tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
sudo apt update
install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
apt update
sudo apt install extrepo
sudo extrepo enable griffo
sudo apt update

🧩 О варианте extrepo. extrepo — штатный инструмент Debian для внешних репозиториев: он создаёт файл sources и устанавливает ключ подписи, предварительно сверив его с подписанными метаданными. Этот репозиторий зарегистрирован в нём как griffo, а бесплатное навсегда зеркало — как griffo-free, поэтому в Debian (bookworm, trixie, forky и sid) команды выше и есть вся настройка.

extrepo настраивает только файл sources и ключ — учётные данные подписки по-прежнему прописываются в /etc/apt/auth.conf.d/deb.griffo.io.conf. Ubuntu не поддерживается, так как extrepo публикует метаданные только для выпусков Debian: там используйте команды с sudo или от root.
