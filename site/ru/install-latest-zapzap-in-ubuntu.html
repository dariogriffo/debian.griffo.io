Что такое ZapZap?

ZapZap — это неофициальный десктопный клиент WhatsApp для Linux, написанный на Python с использованием PyQt6 и QtWebEngine. Он оборачивает WhatsApp Web в полноценное нативное окно рабочего стола с интеграцией в системный трей, уведомлениями рабочего стола, проверкой орфографии, темами и поддержкой нескольких аккаунтов — гораздо приятнее, чем вкладка браузера.

🚀 Почему важны последние версии: ZapZap выпускает частые релизы с новыми функциями, вариантами оформления, улучшениями производительности и исправлениями, которые поддерживают его в соответствии с WhatsApp Web. Последние версии приносят улучшенные уведомления, лучшую поддержку Wayland и обновлённое оформление — этот репозиторий пересобирает их в течение нескольких часов после каждого релиза upstream.

⚡ Ключевые возможности ZapZap

🔔 Трей и уведомления

Значок в системном трее со счётчиком непрочитанных и нативные уведомления рабочего стола, чтобы сообщения доходили до вас без открытого браузера.

👥 Несколько аккаунтов

Запускайте несколько аккаунтов WhatsApp одновременно в одном окне, каждый в своей изолированной сессии.

🎨 Темы и оформление

Светлые, тёмные и пользовательские темы с настройками оформления, которые адаптируют WhatsApp Web под ваш рабочий стол.

✍️ Проверка орфографии

Встроенная проверка орфографии на нескольких языках во время набора сообщений.

🖥️ Wayland и X11

Работает нативно как в современных сессиях Wayland, так и в X11, с интеграцией рабочего стола Qt6.

🔒 Настройки конфиденциальности

Настраивайте предпросмотр уведомлений, поведение трея и системную интеграцию так, как вам нужно от WhatsApp.

🚀 Всегда впереди официальных архивов: Debian и Ubuntu замораживают версии пакетов при выпуске релиза — этот репозиторий публикует новые версии обычно в течение нескольких часов после релиза upstream. Простой apt upgrade всегда держит вас на последней версии.

🚀 Почему выбрать deb.griffo.io?

📊 Сравнение способов установки:
  • Официальный Ubuntu: ZapZap не упакован — apt install вообще недоступен
  • Snap / Flatpak: Дополнительная среда выполнения, особенности песочницы и более крупные загрузки
  • Ручной .deb: Нет автоматических обновлений, легко отстать
  • deb.griffo.io: Нативный apt-пакет с автоматическими обновлениями
  • ✅ Последний релиз: Новейшие функции и исправления ZapZap с точным отслеживанием upstream
  • ✅ Автоматические обновления: Пакеты обновляются в течение нескольких часов после выпуска upstream
  • ✅ Без ручной настройки: Правильный .deb со всеми зависимостями Qt6 и WhatsApp
  • ✅ Правильная интеграция: Ярлык приложения, значок, трей и уведомления работают из коробки
  • ✅ Мультидистрибутив: Работает на Jammy, Noble, Questing и Resolute
  • ✅ Простое обслуживание: Стандартные команды apt для обновлений
🔓 Свободный и открытый исходный код: ZapZap распространяется под лицензией GNU GPL-3.0. Соответствующие пакеты с исходным кодом публикуются вместе с каждой сборкой, поэтому репозиторий полностью соответствует GPL.

❓ Часто задаваемые вопросы

Есть ли ZapZap в официальных репозиториях Ubuntu?

Нет, ZapZap не упакован в официальных архивах Ubuntu. Этот репозиторий сейчас единственный источник apt и предлагает ZapZap 7.4.2.

Как установить последнюю версию ZapZap в Ubuntu?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install zapzap. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Ubuntu поддерживаются?

Ubuntu 22.04 Jammy, 24.04 Noble, 25.10 Questing и 26.04 Resolute.
