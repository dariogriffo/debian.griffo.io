Что такое yt-dlp?

yt-dlp — это консольный загрузчик аудио и видео, поддерживающий значительно больше тысячи сайтов. Он начинался как форк youtube-dl (через ныне заброшенный youtube-dlc) и с тех пор стал активно развиваемым проектом из этих двух: с гораздо более мощным выбором форматов, интеграцией SponsorBlock, встроенной поддержкой внедрения субтитров, глав и метаданных, а также системой плагинов для собственных экстракторов.

🚀 Почему важна последняя версия: здесь это важнее, чем для любого другого инструмента в репозитории. yt-dlp работает с сайтами, которые меняют плееры и API без предупреждения, а исправление приходит новым выпуском yt-dlp — часто в течение нескольких дней. Замороженной версии из архива не просто не хватает возможностей: её экстракторы перестают работать, и загрузки падают с ошибками подписи или формата, пока вы не обновитесь. Работать на текущем выпуске — в этом весь смысл.

⚡ Ключевые возможности yt-dlp

🌐 Тысячи сайтов

Более 1700 экстракторов для видеоплатформ, телеканалов, подкаст-хостингов и новостных сайтов, плюс универсальный экстрактор, который находит медиа даже там, где отдельного экстрактора никто не писал.

🎚️ Точный выбор формата

-f и -S дают полноценный язык выражений по разрешению, кодеку, битрейту и контейнеру, так что вы получаете именно нужный поток, а не тот, что идёт по умолчанию.

🎧 Извлечение аудио

-x --audio-format mp3 вытаскивает звуковую дорожку и перекодирует её, а --embed-thumbnail и --embed-metadata дают файлы с тегами, понятные любому плееру.

💬 Субтитры и главы

Скачивайте или внедряйте субтитры на любом доступном языке, сохраняйте автоматические, записывайте метки глав прямо в файл — или режьте файл по ним.

⏭️ SponsorBlock

Помечайте или удаляйте рекламные вставки, интро и самопродвижение прямо при загрузке, опираясь на базу SponsorBlock, — без последующего монтажа.

🍪 Cookies и сессии

--cookies-from-browser читает авторизованную сессию прямо из Firefox или Chromium, поэтому работают приватные, возрастные и доступные только подписчикам материалы.

🎯 Базовые примеры использования

Повседневная загрузка:

# Скачать видео в наилучшем доступном качестве
yt-dlp 'https://example.com/watch?v=...'

# Лучший MP4 вплоть до 1080p
yt-dlp -S 'res:1080,ext:mp4' 'URL'

# Только звук, в виде MP3 с тегами
yt-dlp -x --audio-format mp3 --embed-thumbnail --embed-metadata 'URL'

# Посмотреть все доступные форматы перед выбором
yt-dlp -F 'URL'

Субтитры, главы и реклама:

# Внедрить английские субтитры, включая автоматические
yt-dlp --embed-subs --sub-langs en --write-auto-subs 'URL'

# Записать метки глав в файл
yt-dlp --embed-chapters 'URL'

# Убрать рекламные вставки и интро прямо при загрузке
yt-dlp --sponsorblock-remove sponsor,intro 'URL'

# Взять только фрагмент вместо всего видео
yt-dlp --download-sections '*00:01:30-00:04:00' 'URL'

Плейлисты, архивы и автоматизация:

# Целый плейлист, в аккуратные папки по авторам
yt-dlp -o '%(uploader)s/%(title)s.%(ext)s' 'PLAYLIST_URL'

# Держать канал в актуальном состоянии, не перекачивая старое
yt-dlp --download-archive seen.txt 'CHANNEL_URL'

# Приватный или возрастной контент через авторизованную сессию браузера
yt-dlp --cookies-from-browser firefox 'URL'

# Более быстрые загрузки через aria2c
yt-dlp --downloader aria2c --downloader-args aria2c:'-x 8 -s 8' 'URL'

🔧 Интеграция с другими инструментами

yt-dlp — это тот загрузчик, на который рассчитывает множество другого ПО:

  • ffmpeg: объединение, ремукс, извлечение звука и внедрение данных идут через него
  • mpv: воспроизводит ссылку напрямую, передавая её yt-dlp на лету
  • aria2: необязательный внешний загрузчик для параллельной сегментированной закачки
  • Медиасерверы: библиотеки Jellyfin, Kodi и Navidrome часто наполняются по шаблонам вывода yt-dlp
  • Файлы конфигурации: положите привычные опции в ~/.config/yt-dlp/config и перестаньте их набирать

❓ Часто задаваемые вопросы

Есть ли yt-dlp в официальных репозиториях Debian?

Да, но официальный архив Debian поставляет yt-dlp 2025.04.30, тогда как этот репозиторий предлагает yt-dlp 2026.07.04 — пересобирается через несколько часов после каждого релиза.

Как установить последнюю версию yt-dlp в Debian?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install yt-dlp. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Debian поддерживаются?

Debian 12 Bookworm, Debian 13 Trixie, Forky и Sid.
