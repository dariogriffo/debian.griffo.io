Что такое fish?

fish — это умная и дружелюбная командная оболочка. Она подсказывает продолжение команды прямо во время набора, опираясь на историю и автодополнения, подсвечивает синтаксис на лету, формирует дополнения по Tab из установленных man-страниц и обходится без замысловатых правил кавычек, унаследованных другими оболочками. Всё работает сразу: чтобы пользоваться fish с удовольствием, ничего настраивать не нужно.

🚀 Почему важны свежие версии: fish 4 переписан на Rust и с тех пор быстро развивается: ускоренный запуск, более качественные дополнения и постоянная шлифовка интерфейса. Версия, замороженная в архиве, старше большей части этих изменений.

⚡ Ключевые возможности fish

💡 Автоподсказки

Во время набора fish предлагает продолжение команды из истории и дополнений. Нажмите →, чтобы принять подсказку.

🎨 Подсветка синтаксиса

Команды подсвечиваются по мере ввода, поэтому опечатка или незакрытая кавычка заметны ещё до нажатия Enter.

⌨️ Дополнения из man-страниц

fish разбирает установленные man-страницы и строит по ним дополнения — даже редкие утилиты дополняют свои опции.

🧠 Разумные скрипты

Никаких сюрпризов с разбиением на слова, никакого [[ ]] против [ ], и настоящие списки. Скрипты читаются так же, как работают.

🔍 Поиск по истории

Наберите начало команды и нажмите ↑, чтобы перебирать только подходящие варианты; есть и поиск по подстроке.

🛠️ Настройка в браузере

fish_config открывает интерфейс для приглашения, цветов, функций и привязок клавиш — без раскопок в dotfiles.

🚀 Всегда впереди официальных архивов: Debian и Ubuntu замораживают версии пакетов на момент выпуска — этот репозиторий публикует новые релизы upstream обычно в течение нескольких часов. Обычный apt upgrade держит вас на последней версии.

❓ Часто задаваемые вопросы

Есть ли fish в официальных репозиториях Debian?

Да, но официальный архив Debian поставляет fish 4.0.2, тогда как этот репозиторий предлагает fish 4.8.1 — пересобирается через несколько часов после каждого релиза.

Как установить последнюю версию fish в Debian?

Добавьте репозиторий deb.griffo.io один раз по инструкции выше, затем выполните: sudo apt install fish. Новые версии приходят через обычный sudo apt upgrade.

Подписаны ли пакеты и как они собираются?

Каждый пакет подписан GPG-ключом репозитория (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) и собирается из релизов upstream в публичных репозиториях GitHub, которые может проверить любой.

Какие версии Debian поддерживаются?

Debian 12 Bookworm, Debian 13 Trixie, Forky и Sid.
