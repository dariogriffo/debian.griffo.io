Neovim とは

Neovim は、古典的な Vim のコードベースを現代の開発に合わせて作り直した拡張性の高い Vim ベースのテキストエディタです。Language Server Protocol クライアント、Treesitter による構文とコードの理解、非同期のジョブ機構、そして一級の Lua スクリプティングを備えているので、プラグインも設定も速く、プログラマブルで、保守しやすくなります。

公式 Ubuntu アーカイブが配布している Neovim は 0.11.6で、古いリリースはさらにずっと前で止まっています。このリポジトリは Ubuntu 22.04、24.04、25.10、26.04 のどれにも Neovim 0.12.4 を配布します。

⚡ Neovim の主な機能

🌙 Lua で設定

豊富で安定した API を使い、Lua でエディタを設定・スクリプト化できます。Vimscript ではなく本物のプログラミング言語なので、速くて保守しやすい設定になります。

🔌 LSP を内蔵

ネイティブの Language Server Protocol クライアントを備え、サーバーがある言語なら補完、診断、定義ジャンプ、リファクタリングが使えます。

🌳 Treesitter

インクリメンタルなパースにより、正規表現ベースをはるかに超える精度でハイライト、インデント、構文単位の選択を行います。

🚀 非同期とプラグイン

ノンブロッキングのジョブとイベントループが UI の応答性を保ち、現代的な Lua プラグインとリモート UI の広大なエコシステムを支えています。

🚀 公式アーカイブより、いつも先へ: Debian と Ubuntu は、リリース時点でパッケージのバージョンを固定します。このリポジトリは上流の新しいリリースを、たいてい数時間以内に公開します。apt upgrade を実行するだけで、常に最新版を使い続けられます。

🎯 基本的な使い方

Neovim を起動する:

# ファイルを開く
nvim file.txt

# Neovim を開いてヘルスチェックを実行
nvim +checkhealth

# nvim を既定のエディタにする
export EDITOR=nvim

設定例:

# 設定ディレクトリを作る
mkdir -p ~/.config/nvim

# 最小限の init.lua（~/.config/nvim/init.lua）
vim.opt.number = true
vim.opt.expandtab = true
vim.opt.shiftwidth = 2
vim.g.mapleader = " "
🧩 任意のデバッグビルド: デバッグシンボルを残した同じ上流バイナリを neovim-unstripped として用意しています。並べて入れて sudo update-alternatives --config nvim で切り替えられます。

🚀 deb.griffo.io を選ぶ理由

⚠️ 公式 Ubuntu での状況: Neovim は公式 Ubuntu アーカイブにありますが、固定されています。いまのリリースは 0.11.6 で、それより古いものはさらに遅れています。deb.griffo.io は上流に追随し、今日は 0.12.4 を配布しています。
  • ✅ すぐ使える: Neovim 0.12.4 を今すぐ。次の Ubuntu リリースを待つ必要はありません
  • ✅ 最新の機能: LSP、Treesitter、Lua API の改善が出た端から
  • ✅ 自動更新: 上流のリリースから数時間以内にパッケージを再ビルド
  • ✅ 上流公式のバイナリ: 独自の再ビルドではなく、上流のビルド済みリリースを再パッケージしています
  • ✅ マルチディストリビューション: Ubuntu 22.04、24.04、25.10、26.04 で動作
  • ✅ コンパイル不要: ビルド済みバイナリなので、ソースからのビルドは不要

❓ よくある質問

Neovim は公式の Ubuntu リポジトリにありますか？

あります。ただし公式 Ubuntu アーカイブが配布しているのは Neovim 0.11.6 で、このリポジトリは上流のリリースから数時間以内に再ビルドした Neovim 0.12.4 を配布しています。

Ubuntu に最新の Neovim を入れるには？

上の手順で deb.griffo.io リポジトリを一度追加してから、sudo apt install neovim を実行してください。新しいリリースは、いつもの sudo apt upgrade で届きます。

パッケージは署名されていますか？ どのようにビルドされていますか？

すべてのパッケージはリポジトリの GPG 鍵（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）で署名されており、誰でも中身を確認できる公開の GitHub パッケージングリポジトリで、上流のリリースからビルドされています。

Ubuntu のどのリリースに対応していますか？

Ubuntu 22.04 Jammy、24.04 Noble、25.10 Questing、26.04 Resolute。
