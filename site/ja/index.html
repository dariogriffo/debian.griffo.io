無料トライアルを始める

手動セットアップ自分で設定したい方へ。3 ステップです

ウェルカムメールのセットアップスクリプトが行う処理と同じです。インデックスは公開されているので、 ステップ 2 の前でも apt update は通ります。パッケージのダウンロードには認証情報が必要です。

コマンドの実行方法

ステップ 1: リポジトリを追加する

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg

echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(. /etc/os-release; echo ${DEBIAN_CODENAME:-${UBUNTU_CODENAME:-$VERSION_CODENAME}}) main" | sudo tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null

sudo apt update

curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg

echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(. /etc/os-release; echo ${DEBIAN_CODENAME:-${UBUNTU_CODENAME:-$VERSION_CODENAME}}) main" | tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null

apt update
sudo apt install extrepo

🆓 ずっと無料のミラーがあります。 deb-free.griffo.io は、アカウントもサブスクリプションもなしでパッケージをずっと無料で配布しています。上流より最大2か月遅れ、セキュリティ修正は即座に公開されます。現在収録しているのは cliamp、Ghostty、lazydocker、Oh My Posh、Uncloud と Zed です。ほかのツールもご要望に応じて追加できます。

無料ミラーの仕組み →

🧩 extrepo オプションについて。 extrepo は外部リポジトリを扱う Debian 標準のツールです。署名済みメタデータと照合して鍵を検証したうえで、sources ファイルの作成と署名鍵のインストールを代わりに行います。このリポジトリは griffo、ずっと無料のミラーは griffo-free という名前で登録されているので、Debian（bookworm、trixie、forky、sid）では上のコマンドだけで設定は完了です。

extrepo が用意するのは sources ファイルと鍵だけなので、サブスクリプションの認証情報は引き続き /etc/apt/auth.conf.d/deb.griffo.io.conf に書きます。extrepo は Debian のスイート向けメタデータしか公開していないため Ubuntu は対象外です。Ubuntu では sudo または root のコマンドを使ってください。

ステップ 2: 認証情報を追加する

ログイン名は登録したメールアドレス、パスワードはウェルカムメールに記載されています。まだ認証情報をお持ちでない場合は、無料トライアルを始めれば数分で届きます。

sudo install -m 600 /dev/null /etc/apt/auth.conf.d/deb.griffo.io.conf
printf 'machine deb.griffo.io\nlogin YOUR_EMAIL\npassword YOUR_PASSWORD\n' | sudo tee /etc/apt/auth.conf.d/deb.griffo.io.conf > /dev/null

sudo apt update
install -m 600 /dev/null /etc/apt/auth.conf.d/deb.griffo.io.conf
printf 'machine deb.griffo.io\nlogin YOUR_EMAIL\npassword YOUR_PASSWORD\n' | tee /etc/apt/auth.conf.d/deb.griffo.io.conf > /dev/null

apt update

任意: ソースパッケージを有効にする

apt-get source でパッケージをダウンロードしてソースからビルドしたい場合は、ソースリストに deb-src の行を追加してください。

echo "deb-src https://deb.griffo.io/apt $(. /etc/os-release; echo ${DEBIAN_CODENAME:-${UBUNTU_CODENAME:-$VERSION_CODENAME}}) main" | sudo tee -a /etc/apt/sources.list.d/deb.griffo.io.list

sudo apt update

📦 ソースパッケージ

このリポジトリはバイナリの .deb パッケージに加えて、 対応するすべてのツールの Debian ソースパッケージも提供しています。ソースパッケージがあれば、 パッケージングの中身を確認したり、ローカルでバイナリを再ビルドしたり、独自のパッチを当てたりでき、そのすべてを 標準の Debian ツールで行えます。ソースパッケージは 3 つのファイルからなります:

  • .dsc: チェックサムとメタデータを含む記述ファイル
  • .orig.tar.gz: 手を加えていない上流のソース tarball
  • .debian.tar.xz: Debian 固有のパッケージングの差分（debian/ ディレクトリ）

ダウンロードしてビルドする

# パッケージのソースをダウンロード（カレントディレクトリに展開されます）
apt-get source zig

# 展開せずにダウンロードだけ（.dsc と tarball のみ）
apt-get source --download-only zig

# 展開されたソースディレクトリに移動（バージョン番号は異なります）
cd zig-stable-0.14.0

# 署名なしでバイナリ .deb をビルド（ローカル利用向け）
dpkg-buildpackage -b --no-sign

# できあがった .deb はひとつ上の階層に置かれます
ls ../zig-stable_*.deb
