🆓 ずっと無料のミラーがあります。 deb-free.griffo.io は、アカウントもサブスクリプションもなしでパッケージをずっと無料で配布しています。上流より最大2か月遅れ、セキュリティ修正は即座に公開されます。現在収録しているのは cliamp、Ghostty、lazydocker、Oh My Posh と Zed です。ほかのツールもご要望に応じて追加できます。

無料ミラーの仕組み →

🧩 extrepo オプションについて。 extrepo は外部リポジトリを扱う Debian 標準のツールです。署名済みメタデータと照合して鍵を検証したうえで、sources ファイルの作成と署名鍵のインストールを代わりに行います。このリポジトリは griffo、ずっと無料のミラーは griffo-free という名前で登録されているので、Debian（bookworm、trixie、forky、sid）では上のコマンドだけで設定は完了です。

extrepo が用意するのは sources ファイルと鍵だけなので、サブスクリプションの認証情報は引き続き /etc/apt/auth.conf.d/deb.griffo.io.conf に書きます。extrepo は Debian のスイート向けメタデータしか公開していないため Ubuntu は対象外です。Ubuntu では sudo または root のコマンドを使ってください。

Optional: enable source packages

Add the deb-src line to your sources list if you want to download and build packages from source using apt-get source.

リポジトリを追加したあとにパッケージを探す

# このリポジトリが提供するパッケージを一覧
apt-cache search --names-only '' | grep -v '^lib'

# 特定のパッケージの詳細を表示
apt-cache show zig

# どのバージョンが、どのソースから入るか確認
apt-cache policy zig

📦 ソースパッケージ

このリポジトリはバイナリの .deb パッケージに加えて、 対応するすべてのツールの Debian ソースパッケージも提供しています。ソースパッケージがあれば、 パッケージングの中身を確認したり、ローカルでバイナリを再ビルドしたり、独自のパッチを当てたりでき、そのすべてを 標準の Debian ツールで行えます。ソースパッケージは 3 つのファイルからなります:

  • .dsc: チェックサムとメタデータを含む記述ファイル
  • .orig.tar.gz: 手を加えていない上流のソース tarball
  • .debian.tar.xz: Debian 固有のパッケージングの差分（debian/ ディレクトリ）

ダウンロードしてビルドする

# パッケージのソースをダウンロード（カレントディレクトリに展開されます）
apt-get source zig

# 展開せずにダウンロードだけ（.dsc と tarball のみ）
apt-get source --download-only zig

deb.griffo.io を選ぶ理由最新版を使いたい人のために

この非公式リポジトリは、人気の開発ツールを最新の状態で、 まっとうな Debian パッケージとして提供することに専念しています。公式リポジトリが上流のリリースから 遅れることが多いなか、ここでは次のことをお約束します:

  • 最新の安定版を、上流の公開から数時間以内に
  • nightly ビルドで最先端の機能を（Zig、ZLS）
  • まっとうな Debian パッケージングと、正しい依存関係
  • 複数のディストリビューションに対応: Debian（Bookworm、Trixie、Forky、Sid）と Ubuntu（Jammy、Noble、Questing、Resolute）
  • ソースパッケージ: apt-get source で、どのパッケージもダウンロード・確認・再ビルドできます
  • 自動更新により、いつでも使える状態を保ちます
