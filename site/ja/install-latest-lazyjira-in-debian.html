lazyjira とは

lazyjira は、lazygit のスタイルで作られたキーボード操作中心の Jira 用ターミナル UI で、Go で書かれています。4 つのパネルに issue、プロジェクト、選択中の issue、そのステータスが並び、vim 風のナビゲーションとマウス操作に対応します。JQL で検索し、issue のトランジション、優先度、担当者、ラベルを変更したり、コメントを追加したり、説明を $EDITOR で編集したり、新しい issue を作成したりと、ブラウザを開かずに作業できます。Jira Cloud と Jira Server/Data Center に対応し、初回起動時にはセットアップウィザードが接続を案内します。パッケージ名もコマンド名も lazyjira です。

🚀 最新版であることの意味: lazyjira は若く進化の速いプロジェクトで、リリースのたびに新しい編集操作、対応する Jira フィールド、設定オプションが加わります。Debian と Ubuntu の公式アーカイブにはまったく含まれておらず、上流は GitHub のリリースにバイナリを公開するだけで apt リポジトリはありません。手で PATH にコピーしたバイナリは自動では更新されません。

⚡ lazyjira の主な機能

🔍 JQL 検索

補完とシンタックスハイライト付きで JQL を入力でき、過去のクエリは永続的な履歴から呼び出せます。保存した JQL タブで、毎日使うビューにキー 1 つで移れます。

🗂️ 4 パネルレイアウト

issue、プロジェクト、issue の詳細、ステータスを横に並べて表示し、狭いターミナルでは縦に積み重ねます。vim 風のキーでもマウスでも操作できます。

✏️ その場で編集

トランジション、優先度、担当者、ラベルの変更、コメントの追加、$EDITOR での説明の編集ができます。新しい issue も同じ画面から作成できます。

🌿 Git 連携

選択中の issue から git ブランチを作成したり、今いるブランチに対応する issue を開いたりして、チケットとコードを常に対応させます。

⚙️ 設定可能

キーバインド、JQL タブ、issue の列、カスタムフィールドは ~/.config/lazyjira/ で設定でき、テーマは標準の ANSI テーマか Catppuccin テーマから選べます。

🔐 Cloud と Server

Jira Cloud はメールアドレスと API トークン、Jira Server と Data Center は個人用アクセストークンでサインインし、mTLS クライアント証明書にも対応しています。

🚀 公式アーカイブより、いつも先へ: Debian と Ubuntu は、リリース時点でパッケージのバージョンを固定します。このリポジトリは上流の新しいリリースを、たいてい数時間以内に公開します。apt upgrade を実行するだけで、常に最新版を使い続けられます。

コマンドの実行方法

ステップ 1: リポジトリを追加する

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | sudo tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
sudo apt update
install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
apt update
sudo apt install extrepo
sudo extrepo enable griffo
sudo apt update

無料ミラーの仕組み →

🧩 extrepo オプションについて。 extrepo は外部リポジトリを扱う Debian 標準のツールです。署名済みメタデータと照合して鍵を検証したうえで、sources ファイルの作成と署名鍵のインストールを代わりに行います。このリポジトリは griffo、ずっと無料のミラーは griffo-free という名前で登録されているので、Debian（bookworm、trixie、forky、sid）では上のコマンドだけで設定は完了です。

extrepo が用意するのは sources ファイルと鍵だけなので、サブスクリプションの認証情報は引き続き /etc/apt/auth.conf.d/deb.griffo.io.conf に書きます。extrepo は Debian のスイート向けメタデータしか公開していないため Ubuntu は対象外です。Ubuntu では sudo または root のコマンドを使ってください。

🔧 ツール連携

lazyjira は既存のターミナル中心の作業にそのまま組み込めます:

  • Git: 選択中の issue からブランチを作成したり、今いるブランチの issue に移動したりできます
  • エディタ: 説明は $EDITOR で開くので、Neovim、Helix など好きなエディタで書けます
  • ブラウザ: Jira の Web 画面全体が必要なときは、xdg-open で選択中の issue をブラウザで開けます
  • クリップボード: xclip でコピーして、コミットメッセージやチャットにそのまま貼り付けられます
  • 社内の Jira: 個人用アクセストークンと mTLS クライアント証明書で、制約の厳しい Server や Data Center 環境にも対応します

🚀 deb.griffo.io を選ぶ理由

📊 リポジトリの比較:
  • 公式 Debian: パッケージなし: lazyjira は Bookworm から Sid まで、どの Debian リリースにも含まれていません
  • 上流のバイナリ: ダウンロードした日には最新ですが、上流は GitHub のリリースにバイナリを公開するだけで apt リポジトリがないため、apt upgrade が新しいバージョンを見つけることはなく、リリースのたびに手動でダウンロードし直すことになります
  • go install でビルド: Go ツールチェーンが必要で、アップグレードのたびに再ビルドになり、変更履歴とドキュメントも入りません
  • deb.griffo.io: 最新版を自動更新で
  • ✅ 実行時の依存なし: lazyjira は静的リンクされた単一の Go バイナリです。git、xclip、xdg-utils は推奨のみで、それぞれブランチ、クリップボード、ブラウザで issue を開く機能に使います
  • ✅ 上流リリースを apt で更新: 上流はバイナリを出しますがリポジトリはありません。ここではすべてのリリースが GPG 署名付きの apt リポジトリに入り、Debian と Ubuntu の各スイート向けにビルドされます
  • ✅ 自動更新: 上流のリリースから数時間以内にパッケージを更新
  • ✅ 完全なパッケージ: lazyjira バイナリに加え、上流の変更履歴と Config、Keybindings、Custom Fields のドキュメントを /usr/share/doc/lazyjira に収録
  • ✅ 2 つのアーキテクチャ: amd64 と arm64 のみ。ノート PC、サーバー、64 ビット ARM ボードで同じ lazyjira が使えます
  • ✅ マルチディストリビューション: Bookworm、Trixie、Forky、Sid で動作
  • ✅ 手間のかからない運用: 更新は通常の apt コマンドだけ

❓ よくある質問

lazyjira は公式の Debian リポジトリにありますか？

ありません。lazyjira は公式 Debian アーカイブにパッケージ化されていません。現在このリポジトリが唯一の apt ソースで、lazyjira 2.19.2 を配布しています。

Debian に最新の lazyjira を入れるには？

上の手順で deb.griffo.io リポジトリを一度追加してから、sudo apt install lazyjira を実行してください。新しいリリースは、いつもの sudo apt upgrade で届きます。

パッケージは署名されていますか？ どのようにビルドされていますか？

すべてのパッケージはリポジトリの GPG 鍵（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）で署名されており、誰でも中身を確認できる公開の GitHub パッケージングリポジトリで、上流のリリースからビルドされています。

Debian のどのリリースに対応していますか？

Debian 12 Bookworm、Debian 13 Trixie、Forky、Sid。
