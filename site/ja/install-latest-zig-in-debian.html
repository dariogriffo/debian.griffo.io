Zig とは

Zig は、堅牢で、最適で、再利用できるソフトウェアを保守するために設計された汎用プログラミング言語兼ツールチェインです。Andrew Kelley が作り、システムプログラマが必要とする単純さと性能を保ったまま、現代的な言語機能を備えた C のより良い代替を目指しています。

🚀 最新版であることの意味: Zig はリリースごとに大きな性能改善、新しい言語機能、重要なバグ修正が入る、急速に進化している言語です。最新の 0.16.0 では、クロスコンパイルの改善、コンパイル時間の短縮、デバッグ機能の強化といった大きな進歩があります。

🔥 Zig の主な機能

⚡ シンプルで速い

隠れた制御フローも、隠れたメモリ確保も、プリプロセッサもありません。言語の知識ではなく、アプリケーションのデバッグに集中できます。

🔧 comptime の魔法

コンパイル時のコード実行と遅延評価。任意の関数をコンパイル時に呼び出し、型を値として扱えます。実行時のオーバーヘッドはありません。

🌐 クロスコンパイル

数十のターゲット向けクロスコンパイルを標準でサポート。ほとんどのプラットフォームで外部依存は不要です。

🔄 C/C++ との相互運用

Zig を C/C++ コンパイラとしてそのまま使えます。クロスコンパイルも優秀で、既存のコードベースに少しずつ Zig を持ち込めます。

🚀 公式アーカイブより、いつも先へ: Debian と Ubuntu は、リリース時点でパッケージのバージョンを固定します。このリポジトリは上流の新しいリリースを、たいてい数時間以内に公開します。apt upgrade を実行するだけで、常に最新版を使い続けられます。

🎯 基本的な使い方

新しいプロジェクトを作る:

# プロジェクトのディレクトリを作って移動
mkdir my-zig-project && cd my-zig-project

# 新しい Zig プロジェクトを初期化
zig init

# ビルドして実行
zig build run

単一ファイルをコンパイル:

# hello.zig を作る
echo 'const std = @import("std");
pub fn main() void {
    std.debug.print("Hello, Zig!\n", .{});
}' > hello.zig

# コンパイルして実行
zig run hello.zig

C コンパイラとして使う:

# Zig で C のコードをコンパイル
zig cc -o program program.c

# 別のターゲット向けにクロスコンパイル
zig cc -target x86_64-windows -o program.exe program.c

🚀 deb.griffo.io を選ぶ理由

⚠️ 公式 Debian の遅れ: 公式 Debian リポジトリの Zig は、最新リリースから数か月、ときには数年遅れていることが多く、重要な機能や性能改善が入っていません。
  • ✅ 常に最新: Zig 0.16.0 を数か月後ではなく今すぐ
  • ✅ nightly ビルド: zig-master パッケージで最先端の機能を
  • ✅ 自動更新: 上流のリリースから数時間以内にパッケージを更新
  • ✅ 依存関係も適切に: 必要な依存をすべて含めて正しくパッケージ化
  • ✅ マルチディストリビューション: Bookworm、Trixie、Sid で動作
  • ✅ 手間いらず: 手動でのコンパイルも、面倒な設定も不要

❓ よくある質問

Zig は公式の Debian リポジトリにありますか？

ありません。Zig は公式 Debian アーカイブにパッケージ化されていません。現在このリポジトリが唯一の apt ソースで、Zig 0.16.0 を配布しています。

Debian に最新の Zig を入れるには？

上の手順で deb.griffo.io リポジトリを一度追加してから、sudo apt install zig-stable を実行してください。新しいリリースは、いつもの sudo apt upgrade で届きます。

パッケージは署名されていますか？ どのようにビルドされていますか？

すべてのパッケージはリポジトリの GPG 鍵（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）で署名されており、誰でも中身を確認できる公開の GitHub パッケージングリポジトリで、上流のリリースからビルドされています。

Debian のどのリリースに対応していますか？

Debian 12 Bookworm、Debian 13 Trixie、Forky、Sid。
