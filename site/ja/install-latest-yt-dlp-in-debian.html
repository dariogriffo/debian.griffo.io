yt-dlp とは

yt-dlp は 1,000 を優に超えるサイトに対応したコマンドラインの音声・動画ダウンローダです。youtube-dl のフォーク（現在は開発の止まった youtube-dlc を経由）として始まり、いまでは両者のうち活発に保守されているほうになりました。はるかに強力なフォーマット選択、SponsorBlock 連携、字幕・チャプター・メタデータの埋め込み対応、そして独自抽出器のためのプラグイン機構を備えています。

🚀 最新版であることの意味: このリポジトリのどのツールよりも重要です。yt-dlp は、プレーヤーや API を予告なく変えるサイトを相手にしており、その修正は新しい yt-dlp のリリースとして、多くの場合は数日以内に届きます。固定されたアーカイブ版は、機能が足りないだけではありません。抽出器が動かなくなり、アップグレードするまで署名やフォーマットのエラーでダウンロードが失敗します。最新リリースを使うことが、そもそもの目的です。

⚡ yt-dlp の主な機能

🌐 数千のサイトに対応

動画プラットフォーム、放送局、ポッドキャストのホスト、ニュースサイトを網羅する 1,700 以上の抽出器に加え、誰も抽出器を書いていないページからメディアを見つける汎用抽出器も備えています。

🎚️ フォーマットを細かく指定

-f と -S は解像度・コーデック・ビットレート・コンテナに対する完全な式言語です。既定のものではなく、欲しいストリームをそのまま指定できます。

🎧 音声の抽出

-x --audio-format mp3 で音声トラックを取り出して再エンコード。--embed-thumbnail と --embed-metadata を付ければ、音楽プレーヤーが理解できるタグ付きファイルになります。

💬 字幕とチャプター

利用可能な任意の言語で字幕をダウンロードまたは埋め込み、自動生成字幕も保持できます。チャプターマーカーは出力ファイルに書き込むことも、そこで分割することもできます。

⏭️ SponsorBlock

SponsorBlock のデータベースを使い、ダウンロード時にスポンサー区間やイントロ、自己宣伝に印を付けたり削除したりできます。あとから編集する必要はありません。

🍪 Cookie とセッション

--cookies-from-browser が Firefox や Chromium のログイン済みセッションを直接読むので、非公開・年齢制限・メンバー限定のコンテンツも扱えます。

🚀 公式アーカイブより、いつも先へ: Debian と Ubuntu は、リリース時点でパッケージのバージョンを固定します。このリポジトリは上流の新しいリリースを、たいてい数時間以内に公開します。apt upgrade を実行するだけで、常に最新版を使い続けられます。

🧩 extrepo オプションについて。 extrepo は外部リポジトリを扱う Debian 標準のツールです。署名済みメタデータと照合して鍵を検証したうえで、sources ファイルの作成と署名鍵のインストールを代わりに行います。このリポジトリは griffo、ずっと無料のミラーは griffo-free という名前で登録されているので、Debian（bookworm、trixie、forky、sid）では上のコマンドだけで設定は完了です。

extrepo が用意するのは sources ファイルと鍵だけなので、サブスクリプションの認証情報は引き続き /etc/apt/auth.conf.d/deb.griffo.io.conf に書きます。extrepo は Debian のスイート向けメタデータしか公開していないため Ubuntu は対象外です。Ubuntu では sudo または root のコマンドを使ってください。

🎯 基本的な使い方

日々のダウンロード:

# 利用できる最高画質で動画をダウンロード
yt-dlp 'https://example.com/watch?v=...'

# 1080p までで最良の MP4
yt-dlp -S 'res:1080,ext:mp4' 'URL'

# 音声のみ、タグ付き MP3 で
yt-dlp -x --audio-format mp3 --embed-thumbnail --embed-metadata 'URL'

# 選ぶ前に、提供されている全フォーマットを見る
yt-dlp -F 'URL'

字幕、チャプター、スポンサー区間:

# 英語字幕を、自動生成字幕も含めて埋め込む
yt-dlp --embed-subs --sub-langs en --write-auto-subs 'URL'

# チャプターマーカーをファイルに書き込む
yt-dlp --embed-chapters 'URL'

# ダウンロード時にスポンサー区間とイントロを削除
yt-dlp --sponsorblock-remove sponsor,intro 'URL'

# 動画全体ではなく、一区間だけを取得
yt-dlp --download-sections '*00:01:30-00:04:00' 'URL'

プレイリスト、アーカイブ、自動化:

# プレイリスト全体を、投稿者ごとのフォルダに整理して
yt-dlp -o '%(uploader)s/%(title)s.%(ext)s' 'PLAYLIST_URL'

# 古い項目を落とし直さずにチャンネルを同期
yt-dlp --download-archive seen.txt 'CHANNEL_URL'

# ログイン済みのブラウザセッションを使って、非公開・年齢制限のコンテンツを
yt-dlp --cookies-from-browser firefox 'URL'

# aria2c を使って高速にダウンロード
yt-dlp --downloader aria2c --downloader-args aria2c:'-x 8 -s 8' 'URL'

🔧 ツール連携

yt-dlp は、多くのソフトウェアが前提にしているダウンロードバックエンドです:

  • ffmpeg: 結合、リマックス、音声抽出、埋め込みはすべてこれを呼び出します
  • mpv: URL をその場で yt-dlp に渡して直接再生します
  • aria2: 並列・分割転送のための、任意の外部ダウンローダ
  • メディアサーバー: Jellyfin、Kodi、Navidrome のライブラリは yt-dlp の出力テンプレートから作られることがよくあります
  • 設定ファイル: いつものフラグを ~/.config/yt-dlp/config に書けば、毎回打ち直さずに済みます

🚀 deb.griffo.io を選ぶ理由

📊 リポジトリの比較:
  • 公式 Debian: 提供はあるが、リリース時点のバージョンで固定。抽出器の修正が数か月ぶん遅れています
  • pip / pipx: 最新ではありますが apt の外であり、PEP 668 のせいで Debian ではシステム全体への pip install が扱いにくくなっています
  • deb.griffo.io: 最新版を自動更新でお届け
  • ✅ 動く抽出器: 最新リリースであることが、ダウンロードが失敗しない理由です
  • ✅ セットアップ不要: pip も virtualenv も、/usr/local/bin に書き込む自己更新もありません
  • ✅ 自動更新: 上流のリリースから数時間以内にパッケージを更新
  • ✅ 全部入り: 上流公式のビルド、yt-dlp.1 man ページ、bash / zsh / fish の補完
  • ✅ どのアーキテクチャでも: Architecture: all で配布しているので、amd64、arm64、armhf、riscv64 などすべてで同じパッケージが入ります
  • ✅ マルチディストリビューション: Bookworm、Trixie、Forky、Sid で動作
  • ✅ 手間のかからない運用: 更新は通常の apt コマンドだけ

❓ よくある質問

yt-dlp は公式の Debian リポジトリにありますか？

あります。ただし公式 Debian アーカイブが配布しているのは yt-dlp 2025.04.30 で、このリポジトリは上流のリリースから数時間以内に再ビルドした yt-dlp 2026.08.19 を配布しています。

Debian に最新の yt-dlp を入れるには？

上の手順で deb.griffo.io リポジトリを一度追加してから、sudo apt install yt-dlp を実行してください。新しいリリースは、いつもの sudo apt upgrade で届きます。

パッケージは署名されていますか？ どのようにビルドされていますか？

すべてのパッケージはリポジトリの GPG 鍵（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）で署名されており、誰でも中身を確認できる公開の GitHub パッケージングリポジトリで、上流のリリースからビルドされています。

Debian のどのリリースに対応していますか？

Debian 12 Bookworm、Debian 13 Trixie、Forky、Sid。
