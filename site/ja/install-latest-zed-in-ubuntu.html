Zed とは

Zed は、人と AI の高速な共同作業のために設計された次世代のコードエディタです。Atom と Tree-sitter を作った人たちが手がけ、複数の CPU コアと GPU を活かすために Rust でゼロから書かれています。驚くほど速く、反応のよい編集体験が得られます。

🚀 最新版であることの意味: Zed はネイティブなデバッグ対応、エージェント的な編集、Git 連携、性能改善といった新機能をリリースごとに追加しています。最新にしておくことが、いちばん良い編集体験につながります。

🔥 Zed の主な機能

⚡ 圧倒的な速さ

複数の CPU コアと GPU を活かすため、Rust でゼロから書かれています。起動は一瞬で、120fps のなめらかなスクロールが得られます。

🤝 複数人での同時編集

リアルタイムの共同作業を内蔵。チームとチャットし、一緒にメモを書き、画面とプロジェクトをそのまま共有できます。

🤖 AI 連携

エージェント的な編集、インラインアシスタント、Zeta モデルによる編集予測で、LLM をワークフローに組み込めます。

🐛 ネイティブなデバッグ

Debug Adapter Protocol（DAP）を土台にしており、複数の言語のデバッグをネイティブにサポートします。

🔧 Vim ライクな操作

Vim のキーバインドによる一級のモーダル編集。テキストオブジェクト、マーク、お気に入りのモーションもそのまま使えます。

🌐 リモート開発

手元のマシンで動くのは Zed の UI だけ。コードベース自体はリモートサーバーで動くので、強力なクラウド開発ができます。

🚀 deb.griffo.io を選ぶ理由

⚠️ 公式 Debian の遅れ: 公式 Debian リポジトリには Zed が入っていないか、古いバージョンしかなく、重要な機能や性能改善、最新の AI 機能が使えません。
  • ✅ 常に最新: Zed の最新リリースを数か月後ではなく今すぐ
  • ✅ 自動更新: 上流のリリースから数時間以内にパッケージを更新
  • ✅ 依存関係も適切に: 必要な依存をすべて含めて正しくパッケージ化
  • ✅ マルチディストリビューション: Jammy と Noble で動作
  • ✅ 手間いらず: 手動でのコンパイルも、面倒な設定も不要
  • ✅ マルチアーキテクチャ: amd64 と arm64 に対応

❓ よくある質問

Zed は公式の Ubuntu リポジトリにありますか？

ありません。Zed は公式 Ubuntu アーカイブにパッケージ化されていません。現在このリポジトリが唯一の apt ソースで、Zed 1.16.1 を配布しています。

Ubuntu に最新の Zed を入れるには？

上の手順で deb.griffo.io リポジトリを一度追加してから、sudo apt install zed を実行してください。新しいリリースは、いつもの sudo apt upgrade で届きます。

パッケージは署名されていますか？ どのようにビルドされていますか？

すべてのパッケージはリポジトリの GPG 鍵（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）で署名されており、誰でも中身を確認できる公開の GitHub パッケージングリポジトリで、上流のリリースからビルドされています。

Ubuntu のどのリリースに対応していますか？

Ubuntu 22.04 Jammy、24.04 Noble、25.10 Questing、26.04 Resolute。
