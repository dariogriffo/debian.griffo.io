ble.sh とは

ble.sh（Bash Line Editor）は、純粋な Bash で書かれたコマンドラインエディタで、対話的な Bash セッションの GNU Readline を置き換えます。Bash も ~/.bashrc もエイリアスもスクリプトもそのままに、普通ならシェルを乗り換えないと手に入らないものが加わります。入力中のシンタックスハイライト、fish 風の履歴からの自動サジェスト、emacs キーバインドと並ぶ本格的な vim モード、メニューと説明付きの補完、略語展開、そして bash-completion や fzf との連携です。作者は Koichi Murase で、BSD-3-Clause ライセンスで公開されています。実行するバイナリはありません。パッケージはスクリプトを /usr/share/blesh/ble.sh にインストールし、~/.bashrc に 2 行足せば有効になります。

🚀 最新版であることの意味: ble.sh は master ブランチで継続的に開発されており、タグ付きの安定版リリースはまれで間隔も長いため、上流のインストール手順は nightly ビルドか git チェックアウトを案内しています。Debian と Ubuntu がパッケージ化しているのは、リリースの寿命中ずっと固定されるスナップショットです（Debian 安定版には収録すらされていません）。このリポジトリは上流の nightly スナップショットを追いかけるので、新しい Bash、端末、補完連携への修正が apt upgrade で届きます。

⚡ ble.sh の主な機能

🎨 シンタックスハイライト

コマンド、キーワード、文字列、変数、リダイレクト、ファイル名が入力中に色分けされ、存在しないコマンドや構文エラーは Enter を押す前にわかります。

💡 自動サジェスト

履歴と補完から作られる fish 風の候補が、カーソルの後ろに灰色で表示されます。右矢印か C-f で全体を、M-f で 1 単語ずつ確定できます。

⌨️ vim / emacs モード

既定は emacs キーバインド。set -o vi で本格的な vi/vim モードになり、ノーマル・挿入・ビジュアルモード、テキストオブジェクト、レジスタ、さらに vim-airline 風のステータスラインも使えます。

📋 メニュー補完

Tab で候補のメニューが開き、矢印キーで移動できます。説明があれば表示し、あいまい一致にも対応します。

✂️ 略語展開

ble-sabbrev で、入力中に展開される略語を定義できます。fish の略語や zsh のグローバルエイリアスのように、L を | less に展開できます。

🐚 純粋な Bash、バイナリなし

コンパイルするものも、アーキテクチャに依存するものもありません。ble.sh は Bash 3.0 以降が動く環境ならどこでも動く Bash スクリプトで、非対話シェルやスクリプトには手を出しません。

🚀 公式アーカイブより、いつも先へ: Debian と Ubuntu は、リリース時点でパッケージのバージョンを固定します。このリポジトリは上流の新しいリリースを、たいてい数時間以内に公開します。apt upgrade を実行するだけで、常に最新版を使い続けられます。

~/.blerc での設定:

# ble.sh は ~/.blerc（または ~/.config/blesh/init.sh）から設定を読みます
# emacs ではなく vim のキーバインドにする
set -o vi

# 自動サジェストを出すまで 300 ms 待つ
bleopt complete_auto_delay=300

# 自動サジェストを完全に無効にする
bleopt complete_auto_complete=

# サジェスト文字の色を変える
ble-face auto_complete='fg=242'

略語、キーバインド、連携:

# 入力中に「L」を「| less」に展開
ble-sabbrev L='| less'

# Ctrl+C で現在の行を破棄
ble-bind -f 'C-c' discard-line

# ble.sh 向けに調整された fzf の補完とキーバインド
ble-import -d integration/fzf-completion
ble-import -d integration/fzf-key-bindings

# vim-airline 風のステータスライン（ble.sh-airline-themes が必要）
ble-import vim-airline
bleopt vim_airline_theme=dark

🔧 ツール連携

ble.sh は既存の Bash 環境を置き換えるのではなく、その下に入り込みます:

  • bash-completion: bash-completion パッケージの補完を自動で取り込み、メニューに表示します
  • fzf: ble-import で、ble.sh 向けに調整された fzf の補完とキーバインドを読み込めます
  • Atuin: Atuin の Bash 連携は ble.sh に対応しており、履歴を記録するための確実な preexec フックが得られます
  • Starship / Oh My Posh: 生成されるプロンプトはそのまま動きます
  • 設定ファイル: ~/.blerc に bleopt、ble-face、ble-bind の設定を ~/.bashrc とは分けて書けます

❓ よくある質問

ble.sh は公式の Ubuntu リポジトリにありますか？

あります。ただし公式 Ubuntu アーカイブが配布しているのは ble.sh 0.4.0 で、このリポジトリは上流のリリースから数時間以内に再ビルドした ble.sh 0.4.0 を配布しています。

Ubuntu に最新の ble.sh を入れるには？

上の手順で deb.griffo.io リポジトリを一度追加してから、sudo apt install ble.sh を実行してください。新しいリリースは、いつもの sudo apt upgrade で届きます。

パッケージは署名されていますか？ どのようにビルドされていますか？

すべてのパッケージはリポジトリの GPG 鍵（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）で署名されており、誰でも中身を確認できる公開の GitHub パッケージングリポジトリで、上流のリリースからビルドされています。

Ubuntu のどのリリースに対応していますか？

Ubuntu 22.04 Jammy、24.04 Noble、25.10 Questing、26.04 Resolute。
