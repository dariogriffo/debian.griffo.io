プライバシーと Cookie

deb.griffo.io と apt リポジトリが何を、なぜ収集するのか、そしてあなたにできること

最終更新日：2026 年 10 月 19 日

要点。Google アナリティクスに同意しない限り、このサイトは Cookie を一切設定しません。この選択はいつでも変更できます。トライアルを始めたり購読したりした場合、リポジトリは apt でのアクセスに必要なものだけを保存します。メールアドレス、購読の状態、パスワードのハッシュです。カード情報は Stripe に送られ、このサイトに届くことはありません。

1. 運営者

deb.griffo.io、deb-free.griffo.io のトップページ、およびその背後にある apt リポジトリは Dario Griffo（以下「私」）が運営しています。ご自身のデータに関する質問や依頼は GitHub またはプロジェクトの Discord コミュニティからお寄せください。

2. アクセス解析

Google アナリティクスは、同意いただいた場合のみ。Cookie のお知らせで 同意するを押すまでは、Google のスクリプトは読み込まれず、Google の Cookie も設定されず、ブラウザから Google には何も送信されません。同意いただくと、Google アナリティクスは閲覧したページと、そこでのいくつかの操作を記録します。無料トライアルのフォームを開く、トライアルを始める、決済に進む、の 3 つです。同じ計測はこのサイトの広告が効果を上げているかの判断にも使うため、同意すると、トライアルや購入をクリックした広告と Google が結び付けることも可能になります。広告のパーソナライズは無効のままです。

完了した購入。支払いが完了すると、リポジトリのサーバーがその売上を Google アナリティクスに報告します。内容はプラン、金額、通貨、Stripe の決済参照番号です。氏名やメールアドレスは含まれません。あなたの訪問と結び付くのは、アクセス解析の Cookie に同意していた場合だけです。

Ahrefs Web Analytics。deb.griffo.io のページでは Ahrefs Web Analytics も読み込まれます。Cookie を使わず、ページの統計を集計した形でのみ表示するものです。

3. 無料トライアル

トライアルを始めるにはメールアドレスを入力します。フォームは Cloudflare Turnstile で保護されており、フォームを開いたときにだけ読み込まれます。サーバーはその結果を Cloudflare に照合し、その際に IP アドレスを送信します。リポジトリが保存するのはメールアドレスと、アクセス解析の Cookie に同意した場合に限り、_ga Cookie にある Google アナリティクスのクライアント ID です。後日の購入を、トライアルを始めた訪問に結び付けるためです。メールアドレスは、認証情報、トライアル終了前のリマインダー、その他アクセスに関するお知らせの送信に使います。

4. 支払い

支払いは Stripe が処理します。カード情報は Stripe に送られ、このサイトにもそのサーバーにも届きません。Stripe の利用には Stripe 自身の規約とプライバシーポリシーが適用されます。リポジトリが保存するのは、メールアドレス、あなたと購読に対する Stripe の参照番号、プラン、購読の状態と期間です。このアドレスには認証情報と購読に関するお知らせが届き、購読開始の数日後には一度だけレビューのお願いが届きます。

5. リポジトリへのアクセス

apt はログイン名（メールアドレス）と、あなたのために生成されたパスワードで認証します。パスワードは bcrypt のハッシュとしてのみ保存されます。一般的なウェブサーバーと同様に、リポジトリのサーバーはサービスの運用と不正利用の防止のため、IP アドレス、ユーザーエージェント、要求されたファイルを含むリクエストを記録します。

6. Cookie とブラウザのストレージ

名前種類目的
_gaCookie、Google アナリティクス同じブラウザからの訪問を見分けます。同意した場合のみ設定されます。
_ga_<id>Cookie、Google アナリティクス現在の訪問を追跡します。同意した場合のみ設定されます。
dgi-consentローカルストレージ、このサイトアクセス解析の Cookie に同意したか拒否したかを記憶します。
deb-griffo-install-variantローカルストレージ、このサイトコマンドを sudo 付き、root、extrepo のどれで表示するかの好みを記憶します。

このサイトがこれ以外の Cookie を設定することはありません。2 つのローカルストレージの項目がブラウザの外に出ることもありません。

7. あなたの選択

  • Cookie の選択の変更は、各ページ下部の Cookie 設定からいつでもできます。拒否すると Google アナリティクスの Cookie は削除されます。
  • 保存されている情報の確認、訂正、削除は GitHub または Discord コミュニティからご依頼ください。GitHub の issue は公開されるため、メールアドレスは書き込まないでください。プライバシーに関する依頼があるとだけ書いていただければ、その後は非公開でやり取りします。アカウントを削除すると、リポジトリへのアクセスも終了します。

8. 変更

このページを変更した場合は、更新日を改めたうえでここに新しい版を掲載します。
