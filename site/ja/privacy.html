deb.griffo.io と apt リポジトリが何を、なぜ収集するのか、そしてあなたにできること

最終更新日：2026 年 10 月 20 日

要点。訪問は 2 つの方法で計測しています。ブラウザに Cookie を設定する Google Analytics と、私たち自身のサーバー上で動く小さなファーストパーティのサービス ttics です。ttics は Cookie を設定せず、日をまたいであなたを識別することもできません。Google Analytics は、その Cookie をブロックするか、広告ブロッカーか、Google のオプトアウト アドオンを使えば無効にできます。トライアルを始めたり購読したりした場合、リポジトリは apt でのアクセスを提供するのに必要なものを保存します。メールアドレス、購読の状態、パスワードのハッシュです。カード情報は Stripe に送られ、このサイトに届くことはありません。

1. 運営者

deb.griffo.io、deb-free.griffo.io、およびその背後にある apt リポジトリは Dario Griffo（以下「私」）が運営しています。ご自身のデータに関する質問や依頼は GitHub またはプロジェクトの Discord コミュニティからお寄せください。

2. アクセス解析

Google Analytics。deb.griffo.io と deb-free.griffo.io のページでは Google Analytics 4 を使っています。Google Ireland Limited（EEA、英国、スイス以外では Google LLC）のサービスです。これはファーストパーティの Cookie _ga と _ga_<id> を設定し、Google はこれを最長 2 年間保持します。再訪したブラウザと新しいブラウザを見分けるためのものです。これらを使って、訪問数と閲覧されたページ、訪問者の流入元（utm_ キャンペーンタグを含む）、端末、ブラウザ、おおよその地域、そしていくつかの操作（無料トライアルのフォームを開く、トライアルを始める、決済に進む。決済ではプランとその価格も含む）を計測します。私はこれを、どのページが役に立っているかを確認し、広告経由のものも含めてトライアルの登録数と決済ボタンのクリック数を測るために使っています。Google によれば、Google Analytics 4 は IP アドレスを記録も保存もしません。Google はこのデータを自社のプライバシー ポリシーに基づいて処理し、データはお住まいの国以外（米国を含む）のサーバーに転送されることがあります。

Google Analytics は、Google のオプトアウト アドオンで無効にできます。このサイトの Cookie をブロックしたり、広告ブロッカーやトラッカーブロッカーを使ったりしても無効になります。どちらの場合も、サイトはまったく同じように使えます。

ttics。ページビューは、私が自分で運用している小さなアクセス解析サービス ttics も、私たち自身のサーバー上で数えています。Cookie を設定せず、端末に何も保存せず、データを受け取る第三者もいません。ページが読み込まれると、ブラウザはそのページのアドレスと訪問に関するいくつかの情報をこのサービスに送ります。そこから記録するのは次のものです。

  • 訪問したページ（パスのみで、クエリ文字列は含みません）
  • このサイトにリンクしていたサイトのホスト名（完全なアドレスは記録しません）
  • アドレスに utm_ キャンペーンタグがある場合はそのタグ（広告やニュースレターから来た訪問であることを示します）
  • ページの言語
  • ウィンドウの幅から判定した端末の種類（モバイル、タブレット、デスクトップ）
  • ブラウザと OS の種類（例：Linux 上の Firefox）。バージョンは含みません
  • いくつかの操作：無料トライアルのフォームを開く、トライアルを始める、決済に進む
  • 日ごとの訪問者ハッシュ（下で説明します）

訪問者ハッシュは、毎日変わるランダムな値（日ごとのソルト）、IP アドレス、ブラウザの User-Agent、サイトのホスト名から計算した SHA-256 です。これにより、ある日に何人の異なる人が訪問したかを数えられます。各ソルトは 2 日後に削除され、それ以降はアドレスからハッシュを再計算できなくなります。また、新しい日のハッシュが過去のハッシュと一致することはないため、日をまたいであなたが識別されることはありません。IP アドレスと完全な User-Agent は保存されません。どちらもこのハッシュの計算に使われるだけです。明らかなボットやクローラーは、何かが記録される前に除外されます。

これらの数値は、どのページが必要な情報を見つける助けになっているか、そしてこのサイトの広告が効果を上げているかを確認するために使います。キャンペーンタグ付きで来た訪問には、同じ日に始まったトライアルと決済が成果として計上されます。

Ahrefs Web Analytics。deb.griffo.io のページでは Ahrefs Web Analytics も読み込まれます。Ahrefs が提供する Cookie を使わないサービスで、ページの統計を集計した形で報告します。

3. 無料トライアル

トライアルを始めるにはメールアドレスを入力します。フォームは Cloudflare Turnstile で保護されています。そのスクリプトはフォームを開いたときにだけ取得されるため、フォームを開かない訪問では読み込まれません。回答を確認するため、サーバーはそれを IP アドレスとともに Cloudflare に渡します。リポジトリはメールアドレスを保存し、認証情報、トライアル終了前のリマインダー、その他アクセスに関するお知らせの送信に使います。IP アドレスも、1 つのアドレスにつき 1 日 1 回までトライアルの申し込みを受け付けるために使いますが、メモリ上でのみ扱います。

4. 支払い

支払いは Stripe が処理します。カード情報は Stripe に送られ、このサイトにもそのサーバーにも届きません。Stripe の利用には Stripe 自身の規約とプライバシーポリシーが適用されます。リポジトリが保存するのは、メールアドレス、あなたと購読に対する Stripe の参照番号、プラン、購読の状態と日付です。購入は、そのメールアドレスによって以前のトライアルと結び付けられます。これにより、トライアルのうちどれだけが購読につながったかを把握できます。このアドレスには認証情報と購読に関するお知らせが届き、購読開始の数日後には一度だけレビューのお願いが届きます。

5. リポジトリへのアクセスとサーバーログ

apt はログイン名（メールアドレス）と、あなたのために生成されたパスワードで認証します。パスワードは bcrypt のハッシュとしてのみ保存されます。一般的なウェブサーバーと同様に、サイトとリポジトリを支えるサーバーは、サービスの運用と不正利用の防止のため、IP アドレス、ユーザーエージェント、要求されたファイルを含むリクエストを記録します。例外は ttics で、そのログにはアドレス、ユーザーエージェント、リファラーが含まれません。

6. Cookie とブラウザのストレージ

このサイトの Cookie は、第 2 節で説明した Google Analytics の _ga と _ga_<id> だけです。ブラウザでブロックしても、サイトの機能が失われることはありません。ttics と Ahrefs はブラウザに何も書き込みません。それ以外にサイト自体がブラウザに保存する可能性があるのは、好みの設定ひとつだけです。インストールコマンドの表示を sudo 付き、root、extrepo の間で切り替えると、次のページでも同じ形式で表示されるよう、その選択がブラウザのローカルストレージに deb-griffo-install-variant として保存されます。これがブラウザの外に出ることはなく、サイトデータを消去すれば削除されます。Cloudflare Turnstile（トライアルのフォームを開いたときのみ）と Stripe（決済に進んだときのみ）は、それぞれの企業が自社のポリシーに基づいて運用しています。

7. あなたの権利

  • 保存されている情報の確認、訂正、削除は GitHub または Discord コミュニティからご依頼ください。GitHub の issue は公開されるため、メールアドレスは書き込まないでください。プライバシーに関する依頼があるとだけ書いていただければ、その後は非公開でやり取りできます。アカウントを削除すると、リポジトリへのアクセスも終了します。
  • ttics のデータからあなたをたどることはできません。氏名、メールアドレス、IP アドレス、Cookie はいずれも含まれず、日ごとのハッシュはソルトが削除されると個人と結び付けられなくなります。そのため、特定の訪問者について照会したり削除したりできるものは含まれていません。
  • Google Analytics はいつでも無効にできます。Google の オプトアウト アドオンを使うか、その Cookie をブロックするか、広告ブロッカーを使ってください。ブラウザから _ga Cookie を削除すると、新しい訪問者として扱われるようになります。
  • データが不適切に扱われたと思われる場合は、お住まいの地域のデータ保護機関に苦情を申し立てることができます。
