Deno とは

Deno は、Node.js の生みの親 Ryan Dahl が作った、V8 と Rust の上に築かれた安全な JavaScript / TypeScript ランタイムです。コンパイル手順なしに TypeScript をそのまま実行でき、既定で安全なサンドボックスを備え、現代的な Web 標準 API を実装しています。Deno 2 では Node.js と npm への完全な互換性が加わりました。

🚀 最新版であることの意味: Deno はリリースごとに大きく改善しており、Node.js / npm 互換の強化、性能改善、新しい Web 標準 API の実装が入っています。最新版には重要なセキュリティ修正と TypeScript 対応の改善も含まれます。

🔥 Deno の主な機能

⚡ 圧倒的な速さ

V8 エンジンと Rust で構築され、JavaScript と TypeScript の処理で高い性能を発揮します。

🔒 デフォルトで安全

明示的に許可しない限り、ファイル、ネットワーク、環境変数にアクセスできません。細かな権限の仕組みを備えています。

📝 TypeScript ネイティブ

コンパイル手順も設定も要らずに、TypeScript ファイルをそのまま実行できます。

🌐 Web 標準 API

fetch、WebSocket、Streams といったブラウザ互換の API を最初から備えています。

🔄 Node.js 互換

Deno 2 は Node.js の API と npm パッケージに対応しており、移行がスムーズです。

📦 ツールチェインを同梱

フォーマッタ、リンタ、テストランナー、バンドラ、ドキュメント生成を同梱しています。

📋 利用できる Deno パッケージ

deb.griffo.io では、用途に応じて 2 種類の Deno パッケージを提供しています:

🦕 deno（推奨）

Deno の完全なランタイム。REPL、LSP、フォーマッタ、リンタ、テストランナー、バンドラといった開発ツールがすべて入っています。ほとんどの方にはこちらがおすすめです。

sudo apt install deno
apt install deno
⚡ denort

開発ツールを含まない軽量な Deno ランタイム。コンパイル済みの Deno プログラムを動かすだけでよい本番環境向けで、オーバーヘッドもバイナリサイズも小さく済みます。

sudo apt install denort
apt install denort

🔄 両方のパッケージを使い分ける

deno と denort は同時にインストールできます:

両方を入れる:

sudo apt install deno denort
apt install deno denort

deno のバージョンを確認:

deno --version

denort を確認:

denort --version

ステップ 2: Deno をインストールする

sudo apt install deno
apt install deno

ステップ 3: インストールを確認する

deno --version
deno --help

🚀 クイックスタート

TypeScript を直接実行する:

echo 'console.log("Hello from Deno!")' > app.ts
deno run app.ts

権限を指定して実行する:

deno run --allow-net --allow-read app.ts

新しいプロジェクトを作る:

deno init my-deno-app
cd my-deno-app
deno run main.ts

npm パッケージと一緒に実行する:

import { express } from "npm:express@4";
deno run --allow-net server.ts

テストを実行する:

deno test

整形と静的解析:

deno fmt
deno lint

❓ よくある質問

Deno は公式の Debian リポジトリにありますか？

ありません。Deno は公式 Debian アーカイブにパッケージ化されていません。現在このリポジトリが唯一の apt ソースで、Deno 2.9.5 を配布しています。

Debian に最新の Deno を入れるには？

上の手順で deb.griffo.io リポジトリを一度追加してから、sudo apt install deno を実行してください。新しいリリースは、いつもの sudo apt upgrade で届きます。

パッケージは署名されていますか？ どのようにビルドされていますか？

すべてのパッケージはリポジトリの GPG 鍵（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）で署名されており、誰でも中身を確認できる公開の GitHub パッケージングリポジトリで、上流のリリースからビルドされています。

Debian のどのリリースに対応していますか？

Debian 12 Bookworm、Debian 13 Trixie、Forky、Sid。
