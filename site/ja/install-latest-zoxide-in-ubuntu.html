zoxide とは

zoxide は Ajeet D'Souza が Rust で書いた賢い cd コマンドです。z と autojump に着想を得ています。よく使うディレクトリを覚えているので、数打鍵で「飛ぶ」ことができます。GitHub スターは 2 万 8,000 を超え、世界中のコマンドラインユーザーのディレクトリ移動を変えました。

😤 ふつうの cd のつらいところ: 長いパスを打つのに疲れていませんか。`cd ../../projects/my-app/src/components` にうんざりしていませんか。正確なディレクトリ名を思い出すのが面倒ではありませんか。zoxide はあなたの癖を覚え、数文字でどこへでも飛ばしてくれます。
🚀 最新版であることの意味: zoxide は活発に開発されており、性能改善、新しいシェル連携、アルゴリズムの強化、互換性の向上が頻繁にリリースされます。最新版ではあいまい一致、シェル対応、サードパーティ連携が改善されています。

⚡ zoxide の主な機能

🧠 使うほど賢くなる

ディレクトリの使い方を学習し、頻度と新しさで順位付けします。よく訪れるディレクトリほど、たどり着きやすくなります。

🔍 あいまい検索

部分一致でディレクトリに移動できます。数文字打つだけで、履歴から正しいディレクトリを見つけてくれます。

🐚 主要なシェルすべてに対応

bash、zsh、fish、PowerShell、Nushell、Elvish、Tcsh、Xonsh に対応。主要なシェルすべてで同じ体験になります。

🔌 充実した連携

対話的に選ぶための fzf 連携をネイティブに備え、Vim、Emacs、ファイルマネージャ、tmux セッションマネージャ向けのプラグインもあります。

📊 データのインポート

autojump、z、z.lua、fasd など、他のディレクトリジャンプツールのデータを取り込めます。ゼロから始め直す必要はありません。

⚙️ 細かく設定できる

スコアリングのアルゴリズム、除外パターン、経年による減衰、コマンドの接頭辞まで設定できます。使い方に合わせて調整できます。

🏆 生産性の面でのメリット

  • 時間の節約: フルパスを打つ代わりに、2〜3 打鍵でどこへでも
  • ミスが減る: 長いパスの打ち間違いとお別れ
  • 使い方を学習: よく使うディレクトリに自動で適応します
  • セッションをまたいで: 端末を閉じてもディレクトリを覚えています
  • 対話モード: fzf と組み合わせて、目で見ながらディレクトリを選べます
🚀 公式アーカイブより、いつも先へ: Debian と Ubuntu は、リリース時点でパッケージのバージョンを固定します。このリポジトリは上流の新しいリリースを、たいてい数時間以内に公開します。apt upgrade を実行するだけで、常に最新版を使い続けられます。

🎯 基本的な使い方

賢いディレクトリ移動:

# 「projects」を含むディレクトリへジャンプ
z projects

# 「my」と「app」に一致するディレクトリへジャンプ
z my app

# 「src」で始まるサブディレクトリへジャンプ
z src/

# 直前のディレクトリに戻る
z -

# fzf で対話的に選ぶ
zi

従来の cd も動きます:

# ふつうの cd としても使える
z ~/Documents
z ../
z /usr/local/bin

# 相対パス
z ./src/components

高度な機能:

# ジャンプせずにディレクトリを問い合わせる
zoxide query projects

# ディレクトリを手動で追加
zoxide add /path/to/directory

# データベースからディレクトリを削除
zoxide remove /path/to/directory

# 他のツールから取り込む
zoxide import --from=autojump ~/.local/share/autojump/autojump.txt
zoxide import --from=z ~/.z

カスタマイズ:

# 別のコマンド接頭辞を使う（z ではなく j）
eval "$(zoxide init bash --cmd j)"

# cd を完全に置き換える
eval "$(zoxide init bash --cmd cd)"

# ジャンプ前にディレクトリを表示
export _ZO_ECHO=1

# 特定のディレクトリを除外
export _ZO_EXCLUDE_DIRS="$HOME:$HOME/private/*"

🚀 deb.griffo.io を選ぶ理由

📊 リポジトリの比較:
  • 公式 Ubuntu: 提供はあるが、古いバージョンであることが多い
  • cargo install: Rust ツールチェインとコンパイルが必要
  • インストールスクリプト: 更新は手動で、パッケージ管理もなし
  • deb.griffo.io: 最新版を自動更新でお届け
  • ✅ 最新のアルゴリズム: スコアリングとマッチングの最新改善が手に入ります
  • ✅ Rust のコンパイル不要: ビルド済みバイナリなので、ツールチェインは要りません
  • ✅ 自動更新: 上流のリリースから数時間以内にパッケージを更新
  • ✅ 全部入り: シェル連携とドキュメントを同梱
  • ✅ マルチディストリビューション: Jammy と Noble で動作
  • ✅ 手間のかからない運用: 更新は通常の apt コマンドだけ

❓ よくある質問

zoxide は公式の Ubuntu リポジトリにありますか？

あります。ただし公式 Ubuntu アーカイブが配布しているのは zoxide 0.9.8 で、このリポジトリは上流のリリースから数時間以内に再ビルドした zoxide 0.10.0 を配布しています。

Ubuntu に最新の zoxide を入れるには？

上の手順で deb.griffo.io リポジトリを一度追加してから、sudo apt install zoxide を実行してください。新しいリリースは、いつもの sudo apt upgrade で届きます。

パッケージは署名されていますか？ どのようにビルドされていますか？

すべてのパッケージはリポジトリの GPG 鍵（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）で署名されており、誰でも中身を確認できる公開の GitHub パッケージングリポジトリで、上流のリリースからビルドされています。

Ubuntu のどのリリースに対応していますか？

Ubuntu 22.04 Jammy、24.04 Noble、25.10 Questing、26.04 Resolute。
