Ghostty とは

Ghostty は、プラットフォームネイティブの UI と GPU アクセラレーションを使う高速で多機能なクロスプラットフォームのターミナルエミュレータです。HashiCorp 創業者の Mitchell Hashimoto が作りました。速度、機能、ネイティブな使い心地のどれかを諦めさせない、というのが Ghostty の立ち位置です。

Ghostty は Ubuntu 24.04 LTS（noble）、25.10（questing）、26.04 LTS（resolute）向けにビルドしています。 Ubuntu 22.04（jammy）の GTK は 4.6 で、Ghostty をビルドするには古すぎます。

⚡ Ghostty の主な機能

🎮 GPU アクセラレーション

Linux では OpenGL、macOS では Metal を使ってハードウェアで描画します。高負荷でも 60fps を維持する優れた性能です。

🖥️ ネイティブ UI

本当の意味でプラットフォームネイティブ。macOS では SwiftUI、Linux では GTK。ちゃんとしたウィンドウ管理、メニューバー、ネイティブの設定画面を備えています。

📊 標準に準拠

現存するターミナルエミュレータの中でも屈指の互換性。xterm への広範な互換性と、現代的な機能を両立しています。

🔧 機能が充実

複数ウィンドウ、タブ、分割、リガチャ、豊富なカスタマイズを、性能を犠牲にせずに実現します。

🏆 性能ベンチマーク

  • 大量テキストの描画は iTerm や Kitty の 4 倍
  • IO 処理は Terminal.app の 2 倍
  • Alacritty に匹敵する速さで、機能ははるかに豊富
  • 高負荷でも 60fps を維持
  • IO のジッタが小さい専用 IO スレッド
🚀 公式アーカイブより、いつも先へ: Debian と Ubuntu は、リリース時点でパッケージのバージョンを固定します。このリポジトリは上流の新しいリリースを、たいてい数時間以内に公開します。apt upgrade を実行するだけで、常に最新版を使い続けられます。

🚀 deb.griffo.io を選ぶ理由

⚠️ 公式 Ubuntu での状況: Ubuntu が配布している Ghostty は 1.3.0 で、しかも 26.04 以降だけです。24.04 LTS と 25.10 には Ghostty がまったくありません。このリポジトリは上流のリリースに追随し、3 つすべてをカバーします。
  • ✅ すぐ使える: Ghostty 1.3.1 以降を今すぐ。公式パッケージ化を待つ必要はありません
  • ✅ 最新の機能: 最新の性能改善と新機能が使えます
  • ✅ 自動更新: 上流のリリースから数時間以内にパッケージを更新
  • ✅ 依存関係も適切に: GTK とグラフィックの依存を正しくパッケージ化
  • ✅ マルチディストリビューション: Ubuntu 24.04 LTS、25.10、26.04 LTS で動作
  • ✅ コンパイル不要: ビルド済みバイナリなので、ソースからのビルドは不要

❓ よくある質問

Ghostty は公式の Ubuntu リポジトリにありますか？

あります。ただし公式 Ubuntu アーカイブが配布しているのは Ghostty 1.3.0 で、このリポジトリは上流のリリースから数時間以内に再ビルドした Ghostty 1.3.1 を配布しています。

Ubuntu に最新の Ghostty を入れるには？

上の手順で deb.griffo.io リポジトリを一度追加してから、sudo apt install ghostty を実行してください。新しいリリースは、いつもの sudo apt upgrade で届きます。

パッケージは署名されていますか？ どのようにビルドされていますか？

すべてのパッケージはリポジトリの GPG 鍵（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）で署名されており、誰でも中身を確認できる公開の GitHub パッケージングリポジトリで、上流のリリースからビルドされています。

Ubuntu のどのリリースに対応していますか？

Ubuntu 22.04 Jammy、24.04 Noble、25.10 Questing、26.04 Resolute。
