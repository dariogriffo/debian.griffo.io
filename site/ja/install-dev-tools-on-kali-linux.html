Kali Linux で最新の開発ツールを使う

63 個の開発ツールを上流の最新バージョンで。apt コマンドひとつ、GPG 署名付き

⚡ 結論から言うと。 はい、deb.griffo.io は Kali Linux で使えます。Kali Linux では 63 個の開発ツールを普通の apt でインストールでき、セットアップコマンドも Debian や Ubuntu と同じです。コマンドは /etc/os-release から VERSION_CODENAME を読み、対応するスイートを要求します（Kali Linux なら kali-rolling）。

Kali Linux は Debian testing から作られるローリングリリースのディストリビューションです。独自のアーカイブはセキュリティツールが中心で、一般的な開発ツールは Debian から、testing にあるバージョンのまま入ってきます。deb.griffo.io は Kali 専用の kali-rolling スイートを用意しており、Debian testing のスイートと同じパッケージを収録しているので、下のツールは普通の apt で入ります。

Kali は VERSION_CODENAME=kali-rolling を設定しており、このリポジトリには kali-rolling スイートがあるので、セットアップコマンドはそのまま動きます。このスイートは Debian testing（forky）のパッケージから作られ、それと同時に公開されるので、Kali だけ別のビルドを待つことはありません。

Kali はサブスクリプションのリポジトリでのみ提供しています。無料ミラーには kali-rolling スイートはありません。

❓ よくある質問

Kali 向けの無料ミラーがないのはなぜですか？

無料ミラーが扱うのは Debian と Ubuntu のリリースのスイートだけです。kali-rolling スイートはサブスクリプションのリポジトリの一部で、無料トライアルでも使えます。

追加すると Kali 自身のツールに影響しませんか？

影響しません。ここにあるのは独自の名前を持つ一般的な開発ツールで、~griffo という接尾辞付きのバージョンなので、同じバージョンの公式パッケージがあれば必ずそちらが優先されます。Kali のセキュリティツールは、これまでどおり Kali 自身のアーカイブから入ります。

deb.griffo.io は Kali Linux の公式リポジトリですか？

いいえ。Dario Griffo が運営する非公式のリポジトリで、Kali Linux とは関係ありません。すべてのパッケージは上流の公式リリースから自動でビルドされ、パッケージングは GitHub でオープンソースとして公開されており、アーカイブは GPG で署名されています。

料金はかかりますか？

リポジトリはサブスクリプション制（年額 €15、または買い切り €150）で、無料トライアルがあります。

リポジトリを削除するには？

/etc/apt/sources.list.d/deb.griffo.io.list と /etc/apt/keyrings/deb.griffo.io.gpg を削除してから、sudo apt update を実行してください。インストール済みのツールは、apt remove で削除するまでそのまま残ります。
