📊 Debian 13 と Ubuntu のパッケージバージョン

公式アーカイブが配布しているものと、このリポジトリが提供しているもの — 2026-08-27

⚡ 短い答え。 このリポジトリにある 52 個のツールのうち、37 個は Debian 13 にも Ubuntu 26.04 にも入っていません。残りも、それぞれのディストリビューションがリリースされた時点のバージョンで固定されています。Debian と Ubuntu はリリースの時点でパッケージのバージョンを凍結し、以降はセキュリティ修正くらいしか当てません。これは意図的なトレードオフで、多くの場合は賢明な判断でもあります。ただしそれは、素の状態のシステムで apt install して得られるのが、リリース当日に最新だったバージョンだということでもあります。この表は開発ツール一式の全体像を示すもので、手で書き写すのではなく、パッケージを公開するたびに再生成しています。

🔍 表の読み方

  • 「パッケージなし」は、そのディストリビューションの現在の安定版に、その名前のパッケージが存在しないという意味です。素の状態のシステムでは、apt install は「Unable to locate package」で失敗します。
  • バージョンはアーカイブが報告するとおりに、epoch と Debian リビジョンを取り除いて表示しています。そのため 1:0.44.1-1ubuntu2 は 0.44.1 と読めます。上流のプロジェクトが自分のものだと認識する番号です。
  • Ubuntu にはあるが Debian にはない、あるいはその逆、ということもあります。2 つのアーカイブは独立に判断し、凍結する時期も違うからです。
  • ここに書かれていることは、どれも Debian への批判ではありません。凍結されたアーカイブこそが安定版を安定させているのであり、多くのパッケージではそれがまさに望ましいものです。合わないのは 2 〜 3 週間おきにリリースされるツールで、このリポジトリが存在する理由もそこにあります。

✅ どの行も自分で確かめられます

上の数字はすべて公開されているものです。Debian か Ubuntu のマシンで、次のように確かめられます。

apt-cache policy ripgrep        # そのシステムが何をインストールするか、どのソースからか
apt-cache madison ripgrep       # 設定済みのソースが提供しているすべてのバージョン
rmadison ripgrep                # 公式アーカイブが配布しているもの。何もインストールせずに確認

rmadison は devscripts パッケージに入っていて、この表を組み立てているのと同じサービスに問い合わせます。deb.griffo.io の列は各プロジェクトの最新リリースを追いかけ、数時間以内に再ビルドしたものです。各ツールのパッケージングリポジトリはパッケージのビルド方法のページに一覧があります。

📦 代わりに最新版を入れる

リポジトリの行を 1 つ追加するだけで、表にあるすべてのツールがカバーされます。どれも上流のリリースから数時間以内に再ビルドされています。

コマンドの実行方法
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | sudo tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
sudo apt update
install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
apt update
sudo apt install extrepo
sudo extrepo enable griffo
sudo apt update

🧩 extrepo オプションについて。 extrepo は外部リポジトリを扱う Debian 標準のツールです。署名済みメタデータと照合して鍵を検証したうえで、sources ファイルの作成と署名鍵のインストールを代わりに行います。このリポジトリは griffo、ずっと無料のミラーは griffo-free という名前で登録されているので、Debian（bookworm、trixie、forky、sid）では上のコマンドだけで設定は完了です。

extrepo が用意するのは sources ファイルと鍵だけなので、サブスクリプションの認証情報は引き続き /etc/apt/auth.conf.d/deb.griffo.io.conf に書きます。extrepo は Debian のスイート向けメタデータしか公開していないため Ubuntu は対象外です。Ubuntu では sudo または root のコマンドを使ってください。
