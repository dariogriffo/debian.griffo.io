Rust とは

Rust は速度、メモリ安全性、信頼できる並行性を重視したシステムプログラミング言語で、このパッケージは公式の Rust 安定版ツールチェーンです。static.rust-lang.org のバイナリ、つまり rustup がインストールするものとまったく同じものを、変更せずに再パッケージしています。各ビルドはパッケージ化の前に検証されます。リリースマニフェストの GPG 署名を Rust のリリース署名鍵（フィンガープリント 108F 6620 5EAE B0AA A8DD 5E1C 85AB 96E6 FA1B E5FE）で確認し、各 tarball の SHA-256 をそのマニフェストと照合します。rust-stable というひとつのパッケージで rustc、cargo、rustdoc、rustfmt、clippy、rust-analyzer、標準ライブラリがそろい、安定版のリリースごと、つまり 6 週間ごとと各ポイントリリースで更新されます。Debian と Ubuntu は同じコンパイラを rustc という名前でパッケージしていますが、ここで名前が違うのは意図的です。理由は後述します。

🚀 最新バージョンが重要な理由: Rust は 6 週間ごとに新しい安定版をリリースし、crate もそれに合わせて進みます。新しい言語機能やライブラリ API は安定化されるとすぐに使われ、より新しい rust-version を宣言した crate は古いコンパイラではビルドできません。Ubuntu は Rust を rustc と cargo としてパッケージしており、26.04 は rustc 1.93.1 で固定されているため、標準のシステムはリリースのたびに遅れていきます。このリポジトリは Rust 1.100.0 を rust-stable として提供します。ディストリビューションの rustc と cargo に代わる完全なツールチェーンで、apt upgrade のたびに新しくなります。

⚡ Rust の主な機能

🦀 ツールチェーン一式

rustc、cargo、rustdoc、rustfmt、clippy（cargo clippy）、rust-analyzer、rust-gdb と rust-lldb のラッパー、そしてこのマシン用の標準ライブラリ。すべて同じリリースのものです。

🔏 検証済みの公式バイナリ

rustup が static.rust-lang.org からダウンロードするのとまったく同じバイナリを、変更せずに再パッケージしています。ビルドでは何かをパッケージ化する前に、マニフェストの GPG 署名と各 tarball の SHA-256 を確認します。

👥 全ユーザーでひとつのインストール

ホームディレクトリごとに ~/.rustup を持つのではなく、マシンの全ユーザーが共有するシステム全体でひとつのツールチェーンです。更新は apt がシステムのほかの部分と一緒に行います。

🧩 常にそろえて、混ぜない

rustc、cargo、標準ライブラリ、clippy、rustfmt はバージョンが固定されたひとまとまりです。rustc だけを置き換えると新しいコンパイラと古い std が組み合わさるため、rust-stable は常にツールチェーン全体をまとめて更新します。

🎯 追加ターゲットもパッケージで

独自の musl を同梱する rust-stable-std-musl で静的な Linux バイナリを、wasm32-unknown-unknown、wasm32-wasip1、wasm32-wasip2 で WebAssembly をビルドできます。どれも apt install ひとつで追加できます。

📚 ソースとオフラインドキュメント

rust-stable-src は rust-analyzer が読む標準ライブラリのソースを追加し、rust-stable-doc は The Book、std API ドキュメント、Cargo ブックをディスクに置いてオフラインで読めるようにします。

🚀 公式アーカイブより、いつも先へ: Debian と Ubuntu は、リリース時点でパッケージのバージョンを固定します。このリポジトリは上流の新しいリリースを、たいてい数時間以内に公開します。apt upgrade を実行するだけで、常に最新版を使い続けられます。

🔧 ツール連携

ツールチェーンはほかのシステムパッケージと同じように配置されるので、環境のほかの部分は設定なしでそれを見つけられます:

  • 配置: すべては専用の LLVM を同梱した /usr/lib/rust-stable にあり、コマンドは /usr/bin にリンクされます。シェルのプロファイルを変更しなくても、すべてのユーザーの PATH に入ります
  • リンク: パッケージは C コンパイラ（gcc または clang）と libc6-dev に依存しており、rustc はこれらでリンクします。インストール直後から cargo build が動きます
  • エディタ: rust-analyzer がパッケージに含まれているので、language server クライアントを持つエディタならどれでも使えます。rust-stable-src があれば標準ライブラリの中まで移動できます
  • デバッガ: rust-gdb と rust-lldb は Rust の pretty-printer を読み込んだ状態で gdb や lldb を起動し、Rust の型を読みやすく表示します
  • シェル: cargo の man ページと bash、zsh 用の補完がパッケージと一緒にインストールされます
  • クロスターゲット: musl と WebAssembly の標準ライブラリは別パッケージで、rustup target add の代わりに apt install で追加します
  • ドキュメント: rust-stable-doc は HTML ドキュメントを /usr/share/doc/rust-stable-doc/html にインストールし、すべて doc.rust-lang.org でもオンラインで読めます

🚀 deb.griffo.io を選ぶ理由

📊 リポジトリの比較:
  • 公式 Ubuntu: Rust を rustc と cargo としてパッケージし、26.04 では 1.93.1。リリースの存続期間中は固定されます
  • rustup: 同じ公式バイナリですが、ユーザーごとに ~/.rustup に別々にインストールされ、apt ではなく rustup update で更新します
  • ソースからビルド: 前のバージョンのコンパイラで rustc をブートストラップし、その LLVM もビルドする、長く重いコンパイル
  • deb.griffo.io: 最新版を自動更新でお届け
  • ✅ そろったツールチェーン: パッケージ名が rustc ではなく rust-stable なのは、コンパイラ、cargo、std、clippy、rustfmt が同じリリースのものでなければならないからです。そのため一緒に配布され、一緒に更新されます
  • ✅ 公式バイナリ: rustup が static.rust-lang.org からインストールするものとまったく同じで、変更なし。ビルド時に Rust のリリース署名鍵とマニフェストの SHA-256 で検証しています
  • ✅ 完全なパッケージ: 専用の LLVM を含む /usr/lib/rust-stable のツールチェーン、/usr/bin のコマンド、man ページ、cargo の補完。rust-stable-src を推奨し、ドキュメントと musl、WebAssembly ターゲットは任意のパッケージです
  • ✅ 自動更新: 上流のリリースから数時間以内にパッケージを更新
  • ✅ 2 つのアーキテクチャ: すべてのバージョンで amd64 と arm64。64 ビット OS の Raspberry Pi 4 と 5 も含みます
  • ✅ マルチディストリビューション: Ubuntu 22.04、24.04、25.10、26.04 で動作
  • ✅ 手間のかからない運用: 更新は通常の apt コマンドだけ

❓ よくある質問

Rust は公式の Ubuntu リポジトリにありますか？

あります。ただし公式 Ubuntu アーカイブが配布しているのは Rust 1.93.1 で、このリポジトリは上流のリリースから数時間以内に再ビルドした Rust 1.100.0 を配布しています。

Ubuntu に最新の Rust を入れるには？

上の手順で deb.griffo.io リポジトリを一度追加してから、sudo apt install rust-stable を実行してください。新しいリリースは、いつもの sudo apt upgrade で届きます。

パッケージは署名されていますか？ どのようにビルドされていますか？

すべてのパッケージはリポジトリの GPG 鍵（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）で署名されており、誰でも中身を確認できる公開の GitHub パッケージングリポジトリで、上流のリリースからビルドされています。

Ubuntu のどのリリースに対応していますか？

Ubuntu 22.04 Jammy、24.04 Noble、25.10 Questing、26.04 Resolute。
