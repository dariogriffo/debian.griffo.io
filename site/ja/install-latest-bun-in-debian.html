← ホームに戻る
📌 特定のリリースに入れますか？ Debian 12 (bookworm) · Debian 13 (trixie) · Debian 14 (forky) · Debian Sid
🥟 Debian で Bun を、curl | bash ではなく apt の作法で: Bun は公式 Debian アーカイブになく、上流のインストーラはスクリプトをそのままシェルに流し込みます。このリポジトリは代わりに、Bun 1.4.0 をまっとうな .deb としてパッケージ化しています。 GPG 署名付きで、apt が管理し、apt upgrade で更新でき、apt remove で消えます。リポジトリを一度追加して（下記）、こう実行してください: 
sudo apt install bun
apt install bun

Bun とは

Bun は、現代の JavaScript エコシステムのためにゼロから作られた高速なオールインワン JavaScript ランタイムです。Node.js をそのまま置き換えられる設計で、性能は大幅に上。バンドラ、テストランナー、パッケージマネージャを 1 つの実行ファイルに備えています。

🚀 最新版であることの意味: Bun は急速に進化しており、リリースごとに大きな性能改善、JavaScript / TypeScript の新機能、互換性の向上が入っています。最新版には重要なバグ修正、Node.js 互換の改善、パッケージ管理とバンドルの大幅な高速化が含まれます。

🔥 Bun の主な機能

⚡ 圧倒的な速さ

最適化された JavaScript エンジンとネイティブコードのコンパイルにより、多くの処理で Node.js の最大 4 倍の速度が出ます。

📦 パッケージマネージャを内蔵

パッケージ管理とロックファイル互換を内蔵し、npm の最大 25 倍の速さでインストールできます。

🛠️ バンドラを同梱

ツリーシェイキング、コード分割、ホットリロードを備えたネイティブのバンドラ。webpack も rollup も要りません。

コマンドの実行方法

ステップ 1: リポジトリを追加する

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | sudo tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
sudo apt update
install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | gpg --dearmor --yes -o /etc/apt/keyrings/deb.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb.griffo.io.gpg] https://deb.griffo.io/apt $(lsb_release -sc 2>/dev/null) main" | tee /etc/apt/sources.list.d/deb.griffo.io.list > /dev/null
apt update
sudo apt install extrepo
sudo extrepo enable griffo
sudo apt update

無料ミラーの仕組み →

🧩 extrepo オプションについて。 extrepo は外部リポジトリを扱う Debian 標準のツールです。署名済みメタデータと照合して鍵を検証したうえで、sources ファイルの作成と署名鍵のインストールを代わりに行います。このリポジトリは griffo、ずっと無料のミラーは griffo-free という名前で登録されているので、Debian（bookworm、trixie、forky、sid）では上のコマンドだけで設定は完了です。

extrepo が用意するのは sources ファイルと鍵だけなので、サブスクリプションの認証情報は引き続き /etc/apt/auth.conf.d/deb.griffo.io.conf に書きます。extrepo は Debian のスイート向けメタデータしか公開していないため Ubuntu は対象外です。Ubuntu では sudo または root のコマンドを使ってください。

📋 利用できる Bun パッケージ

deb.griffo.io では、用途に応じて 3 種類の Bun パッケージを提供しています:

🥟 bun（推奨）

最新安定版の bun-one を自動的に入れるメタパッケージ。常に最新の安定版が手に入るので、ほとんどの方にはこちらがおすすめです。

sudo apt install bun
apt install bun
🚀 bun-one

Bun ランタイムの最新安定版。性能と安定性のために最適化された、本番向けのパッケージです。

sudo apt install bun-one
apt install bun-one
🔍 bun-profile

デバッグシンボルとプロファイリング機能を含む、プロファイリング対応ビルドの Bun。開発・デバッグ・性能分析に向いています。デバッグ情報がある分、バイナリはやや大きめです。

sudo apt install bun-profile
apt install bun-profile

🔄 複数の Bun バージョンを使い分ける

bun-one と bun-profile は同時にインストールでき、Debian の update-alternatives で切り替えられます:

両方のバージョンを入れる:

sudo apt install bun-one bun-profile
apt install bun-one bun-profile

alternatives を設定する（パッケージのインストール時に自動で行われます）:

sudo update-alternatives --install /usr/bin/bun bun /usr/bin/bun-one 100
sudo update-alternatives --install /usr/bin/bun bun /usr/bin/bun-profile 90
update-alternatives --install /usr/bin/bun bun /usr/bin/bun-one 100
update-alternatives --install /usr/bin/bun bun /usr/bin/bun-profile 90

対話的にバージョンを切り替える:

sudo update-alternatives --config bun
update-alternatives --config bun

現在のバージョンを確認:

bun --version
which bun

ステップ 2: Bun をインストールする

sudo apt install bun
apt install bun

ステップ 3: インストールを確認する

bun --version
bun --help

🚀 クイックスタート

新しいプロジェクトを作る:

mkdir my-bun-app && cd my-bun-app
bun init

パッケージを入れる（npm より高速）:

bun install express
bun add -d @types/express

TypeScript を直接実行する:

echo 'console.log("Hello from Bun!")' > app.ts
bun run app.ts

本番用にバンドルする:

bun build ./app.ts --outdir ./dist --minify

テストを実行する:

bun test

🔧 設定

Bun は、プロジェクトのルートかホームディレクトリに置いた bunfig.toml で設定できます:

# bunfig.toml
[install]
# パッケージマネージャの挙動を設定
cache = "~/.bun/install/cache"
registry = "https://registry.npmjs.org"

[run]
# スクリプトランナーを設定
shell = "bash"

[test]
# テストランナーを設定
preload = ["./setup.ts"]

❓ よくある質問

Bun は公式の Debian リポジトリにありますか？

ありません。Bun は公式 Debian アーカイブにパッケージ化されていません。現在このリポジトリが唯一の apt ソースで、Bun 1.4.0 を配布しています。

Debian に最新の Bun を入れるには？

上の手順で deb.griffo.io リポジトリを一度追加してから、sudo apt install bun を実行してください。新しいリリースは、いつもの sudo apt upgrade で届きます。

パッケージは署名されていますか？ どのようにビルドされていますか？

すべてのパッケージはリポジトリの GPG 鍵（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）で署名されており、誰でも中身を確認できる公開の GitHub パッケージングリポジトリで、上流のリリースからビルドされています。

Debian のどのリリースに対応していますか？

Debian 12 Bookworm、Debian 13 Trixie、Forky、Sid。
