Linux Mint で最新の開発ツールを使う

61 個の開発ツールを上流の最新バージョンで。apt コマンドひとつ、GPG 署名付き

⚡ 結論から言うと。 はい、deb.griffo.io は Linux Mint で使えます。Linux Mint 22.x、Linux Mint 21.x では 61 個の開発ツールを普通の apt でインストールでき、セットアップコマンドも Debian や Ubuntu と同じです。コマンドは /etc/os-release から UBUNTU_CODENAME を読み、対応するスイートを要求します（Linux Mint 22.x (Wilma、Xia、Zara) なら noble）。

Linux Mint は Ubuntu LTS をベースにしており、そのアーカイブには元になった Ubuntu リリースが出荷したものが、リリースの期間中ずっと固定されたまま入っています。Mint 22 で使える開発ツールは、Ubuntu 24.04 が 2024 年 4 月時点で持っていたものです。deb.griffo.io は、下の各ツールの上流の最新リリースを、Mint のベースとなる Ubuntu 向けにビルドして提供しています。

Mint 独自のコードネーム（Zara、Xia、Wilma）は、どこにも apt のスイートとして存在しません。サードパーティのインストール手順の多くが Mint で失敗するのはこのためです。lsb_release -sc や VERSION_CODENAME を使うと、zara という存在しないスイートを要求してしまいます。下のセットアップコマンドは代わりに UBUNTU_CODENAME を読みます。Mint はここにベースの Ubuntu リリースを設定しているので、Mint 21 と 22 のどのリリースでも同じ 3 行で動きます。

リポジトリを追加すると、アップデートマネージャーが Mint 自身の更新と並べてこれらのツールの新しいバージョンを表示します。追加で何かを実行する必要はありません。

❓ よくある質問

インストールコマンドに「zara」や「xia」が出てこないのはなぜですか？

それは Linux Mint 独自のリリース名で、それ向けにビルドされた apt リポジトリはありません。Mint は /etc/os-release の UBUNTU_CODENAME に土台となる Ubuntu リリース（Mint 22 なら noble、Mint 21 なら jammy）を設定しており、コマンドはそれを使います。そのため、実際に動いているベースにぴったり合わせたパッケージが入ります。

Linux Mint Debian Edition（LMDE）でも使えますか？

はい。LMDE は Ubuntu ではなく Debian をベースにしており、同じコマンドが Debian のスイートを選びます。LMDE には専用のページがあります。

deb.griffo.io は Linux Mint の公式リポジトリですか？

いいえ。Dario Griffo が運営する非公式のリポジトリで、Linux Mint とは関係ありません。すべてのパッケージは上流の公式リリースから自動でビルドされ、パッケージングは GitHub でオープンソースとして公開されており、アーカイブは GPG で署名されています。

料金はかかりますか？

リポジトリはサブスクリプション制（年額 €15、または買い切り €150）で、無料トライアルがあります。無料ミラーの deb-free.griffo.io でも、より少ないツールを少し遅れて配布しており、このディストリビューションでのセットアップ方法は同じです。

リポジトリを削除するには？

/etc/apt/sources.list.d/deb.griffo.io.list と /etc/apt/keyrings/deb.griffo.io.gpg を削除してから、sudo apt update を実行してください。インストール済みのツールは、apt remove で削除するまでそのまま残ります。
