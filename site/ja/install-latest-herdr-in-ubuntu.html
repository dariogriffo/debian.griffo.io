herdr とは

herdr はターミナルに住むエージェントマルチプレクサです。複数の AI コーディングエージェントを並べて動かし、束ねるためのワークスペース管理ツールで、Rust で書かれ、単一の静的バイナリとして配布されています。Claude Code、Codex、Gemini、Aider などのエージェント群を、キーボード中心の TUI ひとつから操作でき、永続セッション、git ワークツリー、SSH 越しのリモートアクセスを備えています。

🤖 AI コーディングエージェントのために:
  • エージェントを同時にたくさん: それぞれ専用のペイン、タブ、ワークスペースで
  • 切断されても残るセッション。エージェント版のマルチプレクサのようなもの
  • Git worktree に対応: エージェントごとに専用ブランチで隔離できます
  • SSH 越しのリモート: どこで動いている herdr サーバーにも接続できます
🚀 最新版であることの意味: herdr は動きが速く、stable と preview のチャンネルがあり、新しいエージェント連携、ワークスペース機能、TUI の改善が頻繁に入ります。deb.griffo.io から入れれば、内蔵の自己更新を使わずに最新リリースを保てます。

⚡ herdr の主な機能

🤖 複数のエージェントを並べて

複数の AI コーディングエージェントを同時に起動して束ねられます。それぞれ専用のペインとタブに入り、ターミナルを離れずに切り替えられます。

🗂️ ワークスペースとセッション

作業に名前を付けて、永続的なセッションとワークスペースにまとめられます。バックグラウンドで動き続け、すぐに再接続できます。

🌿 Git ワークツリー

エージェントごとに専用の git ワークツリーとブランチを与えるので、並行作業がぶつからず、差分もきれいでレビューしやすいままです。

🖥️ SSH 越しのリモート操作

SSH でどのマシンの herdr サーバーにも接続でき、リモートのセッションをローカルと同じように操作できます。

⌨️ キーボード中心の TUI

マウスがなくても使える高速なターミナル UI。キーバインド、タブ、ペインを設定でき、どの操作も 1 打鍵の距離にあります。

🔌 連携と拡張性

エージェントとの連携を内蔵しつつ、ソケット API と設定ファイルを備え、一級のプラグインのエコシステムが育ちつつあります。

🚀 公式アーカイブより、いつも先へ: Debian と Ubuntu は、リリース時点でパッケージのバージョンを固定します。このリポジトリは上流の新しいリリースを、たいてい数時間以内に公開します。apt upgrade を実行するだけで、常に最新版を使い続けられます。

🎯 基本的な使い方

セッションを起動して接続する:

# 永続セッションを起動、または再接続
herdr

# 名前付きセッションを使う、または作る
herdr --session work

# 名前付きセッションに接続
herdr session attach work

リモートサーバーを扱う:

# SSH でリモートの herdr サーバーに接続
herdr --remote user@server

# リモートホストで名前付きセッションを開く
herdr --remote user@server --session build

ワークスペース・ワークツリー・エージェントを管理する:

# ソケット API 経由のワークスペース・ワークツリー・エージェント補助
herdr workspace list
herdr worktree list
herdr agent list

# ローカルのクライアントと、動作中のサーバーの状態を表示
herdr status

チャンネル、設定、シェル補完:

# stable か preview か、更新チャンネルを選ぶ
herdr channel set stable

# zsh 用のシェル補完を生成
herdr completion zsh

# 既定の設定を表示
herdr --default-config

🚀 deb.griffo.io を選ぶ理由

📊 インストール方法の比較:
  • 公式 Ubuntu: herdr はパッケージ化されておらず、入れるものがありません
  • curl / 自己更新: 手動セットアップで、更新はパッケージマネージャの外
  • ソースからビルド: Rust ツールチェインと時間が必要
  • deb.griffo.io: 最新版を apt の自動更新で
  • ✅ 最新の機能: 最新のエージェント連携と TUI の改善が手に入ります
  • ✅ 自動更新: 上流のリリースから数時間以内にパッケージを更新
  • ✅ セットアップ不要: ビルド済みの静的バイナリ、Rust のコンパイルは不要
  • ✅ 正しく統合: 正しくパッケージ化され、/usr/bin にインストールされます
  • ✅ マルチディストリビューション: Jammy、Noble、Questing、Resolute で動作
  • ✅ 手間のかからない運用: 更新は通常の apt コマンドだけ

🏆 herdr がほかと違うところ

  • エージェント前提の設計: AI コーディングエージェントを並列で走らせるために作られています
  • 永続的: サーバー / クライアント方式なので、切断してもセッションが生き残ります
  • Git ネイティブ: ワークツリーでエージェントごとに専用ブランチに隔離
  • リモート対応: SSH でどこの herdr サーバーにも接続できます
  • 単一バイナリ: 実行時依存のない静的 Rust ビルド

❓ よくある質問

herdr は公式の Ubuntu リポジトリにありますか？

ありません。herdr は公式 Ubuntu アーカイブにパッケージ化されていません。現在このリポジトリが唯一の apt ソースで、herdr 0.8.2 を配布しています。

Ubuntu に最新の herdr を入れるには？

上の手順で deb.griffo.io リポジトリを一度追加してから、sudo apt install herdr を実行してください。新しいリリースは、いつもの sudo apt upgrade で届きます。

パッケージは署名されていますか？ どのようにビルドされていますか？

すべてのパッケージはリポジトリの GPG 鍵（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）で署名されており、誰でも中身を確認できる公開の GitHub パッケージングリポジトリで、上流のリリースからビルドされています。

Ubuntu のどのリリースに対応していますか？

Ubuntu 22.04 Jammy、24.04 Noble、25.10 Questing、26.04 Resolute。
