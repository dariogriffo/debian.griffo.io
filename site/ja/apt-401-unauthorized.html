apt-get update --fix-missing を実行しても解決しません。欠けているものは何もなく、サーバーはきちんと応答していて、その答えが「認証されていません」だったからです。apt のバージョンによっては The repository … is not signed と表示されることがありますが、それは鍵に問題があるときだけです。401 だけが出ているなら、原因は必ず認証です。

1. サブスクリプションをお持ちなら、認証情報を保存する

認証情報は /etc/apt/auth.conf.d/ に置きます。sources.list の行に書いてはいけません。そこに書くとマシンの誰もが読めてしまい、apt がエラーメッセージの中で漏らしてしまいます。

コマンドの実行方法
sudo tee /etc/apt/auth.conf.d/deb.griffo.io.conf > /dev/null <<'EOF'
machine deb.griffo.io
login your-email@example.com
password your-subscription-password
EOF
sudo chmod 600 /etc/apt/auth.conf.d/deb.griffo.io.conf
sudo apt update
tee /etc/apt/auth.conf.d/deb.griffo.io.conf > /dev/null <<'EOF'
machine deb.griffo.io
login your-email@example.com
password your-subscription-password
EOF
chmod 600 /etc/apt/auth.conf.d/deb.griffo.io.conf
apt update

これで sudo apt install <package> が以前とまったく同じように動きます。それでも 401 が返る場合は、次の点を順に確認してください。

まだ購読しておらず、何に申し込むことになるのか気になりますか？ サブスクリプションの仕組みで、メールで届く認証情報、無制限のマシン台数、更新、解約、返金まで、全体の流れを説明しています。

  • machine の行は deb.griffo.io です。https:// は付けず、末尾のスラッシュも /apt というパスも付けません。
  • ファイルは /etc/apt/auth.conf.d/ にあり、名前が .conf で終わっていること。それ以外の拡張子を apt は黙って無視します。
  • ファイルが root 所有でパーミッション 600 になっていること。ほかのユーザーが読める認証情報を apt は読み込もうとしません。
  • パスワードの前後に余計な引用符や末尾の空白がないこと。
  • それでも解決しない場合は Discord で聞いてください。それがいちばん早く片づく方法です。

2. ずっと無料のミラーに切り替える

deb-free.griffo.io は、アカウントも支払いも一切不要です。配信するのは公開から 2 か月以上経った最新のリリースで、そのリリースに対するセキュリティ修正とパッチ修正はすぐに公開されます。現在扱っているのは cliamp、Ghostty、lazydocker、Oh My Posh、Uncloud と Zed です。ほかのツールも要望があれば追加できるので、必要なものがあれば Discord で聞いてください。

コマンドの実行方法
sudo rm -f /etc/apt/sources.list.d/deb.griffo.io.list
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb-free.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | sudo gpg --dearmor --yes -o /etc/apt/keyrings/deb-free.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb-free.griffo.io.gpg] https://deb-free.griffo.io/apt $(. /etc/os-release; echo ${DEBIAN_CODENAME:-${UBUNTU_CODENAME:-$VERSION_CODENAME}}) main" | sudo tee /etc/apt/sources.list.d/deb-free.griffo.io.list > /dev/null
sudo apt update
rm -f /etc/apt/sources.list.d/deb.griffo.io.list
install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://deb-free.griffo.io/EA0F721D231FDD3A0A17B9AC7808B4DD62C41256.asc | gpg --dearmor --yes -o /etc/apt/keyrings/deb-free.griffo.io.gpg
echo "deb [signed-by=/etc/apt/keyrings/deb-free.griffo.io.gpg] https://deb-free.griffo.io/apt $(. /etc/os-release; echo ${DEBIAN_CODENAME:-${UBUNTU_CODENAME:-$VERSION_CODENAME}}) main" | tee /etc/apt/sources.list.d/deb-free.griffo.io.list > /dev/null
apt update
sudo apt install extrepo
sudo extrepo enable griffo-free
sudo apt update

🧩 extrepo オプションについて。 extrepo は外部リポジトリを扱う Debian 標準のツールです。署名済みメタデータと照合して鍵を検証したうえで、sources ファイルの作成と署名鍵のインストールを代わりに行います。このリポジトリは griffo、ずっと無料のミラーは griffo-free という名前で登録されているので、Debian（bookworm、trixie、forky、sid）では上のコマンドだけで設定は完了です。

extrepo は Debian のスイート向けメタデータしか公開していないため、Ubuntu は対象外です。Ubuntu では sudo または root のコマンドを使ってください。

2 つのリポジトリを同時に有効にしないでください。apt はバージョンの高いほう（サブスクリプション側）をインストールしようとするので、また 401 に戻ってしまいます。 無料ミラーの詳しい説明はこちら →

3. GitHub から .deb を入手する

ここにあるパッケージはすべて公開の場でビルドされ、ビルド成果物は GitHub の公開リリースに添付されています。そのダウンロードは無料で認証も不要です。今も、10 月 1 日以降も変わりません。

wget https://github.com/dariogriffo/ghostty-debian/releases/latest/download/ghostty_1.3.1-5~trixie_amd64.deb
sudo apt install ./ghostty_1.3.1-5~trixie_amd64.deb
wget https://github.com/dariogriffo/ghostty-debian/releases/latest/download/ghostty_1.3.1-5~trixie_amd64.deb
apt install ./ghostty_1.3.1-5~trixie_amd64.deb

自動アップグレードはなくなります（サブスクリプションの対価はまさにそこです）が、ソフトウェアそのものへのアクセスを失うことはありません。各ツールのパッケージングリポジトリはパッケージのビルド方法に一覧があります。
