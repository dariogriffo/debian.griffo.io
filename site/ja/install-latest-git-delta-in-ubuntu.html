delta とは

delta は git、diff、grep、blame の出力をシンタックスハイライトするページャです。一度 git のページャに設定すれば、git diff、git show、git log -p、git blame、git add -p のすべてが、エディタと同じように色付けされたコード、変更行の中で実際に変わった単語のマーク、必要に応じて左右分割表示と行番号、そして n と N で移動できるファイル見出し付きで表示されます。任意の unified diff を読み込み、2 つのファイルを直接比較し、ripgrep の JSON 出力もハイライトできます。Dan Davison が Rust で書いており、bat と同じ構文定義とカラーテーマを使い、設定は ~/.gitconfig に書きます。ライセンスは MIT です。パッケージ名は git-delta、インストールされるコマンドは delta です。

🚀 最新版が効いてくる理由: delta は年に数回リリースされ、新しいオプション、左右分割表示での折り返しの改善、そして git・端末・ページャの組み合わせで起きるさまざまな問題の修正が加わります。Ubuntu 26.04 は 0.18.2、24.04 LTS は 0.16.5 で固定され、22.04 には git-delta 自体がありません。現在のマニュアルにあるオプションが手元の版には存在しないこともあります。このリポジトリは同じパッケージ名 git-delta を使うので、apt install git-delta と apt upgrade でアーカイブ版ではなく最新リリースが入ります。

⚡ delta の主な機能

🎨 シンタックスハイライト

diff の中のコードを、bat と同じ構文定義とカラーテーマでエディタのように色付けします。syntax-theme でテーマを選ぶか、端末の明るい背景・暗い背景に delta を合わせさせることもできます。

🔍 単語単位の変更表示

変更された各行の中で、実際に違う単語だけをマークします。変数名の変更や条件の反転が、ほとんど同じ赤と緑の 2 行に埋もれずにすぐ目に入ります。

↔️ 左右分割表示

side-by-side = true で旧版と新版を行番号付きの 2 列に並べ、長い行は切らずに折り返します。1 回だけ試すなら git -c delta.side-by-side=true diff。

🧭 ナビゲーションとリンク

navigate = true にすると、長い git log -p でも n と N でファイルからファイルへ移動できます。hyperlinks = true にすると、対応する端末でファイルパスやコミットハッシュがクリックできるリンクになります。

🧩 blame・grep・コンフリクト

git blame はコミット情報をまとめた上でコードを色付けし、git grep や rg --json の結果はハイライトしてファイルごとにまとめ、マージ中のコンフリクトファイルも読みやすい diff として表示します。

⚙️ 設定は ~/.gitconfig に

すべてのオプションは git 設定の [delta] セクションに書き、名前付きの機能セットで見た目をまとめて切り替えられます。パッケージには upstream の themes.gitconfig(既製テーマ集)も入っています。

🚀 公式アーカイブより、いつも先へ: Debian と Ubuntu は、リリース時点でパッケージのバージョンを固定します。このリポジトリは上流の新しいリリースを、たいてい数時間以内に公開します。apt upgrade を実行するだけで、常に最新版を使い続けられます。

ステップ 3: 最初の起動

# delta を git のページャにする: diff、show、log -p、blame、grep がすべて通る
git config --global core.pager delta

# git add -p でも同じハイライト
git config --global interactive.diffFilter 'delta --color-only'

git config --global delta.navigate true

# コンフリクトに共通の祖先も表示
git config --global merge.conflictStyle zdiff3

# 試してみる
git diff

🎯 基本的な使用例

diff を読む:

# 左右分割表示を 1 回だけ
git -c delta.side-by-side=true diff

# 常に有効にして行番号も表示
git config --global delta.side-by-side true
git config --global delta.line-numbers true

# 履歴をたどる。n と N でファイル間を移動
git log -p

# ハイライト付きで hunk をステージ
git add -p

git diff 以外でも:

# 2 つのファイルを直接比較
delta old.conf new.conf

# 任意の unified diff
diff -u a.txt b.txt | delta

# ripgrep の結果をハイライトしファイルごとにまとめる
rg --json -C 2 'TODO' | delta

# git blame と git grep も delta を通る
git blame src/main.rs
git grep -n 'TODO'

テーマと設定:

# 実際の diff ですべての構文テーマをプレビュー
git show | delta --show-syntax-themes

# パッケージ同梱の delta テーマを読み込んでプレビュー
git config --global --add include.path /etc/delta/themes.gitconfig
git show | delta --show-themes

# その中の 1 つを使う
git config --global delta.features mellow-barbet

# delta が実際に使っている設定を表示
delta --show-config

🔧 ツール連携

delta は git とページャの間に入るフィルタなので、連携のほとんどは git の設定と端末で決まります:

  • git: core.pager delta で diff、show、log -p、stash show -p、blame、grep をカバーします。interactive.diffFilter には --color-only が必要です。git は hunk の各行に対して 1 行ずつ返ってくることを前提にしているためです
  • less: delta は出力を less でページ送りします(パッケージの推奨依存)。less がなければ端末にそのまま出力します。DELTA_PAGER または delta.pager で別のページャを選べ、--paging=never でページ送りを無効にできます
  • lazygit: lazygit は diff を delta 経由で表示できます。ページャ設定に delta --dark --paging=never を指定してください
  • difftastic: 両者は補い合います。普段の diff は git のページャとして delta、構文木で比較したいときは git difftool で difftastic
  • ripgrep: rg --json を delta に渡すと、diff と同じテーマでハイライトされ、ファイルごとにまとまった検索結果になります
  • 端末: delta は背景が明るいか暗いかを自分で判定し、外れたときは delta.dark か delta.light で直せます。hyperlinks = true が出すリンクは kitty や Ghostty で開けます
  • シェル: bash、zsh、fish 用の delta 補完がパッケージに含まれています

🚀 deb.griffo.io を選ぶ理由

📊 リポジトリの比較:
  • 公式 Ubuntu: 26.04 に git-delta 0.18.2、24.04 に 0.16.5 があり、22.04 にはなく、それぞれリリースの間ずっと固定
  • cargo install git-delta: Rust ツールチェーンと数分のコンパイルで ~/.cargo/bin に 1 ユーザー分のバイナリ。補完はなく、リリースのたびに手動で再ビルド
  • upstream のダウンロード: GitHub のリリースページから .deb や tarball。取得した日は最新でも、以降のリリースごとに手動で取り直し
  • deb.griffo.io: 最新版を自動更新でお届け
  • ✅ アーカイブと同じパッケージ名: Debian と Ubuntu が使うのと同じ git-delta なので、普通に sudo apt install git-delta すればこの新しい版が選ばれ、apt upgrade で古いアーカイブ版がその場で置き換わります
  • ✅ パッケージは git-delta、コマンドは delta: git-delta をインストールし、delta を実行します。似た名前の 2 つは無関係です。アーカイブの delta パッケージはテストケース縮小ツール(multidelta、singledelta)で、git-extras の git delta コマンドは別ブランチと異なるファイルを一覧表示します
  • ✅ 公式ビルド: upstream のリリースバイナリをそのまま /usr/bin/delta に配置。bash、zsh、fish の補完と、Debian 自身のパッケージと同じ場所 /etc/delta/themes.gitconfig に themes.gitconfig を同梱。upstream は man ページを出していないので、リファレンスは delta --help です
  • ✅ 軽い依存関係: git と less を推奨しますが、動作にはどちらも不要です。less がなければ delta はページ送りせずにそのまま出力します
  • ✅ 自動更新: 上流のリリースから数時間以内にパッケージを更新
  • ✅ 3 つのアーキテクチャ: amd64、arm64、armhf を Ubuntu 22.04、24.04、25.10、26.04、26.10 で提供。i386、ppc64el、s390x、riscv64 のビルドはありません
  • ✅ マルチディストリビューション: Ubuntu 22.04、24.04、25.10、26.04、26.10 で動作
  • ✅ 手間のかからない運用: 更新は通常の apt コマンドだけ

❓ よくある質問

delta は公式の Ubuntu リポジトリにありますか？

あります。ただし公式 Ubuntu アーカイブが配布しているのは delta 0.18.2 で、このリポジトリは上流のリリースから数時間以内に再ビルドした delta 0.22.0 を配布しています。

Ubuntu に最新の delta を入れるには？

上の手順で deb.griffo.io リポジトリを一度追加してから、sudo apt install git-delta を実行してください。新しいリリースは、いつもの sudo apt upgrade で届きます。

パッケージは署名されていますか？ どのようにビルドされていますか？

すべてのパッケージはリポジトリの GPG 鍵（EA0F721D231FDD3A0A17B9AC7808B4DD62C41256）で署名されており、誰でも中身を確認できる公開の GitHub パッケージングリポジトリで、上流のリリースからビルドされています。

Ubuntu のどのリリースに対応していますか？

Ubuntu 22.04 Jammy、24.04 Noble、25.10 Questing、26.04 Resolute、26.10 Stonking。
