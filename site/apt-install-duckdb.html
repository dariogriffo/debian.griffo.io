🦆 apt install duckdb

A fast in-process analytical SQL database — SQLite for analytics

⚡ The short answer. On a stock system apt install duckdb fails outright — DuckDB is not in the official Debian or Ubuntu archives at all. Add the deb.griffo.io repository below and sudo apt install duckdb gives you the current release on Debian and Ubuntu alike — currently duckdb 1.5.5 (updated 2026-08-18).

🔄 How to apt install the latest DuckDB

Once the repository is added there is no separate "install latest" command — apt already resolves to the newest version this repository serves, and that is rebuilt within hours of every upstream DuckDB release. To move an existing install up to the latest version:

sudo apt update && sudo apt install --only-upgrade duckdb
apt update && apt install --only-upgrade duckdb

Or upgrade everything on the machine at once with sudo apt update && sudo apt upgrade. To see which version you would get before installing, run apt policy duckdb.

❓ Common questions

Does apt-get install duckdb work too?

Yes. apt and apt-get read the same sources, so sudo apt-get install duckdb is equivalent. apt is the friendlier front-end; apt-get is the stable one to prefer inside scripts.

Why doesn't apt install duckdb work out of the box?

DuckDB is not packaged in the official Debian or Ubuntu archives, so a stock system has nothing to install and apt install duckdb fails with "Unable to locate package". Adding this repository gives apt a source that carries DuckDB and keeps it current.

Which Debian and Ubuntu releases are supported?

Every currently supported release listed in the table above. The $(lsb_release -sc) in the setup command picks the right suite for the machine you run it on, so the same three lines work everywhere.

Is this repository trustworthy?

It's an unofficial repository maintained by Dario Griffo. Packages are built automatically from official upstream DuckDB releases, the packaging is open source at dariogriffo/duckdb-debian, and the whole archive is GPG-signed. Several upstream projects link to it from their official installation docs.
