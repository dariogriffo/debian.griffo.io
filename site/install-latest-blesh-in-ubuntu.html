What is ble.sh?

ble.sh, the Bash Line Editor, is a command line editor written in pure Bash that replaces GNU Readline in interactive Bash sessions. You keep Bash, your ~/.bashrc, your aliases and your scripts, and gain what usually means switching shells: syntax highlighting as you type, fish-like auto-suggestions from history, a full vim mode alongside emacs bindings, completion with menus and descriptions, abbreviations, and integration with bash-completion and fzf. It is written by Koichi Murase and released under the BSD-3-Clause licence. There is no binary to run: the package installs the script to /usr/share/blesh/ble.sh, and two lines in your ~/.bashrc turn it on.

🚀 Why Latest Versions Matter: ble.sh is developed continuously on its master branch, and tagged stable releases are rare and far apart, so upstream's own install instructions point to the nightly build or a git checkout. Debian and Ubuntu package a snapshot that stays frozen for the life of the release (Debian stable does not ship it at all). This repository follows the upstream nightly snapshots, so fixes for new Bash versions, terminals and completion integrations reach you through apt upgrade.

⚡ Key Features of ble.sh

🎨 Syntax Highlighting

Commands, keywords, strings, variables, redirections and file names are colored as you type, and an unknown command or a syntax error shows up before you press Enter.

💡 Auto-Suggestions

Fish-style suggestions from history and completion appear in gray after the cursor. Accept the whole suggestion with the right arrow or C-f, or one word at a time with M-f.

⌨️ Vim and Emacs Modes

Emacs bindings by default, and a full vi/vim mode with set -o vi: normal, insert and visual modes, text objects, registers and an optional vim-airline-style status line.

📋 Menu Completion

Tab opens a menu of candidates you move through with the arrow keys, with descriptions where available and ambiguous (fuzzy) matching.

✂️ Abbreviations

ble-sabbrev defines abbreviations that expand as you type, like fish abbreviations or zsh global aliases, so L becomes | less.

🐚 Pure Bash, No Binary

Nothing to compile and nothing architecture-specific: ble.sh is a Bash script that runs wherever Bash 3.0 or newer does, and it stays out of non-interactive shells and scripts.

🚀 Always ahead of the official archives: Debian and Ubuntu freeze package versions when a release ships. This repository publishes new upstream releases typically within hours. A simple apt upgrade keeps you on the latest version.

# ble.sh has no command to run: Bash loads it from ~/.bashrc.
# Put this line near the TOP of ~/.bashrc:

# ...the rest of your ~/.bashrc stays as it is...

# And this line at the very END of ~/.bashrc:
[[ ${BLE_VERSION-} ]] && ble-attach

# Open a new terminal, then:
# Verify installation
echo $BLE_VERSION

🎯 Basic Usage Examples

Everyday use:

# Check that ble.sh is active in this shell
echo $BLE_VERSION

# Reload ble.sh after changing its settings
ble-reload

# Updates come through apt; ble-update points you there
sudo apt update && sudo apt upgrade

# Reload ble.sh after changing its settings
ble-reload

# Updates come through apt; ble-update points you there
apt update && apt upgrade

Settings in ~/.blerc:

# ble.sh reads its settings from ~/.blerc (or ~/.config/blesh/init.sh)
# Vim key bindings instead of emacs
set -o vi

# Wait 300 ms before showing an auto-suggestion
bleopt complete_auto_delay=300

# Turn auto-suggestions off entirely
bleopt complete_auto_complete=

# Change the color of the suggested text
ble-face auto_complete='fg=242'

Abbreviations, key bindings and integrations:

# Expand "L" into "| less" as you type
ble-sabbrev L='| less'

# Make Ctrl+C discard the current line
ble-bind -f 'C-c' discard-line

# fzf completion and key bindings, adapted to ble.sh
ble-import -d integration/fzf-completion
ble-import -d integration/fzf-key-bindings

# vim-airline-style status line (needs ble.sh-airline-themes)
ble-import vim-airline
bleopt vim_airline_theme=dark

🔧 Tool Integrations

ble.sh sits underneath your existing Bash setup instead of replacing it:

  • bash-completion: completions from the bash-completion package are picked up automatically and shown in the menu
  • fzf: ble-import loads versions of fzf's completion and key bindings adapted to ble.sh
  • Atuin: Atuin's Bash integration supports ble.sh, which gives it reliable preexec hooks for recording history
  • Starship / Oh My Posh: the prompts they generate keep working unchanged
  • Config file: ~/.blerc holds your bleopt, ble-face and ble-bind settings, separate from ~/.bashrc

❓ Frequently asked questions

Is ble.sh in the official Ubuntu repositories?

Yes, but the official Ubuntu archive ships ble.sh 0.4.0, while this repository serves ble.sh 0.4.0, rebuilt within hours of each upstream release.

How do I install the latest ble.sh on Ubuntu?

Add the deb.griffo.io repository once using the instructions above, then run: sudo apt install ble.sh. New releases arrive through the normal sudo apt upgrade.

Are the packages signed and how are they built?

Every package is signed with the repository's GPG key (EA0F721D231FDD3A0A17B9AC7808B4DD62C41256) and built from upstream releases in public GitHub packaging repositories that anyone can inspect.
