🎵 Terminal Media Tools

for Debian & Ubuntu, always the latest versions via apt

Music, images and media from the comfort of the terminal. Every tool below installs with one apt command from deb.griffo.io, is GPG-signed, and is rebuilt within hours of each upstream release, no snap, no manual builds, no stale versions.

🆓 There is an always-free mirror. deb-free.griffo.io serves packages free forever, no account, no subscription, at most 2 months behind upstream, security fixes immediately. It currently carries cliamp, Ghostty, lazydocker, Oh My Posh and Zed; any other tool can be enrolled on request.
